# ✅ 정답과 설명 (초등학교 5학년 눈높이)

## 네이버 로그인 공격
**조건문** 정답: ① `>=` ② `>=`
- 순서대로 검사하는 "문 지키기"예요. 먼저 "5번 이상?"을 물어보고 아니면 "3번 이상?"을 물어봐요. 5번 넘게 틀린 사람이 두 번째 질문까지 가지 않도록, **무서운 것(LOCK)부터** 먼저 물어야 해요. 그래서 `else if`를 써요.

**반복문** 정답: ① `10` ② `0`
- 반 친구 10명 출석부를 처음부터 끝까지 한 명씩 보며 "결석(0)이면 +1" 하는 것과 같아요. `i`는 번호표, 10번 전까지(`i < 10`)만 봐요. 배열 번호는 0부터 9까지라서 10을 넣으면 없는 칸을 보게 돼요!

**흐름제어** 정답: A=`continue`, B=`break`
- `continue`는 "이 친구는 패스, 다음 친구!" 라는 뜻이에요. 성공 로그는 세지 않고 넘어가죠. `break`는 "그만! 반복 끝!" 이에요. 이미 5번 틀렸으면 나머지를 볼 필요가 없어요. 시간도 아끼고요.

## 삼성 냉장고
**조건문** 정답: `if (t > 5) COOL; else if (t < 0) FREEZE; else GOOD;`
- 0도와 5도는 `>`와 `<`에 안 걸려서 "GOOD"이에요. `>=`와 `>`의 작은 차이가 큰 오류를 만들어요. 경계값은 꼭 손가락으로 짚어 확인해요!

**반복문** 정답: ① `temp[i]` ② `(double)sum / 24`
- 저금통에 24번 동전을 넣고(sum), 마지막에 24로 나누면 평균이에요. 그런데 `int`끼리 나누면 소수점이 잘려요(7/2=3). 먼저 `double`로 바꿔 나누어야 3.5가 나와요.

**흐름제어** 정답 예시:
```c
int streak = 0;
for (int i = 0; i < 24; i++) {
    if (temp[i] == -999) continue;
    if (temp[i] > 10) streak++;
    else streak = 0;
    if (streak == 3) { printf("ALARM"); break; }
}
```
- 고장 난 숫자(-999)는 "무시" = `continue`. "연속"이라는 건 중간에 끊기면 처음부터 다시 세는 거예요. 그래서 **10도 이하가 나오는 순간 `streak = 0`**! 연속 3번이 되면 `break`로 경보를 울리고 끝내요.
