# 2026-10-10 C언어 현업 퀴즈 (난이도: 중간)

## 문제 A. [삼성 반도체 공장 엔지니어가 직면한 문제]
공장 온도센서가 하루 24시간 동안 1시간마다 온도를 기록했다. `int temps[24];`에 저장돼 있다고 가정한다.

- **조건문 퀴즈**: 온도 `int t`가 80 이상이면 "경고", 60 이상 80 미만이면 "주의", 그 외에는 "정상"을 출력하는 if / else if / else 코드를 작성하세요.
- **반복문 퀴즈**: for문으로 `temps[24]`의 24개 온도 평균을 구해 출력하세요. (힌트: 합계 `sum`을 먼저 0으로!)
- **흐름제어 퀴즈**: 0시부터 차례로 확인하다가 처음으로 80 이상인 온도를 발견하면 "N시 위험!"을 출력하고 반복을 바로 끝내세요(break). 단, 0 이하 값은 센서 고장이므로 건너뛰세요(continue).

## 문제 B. [스페이스X 엔지니어가 만들어야 할 프로그램] 로켓 발사 카운트다운
- **조건문 퀴즈**: 연료 `fuel`(%)이 20 미만이면 "발사 불가", 아니면 "발사 가능"을 출력하세요.
- **반복문 퀴즈**: 10부터 1까지 거꾸로 숫자를 출력하고, 끝나면 "발사!"를 출력하세요.
- **흐름제어 퀴즈**: 카운트다운 10→1 동안 매초 연료가 2%씩 줄어든다(처음 `fuel=30`). 연료가 20 미만이 되는 순간 "중단!"을 출력하고 break로 멈추세요. 끝까지 오면 "발사!"를 출력하세요. (힌트: 중단 여부를 기억할 변수 필요)

# 정답과 쉬운 설명

## 문제 A
### 조건문
```c
if (t >= 80)      printf("경고\n");
else if (t >= 60) printf("주의\n");
else              printf("정상\n");
```
급식 줄처럼 위에서부터 차례로 확인해요. 하나라도 "맞아!"가 나오면 나머지는 보지 않아요. 가장 심각한 것(80)을 맨 앞에 둬야 해요. 60을 먼저 물으면 90도도 "주의"가 돼 버려요.

### 반복문
```c
int sum = 0;
for (int i = 0; i < 24; i++) {
    sum += temps[i];
}
printf("평균: %.1f\n", sum / 24.0);
```
저금통에 24번 동전을 넣어 총합을 구하는 것과 같아요. 처음에 저금통을 비워 둬야 하니 `sum = 0`이에요. 배열 번호는 0~23이라 `i < 24`예요. `24.0`으로 나누는 이유는 `24`로 나누면 소수점이 잘려서예요.

### 흐름제어
```c
for (int i = 0; i < 24; i++) {
    if (temps[i] <= 0) continue;
    if (temps[i] >= 80) {
        printf("%d시 위험!\n", i);
        break;
    }
}
```
`continue`는 "이 칸은 건너뛰고 다음 칸으로", `break`는 "찾았으니 그만 찾자"예요. 고장 난 센서는 읽을 필요가 없으니 건너뛰고, 위험한 온도를 찾으면 바로 알리고 멈춰요.

## 문제 B
### 조건문
```c
if (fuel < 20) printf("발사 불가\n");
else           printf("발사 가능\n");
```
자동차에 기름이 부족하면 출발하지 않는 것과 같아요. 둘 중 하나만 고르니 `if-else`를 써요.

### 반복문
```c
for (int i = 10; i >= 1; i--) {
    printf("%d\n", i);
}
printf("발사!\n");
```
10에서 시작해 1씩 줄여요(`i--`). 1까지 말해야 하니 `i >= 1`이에요. "발사!"는 반복문 밖에 둬요. 안에 두면 10번 외치게 돼요.

### 흐름제어
```c
int fuel = 30;
int aborted = 0;
for (int i = 10; i >= 1; i--) {
    printf("%d\n", i);
    fuel -= 2;
    if (fuel < 20) {
        printf("중단!\n");
        aborted = 1;
        break;
    }
}
if (!aborted) printf("발사!\n");
```
`aborted`는 "중간에 멈췄는지" 적어 두는 쪽지예요. 쪽지가 `0`이면 끝까지 왔다는 뜻이라 "발사!"를 외쳐요. 계산하면 5초째에 연료가 20이 되고, 6초째에 18이 되면서 "중단!"이 나와요. 반복문(세기), 조건문(검사), `break`(멈추기)를 합친 것이 흐름제어예요.
