### 흐름제어 퀴즈1

# ✅ 정답과 해설 (초등학교 5학년 버전)

## 📌 문제 1: 대한항공 수하물

### 조건문 정답
```c
if (w >= 32) {
    printf("접수 불가\n");
} else if (w > 23) {
    printf("초과 요금\n");
} else {
    printf("정상\n");
}
```
**왜?** 놀이기구 몸무게 제한과 같아요. 가장 무거운 경우(32 이상)부터 먼저 물어봐야 해요. "23 초과?"를 먼저 물으면 40kg 가방도 "초과 요금"만 내고 통과해 버려요. 앞 질문이 "아니오"일 때만 다음 `else if`로 내려가요. 또 "23 초과"라서 정확히 23kg은 정상이에요(`>`와 `>=`를 잘 구분해요!).

### 반복문 정답
```c
int count = 0;
for (int i = 0; i < 6; i++) {
    if (weight[i] > 23) {
        count++;
    }
}
printf("%d\n", count);
```
**왜?** 가방을 하나씩 저울에 올리며 "무거운 가방"만 막대기로 표시하는 것과 같아요. 처음엔 0개에서 시작하고, 조건에 맞을 때만 하나 올려요. 칸이 6개(번호 0~5)라서 `i < 6`이에요. 25, 31이 해당되어 결과는 **2**예요. (23은 "초과"가 아니라서 세지 않아요.)

### 흐름제어 정답
```c
int total = 0;
for (int i = 0; i < 6; i++) {
    if (weight[i] == 0) {
        continue;
    }
    total += weight[i];
    if (total > 80) {
        printf("적재 한도 초과, 번호: %d\n", i);
        break;
    }
}
```
**출력:** `적재 한도 초과, 번호: 4`

**왜?** 빈 칸(0)은 "가방이 없네!" 하고 `continue`로 휙 넘어가요. 나머지는 장바구니에 담듯 `total`에 더해요. 18 → 43 → 66까지는 괜찮지만, 번호 4의 31kg을 더하면 97이 되어 80을 넘어요. 그 순간 `break`로 멈춰요. 더하고 나서 검사하는 순서가 중요해요!

## 📌 프로그램 1: 삼성 스마트 TV 자동 밝기

### 조건문 정답
```c
if (l >= 60) {
    printf("화면 밝게\n");
} else if (l >= 30) {
    printf("화면 보통\n");
} else {
    printf("화면 어둡게\n");
}
```
**왜?** 방이 아주 밝은 경우(60 이상)부터 먼저 물어봐요. 순서를 바꿔 "30 이상?"을 먼저 물으면 80처럼 아주 밝은 방도 "보통"이 되어 버려요. 위에서부터 차례로 물어보고, 처음 "예"가 나온 곳에서 끝나요.

### 반복문 정답
```c
int count = 0;
for (int i = 0; i < 5; i++) {
    if (light[i] < 30) {
        count++;
    }
}
printf("%d\n", count);
```
**왜?** 하루 다섯 번 방을 둘러보며 "어두웠던 횟수"에 막대기를 긋는 것과 같아요. 5와 15가 30 미만이라 결과는 **2**예요. (35는 30보다 크니까 세지 않아요.)

### 흐름제어 정답
```c
for (int i = 0; i < 5; i++) {
    if (light[i] >= 30) {
        continue;
    }
    if (light[i] < 10) {
        printf("취침 모드, 번호: %d\n", i);
        break;
    }
}
```
**출력:** `취침 모드, 번호: 2`

**왜?** 80, 35처럼 밝은 값은 `continue`로 넘어가요. 번호 2의 값 5는 30 미만이라 검사를 받고, 10 미만이니 "취침 모드"를 알린 뒤 `break`로 멈춰요. "처음 발견한 것"만 알려 주기 때문에 뒤의 50, 15는 보지 않아요.
