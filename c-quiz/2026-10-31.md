**[Google Gmail 팀]** 메일에 붙인 파일 5개의 크기(MB)가 배열에 들어 있어요. `0`은 업로드에 실패한 파일이에요. 메일 하나에 붙일 수 있는 전체 용량은 25MB예요.

```c
int sizes[5] = {5, 0, 17, 9, 8};
```

- **흐름제어 퀴즈 1:** 위 반복문에서 0인 파일은 건너뛰고(더하지 않기), `total`이 25를 넘으면 "용량 초과!"를 출력하고 반복을 멈추는 코드를 작성하세요.

# 정답 및 해설 (초등학교 5학년 눈높이)

## 문제 1: Gmail 첨부파일 점검

### 조건문 정답
```c
if (size >= 25) {
    printf("첨부 불가\n");
} else if (size >= 10) {
    printf("드라이브 링크로 변경\n");
} else {
    printf("일반 첨부\n");
}
```
**왜 이렇게?** 택배 상자 크기 검사와 같아요. 제일 큰 상자부터 물어봐요. "25 이상? 너무 커서 못 보내요!" 아니면 "10 이상? 큰 편이니까 링크로 보내요." 둘 다 아니면 "그냥 보내요!"
작은 기준(10)부터 물으면 30MB짜리도 "10 이상이네?" 하고 링크로 변경이 돼 버려요. 큰 것부터 물어야 정확해요.

### 반복문 정답
```c
int total = 0;
for (int i = 0; i < 5; i++) {
    total += sizes[i];
}
```
**왜 이렇게?** 빈 가방에 책 5권을 하나씩 넣고 무게를 재는 것과 같아요. `total`은 빈 가방이라서 0으로 시작해야 해요. `i`는 번호표인데 컴퓨터는 0번부터 세니까 0, 1, 2, 3, 4번 총 5번 돌아요. 그래서 `i < 5`예요.

### 흐름제어 정답
```c
int total = 0;
for (int i = 0; i < 5; i++) {
    if (sizes[i] == 0) {
        continue;
    }
    total += sizes[i];
    if (total > 25) {
        printf("용량 초과!\n");
        break;
    }
}
```
**왜 이렇게?**
- `continue`는 "이 친구는 패스! 다음으로 가자"예요. 업로드에 실패한 파일(0)은 가방에 안 넣고 넘어가요.
- `break`는 "그만! 오늘은 여기까지!"예요. 가방이 25를 넘으면 더 넣어 봐야 소용없으니 반복 전체를 끝내요.
- 예시 값으로 따라가면: 5 → 합계 5, 0 → 패스, 17 → 합계 22, 9 → 합계 31이라 "용량 초과!" 출력 후 멈춰요(마지막 8은 보지 않아요).
- 순서도 중요해요. 먼저 더하고 나서 넘었는지 확인해야 방금 넣은 파일 때문에 넘었는지 알 수 있어요.

## 프로그램 1: CU 무인 계산대

### 조건문 정답
```c
if (paid >= price) {
    printf("결제 완료\n");
} else {
    printf("금액 부족\n");
}
```
**왜 이렇게?** 내 용돈이 과자 값보다 많거나 같으면 살 수 있고, 모자라면 못 사요. `>=`에서 `=`가 들어가야 "딱 맞게 낸 경우"도 살 수 있어요. `>`만 쓰면 1000원짜리 과자를 1000원으로 못 사는 이상한 가게가 돼요!

### 반복문 정답
```c
int count = 0;
while (change >= 500) {
    count++;
    change -= 500;
}
```
**왜 이렇게?** "몇 번 할지 모르지만, 조건이 맞는 동안은 계속!"일 때는 `while`이 좋아요. 거스름돈이 3700원이면 500원을 한 개 주고 3200원, 또 주고 2700원... 이렇게 500원 미만이 될 때까지 계속 줘요. 동전을 줄 때마다 `change`를 줄여야 해요. 안 줄이면 영원히 안 끝나요(무한 반복)!

### 흐름제어 정답
```c
int count = 0;
while (change >= 500) {
    if (count == stock) {
        printf("동전 부족! 직원 호출\n");
        break;
    }
    count++;
    change -= 500;
}
```
**왜 이렇게?** 주머니에 동전이 5개뿐인데 6번째를 꺼내려는 상황을 막아야 해요. 그래서 동전을 주기 전에 먼저 "이미 다 줬나?"(`count == stock`)를 확인해요. 다 줬으면 직원 아저씨를 부르고 `break`로 반복을 끝내요.
예시로 `change`가 3700이면 동전이 7개 필요한데 5개뿐이라서, 5개를 주고 나면(남은 거스름돈 1200원) 직원 호출이 나와요. 확인을 동전을 주기 전에 해야 6번째 동전을 잘못 주지 않아요.
