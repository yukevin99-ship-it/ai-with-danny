## 📌 엔지니어가 직면한 가상의 문제 1
**[현대자동차 공장]** 로봇팔이 부품의 길이(mm)를 재서 규격(98~102mm)에 맞는지 검사해요. 불량이 나오면 생산 라인을 멈춰야 해요. 0은 측정 실패예요.
(`int len[6] = {100, 0, 101, 105, 99, 97};`)

### 조건문 퀴즈1
정수 `x`(부품 길이)가 98 이상 102 이하이면 "합격", 아니면 "불량"을 출력하는 코드를 작성하세요.

### 반복문 퀴즈1
`len` 배열 6개의 길이 합계를 for문으로 구해 출력하세요.

### 흐름제어 퀴즈1
부품 번호는 1번부터입니다. 값이 0이면 건너뛰고(`continue`), 합격이면 "N번 부품 OK", 불량이면 "N번 부품 불량! 라인 정지"를 출력한 뒤 반복을 끝내세요(`break`).

## 📌 엔지니어가 창작해야 하는 가상의 프로그램 1
**[카카오톡]** 채팅방 5개의 '안 읽은 메시지 배지'를 만들어요.
(`int unread[5] = {3, 0, 120, 45, 0};`)

### 조건문 퀴즈1
정수 `n`(안 읽은 개수)이 0이면 "배지 없음", 99 초과면 "99+", 그 밖에는 숫자 그대로 출력하는 코드를 작성하세요.

### 반복문 퀴즈1
`unread` 배열의 안 읽은 메시지 총합을 while문(또는 for문)으로 구해 출력하세요.

### 흐름제어 퀴즈1
방 번호는 1번부터입니다. 0개인 방은 건너뛰고(`continue`), 나머지는 "N번 방: n개"를 출력하면서 총합에 더하세요. 총합이 100을 넘으면 "알림 폭탄!"을 출력하고 반복을 끝내세요(`break`).

# ✅ 정답 및 해설

## 📌 문제 1: 현대자동차 공장

### 조건문
```c
if (x >= 98 && x <= 102) {
    printf("합격\n");
} else {
    printf("불량\n");
}
```
**쉬운 설명:** 문 두 개를 모두 통과해야 들어갈 수 있는 놀이공원 같아요. "98보다 작지 않고" **그리고** "102보다 크지 않아야" 합격이에요. 두 조건을 `&&`(그리고)로 묶어요. 하나라도 틀리면 else(그 외)로 가서 불량이 돼요.

### 반복문
```c
int len[6] = {100, 0, 101, 105, 99, 97};
int sum = 0;
for (int i = 0; i < 6; i++) {
    sum += len[i];
}
printf("%d\n", sum);   // 502
```
**쉬운 설명:** 저금통에 동전을 하나씩 넣어서 총액을 세는 것과 같아요. `sum`은 빈 저금통(0)에서 시작하고, 반복할 때마다 상자 하나씩 꺼내 더해요. 배열 칸은 0~5번이라서 `i < 6`일 때까지만 해요.

### 흐름제어
```c
for (int i = 0; i < 6; i++) {
    if (len[i] == 0) continue;
    if (len[i] >= 98 && len[i] <= 102) {
        printf("%d번 부품 OK\n", i + 1);
    } else {
        printf("%d번 부품 불량! 라인 정지\n", i + 1);
        break;
    }
}
```
출력:
```
1번 부품 OK
3번 부품 OK
4번 부품 불량! 라인 정지
```
**쉬운 설명:** 고장 난 센서(0)는 "패스!" 하고 다음 친구로 넘어가요(`continue`). 불량을 발견하면 빨간 버튼을 눌러 전체를 멈춰요(`break`). 컴퓨터는 0번부터 세지만 사람은 1번부터 세니까 `i + 1`을 출력해요.

## 📌 프로그램 1: 카카오톡 배지

### 조건문
```c
if (n == 0) {
    printf("배지 없음\n");
} else if (n > 99) {
    printf("99+\n");
} else {
    printf("%d\n", n);
}
```
**쉬운 설명:** 먼저 "0개야?"를 묻고, 아니면 "99개보다 많아?"를 물어요. 위에서부터 차례로 묻다가 맞는 것을 만나면 거기서 끝나요. 숫자가 너무 크면 칸이 좁아서 "99+"로 줄여 보여 주는 거예요.

### 반복문
```c
int total = 0, i = 0;
while (i < 5) {
    total += unread[i];
    i++;
}
printf("%d\n", total);   // 168
```
**쉬운 설명:** "5칸을 다 볼 때까지 계속해!"라는 뜻이에요. `i++`를 빼먹으면 같은 칸만 계속 봐서 영원히 끝나지 않아요(무한 반복). 그래서 한 번 돌 때마다 꼭 한 칸씩 앞으로 가야 해요.

### 흐름제어
```c
int total = 0;
for (int i = 0; i < 5; i++) {
    if (unread[i] == 0) continue;
    printf("%d번 방: %d개\n", i + 1, unread[i]);
    total += unread[i];
    if (total > 100) {
        printf("알림 폭탄!\n");
        break;
    }
}
```
출력:
```
1번 방: 3개
3번 방: 120개
알림 폭탄!
```
**쉬운 설명:** 0개인 방(2번)은 볼 게 없으니 건너뛰어요. 방마다 더하고 나서 "100 넘었나?" 확인해요. 3번 방에서 3+120=123이 되어 100을 넘으니 바로 멈춰요(`break`). 그래서 4번, 5번 방은 보지 않아요. 더하기를 **먼저** 하고 검사를 **나중에** 해야 순서가 맞아요.
