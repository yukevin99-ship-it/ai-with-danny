## 엔지니어가 직면한 가상의 문제 1

**[Netflix 스트리밍 품질팀]** 영상 하나를 5개 구간(chunk)으로 나눠 보냈어요. 각 구간은 번호(`id`), 버퍼링 시간(`buffer_ms`, 밀리초), 재시도 횟수(`retries`), 캐시 여부(`cached`, 1이면 캐시)를 가져요. 규칙: 캐시된 구간은 버퍼링이 아무리 길어도 "캐시"예요. 그 밖에는 버퍼링이 500 **이상**이면 "느림", 200 이상 500 미만이면 "주의", 그보다 작으면 "정상"이에요.

```c
int buffer[5] = {120, 250, 800, 90, 520};
// 구간 5개: {id, buffer_ms, retries, cached}
// {1,120,0,0} {2,250,1,0} {3,800,3,1} {4,90,0,0} {5,520,2,0}
```

- **조건문 퀴즈 1:** 구간 하나의 `cached`, `buffer_ms`를 보고 "캐시", "느림", "주의", "정상" 중 하나를 출력하는 코드를 작성하세요. (캐시 검사를 먼저!)
- **반복문 퀴즈 1:** 구조체 배열 `chunks[5]`를 처음부터 끝까지 돌면서 `"1번 구간: 지연 120"` 모양으로 출력하는 코드를 작성하세요. (번호는 1부터)
- **흐름제어 퀴즈 1:** 위 반복문에서 캐시된 구간(`cached == 1`)은 건너뛰고, 버퍼링이 500 이상인 구간을 처음 발견하면 "느린 구간: (id)"를 출력하고 반복을 멈추는 코드를 작성하세요.
- **배열 퀴즈 1:** `buffer` 배열에서 500 **이상**인 값이 몇 개인지 세어 `cnt`에 저장하고 출력하세요.
- **포인터 변수 퀴즈 1:** 포인터 `p`가 `buffer` 배열의 처음부터 끝까지 한 칸씩 이동하며(`p++`), 가리키는 값이 600보다 **큰 칸만** 600으로 줄이는 코드를 작성하세요. (`buffer[i]`가 아니라 `*p`를 사용)
- **구조체 퀴즈 1:** 번호(`id`), 버퍼링 시간(`buffer_ms`), 재시도 횟수(`retries`), 캐시 여부(`cached`)를 가진 구조체 `struct Chunk`를 정의하세요.
- **함수 퀴즈 1:** 구간 배열의 시작 주소 `c`와 개수 `n`을 받아서, 캐시되지 않았고 버퍼링이 500 이상인 구간의 수를 반환하는 함수 `count_slow`를 작성하세요.
- **흐름제어 퀴즈 2 (종합):** `main`에서 구간 5개짜리 구조체 배열과 `count_slow`를 사용해, 개수가 0이면 "느린 구간 없음", 아니면 "느린 구간: N개"를 출력하는 코드를 작성하세요.

**[배달의민족 배차팀]** 라이더 5명 중 주문을 맡길 한 명을 골라 주는 프로그램을 만들어요. 배차 조건은 가게까지 거리(`dist`)가 3km **이하**이고 별점(`rating`)이 4 **이상**이에요. 이미 배달 중인 라이더(`busy == 1`)는 검사하지 않아요.

int dists[5]   = {5, 2, 1, 3, 4};

- **포인터 변수 퀴즈 1:** 포인터 `p`가 `ratings` 배열의 처음부터 끝까지 한 칸씩 이동하며(`p++`), 값이 4 **미만인 칸만** 4로 올리는(최소 별점 보정) 코드를 작성하세요. (`*p` 사용, 4 이상인 칸은 그대로)
- **구조체 퀴즈 1:** 이름(`char name[20]`), 거리(`int dist`), 별점(`int rating`), 배달 중 여부(`int busy`)를 가진 구조체 `struct Rider`를 정의하고, 변수 `one`을 `"Han"`, `2`, `5`, `0`으로 만들어 이름과 "배차 가능" 또는 "배차 불가"를 출력하는 코드를 작성하세요.
- **함수 퀴즈 1:** 라이더 배열 시작 주소 `r`, 개수 `n`을 받아, 배달 중이 아니고 배차 가능한 라이더 중 거리가 가장 가까운 사람의 **인덱스(번호표)** 를 반환하는 함수 `find_nearest`를 작성하세요. 대상이 없으면 `-1`을 반환하세요.
- **흐름제어 퀴즈 2 (종합):** `main`에서 `find_nearest`를 호출해 `-1`이면 "배차 가능한 라이더 없음", 아니면 "배차: 이름 (거리 Nkm)"을 출력하는 코드를 작성하세요.

# 정답 및 해설 (초등학교 5학년 눈높이)

## 문제 1: Netflix 스트리밍 구간 품질 점검

### 조건문 정답
```c
if (cached == 1) {
    printf("캐시\n");
} else if (buffer_ms >= 500) {
    printf("느림\n");
} else if (buffer_ms >= 200) {
    printf("주의\n");
} else {
    printf("정상\n");
}
```
**왜 이렇게?** 도서관에서 "이 책은 이미 내 책가방에 있어!" 하면 얼마나 멀리 있는 책이든 상관없죠? 캐시는 이미 가까이 있다는 뜻이라 **맨 먼저** 물어봐요. 그다음엔 **큰 기준부터** 물어봐요. 200 이상을 먼저 물으면 800도 "주의"에서 걸려 버려요. 딱 500도 느린 걸로 보니까 `>=`예요.

### 반복문 정답
```c
for (int i = 0; i < 5; i++) {
    printf("%d번 구간: 지연 %d\n", i + 1, chunks[i].buffer_ms);
}
```
**왜 이렇게?** 구간이 5개로 정해져 있으니 `for`가 딱이에요. 컴퓨터는 0부터 세지만 사람은 1번부터 부르니까 보여줄 때만 `i + 1`을 써요. `i < 5`라야 0~4, 딱 5칸만 열어요.

### 흐름제어 정답 (1)
```c
for (int i = 0; i < 5; i++) {
    if (chunks[i].cached == 1) {
        continue;
    }
    if (chunks[i].buffer_ms >= 500) {
        printf("느린 구간: %d\n", chunks[i].id);
        break;
    }
}
```
**왜 이렇게?** `continue`는 "이건 캐시니까 패스, 다음!", `break`는 "찾았다! 이제 그만 찾아도 돼!"예요. 3번 구간은 800으로 느리지만 캐시라서 건너뛰고, 5번(520)이 처음으로 걸려요. 출력은 `느린 구간: 5`예요.

### 배열 정답
```c
int cnt = 0;
for (int i = 0; i < 5; i++) {
    if (buffer[i] >= 500) {
        cnt++;
    }
}
printf("%d\n", cnt);   // 2
```
**왜 이렇게?** 조건에 맞는 칸을 만날 때마다 막대기를 하나씩 긋는(`cnt++`) 거예요. 800과 520, 두 칸이 500 이상이라 답은 2예요. 이 문제는 캐시 여부를 묻지 않았으니 3번(800)도 센다는 게 포인트예요!

### 포인터 정답
```c
int *p = buffer;
for (int i = 0; i < 5; i++) {
    if (*p > 600) {
        *p = 600;
    }
    p++;
}
// buffer는 {120, 250, 600, 90, 520}이 돼요
```
**왜 이렇게?** 배열 이름 `buffer`는 "첫 칸의 주소"예요. `p`는 손가락, `*p`는 손가락이 가리키는 칸 안의 값이에요. 600보다 큰 칸(800)만 600으로 줄이고, 손가락은 `p++`로 한 칸씩 옮겨요. `p++`는 `if` 바깥에 둬야 해요. 안에 두면 작은 값 칸에서 손가락이 못 움직여서 같은 칸만 계속 보게 돼요.

### 구조체 정답
```c
struct Chunk {
    int id;
    int buffer_ms;
    int retries;
    int cached;
};
```
**왜 이렇게?** 구간 하나에는 번호, 버퍼링 시간, 재시도 횟수, 캐시 여부가 항상 같이 다녀요. 배열 4개로 따로 두면 짝이 어긋나기 쉬우니 하나의 "구간 카드"로 묶어요.

### 함수 정답
```c
int count_slow(struct Chunk *c, int n) {
    int cnt = 0;
    for (int i = 0; i < n; i++) {
        if (c[i].cached == 1) {
            continue;
        }
        if (c[i].buffer_ms >= 500) {
            cnt++;
        }
    }
    return cnt;
}
```
**왜 이렇게?** `return cnt;`는 반드시 **반복문이 끝난 뒤**에 둬요. 안에 두면 첫 구간만 보고 돌아가 버려요. 배열은 통째로 복사하지 않고 시작 주소(`c`)와 개수(`n`)만 받는 게 C언어의 약속이에요.

### 흐름제어 정답 (종합)
```c
struct Chunk chunks[5] = {
    {1, 120, 0, 0}, {2, 250, 1, 0}, {3, 800, 3, 1},
    {4, 90, 0, 0}, {5, 520, 2, 0}
};
int n = count_slow(chunks, 5);
if (n == 0) {
    printf("느린 구간 없음\n");
} else {
    printf("느린 구간: %d개\n", n);
}
```
**왜 이렇게?** 캐시인 3번은 빠지고 520인 5번만 느린 구간이에요. 출력은 `느린 구간: 1개`예요. (배열 퀴즈의 2와 다른 이유: 거기서는 캐시도 셌고, 여기서는 빼기 때문이에요.) 결과를 변수 `n`에 한 번 받아 두면 `if`에서 여러 번 쓸 수 있어요.

## 프로그램 1: 배달의민족 라이더 배차

### 조건문 정답
```c
if (dist <= 3 && rating >= 4) {
    printf("배차 가능\n");
} else {
    printf("배차 불가\n");
}
```
**왜 이렇게?** 두 조건을 **둘 다** 만족해야 하니까 "그리고"를 뜻하는 `&&`로 이어요. 가까워도 별점이 낮으면 안 되고, 별점이 높아도 멀면 안 돼요. 딱 3km, 딱 별점 4도 통과니까 `<=`, `>=`예요.

### 반복문 정답
```c
for (int i = 0; i < 5; i++) {
    printf("%d번 라이더: %s (거리 %d)\n", i + 1, riders[i].name, riders[i].dist);
}
```
**왜 이렇게?** 글자(이름)는 `%s`, 숫자는 `%d`로 출력해요. 번호는 사람 눈높이에 맞춰 `i + 1`!

### 흐름제어 정답 (1)
```c
for (int i = 0; i < 5; i++) {
    if (riders[i].busy == 1) {
        continue;
    }
    if (riders[i].dist <= 3 && riders[i].rating >= 4) {
        printf("첫 배차: %s\n", riders[i].name);
        break;
    }
}
```
**왜 이렇게?** 배달 중인 라이더는 `continue`로 넘어가요. Kim은 거리 5라 탈락, Lee는 별점 3이라 탈락, Park은 조건은 맞지만 배달 중이라 건너뛰어요. Choi(거리 3, 별점 5)가 처음으로 통과! 출력은 `첫 배차: Choi`이고 `break`로 멈춰요.

### 배열 정답
```c
int ok = 0;
for (int i = 0; i < 5; i++) {
    if (busy[i] == 1) {
        continue;
    }
    if (dists[i] <= 3 && ratings[i] >= 4) {
        ok++;
    }
}
printf("%d\n", ok);   // 1
```
**왜 이렇게?** 세 배열의 같은 번호 칸은 같은 라이더의 정보예요. 조건에 맞는 사람은 Park(거리 1, 별점 4)과 Choi인데, Park은 배달 중이라 처음부터 빠져요. 그래서 답은 1이에요.

### 포인터 정답
```c
int *p = ratings;
for (int i = 0; i < 5; i++) {
    if (*p < 4) {
        *p = 4;
    }
    p++;
}
// ratings는 {5, 4, 4, 5, 4}가 돼요
```
**왜 이렇게?** 4보다 작은 칸(Lee의 3)만 4로 올려요. 이미 4인 칸은 `<`라서 그대로예요. 손가락 `p`는 매 칸마다 `p++`로 한 칸씩 옮겨요.

### 구조체 정답
```c
struct Rider {
    char name[20];
    int dist;
    int rating;
    int busy;
};

struct Rider one = {"Han", 2, 5, 0};
if (one.dist <= 3 && one.rating >= 4) {
    printf("%s: 배차 가능\n", one.name);
} else {
    printf("%s: 배차 불가\n", one.name);
}
```
**왜 이렇게?** 이름은 글자 칸(`char name[20]`), 나머지는 숫자 칸이에요. 값은 선언한 순서대로 채워져요. 거리 2, 별점 5라서 `Han: 배차 가능`이 출력돼요. 구조체 안의 값은 점(`.`)으로 꺼내요.

### 함수 정답
```c
int find_nearest(struct Rider *r, int n) {
    int best = -1;
    for (int i = 0; i < n; i++) {
        if (r[i].busy == 1) {
            continue;
        }
        if (r[i].dist <= 3 && r[i].rating >= 4) {
            if (best == -1 || r[i].dist < r[best].dist) {
                best = i;
            }
        }
    }
    return best;
}
```
**왜 이렇게?** `best`는 "지금까지 1등 후보의 번호표"인데, 처음엔 아무도 없으니 `-1`로 시작해요. 새 후보가 더 가까우면 번호표를 바꿔 들어요. 거리가 같으면 `<`라서 먼저 찾은 사람이 유지돼요. `-1`을 먼저 확인(`best == -1 ||`)해야 `r[-1]`이라는 없는 칸을 들여다보는 사고를 막아요. `return best;`는 반복문이 끝난 뒤에 둬요.

### 흐름제어 정답 (종합)
```c
struct Rider riders[5] = {
    {"Kim", 5, 5, 0}, {"Lee", 2, 3, 0}, {"Park", 1, 4, 1},
    {"Choi", 3, 5, 0}, {"Jung", 4, 4, 0}
};
int idx = find_nearest(riders, 5);
if (idx == -1) {
    printf("배차 가능한 라이더 없음\n");
} else {
    printf("배차: %s (거리 %dkm)\n", riders[idx].name, riders[idx].dist);
}
```
**왜 이렇게?** 배차 가능한 사람은 Choi 한 명뿐이라 `idx`는 3이고, 출력은 `배차: Choi (거리 3km)`예요. 반환값이 `-1`이면 아무도 없다는 신호라서 `riders[idx]`를 쓰기 **전에** 꼭 먼저 확인해야 해요.
