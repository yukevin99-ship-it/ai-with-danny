## 엔지니어가 직면한 가상의 문제 1

**[카카오톡 메시지 서버팀]** "단체방 숫자 1이 안 없어져요!", "나간 친구 때문에 숫자가 영원히 남아요!", "다 읽었는데 숫자가 다시 생겼어요!" 같은 신고가 쏟아졌어요. 엔지니어인 너는 **안 읽음 숫자 계산 → 읽음 영수증 처리 → 많이 밀린 사람에게 알림**을 다시 짜야 해요.

**안 읽음 숫자 규칙**: 메시지 하나의 숫자 = 아래 조건을 **모두** 만족하는 사람 수
1. 방을 **나가지 않았다** (`left == 0`)
2. 그 메시지를 **보낸 사람이 아니다** (내가 보낸 건 내가 이미 읽었죠!)
3. 그 메시지가 올라올 때 **이미 방에 있었다** (`joinSeq <= seq`)
4. 아직 거기까지 **안 읽었다** (`lastRead < seq`)

```c
#include <stdio.h>

#define MAXM   6     // 최대 사람 수
#define MAXMSG 10    // 최대 메시지 수

typedef struct {
    int  id;
    char name[12];
    int  joinSeq;   // 몇 번 메시지부터 방에 있었나
    int  lastRead;  // 마지막으로 읽은 메시지 번호
    int  left;      // 1이면 방을 나감
} Member;

typedef struct {
    int  seq;       // 메시지 번호 (0부터)
    int  senderId;  // 보낸 사람 id
    char text[32];
} Message;

typedef struct {
    int memberId;   // 누가
    int seq;        // "여기까지 읽었어요"
} ReadEvent;

Member members[MAXM] = {
    {1, "민지", 0, 7, 0},
    {2, "준호", 0, 3, 0},
    {3, "서연", 2, 1, 0},   // 2번 메시지 때 들어옴, 아직 하나도 안 읽음
    {4, "도윤", 0, 5, 1},   // 방을 나감!
    {5, "하은", 4, 6, 0},   // 4번 메시지 때 들어옴
};
int nm = 5;

Message msgs[MAXMSG] = {
    {0, 1, "점심 뭐 먹지?"},
    {1, 2, "떡볶이 어때"},
    {2, 4, "난 빠질게"},
    {3, 1, "12시에 정문!"},
    {4, 5, "나도 갈래"},
    {5, 2, "자리 잡았어"},
    {6, 5, "5분 늦어 ㅠ"},
    {7, 1, "메뉴 사진 보냄"},
};
int nmsg = 8;

ReadEvent events[] = {   // 서버에 순서대로 도착한 읽음 영수증
    {2, 6}, {3, 9}, {5, 5}, {4, 7}, {9, 2}, {3, 4}, {0, 0}, {1, 7},
};
#define NE (int)(sizeof events / sizeof events[0])
```

① `Member *findMember(Member *arr, int n, int id)`: 찾으면 **그 칸의 주소** `&arr[i]`, 못 찾으면 `NULL`.
② `int applyRead(Member *m, int seq, int lastSeq)`: `seq`가 0보다 작거나 `lastSeq`보다 크면 `-1`, `seq <= m->lastRead`면(옛날 영수증) 아무것도 안 바꾸고 `0`, 아니면 `m->lastRead = seq;` 하고 `1`.

```c
Member *findMember(Member *arr, int n, int id) {
    for (int i = 0; i < n; i++) {
        Member tmp = arr[i];
        if (tmp.id == id) return &tmp;
    }
    return NULL;
}
```

## 엔지니어가 창작해야되는 가상의 프로그램 1

**[티머니(T-money) 정산 시스템팀 — 가상]** 하루 동안 찍힌 교통카드 기록을 보고 **요금을 정확히 계산하는 정산 프로그램**을 새로 만들어야 해요. 환승 할인, 밤 시간 연장, 같은 버스 다시 타기 금지, 거리 추가요금, 자동충전까지 다 들어가요!

**요금 규칙 (퀴즈용 가상 요금)**

| 교통수단 | 어른 기본요금 |
|---|---|
| 간선버스 `BUS` | 1,500원 |
| 지하철 `SUBWAY` | 1,400원 |
| 마을버스 `VILLAGE` | 1,200원 |

- 청소년 `TEEN`: 어른 요금의 80% / 어린이 `CHILD`: 50% / 어르신 `SENIOR`: **지하철만 0원**, 나머지는 어른 요금
- **거리 추가요금** (어른·청소년만): 10km까지는 0원 → 10km~50km 구간은 **5km마다 100원** → 50km 넘는 구간은 **8km마다 100원** (조금이라도 넘으면 한 칸으로 쳐요)
- 거리는 `0.1km` 단위 정수예요. (`142` = 14.2km)
- **환승 조건 (전부 만족해야 환승)**
  1. 진행 중인 여정이 있다
  2. 지금까지 환승이 4번 미만이다
  3. 지난번 내린 시각부터 이번에 탄 시각까지 **30분 이내** (탄 시각이 **21:00~07:00 밤이면 60분 이내**)
  4. **같은 교통수단의 같은 노선**을 다시 탄 게 아니다
- **환승하면**: 기본요금은 "이번 기본요금 − 지금까지 가장 비쌌던 기본요금"만 (마이너스면 0원). 거리는 여정 전체 거리로 다시 계산해서 **늘어난 만큼만** 내요.
- 잔액이 모자라면 **자동충전 10,000원**(하루 1번만). 그래도 모자라면 거절.

```c
#include <stdio.h>

typedef enum { BUS, SUBWAY, VILLAGE } Mode;
typedef enum { ADULT, TEEN, CHILD, SENIOR } Age;

typedef struct {
    Mode mode;
    int  route;     // 버스 번호 / 지하철 호선
    int  onMin;     // 탄 시각 (자정부터 몇 분: 07:50 → 470)
    int  offMin;    // 내린 시각
    int  dist10;    // 이동 거리 (0.1km 단위)
} Ride;

Ride rides[] = {
    {VILLAGE,   3,  470,  482,  18},   // #1 07:50~08:02
    {SUBWAY,    2,  490,  525, 142},   // #2 08:10~08:45
    {BUS,     470,  560,  580,  64},   // #3 09:20~09:40
    {BUS,     470,  595,  605,  30},   // #4 09:55~10:05
    {SUBWAY,    9,  720,  710, 100},   // #5 12:00~11:50 (?!)
    {SUBWAY,    9,  730,  770, 290},   // #6 12:10~12:50
    {SUBWAY,    2, 1290, 1340, 560},   // #7 21:30~22:20
    {BUS,     741, 1385, 1410,  40},   // #8 23:05~23:30
    {VILLAGE,   5, 1320, 1335,  20},   // #9 22:00~22:15 (?!)
    {VILLAGE,   5, 1430, 1438,  12},   // #10 23:50~23:58
};
#define NR (int)(sizeof rides / sizeof rides[0])
```

## 문제 1 — 카카오톡 안 읽음 숫자

### 조건문 퀴즈1 정답
```c
int shouldCount(const Member *m, const Message *msg) {
    if (m->left)                  return 0;   // 1. 나간 사람
    if (m->id == msg->senderId)   return 0;   // 2. 보낸 사람
    if (m->joinSeq > msg->seq)    return 0;   // 3. 그때 방에 없었음
    if (m->lastRead >= msg->seq)  return 0;   // 4. 이미 읽음
    return 1;                                 // 다 통과 → 안 읽은 사람!
}

const char *badge(int unread, char *buf) {
    if (unread <= 0)       buf[0] = '\0';         // 아무것도 안 보여줌
    else if (unread > 99)  sprintf(buf, "99+");
    else                   sprintf(buf, "%d", unread);
    return buf;
}
```
**🧒 쉽게 설명하면**
놀이공원 입구에 검사원 4명이 줄지어 서 있다고 생각해 봐요. "나간 사람이에요? 탈락!", "보낸 사람이에요? 탈락!"… 한 명이라도 "탈락!"이라고 하면 **바로 집에 가요**(`return 0`). 4명을 모두 통과해야 "안 읽은 사람"으로 세요. 이렇게 하면 `if` 안에 `if` 안에 `if`… 처럼 계단이 깊어지지 않아서 읽기가 쉬워요.
`badge`에서 `> 99`를 먼저 검사하는 이유: 숫자가 크면 화면이 꽉 차니까 "99+"로 줄여 보여주는 거예요. 0일 땐 아무것도 안 보여야 "다 읽었다"는 뜻이 돼요.
③ 서연은 **2번 메시지 때 들어왔어요.** 0번 메시지가 올라올 땐 방에 없었으니 읽을 수도 없었죠. 규칙 3이 없으면 "들어오기 전 메시지" 숫자가 영원히 안 없어지는 버그가 생겨요!

### 포인터 변수 퀴즈1 정답
```c
Member *findMember(Member *arr, int n, int id) {
    for (int i = 0; i < n; i++)
        if (arr[i].id == id) return &arr[i];   // 진짜 그 칸의 주소
    return NULL;                               // "그런 사람 없어요"
}

int applyRead(Member *m, int seq, int lastSeq) {
    if (seq < 0 || seq > lastSeq) return -1;   // 없는 메시지
    if (seq <= m->lastRead)       return 0;    // 옛날 영수증 → 절대 뒤로 가지 않기!
    m->lastRead = seq;                         // 주소로 찾아가서 진짜 값을 바꿈
    return 1;
}
```
③ **버그**: `tmp`는 함수 안에서만 사는 **임시 복사본**이에요. 함수가 끝나면 `tmp`가 살던 자리는 치워져요. 그런데 그 자리 주소(`&tmp`)를 돌려줬으니, 받은 쪽은 **이미 철거된 집 주소**를 들고 있는 셈이에요(유령 포인터). 게다가 복사본이라 `lastRead`를 바꿔도 진짜 `members[]`는 안 바뀌어요. 정답처럼 `&arr[i]`(진짜 칸의 주소)를 돌려줘야 해요.

**🧒 쉽게 설명하면**
- 포인터는 **"사물함 번호"**예요. `findMember`는 "준호 사물함은 2번이야"라고 번호를 알려 주고, `applyRead`는 그 번호로 찾아가 안의 쪽지를 고쳐요.
- "다 읽었는데 숫자가 다시 생겼어요!" 버그의 범인은 **늦게 도착한 옛날 영수증**이었어요. 인터넷에선 편지가 순서대로 안 올 때가 있거든요. 하은은 이미 6번까지 읽었는데 "5번까지 읽음" 영수증이 늦게 오면, 그대로 덮어쓰면 6번 메시지에 숫자가 다시 생겨요. 그래서 `seq <= m->lastRead`면 **무시**해요. "읽은 위치는 앞으로만 간다!"

### 함수 퀴즈1 정답
```c
int countUnread(const ChatRoom *r, const Message *msg) {
    int c = 0;
    for (int i = 0; i < r->nm; i++)
        if (shouldCount(&r->members[i], msg)) c++;
    return c;
}

int unreadOf(const ChatRoom *r, const Member *m) {
    int c = 0;
    for (int k = 0; k < r->nmsg; k++)
        if (shouldCount(m, &r->msgs[k])) c++;
    return c;
}

void printRoom(const ChatRoom *r) {
    char buf[8];
    int total = 0;
    printf("[%s]\n", r->title);
    for (int k = 0; k < r->nmsg; k++) {
        const Message *msg = &r->msgs[k];
        int u = countUnread(r, msg);
        total += u;
        Member *s = findMember(r->members, r->nm, msg->senderId);
        printf("%d번 %s: %s %s\n", msg->seq, s ? s->name : "?", msg->text, badge(u, buf));
    }
    printf("안 읽음 합계: %d\n", total);
}
```
**🧒 쉽게 설명하면** 규칙이 바뀌는 날이 꼭 와요. 예를 들어 "차단한 사람은 안 셈" 같은 규칙이 생기면? 규칙이 `shouldCount` **한 곳**에만 있으면 거기만 고치면 끝! 세 군데에 복사해 두었다면 한 군데를 깜빡하는 순간 "메시지 숫자"와 "내 안 읽음 개수"가 서로 다르게 나오는 버그가 생겨요. `const`는 "이 함수는 보기만 하고 안 고쳐요"라는 약속 도장이에요.

## 프로그램 1 — 티머니 환승 요금 계산기

### 조건문 퀴즈1 정답
```c
int baseFare(Mode m, Age a) {
    int adult;
    switch (m) {
        case BUS:     adult = 1500; break;
        case SUBWAY:  adult = 1400; break;
        case VILLAGE: adult = 1200; break;
        default:      return -1;              // 모르는 교통수단
    }
    if (a == ADULT)  return adult;
    if (a == TEEN)   return adult * 80 / 100;
    if (a == CHILD)  return adult * 50 / 100;
    if (a == SENIOR) return (m == SUBWAY) ? 0 : adult;
    return -1;
}

int isNight(int minute) { return minute >= 21 * 60 || minute < 7 * 60; }

int canTransfer(const Journey *j, const Ride *r) {
    if (!j->active)        return 0;                      // 1
    if (j->transfers >= 4) return 0;                      // 2
    int gap   = r->onMin - j->lastOff;
    int limit = isNight(r->onMin) ? 60 : 30;
    if (gap < 0 || gap > limit) return 0;                 // 3
    if (r->mode == j->lastMode && r->route == j->lastRoute) return 0;  // 4
    return 1;
}
```
요금표: 어른 `1500/1400/1200`, 청소년 `1200/1120/960`, 어린이 `750/700/600`, 어르신 `1500/0/1200`
③ #3은 지난번 하차(08:45)부터 **35분**이 지나서(30분 초과) 환승 실패. #4는 15분밖에 안 지났지만 **같은 470번 버스를 다시 탔기 때문에** 환승 실패!
**🧒 쉽게 설명하면** `adult * 80 / 100`처럼 **곱하기를 먼저** 해요. `adult * (80 / 100)`으로 쓰면 정수 나눗셈에서 80/100 = 0이 되어 요금이 0원이 돼 버려요! `isNight`에서 `||`(또는)를 쓰는 이유: 밤은 "21시 이후" **이거나** "7시 이전"이에요. 자정을 넘어가니까 한 구간으로 쓸 수가 없거든요. "같은 버스 다시 타기 금지"는 내렸다가 같은 버스에 다시 타서 요금을 아끼는 꼼수를 막는 규칙이에요.

### 반복문 퀴즈1 정답

```c
    while (pos < d) {                     // 아직 도착 안 했으면
        int step = (pos < 500) ? 50 : 80; // 50km 전엔 5km, 뒤엔 8km씩
        pos += step;                      // 한 칸 전진
        fee += 100;                       // 100원 추가
    }
    return fee;
}

for (int d = 0; d <= 600; d += 100)
    printf("%2dkm: %d원\n", d / 10, surcharge(d));
```

③ `surcharge(501)` = **900원** (50km까지 8칸 = 800원, 0.1km 넘었으니 8km 칸 하나 더 = 100원)
**🧒 쉽게 설명하면** 징검다리 건너기예요. 10km 돌에서 출발해서 목적지에 아직 못 갔으면 한 칸 뛰고 100원을 내요. 50km까지는 돌 간격이 5km, 그 뒤는 8km라서 멀리 갈수록 덜 비싸요. "조금이라도 넘으면 한 칸"이 `while (pos < d)` 덕분에 저절로 돼요. 15.0km(`150`)면 150에서 멈추지만, 15.1km(`151`)면 한 번 더 뛰거든요.

### 흐름제어 퀴즈1 정답
```c
for (int i = 0; i < NR; i++) {
    const Ride *r = &rides[i];
    if (r->offMin < r->onMin || r->dist10 <= 0) {
        printf("#%d 이상한 기록 → 건너뜀\n", i + 1); skipped++;

    }
    if (c.j.active && r->onMin < c.j.lastOff) {

    int t = canTransfer(&c.j, r);

    if (f < 0) { printf("#%d 잔액 부족 → 거절\n", i + 1); rejected++; continue; }

    printf("#%d %s %d원 (잔액 %d)\n", i + 1, t ? "환승" : "새 승차", f, c.balance);

```
- #5: 12:00에 타서 11:50에 내렸대요 → **이상한 기록, `continue`**
- #9: 22:00에 탔는데 지난번(#8) 하차가 23:30 → 시간이 거꾸로 → **`break`**. 그래서 #10은 **처리되지 않아요.**
**🧒 쉽게 설명하면** 시험지 채점할 때 이름이 없는 시험지 한 장은 옆에 빼 두고 다음 걸 채점해요(`continue`). 그런데 시험지 순서가 뒤죽박죽 섞인 걸 발견하면? 지금까지 채점한 것도 믿을 수 없으니 **채점을 멈추고 선생님께 알려요**(`break`). 하나만 이상한 것과 전체가 이상한 것을 구분하는 게 흐름제어의 핵심이에요. 이상한 기록 검사를 **먼저** 하는 이유: #5 같은 고장 기록 때문에 멀쩡한 정산이 멈추면 안 되니까요.

### 배열 퀴즈1 정답

```c
int first = -1;
for (int i = 0; i < 30; i++)
    if (pre[i] >= 62000) { first = i; break; }     // 처음 한 번만 찾으면 끝
```

- 한 달 총 **82,800원**, 누적이 처음 62,000원을 넘는 날 = **24일**(누적 62,800원) → 정기권이 이득!

**🧒 쉽게 설명하면** 누적합은 **저금통 잔고 기록장**이에요. 매일 넣은 돈을 더해서 "오늘까지 총 얼마"를 적어 두죠. 슬라이딩 윈도우는 **7칸짜리 창문**을 오른쪽으로 한 칸씩 미는 거예요. 창문을 밀면 오른쪽 한 칸이 새로 보이고 왼쪽 한 칸이 사라지죠? 그래서 7개를 매번 다시 더하지 않고 "새 칸 더하기, 사라진 칸 빼기" 두 번만 계산하면 돼요. 날이 1년(365일)이 되어도 금방 끝나요. `bs = i - 6`은 창문의 **왼쪽 끝** 위치예요.

### 구조체 퀴즈1 정답
```c
Card c = {"DANNY-01", ADULT, 6000, 1, 0, {0}};   // {0} → Journey 전부 0

c.j.maxBase      // 변수일 때: 점 두 번
p->j.maxBase     // 포인터일 때: 화살표 한 번, 그다음 점
```
**🧒 쉽게 설명하면** `Card`는 큰 상자고, 그 안에 `Journey`라는 작은 상자가 들어 있어요. "큰 상자(c) 안의 작은 상자(j) 안의 maxBase"라서 `c.j.maxBase`. 큰 상자를 직접 들고 있으면 `.`, 상자의 **위치(주소)**만 들고 있으면 `->`로 먼저 찾아가요. 여정 정보를 따로 묶어 두면 "새 여정 시작 = 작은 상자만 새로 채우기"가 돼서 깔끔해요.

### 함수 퀴즈1 정답
```c
int fareFor(const Card *c, const Ride *r, int transfer) {
    int base    = baseFare(r->mode, c->age);
    int extraOn = (c->age == ADULT || c->age == TEEN);
    if (transfer) {
        int b = base > c->j.maxBase ? base - c->j.maxBase : 0;
        int d = extraOn ? surcharge(c->j.dist10 + r->dist10) - surcharge(c->j.dist10) : 0;
        return b + d;
    }
    return base + (extraOn ? surcharge(r->dist10) : 0);
}

int ride(Card *c, const Ride *r) {
    int t    = canTransfer(&c->j, r);
    int fare = fareFor(c, r, t);
    if (!pay(c, fare)) return -1;                    // 실패하면 여정도 안 건드림
    int base = baseFare(r->mode, c->age);
    if (t) {
        c->j.transfers++;
        if (base > c->j.maxBase) c->j.maxBase = base;
        c->j.dist10 += r->dist10;
        c->j.paid   += fare;
    } else {
        if (c->j.active) printf("    └ 지난 여정 끝: %d원\n", c->j.paid);
        c->j.active = 1;  c->j.transfers = 0;  c->j.maxBase = base;
        c->j.dist10 = r->dist10;  c->j.paid = fare;
    }
    c->j.lastOff = r->offMin;  c->j.lastMode = r->mode;  c->j.lastRoute = r->route;
    return fare;
}
```
③ 청소년: #1 마을버스 **960원** (960 + 거리 0), #2 지하철 환승 **360원** (1120 − 960 = 160 + 거리 추가 200)
**🧒 쉽게 설명하면** 환승 요금은 **"차액만 내기"**예요. 마을버스(1,200원)를 타고 지하철(1,400원)로 갈아타면 이미 1,200원 냈으니까 200원만 더 내요. 거리도 "전체 16.0km 요금(200원) − 이미 낸 1.8km 요금(0원)" = 200원. 반대로 비싼 걸 먼저 타고 싼 걸로 갈아타면 기본요금 차액이 마이너스라서 0원이에요. `ride`는 "판단(canTransfer) → 계산(fareFor) → 결제(pay) → 기록" 순서로 작은 함수들을 이어 붙인 **조립 라인**이에요. 결제가 실패하면 기록을 고치지 않고 바로 돌아가는 것도 중요해요. 돈을 안 냈는데 "탔다"고 적으면 안 되니까요!
