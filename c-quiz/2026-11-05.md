## 엔지니어가 직면한 가상의 문제 1

**[Slack 알림팀]** 메시지 5개가 왔어요. 각 메시지는 번호(`id`), 우선순위(`priority`, 1=낮음 2=보통 3=긴급), 도착 시각(`minute`, 0~1439분: 하루를 분으로 센 값), 채널 음소거 여부(`muted`, 1이면 음소거)를 가져요. 규칙: 음소거 채널은 "무시"예요. 방해금지 시간(밤 22:00 이상 = 1320분 이상, 또는 아침 07:00 전 = 420분 미만)에는 긴급(3)만 "즉시 알림"이고 나머지는 "보류"예요. 방해금지 시간이 아닐 때는 우선순위 2 이상이면 "즉시 알림", 1이면 "묶음 알림"이에요.

```c
int priorities[5] = {1, 3, 2, 3, 2};
// 메시지 5개: {id, priority, minute, muted}
// {1,1,600,0} {2,3,1400,0} {3,2,1380,0} {4,3,300,1} {5,2,720,0}
```

- **조건문 퀴즈 1:** 메시지 하나의 `muted`, `minute`, `priority`를 보고 "무시", "즉시 알림", "보류", "묶음 알림" 중 하나를 출력하는 코드를 작성하세요. (음소거 검사를 먼저!)
- **반복문 퀴즈 1:** 구조체 배열 `msgs[5]`를 처음부터 끝까지 돌면서 `"1번 메시지: 우선순위 1"` 모양으로 출력하는 코드를 작성하세요. (번호는 1부터)
- **흐름제어 퀴즈 1:** 위 반복문에서 음소거된 메시지(`muted == 1`)는 건너뛰고, 방해금지 시간이면서 긴급이 아닌(`priority < 3`) 메시지를 처음 발견하면 "보류 메시지: (id)"를 출력하고 반복을 멈추는 코드를 작성하세요.
- **배열 퀴즈 1:** `priorities` 배열에서 우선순위가 2 이상인 메시지가 몇 개인지 세어 `cnt`에 저장하고 출력하세요.
- **포인터 변수 퀴즈 1:** 포인터 `p`가 `priorities` 배열의 처음부터 끝까지 한 칸씩 이동하며(`p++`), 가리키는 값이 3보다 **작은 칸만** 1씩 올리는(승급) 코드를 작성하세요. (`priorities[i]`가 아니라 `*p`를 사용)
- **구조체 퀴즈 1:** 번호(`id`), 우선순위(`priority`), 시각(`minute`), 음소거 여부(`muted`)를 가진 구조체 `struct Message`를 정의하세요.
- **함수 퀴즈 1:** 메시지 배열의 시작 주소 `m`과 개수 `n`을 받아서, 음소거가 아니면서 "즉시 알림"이 되는 메시지의 개수를 반환하는 함수 `count_instant`를 작성하세요.
- **흐름제어 퀴즈 2 (종합):** `main`에서 메시지 5개짜리 구조체 배열과 `count_instant`를 사용해, 개수가 0이면 "즉시 알림 없음", 아니면 "즉시 알림: N건"을 출력하는 코드를 작성하세요.

- **포인터 변수 퀴즈 1:** 포인터 `p`가 `batts` 배열의 처음부터 끝까지 한 칸씩 이동하며(`p++`), 값이 5 이상인 칸만 5를 빼는(주행 소모) 코드를 작성하세요. (`*p` 사용, 5 미만인 칸은 그대로)

# 정답 및 해설 (초등학교 5학년 눈높이)

## 문제 1: Slack 알림 방해금지 분류

### 조건문 정답
```c
if (muted == 1) {
    printf("무시\n");
} else if (minute >= 1320 || minute < 420) {
    if (priority == 3) {
        printf("즉시 알림\n");
    } else {
        printf("보류\n");
    }
} else if (priority >= 2) {
    printf("즉시 알림\n");
} else {
    printf("묶음 알림\n");
}
```
**왜 이렇게?** 잠자는 시간에 초인종이 울리는 상황을 떠올려 보세요. 먼저 "이 초인종, 아예 꺼 놨니?"(음소거)를 물어요. 꺼 놨다면 더 따질 필요가 없어요. 그다음 "지금 자는 시간이니?"를 묻는데, 밤 10시 **이후** 또는 아침 7시 **이전**이라서 두 조건 중 하나만 맞아도 되니까 `||`(또는)을 써요. 자는 시간에는 불이 난 것처럼 급한(3) 손님만 깨우고, 나머지는 아침까지 보류해요. 깨어 있는 시간에는 보통(2) 이상이면 바로 알려요.

### 반복문 정답
```c
for (int i = 0; i < 5; i++) {
    printf("%d번 메시지: 우선순위 %d\n", i + 1, msgs[i].priority);
}
```
**왜 이렇게?** 메시지가 5개로 정해져 있어서 `for`가 딱이에요. 컴퓨터는 0부터 세지만 사람은 1번부터 부르니까, 화면에 보일 때만 `i + 1`을 써요. `i < 5`라야 0~4, 딱 5칸만 열어요.

### 흐름제어 정답 (1)
```c
for (int i = 0; i < 5; i++) {
    if (msgs[i].muted == 1) {
        continue;
    }
    int night = (msgs[i].minute >= 1320 || msgs[i].minute < 420);
    if (night && msgs[i].priority < 3) {
        printf("보류 메시지: %d\n", msgs[i].id);
        break;
    }
}
```
**왜 이렇게?** `continue`는 "이 편지는 안 읽을래, 다음 편지!"이고, `break`는 "찾았다! 이제 그만 찾아도 돼!"예요. 정답 출력은 `보류 메시지: 3`이에요. 1번은 낮이라 해당이 없고, 2번은 밤이지만 긴급이라 통과, 3번(1380분 = 밤 11시, 우선순위 2)이 처음으로 걸려요. 4번은 음소거라 어차피 건너뛰어요.

### 배열 정답
```c
int cnt = 0;
for (int i = 0; i < 5; i++) {
    if (priorities[i] >= 2) {
        cnt++;
    }
}
printf("%d\n", cnt);   // 4
```
**왜 이렇게?** "중요한 편지 몇 통이야?" 하고 막대기를 그어 세는 것과 같아요. 조건에 맞을 때만 `cnt++`로 하나 더 그어요. 3, 2, 3, 2 네 개라서 답은 4예요.

### 포인터 정답
```c
int *p = priorities;
for (int i = 0; i < 5; i++) {
    if (*p < 3) {
        *p = *p + 1;
    }
    p++;
}
// priorities는 {2, 3, 3, 3, 3}이 돼요
```
**왜 이렇게?** 배열 이름 `priorities`는 "첫 칸의 주소"예요. `p`는 손가락, `*p`는 손가락이 가리키는 칸 안의 값이에요. 3보다 작은 칸만 1을 올리고(이미 3이면 더 올리면 안 되니까요!), 손가락은 `p++`로 다음 칸으로 옮겨요. `p++`는 `if` 바깥에 둬야 해요. 안에 두면 값이 3인 칸에서 손가락이 못 움직여서 계속 같은 칸만 보게 돼요.

### 구조체 정답
```c
struct Message {
    int id;
    int priority;
    int minute;
    int muted;
};
```
**왜 이렇게?** 메시지 한 개에는 번호, 우선순위, 시각, 음소거 여부가 항상 같이 다녀요. 배열 4개로 따로 두면 짝이 어긋나기 쉬워서, 하나의 "편지 봉투"로 묶어요.

### 함수 정답
```c
int count_instant(struct Message *m, int n) {
    int cnt = 0;
    for (int i = 0; i < n; i++) {
        if (m[i].muted == 1) {
            continue;
        }
        int night = (m[i].minute >= 1320 || m[i].minute < 420);
        if (night) {
            if (m[i].priority == 3) {
                cnt++;
            }
        } else if (m[i].priority >= 2) {
            cnt++;
        }
    }
    return cnt;
}
```
**왜 이렇게?** 앞에서 쓴 "음소거 → 밤 → 낮" 순서를 그대로 함수에 담았어요. `return cnt;`는 반드시 **반복문이 끝난 뒤**에 둬요. 안에 두면 첫 메시지만 세고 돌아가 버려요. 배열을 받을 때는 통째로 복사하지 않고 시작 주소(`m`)와 개수(`n`)만 받는 게 C언어의 약속이에요.

### 흐름제어 정답 (종합)
```c
struct Message msgs[5] = {
    {1, 1, 600, 0}, {2, 3, 1400, 0}, {3, 2, 1380, 0},
    {4, 3, 300, 1}, {5, 2, 720, 0}
};
int n = count_instant(msgs, 5);
if (n == 0) {
    printf("즉시 알림 없음\n");
} else {
    printf("즉시 알림: %d건\n", n);
}
```
**왜 이렇게?** 2번(밤인데 긴급)과 5번(낮 12시, 우선순위 2)만 바로 알림이 돼요. 1번은 묶음, 3번은 보류, 4번은 음소거라 빠져요. 출력은 `즉시 알림: 2건`이에요. 결과를 변수 `n`에 한 번 받아 두면 `if`에서 여러 번 쓸 수 있어요.

## 프로그램 1: NASA 화성 로버 귀환 점검

### 조건문 정답
```c
int need = dist * 2;
if (battery < need) {
    printf("위험\n");
} else {
    printf("안전\n");
}
```
**왜 이렇게?** 자전거로 집에 돌아가려면 힘(배터리)이 가야 할 거리만큼 남아 있어야 해요. 딱 필요한 만큼 남았다면 겨우 도착할 수 있으니 아직 안전이에요. 그래서 `<=`가 아니라 `<`를 써요.

### 반복문 정답
```c
for (int i = 0; i < 5; i++) {
    printf("%d번 로버: %s (배터리 %d%%)\n", i + 1, rovers[i].name, rovers[i].battery);
}
```
**왜 이렇게?** 글자(이름)는 `%s`, 숫자는 `%d`로 출력해요. `%` 기호 자체를 화면에 보여 주고 싶을 땐 `%%`라고 두 번 써야 해요! 번호는 사람 눈높이에 맞춰 `i + 1`!

### 흐름제어 정답 (1)
```c
for (int i = 0; i < 5; i++) {
    if (rovers[i].done == 1) {
        continue;
    }
    if (rovers[i].battery < rovers[i].dist * 2) {
        printf("긴급 귀환: %s\n", rovers[i].name);
        break;
    }
}
```
**왜 이렇게?** 이미 기지에 들어온 로버는 `continue`로 건너뛰어요. 위험한 로버를 하나 찾으면 바로 알려야 하니까 `break`로 멈춰요. Alpha는 배터리 80으로 필요량 40보다 많아 안전하고, Beta는 30 < 40이라 걸려서 `긴급 귀환: Beta`가 나와요.

### 배열 정답
```c
int danger = 0;
for (int i = 0; i < 5; i++) {
    if (dones[i] == 0 && batts[i] < dists[i] * 2) {
        danger++;
    }
}
printf("%d\n", danger);   // 2
```
**왜 이렇게?** 같은 번호 칸끼리(`batts[i]`, `dists[i]`, `dones[i]`)가 한 대의 정보예요. 필요량은 40, 40, 60, 8, 20이에요. Beta(30<40)와 Gamma(55<60)가 위험이고 둘 다 임무 중이라 답은 2예요. Delta는 10 ≥ 8로 안전, Echo는 안전한데다 임무도 끝났어요.

### 포인터 정답
```c
int *p = batts;
for (int i = 0; i < 5; i++) {
    if (*p >= 5) {
        *p = *p - 5;
    }
    p++;
}
// batts는 {75, 25, 50, 5, 85}가 돼요
```
**왜 이렇게?** 배터리가 5도 안 남았는데 5를 빼면 마이너스가 되어 말이 안 돼요. 그래서 "5 이상인 칸만" 빼요. 조건에 안 맞는 칸도 손가락은 계속 움직여야 하니 `p++`는 `if` 바깥에 둬요. (이 데이터에서는 모두 5 이상이라 전부 5씩 줄어요: 80→75, 30→25, 55→50, 10→5, 90→85.)

### 구조체 정답
```c
struct Rover {
    char name[20];
    int battery;
    int dist;
    int done;
};

struct Rover one = {"Pixel", 40, 25, 0};
if (one.battery < one.dist * 2) {
    printf("%s: 귀환 불가\n", one.name);
} else {
    printf("%s: 귀환 가능\n", one.name);
}
```
**왜 이렇게?** 이름은 글자 칸(`char name[20]`), 나머지는 숫자 칸이에요. 값은 선언한 순서대로 채워져요. Pixel은 필요량이 25 × 2 = 50인데 배터리가 40이라 부족해서 `Pixel: 귀환 불가`가 나와요.

### 함수 정답
```c
struct Rover *find_lowest_danger(struct Rover *p, int n) {
    struct Rover *best = NULL;
    for (int i = 0; i < n; i++) {
        if (p[i].done == 1) {
            continue;
        }
        if (p[i].battery < p[i].dist * 2) {
            if (best == NULL || p[i].battery < best->battery) {
                best = &p[i];
            }
        }
    }
    return best;
}
```
**왜 이렇게?** 달리기 시합에서 지금까지 1등 후보를 `best`라는 손가락으로 가리켜 두는 거예요. 처음엔 아무도 안 가리키니까 `NULL`이에요. 위험한 로버를 만날 때마다 "후보가 없거나, 이 친구가 후보보다 배터리가 적으면" 손가락을 이 친구로 옮겨요(`&p[i]`는 i번째 로버의 주소). `best == NULL`을 `||` 앞에 두는 게 중요해요. 후보가 없을 때 `best->battery`를 읽으면 없는 곳을 만지는 사고가 나는데, 앞의 조건이 참이면 뒤는 아예 검사하지 않거든요. 끝까지 아무도 못 찾으면 `NULL`이 그대로 돌아가요.

### 흐름제어 정답 (종합)
```c
struct Rover *w = find_lowest_danger(rovers, 5);
if (w == NULL) {
    printf("모두 안전\n");
} else {
    printf("가장 위험: %s (%d%%)\n", w->name, w->battery);
}
```
**왜 이렇게?** 위험한 로버는 Beta(30)와 Gamma(55)인데, 배터리가 더 적은 Beta가 뽑혀요. 출력은 `가장 위험: Beta (30%)`예요. 주소를 돌려받았으니 `w->name`처럼 화살표(`->`)로 안의 값을 꺼내요. 그리고 꺼내기 **전에** `NULL`인지 먼저 확인해야 안전해요.
