# 정답과 쉬운 설명 (2026-10-11)

## 🅰️ 네이버 쇼핑 서버 점검

**조건문**
```c
if (code == 200)       printf("정상\n");
else if (code == 404)  printf("페이지 없음\n");
else if (code >= 500)  printf("서버 오류\n");
else                   printf("기타\n");
```
쉬운 설명: 학교 문 앞 선생님이 "1반이니? 아니면 2반이니? 그것도 아니면 3반 이상이니?" 하고 **위에서부터 차례로** 물어보는 거예요. 맞는 걸 만나면 거기서 멈추고, 아무것도 아니면 마지막 `else`로 가요. 500 이상은 "같다(==)"가 아니라 "크거나 같다(>=)"로 물어야 503도 잡혀요.

**반복문**
```c
int count = 0;
for (int i = 0; i < 8; i++) {
    if (codes[i] >= 500) count++;
}
printf("%d\n", count);   // 3
```
쉬운 설명: 줄 서 있는 8명에게 한 명씩 "너 500 이상이야?" 묻고, 맞으면 공책에 작대기(`count++`)를 하나 그어요. 번호는 0부터 7까지라서 `i < 8`이에요(8까지 가면 줄 밖으로 나가요!). 처음에 `count = 0`으로 공책을 깨끗하게 해 두는 것도 잊지 마세요.

**흐름제어**
```c
int streak = 0;
for (int i = 0; i < 8; i++) {
    if (codes[i] >= 500) {
        streak++;
        if (streak == 2) {
            printf("긴급 경보!\n");
            break;
        }
    } else {
        streak = 0;
    }
}
```
쉬운 설명: "연속"은 **끊기면 처음부터 다시 세는 것**이에요. 줄넘기 연속 2번 성공하면 끝나는 게임인데, 중간에 걸리면 0부터 다시! 그래서 `else`에서 `streak = 0`을 해요. 2번 채우면 알림을 울리고 `break`로 게임을 끝내요. 이 배열에서는 500, 503이 붙어 있어서 경보가 울려요. (중간 500 하나와 뒤의 500은 200이 끊어 줘서 연속이 아니에요.)

## 🅱️ 삼성 냉장고 온도 알림

**조건문**
```c
if (t < 0)       printf("너무 차가움\n");
else if (t <= 5) printf("적정\n");
else             printf("너무 따뜻함\n");
```
쉬운 설명: 먼저 "0보다 작아?"를 묻고, 아니면 "5 이하야?"를 물어요. 앞에서 0 미만을 걸러냈으니 두 번째 질문은 "0~5 사이"가 되는 거예요. 질문 순서를 잘 짜면 `&&`를 안 써도 돼요.

**반복문**
```c
int sum = 0;
for (int i = 0; i < 7; i++) sum += temps[i];
printf("%d\n", sum / 7);   // 합 18 → 18/7 = 2
```
쉬운 설명: 먼저 점수를 전부 더하고(`sum`), 사람 수로 나누면 평균이에요. `int`끼리 나누면 소수점은 버려져서 2.57이 아니라 2가 나와요. 나누는 수 7을 빼먹거나 `sum`을 0으로 시작하지 않으면 틀려요.

**흐름제어**
```c
int ok = 0;
for (int i = 0; i < 5; i++) {
    if (data[i] == -99) continue;
    if (data[i] > 5) {
        printf("경고!\n");
        break;
    }
    ok++;
}
printf("%d\n", ok);   // 2
```
쉬운 설명: `continue`는 "이 친구는 패스, 다음 친구!"이고 `break`는 "게임 끝! 모두 집에 가!"예요. 3은 정상(ok=1), -99는 패스, 4는 정상(ok=2), 7은 너무 높아서 경고하고 끝. 뒤의 2는 읽지도 않아요. **고장 값 확인을 제일 먼저** 해야 해요. 안 그러면 -99도 정상으로 세어 버려요.

## 🔑 오늘의 한 줄 정리
- 조건문 = 갈림길에서 길 고르기 / 반복문 = 같은 일 여러 번 / `continue` = 이번 차례만 건너뛰기 / `break` = 반복 전체 끝내기
