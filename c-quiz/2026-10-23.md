# ✅ 정답과 해설 (초등학교 5학년 버전)

## 📌 문제 1: Google 지도 도로 혼잡도

### 조건문 정답
```c
if (spd >= 40) {
    printf("원활\n");
} else if (spd >= 20) {
    printf("서행\n");
} else {
    printf("정체\n");
}
```
**왜 이렇게?** 달리기 시합 등수를 매길 때를 생각해 보세요. "40 넘으면 금메달부터" 먼저 확인하고, 아니면 "20 넘는지" 확인하고, 둘 다 아니면 나머지예요. 위에서 아래로 차례로 물어보고 **처음 "예"가 나오면 거기서 끝**나요. 그래서 `else if`에서는 "40 미만"이라고 또 쓸 필요가 없어요. 이미 위에서 걸러졌으니까요.

### 반복문 정답
```c
int count = 0;
for (int i = 0; i < 6; i++) {
    if (speed[i] < 20) {
        count++;
    }
}
printf("%d\n", count);   // 2
```
**왜 이렇게?** 반 친구 6명 중 지각생을 세는 것과 같아요. 한 명씩 차례로 보면서(`for`), 지각이면 공책에 줄 하나 긋기(`count++`). 줄 긋는 공책(`count`)은 **시작할 때 0**으로 두어야 해요. 20 미만인 건 15, 8 두 개라서 답은 **2**예요. `i < 6`인 건 칸이 0~5번까지 6개뿐이라서예요.

### 흐름제어 정답
```c
for (int i = 0; i < 6; i++) {
    if (speed[i] >= 40) {
        continue;            // 잘 달리는 곳은 패스!
    }
    if (speed[i] < 20) {
        printf("정체 구간 번호: %d\n", i);
        break;               // 찾았으니 그만!
    }
}
```
**출력:** `정체 구간 번호: 1`

**왜 이렇게?** 0번(60)은 40 이상이라 `continue`로 건너뛰어요. 1번(15)은 20 미만이라 번호 1을 출력하고 `break`로 반복을 끝내요. 숨바꼭질에서 **첫 번째 친구를 찾으면 바로 "찾았다!" 하고 놀이를 멈추는 것**과 같아요. `break`가 없으면 3번(8)까지 계속 찾아서 "처음 나온 곳"이 아니게 돼요. `continue`는 "이번 칸은 건너뛰고 다음 칸으로!", `break`는 "전부 그만!"이라는 차이를 기억하세요.

## 📌 프로그램 1: Roblox 주사위 보드게임

### 조건문 정답
```c
if (d == 6) {
    printf("보너스!\n");
} else if (d >= 4) {
    printf("많이 이동\n");
} else {
    printf("조금 이동\n");
}
```
**왜 이렇게?** 6이 가장 특별하니까 **가장 특별한 경우를 맨 위에** 물어봐요. 만약 `d >= 4`를 먼저 쓰면 6도 거기에 걸려서 "보너스!"가 영원히 안 나와요. 같다고 물을 때는 `=`가 아니라 **`==`** (두 개)를 써야 해요. `=` 하나는 "값을 넣어라"라는 뜻이거든요.

### 반복문 정답
```c
int pos = 0;
for (int i = 0; i < 5; i++) {
    pos += dice[i];
}
printf("%d\n", pos);   // 20
```
**왜 이렇게?** 저금통에 동전을 하나씩 넣는 것과 같아요. 빈 저금통(`pos = 0`)에서 시작해서 3, 6, 2, 5, 4를 차례로 넣으면 3+6+2+5+4 = **20**이에요.

### 흐름제어 정답
```c
int pos = 0;
for (int i = 0; i < 5; i++) {
    pos += dice[i];
    if (dice[i] == 6) {
        pos += 1;            // 보너스 1칸
    }
    if (pos >= 15) {
        printf("%d번째 던지기에서 도착! 위치 %d\n", i + 1, pos);
        break;
    }
}
```
**출력:** `4번째 던지기에서 도착! 위치 17`

**왜 이렇게?** 한 번 던질 때마다 이렇게 변해요.
1. 3 → 위치 3
2. 6 → 6칸 + 보너스 1칸 → 위치 10
3. 2 → 위치 12
4. 5 → 위치 17 → 15 이상! 도착, `break`

도착한 뒤에도 계속 던지면 안 되니까 `break`로 게임을 끝내요. 번호는 `i`가 0부터 시작하므로 사람이 말하는 "몇 번째"는 **`i + 1`** 이에요. 보너스를 더하는 순서도 중요해요. 도착 검사(`pos >= 15`)를 **보너스를 더한 뒤에** 해야 계산이 맞아요.
