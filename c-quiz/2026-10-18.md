# ✅ 정답과 해설 (초등학교 5학년 눈높이)

## 엔지니어가 직면한 가상의 문제 1 (Netflix)

### 조건문 정답
```c
if (s >= 25) {
    printf("HD\n");
} else if (s >= 10) {
    printf("SD\n");
} else {
    printf("저화질\n");
}
```
**왜?** 달리기 시합에서 "기록이 제일 좋은 사람은 금메달, 그다음은 은메달, 나머지는 응원상" 하고 **좋은 쪽부터** 나누는 것과 같아요. 만약 `s >= 10`을 먼저 물으면 속도 50인 사람도 "10 넘었네, SD!" 하고 끝나 버려서 HD를 못 봐요. 그래서 큰 기준부터 물어봐요.

### 반복문 정답
```c
int hd = 0;
for (int i = 0; i < 6; i++) {
    if (speed[i] >= 25) {
        hd++;
    }
}
printf("HD 가능 %d번\n", hd);
```
정답은 2번이에요 (50, 35).

**왜?** 시험지 6장을 한 장씩 넘기며 "90점 이상이 몇 장이지?" 하고 세는 것과 같아요. `hd`는 세는 칸이고 처음엔 0이에요. 하나씩 보다가(`for`) 조건에 맞으면(`if`) 1을 더해요(`hd++`). `i < 6`이라서 0~5번 칸, 딱 6개만 봐요.

### 흐름제어 정답
```c
for (int i = 0; i < 6; i++) {
    if (speed[i] == 0) {
        printf("%d번째: 측정 실패\n", i + 1);
        continue;
    }
    if (speed[i] < 10) {
        printf("%d번째: 버퍼링 위험!\n", i + 1);
        break;
    }
    printf("%d번째: 정상\n", i + 1);
}
```
출력: `1번째: 정상` → `2번째: 정상` → `3번째: 측정 실패` → `4번째: 버퍼링 위험!` (5, 6번째는 안 봐요)

**왜?** `continue`는 "이번 건 패스하고 다음!", `break`는 "여기서 멈춰!"예요. 고장 난 측정(0)은 그냥 넘어가면 되지만, 속도가 너무 느리면 영상이 끊기니까 바로 멈추고 알려야 해요. 중요한 순서가 있어요! **0인지 먼저** 확인해야 해요. 0도 10보다 작아서 순서가 바뀌면 "측정 실패"가 아니라 "버퍼링 위험"으로 잘못 나와요.

## 엔지니어가 창작해야 하는 가상의 프로그램 1 (네이버 지도)

### 조건문 정답
```c
if (m <= 3) {
    printf("곧 도착! 뛰세요\n");
} else if (m <= 10) {
    printf("걸어가세요\n");
} else {
    printf("여유 있어요\n");
}
```
**왜?** 이번에는 "작은 값이 급한 것"이라서 **작은 기준부터** 물어봐요. 만약 `m <= 10`을 먼저 물으면 2분 남은 열차도 "걸어가세요"가 되어 열차를 놓쳐요. 앞의 질문에서 "예"가 나오면 뒤 질문은 보지 않기 때문이에요. 기준이 `>=`이면 큰 것부터, `<=`이면 작은 것부터라고 기억하세요!

### 반복문 정답
```c
int i = 1;
int max = train[0];
while (i < 5) {
    if (train[i] > max) {
        max = train[i];
    }
    i++;
}
printf("가장 늦은 열차: %d분\n", max);
```
정답은 20분이에요.

**왜?** 반에서 키 제일 큰 친구를 찾을 때, 일단 첫 번째 친구를 "지금 1등"으로 정해요. 그리고 다음 친구와 하나씩 키를 비교해서 더 크면 1등을 바꿔요. `max`가 바로 "지금 1등" 칸이에요. 첫 칸(0번)은 이미 1등으로 정했으니 `i`는 1부터 시작해요. `while`에서는 `i++`를 잊으면 영원히 끝나지 않아요!

### 흐름제어 정답
```c
for (int i = 0; i < 5; i++) {
    if (train[i] == 0) {
        continue;
    }
    if (train[i] <= 3) {
        printf("%d번째 열차 타자!\n", i + 1);
        break;
    }
    printf("%d번째: 아직 멀어요\n", i + 1);
}
```
출력: `1번째: 아직 멀어요` → `3번째: 아직 멀어요` → `4번째 열차 타자!` (2번째 0은 건너뛰고, 5번째는 안 봐요)

**왜?** 운행이 없는 0분 열차를 `continue`로 먼저 걸러야 해요. 안 거르면 0은 3 이하라서 "0분 열차 타자!"라는 이상한 말이 나와요. 타고 싶은 열차를 찾았으면 `break`로 멈춰요. 이미 탈 열차를 정했는데 뒤 열차까지 볼 필요는 없으니까요. 마치 버스 정류장에서 내가 탈 버스가 오면 다른 버스는 더 안 보는 것과 같아요!

## 📌 오늘의 한 줄 정리
- `if / else if / else` = 순서대로 묻는 갈림길 (`>=`면 큰 기준부터, `<=`면 작은 기준부터!)
- `max` 찾기 = 첫 칸을 1등으로 정하고 하나씩 비교
- `continue` = 이번만 패스, `break` = 반복 끝! 그리고 걸러낼 값(0)은 **먼저** 검사하기
