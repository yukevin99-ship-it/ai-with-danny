**[Amazon AWS 인프라팀]** 서버 디스크 5개의 사용률(%)을 확인해서, 가득 차기 전에 미리 정리해야 해요. 디스크가 꽉 차면 서버가 멈춰요!

### 조건문 퀴즈1
정수 `usage`(디스크 사용률 %)가 있을 때, 95 이상이면 "긴급 삭제", 80 이상 95 미만이면 "정리 필요", 그 밖에는 "여유"를 출력하는 코드를 작성하세요.

### 반복문 퀴즈1
`int usage[5] = {40, 65, 82, 97, 50};` 에서 사용률이 80 이상인 디스크가 몇 개인지 for문으로 세어 출력하세요.

### 흐름제어 퀴즈1
`int usage[5] = {40, 0, 82, 97, 50};` (0은 점검 불가 디스크)
디스크 번호는 1번부터입니다. 0이면 건너뛰고(`continue`), 95 이상인 디스크를 처음 발견하면 "N번 디스크 긴급! 자동 정리 시작"을 출력하고 반복을 끝내세요(`break`). 80 이상이면 "N번 디스크 주의", 나머지는 "N번 디스크 OK"를 출력합니다.

# ✅ 정답과 해설

## 📌 엔지니어가 직면한 가상의 문제 1 (AWS 디스크)

### 조건문 정답
```c
#include <stdio.h>
int main(void) {
    int usage = 88;
    if (usage >= 95) {
        printf("긴급 삭제\n");
    } else if (usage >= 80) {
        printf("정리 필요\n");
    } else {
        printf("여유\n");
    }
    return 0;
}
```
**쉬운 설명:** 물컵에 물이 얼마나 찼는지 보는 것과 같아요. 가장 위험한 "95 이상"을 먼저 물어봐요. 만약 "80 이상"을 먼저 물으면 97도 거기서 걸려 버려서 "긴급"이 영영 나오지 않아요. 큰 기준부터 차례로 묻는 게 요령이에요!

### 반복문 정답
```c
#include <stdio.h>
int main(void) {
    int usage[5] = {40, 65, 82, 97, 50};
    int count = 0;
    for (int i = 0; i < 5; i++) {
        if (usage[i] >= 80) {
            count++;
        }
    }
    printf("%d개\n", count);   // 2개
    return 0;
}
```
**쉬운 설명:** 반 친구들 중 안경 쓴 친구를 세는 것과 같아요. 한 명씩 차례로 보면서(`for`), 조건에 맞으면 손가락을 하나 접어요(`count++`). 세기 전에 `count = 0`으로 손가락을 모두 펴 두는 것도 잊지 마세요. 82와 97, 두 개예요.

### 흐름제어 정답
```c
#include <stdio.h>
int main(void) {
    int usage[5] = {40, 0, 82, 97, 50};
    for (int i = 0; i < 5; i++) {
        if (usage[i] == 0) {
            continue;                       // 점검 불가 디스크 건너뛰기
        }
        if (usage[i] >= 95) {
            printf("%d번 디스크 긴급! 자동 정리 시작\n", i + 1);
            break;                          // 긴급 상황이면 바로 끝
        }
        if (usage[i] >= 80) {
            printf("%d번 디스크 주의\n", i + 1);
        } else {
            printf("%d번 디스크 OK\n", i + 1);
        }
    }
    return 0;
}
```
출력:
```
1번 디스크 OK
3번 디스크 주의
4번 디스크 긴급! 자동 정리 시작
```
**쉬운 설명:** 소방관이 집집마다 순찰하는 것과 같아요. 빈집(0)은 그냥 지나가고(`continue`), 불난 집(95 이상)을 발견하면 순찰을 멈추고 바로 불부터 꺼요(`break`). 그래서 5번 디스크는 확인하지 않아요. 번호는 0부터 세는 `i`에 1을 더해(`i + 1`) 사람이 쓰는 1번부터 말해 줘요.

## 📌 엔지니어가 창작해야 하는 가상의 프로그램 1 (카카오뱅크 적금)

### 조건문 정답
```c
#include <stdio.h>
int main(void) {
    int age = 15;
    if (age < 19) {
        printf("청소년 적금\n");
    } else if (age >= 65) {
        printf("시니어 적금\n");
    } else {
        printf("일반 적금\n");
    }
    return 0;
}
```
**쉬운 설명:** 놀이공원 입장권 창구와 같아요. 어린이면 어린이 표, 어르신이면 어르신 표, 나머지는 일반 표를 줘요. "19 미만"에서 19살은 포함되지 않아요. 19살은 일반 적금이에요. `<`와 `<=`는 꼭 구분해요!

### 반복문 정답
```c
#include <stdio.h>
int main(void) {
    int saved = 0;
    for (int month = 1; month <= 6; month++) {
        saved += 30000;
        printf("%d개월 잔액 %d원\n", month, saved);
    }
    return 0;
}
```
출력: 30000, 60000, 90000, 120000, 150000, 180000원

**쉬운 설명:** 저금통에 매달 같은 금액을 넣는 거예요. 저금통(`saved`)은 반복문 **밖**에서 0으로 만들어 둬야 해요. 안에서 만들면 매번 비워져서 계속 30000원만 나와요. 달 번호는 1부터 6까지라서 `month <= 6`으로 써요.

### 흐름제어 정답
```c
#include <stdio.h>
int main(void) {
    int saved = 0;
    for (int month = 1; month <= 12; month++) {
        if (month % 4 == 0) {
            continue;                       // 4, 8, 12월은 용돈 없음
        }
        saved += 30000;
        printf("%d개월 잔액 %d원\n", month, saved);
        if (saved >= 150000) {
            printf("%d개월 만에 목표 달성!\n", month);
            break;
        }
    }
    return 0;
}
```
출력:
```
1개월 잔액 30000원
2개월 잔액 60000원
3개월 잔액 90000원
5개월 잔액 120000원
6개월 잔액 150000원
6개월 만에 목표 달성!
```
**쉬운 설명:** 자전거를 사려고 용돈을 모으는 것과 같아요. 용돈이 없는 달(4월)은 저금통에 아무것도 안 넣고 넘어가요(`continue`). 4로 나눈 나머지가 0이면 4의 배수라는 뜻이라 `month % 4 == 0`으로 알아내요. 저금한 다음에 목표를 넘었는지 확인하고, 넘었으면 더 모을 필요가 없으니 그만해요(`break`). 순서가 중요해요: **먼저 저금하고, 그다음에 목표 확인!** 그래서 4월을 건너뛰어도 6개월 만에 목표를 이뤄요.
