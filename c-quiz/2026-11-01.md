## 엔지니어가 직면한 가상의 문제 1

**[Meta Instagram 팀]** 오늘 올라온 게시물 5개의 좋아요 수가 배열에 들어 있어요. `0`은 삭제된 게시물이에요. 좋아요 합계가 15000을 넘으면 서버에 부담이 되어 알림을 보내야 해요.

```c
int likes[5] = {120, 0, 3500, 15000, 80};
```

- **조건문 퀴즈 1:** 게시물 하나의 좋아요 수 `like`가 10000 이상이면 "인기 급상승", 1000 이상이면 "인기", 그 외에는 "일반"을 출력하는 코드를 작성하세요.
- **반복문 퀴즈 1:** `likes` 배열 5개의 좋아요를 모두 더해 `total`에 저장하는 코드를 작성하세요.
- **흐름제어 퀴즈 1:** 위 반복문에서 0인 게시물은 건너뛰고(더하지 않기), `total`이 15000을 넘으면 "서버 알림!"을 출력하고 반복을 멈추는 코드를 작성하세요.

- **흐름제어 퀴즈 1:** 위 반복문에서 첫 1시간은 건너뛰고(요금 안 더하기), `fee`가 10000 이상이 되면 `fee`를 10000으로 맞추고 "최대 요금!"을 출력한 뒤 반복을 멈추는 코드를 작성하세요.

# 정답 및 해설 (초등학교 5학년 눈높이)

## 문제 1: Instagram 좋아요 집계

### 조건문 정답
```c
if (like >= 10000) {
    printf("인기 급상승\n");
} else if (like >= 1000) {
    printf("인기\n");
} else {
    printf("일반\n");
}
```
**왜 이렇게?** 달리기 시합 등수와 같아요. 제일 높은 기준부터 물어봐요. "10000 이상? 우와, 급상승!" 아니면 "1000 이상? 인기 있네!" 둘 다 아니면 "보통이야."
작은 기준(1000)부터 물으면 15000 좋아요도 "1000 이상이네?" 하고 그냥 "인기"가 돼 버려요. 큰 것부터 물어야 정확해요.

### 반복문 정답
```c
int total = 0;
for (int i = 0; i < 5; i++) {
    total += likes[i];
}
```
**왜 이렇게?** 저금통에 동전을 하나씩 넣고 총액을 세는 것과 같아요. `total`은 빈 저금통이라서 0으로 시작해요. `i`는 번호표인데 컴퓨터는 0번부터 세니까 0, 1, 2, 3, 4번 총 5번 돌아요. 그래서 `i < 5`예요.

### 흐름제어 정답
```c
int total = 0;
for (int i = 0; i < 5; i++) {
    if (likes[i] == 0) {
        continue;
    }
    total += likes[i];
    if (total > 15000) {
        printf("서버 알림!\n");
        break;
    }
}
```
**왜 이렇게?**
- `continue`는 "이건 패스! 다음으로 가자"예요. 삭제된 게시물(0)은 더하지 않고 넘어가요.
- `break`는 "그만! 여기서 끝!"이에요. 이미 15000을 넘었으면 더 세어 봐야 소용없으니 반복 전체를 끝내요.
- 예시 값으로 따라가면: 120 → 합계 120, 0 → 패스, 3500 → 합계 3620, 15000 → 합계 18620이라 "서버 알림!" 출력 후 멈춰요(마지막 80은 보지 않아요).
- 순서도 중요해요. 먼저 더하고 나서 넘었는지 확인해야 방금 더한 게시물 때문에 넘었는지 알 수 있어요.

## 프로그램 1: 현대 스마트 주차장

### 조건문 정답
```c
if (hours <= 1) {
    printf("무료 주차\n");
} else {
    printf("유료 주차\n");
}
```
**왜 이렇게?** "첫 1시간은 공짜"이니까 딱 1시간 주차한 사람도 공짜여야 해요. 그래서 `<=`에서 `=`가 꼭 필요해요. `<`만 쓰면 1시간 주차한 사람에게 돈을 받는 억울한 일이 생겨요!

### 반복문 정답
```c
int fee = 0;
for (int h = 1; h <= hours; h++) {
    fee += 1000;
}
```
**왜 이렇게?** "몇 시간 있었는지 알고 있으니" 횟수가 정해진 `for`가 좋아요. 시계가 1시, 2시, 3시... 하고 갈 때마다 1000원씩 올라가는 택시 요금 미터기를 떠올려 보세요. 이번에는 1시간부터 세니까 `h`를 1로 시작하고, `hours`시간까지 모두 세야 하니 `h <= hours`예요(`<`이면 마지막 시간을 빼먹어요). `fee`는 0원에서 시작해요.

### 흐름제어 정답
```c
int fee = 0;
for (int h = 1; h <= hours; h++) {
    if (h == 1) {
        continue;
    }
    fee += 1000;
    if (fee >= 10000) {
        fee = 10000;
        printf("최대 요금!\n");
        break;
    }
}
```
**왜 이렇게?**
- `continue`: 첫 1시간(`h == 1`)은 공짜니까 요금을 올리지 않고 "패스!" 하고 다음 시간으로 넘어가요.
- `break`: 하루 최대 요금은 10000원이에요. 더 오래 세워도 요금이 안 오르니 계산을 멈춰요.
- `fee = 10000;`을 해 주는 이유: 요금이 딱 10000에서 멈추지만, 요금 규칙이 바뀌어 한 번에 더 크게 오를 때를 대비해 "최대 요금은 10000원"이라고 확실히 정해 두는 거예요. 놀이공원의 "최대 입장료" 표지판 같은 거예요.
- 예시로 `hours`가 14이면: 1시간째는 패스, 2시간째부터 1000원씩 올라 11시간째에 10000원이 되어 "최대 요금!"을 출력하고 멈춰요(12~14시간째는 보지 않아요).
