# ✅ 정답과 해설 (초등학교 5학년 버전)

## 📌 문제 1: SK텔레콤 기지국

### 조건문 정답
```c
if (s >= 70) {
    printf("좋음\n");
} else if (s >= 30) {
    printf("보통\n");
} else {
    printf("약함\n");
}
```
**왜?** 핸드폰 안테나 막대기 같아요. 가장 센 경우(70 이상)부터 먼저 물어봐야 해요. "30 이상?"을 먼저 물으면 85도 "보통"이 돼 버려요. 위에서부터 차례로 물어보고, 처음 "예"가 나온 곳에서 끝나요.

### 반복문 정답
```c
int count = 0;
for (int i = 0; i < 6; i++) {
    if (signal[i] < 50) {
        count++;
    }
}
printf("%d\n", count);
```
**왜?** 기지국을 하나씩 돌며 "약한 기지국"에 막대기를 긋는 것과 같아요. 0에서 시작해 조건에 맞을 때만 하나 올려요. 칸이 6개(번호 0~5)라서 `i < 6`이에요. 40, 0, 15, 5가 50 미만이라 결과는 **4**예요. (꺼진 기지국 0도 50보다 작아서 세요!)

### 흐름제어 정답
```c
for (int i = 0; i < 6; i++) {
    if (signal[i] == 0) {
        continue;
    }
    if (signal[i] < 10) {
        printf("긴급 점검, 번호: %d\n", i);
        break;
    }
}
```
**출력:** `긴급 점검, 번호: 5`

**왜?** 꺼진 기지국(0)은 "이건 점검 대상이 아니야" 하고 `continue`로 휙 넘어가요. 만약 건너뛰지 않으면 0도 10 미만이라 번호 2번이 먼저 걸려 버려요. 85, 40, 15, 60은 괜찮고, 번호 5의 값 5가 처음으로 10 미만이라 알림을 보낸 뒤 `break`로 멈춰요.

## 📌 프로그램 1: LG 로봇청소기

### 조건문 정답
```c
if (d >= 70) {
    printf("강력 청소\n");
} else if (d >= 30) {
    printf("일반 청소\n");
} else {
    printf("가볍게 청소\n");
}
```
**왜?** 방이 아주 더러운 경우(70 이상)부터 먼저 물어봐요. 순서를 바꿔 "30 이상?"을 먼저 물으면 90처럼 엄청 더러운 방도 "일반 청소"만 하게 돼요.

### 반복문 정답
```c
int sum = 0;
for (int i = 0; i < 5; i++) {
    sum += dust[i];
}
printf("%d\n", sum);
```
**왜?** 저금통에 동전을 하나씩 넣듯이 방마다 먼지량을 `sum`에 더해요. 처음엔 빈 저금통(0)에서 시작해야 해요. 20 + 75 + 0 + 45 + 90 = **230**이에요.

### 흐름제어 정답
```c
int total = 0;
for (int i = 0; i < 5; i++) {
    if (dust[i] == 0) {
        continue;
    }
    total += dust[i];
    if (total > 100) {
        printf("충전 필요, 번호: %d\n", i);
        break;
    }
}
```
**출력:** `충전 필요, 번호: 3`

**왜?** 이미 깨끗한 방(0)은 `continue`로 건너뛰어요. 나머지는 청소한 양을 `total`에 쌓아요. 20 → 95까지는 괜찮지만, 번호 3의 45를 더하면 140이 되어 100을 넘어요. 그 순간 "충전 필요!"를 알리고 `break`로 멈춰요. 더한 다음에 검사하는 순서가 중요해요!
