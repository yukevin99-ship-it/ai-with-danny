## 📌 엔지니어가 직면한 가상의 문제 1
**[네이버 데이터센터]** 서버 5대의 온도를 감시하는데, 너무 뜨거운 서버를 빨리 찾아야 해요.

### 조건문 퀴즈1
정수 `temp`(서버 온도)가 있을 때, 90 이상이면 "위험", 70 이상 90 미만이면 "주의", 그 밖에는 "정상"을 출력하는 코드를 작성하세요.

### 반복문 퀴즈1
`int temps[5] = {55, 72, 68, 91, 60};` 의 온도 합계와 평균을 for문으로 구해 출력하세요.

### 흐름제어 퀴즈1
`int temps[5] = {55, 0, 72, 93, 60};` (0은 고장 난 센서)
서버 번호는 1번부터입니다. 온도가 0이면 건너뛰고(`continue`), 90 이상인 서버를 처음 발견하면 "N번 서버 긴급!"을 출력한 뒤 반복을 끝내세요(`break`). 정상 서버는 "N번 서버 OK"를 출력합니다.

## ✅ 정답 및 해설 (먼저 직접 풀어본 뒤 보세요!)

### 문제1 - 조건문
```c
if (temp >= 90) printf("위험\n");
else if (temp >= 70) printf("주의\n");
else printf("정상\n");
```
👉 시험 점수로 A, B, C를 나눌 때처럼 **가장 높은 기준부터** 물어봐야 해요. 90 이상을 먼저 묻지 않으면 95도도 "70 이상이네? 주의!"에서 끝나 버려요. `else if`는 앞 질문의 답이 '아니오'일 때만 다음 질문을 하는 길이에요.

### 문제1 - 반복문
```c
int sum = 0;
for (int i = 0; i < 5; i++) sum += temps[i];
printf("합계 %d, 평균 %.1f\n", sum, sum / 5.0);
```
출력: `합계 346, 평균 69.2`

👉 저금통에 동전을 하나씩 넣듯 `sum`에 계속 더해요. 5칸이니까 0~4번까지만 돌아요(`i < 5`). 5.0으로 나누는 이유는 정수끼리 나누면 소수점이 잘리기 때문이에요.

### 문제1 - 흐름제어
```c
for (int i = 0; i < 5; i++) {
    if (temps[i] == 0) continue;
    if (temps[i] >= 90) { printf("%d번 서버 긴급!\n", i + 1); break; }
    printf("%d번 서버 OK\n", i + 1);
}
```
출력: `1번 서버 OK` / `4번 서버 긴급!` (2번은 건너뛰고, 5번은 검사하지 않음)

👉 `continue`는 "이 친구는 패스, 다음 친구!", `break`는 "찾았다! 이제 그만!"이에요. 보물을 찾았으면 나머지 상자는 안 열어도 되죠. 번호는 0부터 세니까 출력할 땐 `i + 1`을 해요.

### 문제2 - 조건문
```c
if (likes >= 1000) printf("인기글\n");
else if (likes >= 100) printf("좋은 반응\n");
else printf("보통\n");
```
👉 큰 기준부터 차례대로 묻는 이유는 문제1과 같아요.

### 문제2 - 반복문
```c
int total = 0, i = 0;
while (i < 5) { total += likes[i]; i++; }
printf("총합 %d\n", total);
```
출력: `총합 1560`

👉 `while`은 "조건이 참인 동안 계속"이에요. `i++`를 빼먹으면 영원히 같은 자리만 도는 무한 반복이 돼요!

### 문제2 - 흐름제어
```c
for (int i = 0; i < 5; i++) {
    if (likes[i] == 0) continue;
    if (likes[i] >= 1000) { printf("%d번 글 인기!\n", i + 1); break; }
    printf("%d번 글: %d개\n", i + 1, likes[i]);
}
```
출력: `1번 글: 30개` / `3번 글: 250개` / `4번 글 인기!`

👉 순서가 중요해요: 0개 거르기(`continue`) → 인기글 확인(`break`) → 일반 출력. 출력을 먼저 하면 0개 글도 나오고 인기글 알림도 놓쳐요.
