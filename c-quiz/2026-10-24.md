## 📌 문제 1: 네이버 접속자 과부하

### 조건문 정답
```c
if (n >= 1000) {
    printf("과부하\n");
} else if (n >= 500) {
    printf("주의\n");
} else {
    printf("안정\n");
}
```
**왜?** 학교 급식실 줄을 생각해 보세요. 줄이 아주 길면 "너무 많아요!", 조금 길면 "좀 기다려야 해요", 짧으면 "괜찮아요"라고 하죠? 가장 심한 것부터 물어봐야 해요. 만약 "500 이상?"을 먼저 물으면 1200도 "주의"가 되어 버리거든요. `else if`는 "앞에서 아니었으면 그다음 질문!"이라는 뜻이에요.

### 반복문 정답
```c
int sum = 0;
for (int i = 0; i < 6; i++) {
    sum += users[i];
}
printf("%d\n", sum);
```
**왜?** 저금통에 동전 6개를 하나씩 넣으며 합계를 세는 것과 같아요. 처음에 `sum`을 0으로 비워 두고(빈 저금통), 한 칸씩 가면서 더해요. 배열 번호는 0부터 5까지라서 `i < 6`이에요. 결과는 **3750**이에요.

### 흐름제어 정답
```c
for (int i = 0; i < 6; i++) {
    if (users[i] < 200) {
        continue;
    }
    if (users[i] >= 1000) {
        printf("과부하 번호: %d, 접속자: %d\n", i, users[i]);
        break;
    }
}
```
**출력:** `과부하 번호: 4, 접속자: 1200`

**왜?** `continue`는 "이 친구는 패스! 다음 친구!"예요. 0번(120)은 200보다 작아서 패스해요. 1번(450), 2번(980), 3번(300)은 1000이 안 되니 그냥 지나가요. 4번(1200)에서 드디어 1000 이상이라 알려 주고, `break`로 반복을 끝내요. 술래가 숨은 친구를 찾으면 "찾았다!" 하고 놀이를 멈추는 것과 같아요. 그래서 5번(700)은 보지도 않아요.

## 📌 프로그램 1: Minecraft 가방 담기

### 조건문 정답
```c
if (cnt >= 64) {
    printf("가득 참\n");
} else if (cnt >= 32) {
    printf("반쯤\n");
} else {
    printf("여유\n");
}
```
**왜?** 물통에 물이 가득이면 "가득", 절반쯤이면 "반쯤", 조금이면 "여유"라고 말하죠? 숫자가 큰 기준부터 차례로 물어봐야 정확해요. 위에서부터 읽다가 맞는 첫 번째 칸에서 멈춘답니다.

### 반복문 정답
```c
int sum = 0;
for (int i = 0; i < 5; i++) {
    sum += items[i];
}
printf("%d\n", sum);
```
**왜?** 장바구니에 담긴 물건을 하나씩 세어 더하는 거예요. 묶음이 5개라서 0, 1, 2, 3, 4번을 돌아요(`i < 5`). 30+40+64+10+50 = **194**예요.

### 흐름제어 정답
```c
int total = 0;
for (int i = 0; i < 5; i++) {
    if (total + items[i] > 100) {
        printf("%d번째 묶음부터 못 담음, 담은 개수 %d\n", i + 1, total);
        break;
    }
    total += items[i];
}
```
**출력:** `3번째 묶음부터 못 담음, 담은 개수 70`

**왜?** 가방에 넣기 **전에** "넣어도 100을 안 넘나?" 먼저 확인해야 해요. 30을 넣으면 30, 40을 넣으면 70이에요. 세 번째 64를 넣으면 134라서 넘치니까 넣지 않고 `break`로 멈춰요. 먼저 넣고 나서 확인하면 가방이 터져 버리겠죠? 사람이 세는 순서는 1번째부터라서 번호 `i`(2)에 1을 더해 "3번째"라고 말해요.
