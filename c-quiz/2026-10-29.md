## 📌 엔지니어가 직면한 가상의 문제 1

**[아마존(AWS) 서버 운영팀]** 서버가 남긴 로그 8줄의 상태 코드가 배열에 들어 있어요. `200`은 정상, `404`는 없는 페이지, `500`은 서버 에러예요.

```c
int code[8] = {200, 200, 404, 500, 200, 500, 500, 200};
```

### 조건문 퀴즈 1
상태 코드 한 개 `c`를 받아 다음 메시지를 출력하는 코드를 작성하세요.
- 500이면 "서버 에러! 엔지니어 호출"
- 404이면 "페이지 없음"
- 그 외에는 "정상"

### 반복문 퀴즈 1
`for` 문으로 8개의 코드를 모두 살펴보고, `500` 에러가 모두 몇 번 나왔는지 세어 출력하는 코드를 작성하세요.

### 흐름제어 퀴즈 1
`for` 문으로 로그를 앞에서부터 검사하되,
- `200`(정상)은 건너뛰고(`continue`),
- 500 에러가 **3번째** 나오면 "경보 발령!"을 출력하고 검사를 멈추는(`break`) 코드를 작성하세요.
- 경보가 울렸을 때 몇 번째 줄(1번부터 센 번호)에서 울렸는지도 출력하세요.

## 📌 엔지니어가 창작해야 하는 가상의 프로그램 1

**[닌텐도]** 사용자(`me`)와 컴퓨터(`com`)가 가위바위보를 하는 미니게임을 만들어요. 가위=0, 바위=1, 보=2로 정해요. 먼저 2번 이기는 쪽이 우승(3판 2선승제)이에요.

### 조건문 퀴즈 1
`me`와 `com`을 비교해서 "무승부", "내가 승리", "컴퓨터 승리" 중 하나를 출력하는 코드를 작성하세요. (힌트: 내가 이기는 경우는 `(me - com + 3) % 3 == 1` 일 때예요.)

### 반복문 퀴즈 1
`while` 문으로 "내 점수(`myWin`)나 컴퓨터 점수(`comWin`) 중 누구도 2점이 되지 않았다면" 계속 게임을 진행하는 반복의 뼈대를 작성하세요. (한 판 결과에 따라 점수 올리기까지 포함)

### 흐름제어 퀴즈 1

# 정답 및 해설

## 문제 1: 아마존 서버 에러 로그 점검

### 조건문 정답
```c
if (c == 500) {
    printf("서버 에러! 엔지니어 호출\n");
} else if (c == 404) {
    printf("페이지 없음\n");
} else {
    printf("정상\n");
}
```
**쉬운 설명:** 우체국 분류 상자 같아요. 편지(코드)가 오면 "500 상자 맞니? 아니면 404 상자 맞니? 둘 다 아니면 나머지 상자!" 하고 한 곳에만 넣어요. `==`는 "같니?"라고 묻는 말이고, `=` 하나는 "넣어라!"라는 뜻이라서 헷갈리면 안 돼요.

### 반복문 정답
```c
int count500 = 0;
for (int i = 0; i < 8; i++) {
    if (code[i] == 500) {
        count500++;
    }
}
printf("500 에러 횟수: %d\n", count500);
```
**쉬운 설명:** 출석부를 한 줄씩 보면서 "결석한 친구"가 나올 때마다 연필로 표시하는 것과 같아요. 8줄을 모두 보려고 `i`가 0부터 7까지 가요. 500이 나올 때마다 `count500`을 1 올리면 마지막에 총 **3번**이 나와요.

### 흐름제어 정답
```c
int errCount = 0;
for (int i = 0; i < 8; i++) {
    if (code[i] == 200) {
        continue;             // 정상이면 다음 줄로
    }
    if (code[i] == 500) {
        errCount++;
        if (errCount == 3) {
            printf("경보 발령! (%d번째 줄)\n", i + 1);
            break;            // 더 볼 필요 없음
        }
    }
}
```
**쉬운 설명:** `continue`는 "이 문제는 쉬우니까 **넘어가고 다음 문제로!**"이고, `break`는 "세 번째 불이 났다! **더 이상 찾지 말고 소방차 부르러 가자!**"예요. 이 배열에서는 500이 4번째, 6번째, 7번째 줄에 있어서 3번째 500은 **7번째 줄**에서 경보가 울려요. 컴퓨터는 0부터 세기 때문에 `i`는 6인데, 사람이 읽기 쉽게 `i + 1`을 출력해요. 경보가 울린 뒤에도 계속 검사하면 시간만 낭비라서 `break`로 멈춰요.

## 프로그램: 닌텐도 가위바위보 3판 2선승제

### 조건문 정답
```c
if (me == com) {
    printf("무승부\n");
} else if ((me - com + 3) % 3 == 1) {
    printf("내가 승리\n");
} else {
    printf("컴퓨터 승리\n");
}
```
**쉬운 설명:** 먼저 "둘이 똑같니?"를 물어서 비기는 경우를 따로 빼요. 그다음 이기는 경우인지 확인하고, 나머지는 모두 지는 경우예요. 가위바위보는 세 가지뿐이라서 비기는 것도 아니고 이기는 것도 아니면 질 수밖에 없어요. 그래서 마지막은 조건 없이 `else`로 끝내도 돼요. (`(me - com + 3) % 3`은 가위→바위→보→가위로 돌아가는 원 모양을 계산하는 요술 공식이에요.)

### 반복문 정답
```c
int myWin = 0, comWin = 0, r = 0;
while (myWin < 2 && comWin < 2) {
    int me = mine[r];
    int com = rounds[r];
    r++;
    if (me != com) {
        if ((me - com + 3) % 3 == 1) myWin++;
        else comWin++;
    }
}
```
**쉬운 설명:** "둘 다 아직 2점이 안 됐을 때만 계속 놀아요"라는 뜻이에요. `&&`는 "그리고"라서 **둘 다** 2점 미만일 때만 반복해요. 한 명이라도 2점이 되면 조건이 거짓이 되어 놀이가 끝나요. `r++`로 다음 판으로 넘어가지 않으면 같은 판만 계속 반복돼요.

### 흐름제어 정답
```c
int myWin = 0, comWin = 0;
for (int r = 0; r < 3; r++) {
    int me = mine[r];
    int com = rounds[r];
    if (me == com) {
        printf("무승부! 다시!\n");
        continue;             // 점수 없이 다음 판
    }
    if ((me - com + 3) % 3 == 1) myWin++;
    else comWin++;

    if (myWin == 2 || comWin == 2) {
        break;                // 우승자 결정!
    }
}
if (myWin == 2) printf("내가 우승!\n");
else if (comWin == 2) printf("컴퓨터 우승!\n");
else printf("승부 결정 못함\n");
```
**쉬운 설명:** 무승부는 "비겼으니 점수 없이 **다음 판으로 넘어가**" 하는 `continue`예요. 누군가 2점이 되면 "우승자 나왔다, **경기 끝!**" 하는 `break`예요. `||`는 "또는"이라서 둘 중 **한 명만** 2점이 돼도 멈춰요. 반복이 끝난 뒤에는 점수를 다시 확인해서 우승자를 말해 줘요. 만약 3판 안에 승부가 안 났다면(무승부가 많았을 때) 마지막 `else`로 "승부 결정 못함"을 알려 주는 것도 좋은 습관이에요.

---

오늘의 핵심: **조건문**은 "갈림길에서 길 고르기", **반복문**은 "같은 일을 정해진 만큼 되풀이하기", **continue**는 "이번 차례만 건너뛰기", **break**는 "반복 전체를 끝내기"예요.
