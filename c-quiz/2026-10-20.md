## 📌 엔지니어가 직면한 가상의 문제 1
**[Zoom 화상회의 팀]** 회의 중 영상이 자꾸 끊긴다는 신고가 들어왔어요. 인터넷 응답 시간(ping, ms)을 재서 연결 상태를 알려 주고, 너무 나쁘면 자동으로 다시 연결해야 해요.

### 조건문 퀴즈1
정수 `ping`이 있을 때, 50 미만이면 "쾌적", 50 이상 150 미만이면 "보통", 그 밖에는 "끊김 위험"을 출력하는 코드를 작성하세요.

### 반복문 퀴즈1
`int ping[5] = {30, 45, 200, 60, 90};` 중에서 가장 큰 값(최댓값)을 for문으로 찾아 출력하세요.

### 흐름제어 퀴즈1
`int ping[6] = {40, 0, 80, 300, 50, 60};` (0은 측정 실패)
측정 번호는 1번부터입니다. 값이 0이면 건너뛰고(`continue`), 200 초과인 값을 처음 발견하면 "N번째 측정: 연결 불안정! 재접속"을 출력하고 반복을 끝내세요(`break`). 나머지는 "N번째 측정 OK"를 출력합니다.

# ✅ 정답 및 해설

## 📌 문제 1: Zoom 연결 상태

### 조건문 정답
```c
#include <stdio.h>
int main(void) {
    int ping = 120;
    if (ping < 50) {
        printf("쾌적\n");
    } else if (ping < 150) {
        printf("보통\n");
    } else {
        printf("끊김 위험\n");
    }
    return 0;
}
```
**쉬운 설명:** 놀이공원 키 재기 줄이랑 같아요. 위에서부터 차례로 "너 50 안 되니?" → 아니면 "150 안 되니?" → 그것도 아니면 나머지! `else if`는 앞 질문에서 걸리지 않은 친구에게만 다음 질문을 해요. 그래서 두 번째 칸은 `ping >= 50`이라고 또 쓰지 않아도 돼요. 이미 50 미만은 첫 번째에서 빠졌거든요.

### 반복문 정답
```c
#include <stdio.h>
int main(void) {
    int ping[5] = {30, 45, 200, 60, 90};
    int max = ping[0];
    for (int i = 1; i < 5; i++) {
        if (ping[i] > max) {
            max = ping[i];
        }
    }
    printf("최댓값: %d\n", max);   // 200
    return 0;
}
```
**쉬운 설명:** 달리기 대회에서 "지금까지 1등" 팻말을 들고 있는 친구를 떠올려 보세요. 처음엔 첫 번째 친구가 팻말을 들어요(`max = ping[0]`). 그다음 친구들을 한 명씩 보면서 더 큰 친구가 나오면 팻말을 넘겨줘요. 끝까지 돌면 팻말을 든 친구가 진짜 1등이에요. `max`를 0으로 시작하지 않고 첫 값으로 시작하는 이유는, 값이 전부 음수여도 틀리지 않게 하려는 안전장치예요.

### 흐름제어 정답
```c
#include <stdio.h>
int main(void) {
    int ping[6] = {40, 0, 80, 300, 50, 60};
    for (int i = 0; i < 6; i++) {
        if (ping[i] == 0) {
            continue;                       // 측정 실패는 건너뛰기
        }
        if (ping[i] > 200) {
            printf("%d번째 측정: 연결 불안정! 재접속\n", i + 1);
            break;                          // 반복 끝
        }
        printf("%d번째 측정 OK\n", i + 1);
    }
    return 0;
}
```
출력:
```
1번째 측정 OK
3번째 측정 OK
4번째 측정: 연결 불안정! 재접속
```
**쉬운 설명:** `continue`는 "이 친구는 패스! 다음 친구!", `break`는 "게임 끝! 모두 집에 가요!"예요. 2번째 값 0은 고장이라 패스(`continue`)하고, 4번째 값 300은 너무 나빠서 바로 재접속하고 끝(`break`)이에요. 그래서 5번째, 6번째는 검사하지 않아요. 번호는 `i`가 0부터 시작하니까 사람이 읽기 쉽게 `i + 1`로 출력해요. 또 0 검사를 200 검사보다 먼저 해야 고장 난 값을 잘못 판단하지 않아요.

## 📌 프로그램 1: Spotify 재생목록

### 조건문 정답
```c
#include <stdio.h>
int main(void) {
    int sec = 250;
    if (sec <= 180) {
        printf("짧은 곡\n");
    } else if (sec <= 300) {
        printf("보통 곡\n");
    } else {
        printf("긴 곡\n");
    }
    return 0;
}
```
**쉬운 설명:** 키가 작은 순서대로 줄 세우듯, 작은 기준부터 물어봐요. "180초 이하?" 아니면 "300초 이하?" 아니면 나머지. 정확히 180초는 `<=` 덕분에 "짧은 곡"에 들어가요. `<`와 `<=`를 헷갈리면 경계에 있는 친구가 엉뚱한 반에 가니까 문제를 꼭 다시 읽어요!

### 반복문 정답
```c
#include <stdio.h>
int main(void) {
    int len[5] = {180, 240, 200, 0, 260};
    int total = 0;
    int i = 0;
    while (i < 5) {
        total += len[i];
        i++;
    }
    printf("총 %d분 %d초\n", total / 60, total % 60);   // 총 14분 40초
    return 0;
}
```
**쉬운 설명:** 저금통에 동전을 하나씩 넣듯 `total`에 곡 길이를 차곡차곡 더해요. 저금통은 처음에 비어 있어야 하니까 `total = 0`으로 시작해요. `while`은 `i++`로 번호를 올려 주지 않으면 같은 곡만 영원히 더하는 무한 반복이 되니까 조심! 합계 880초를 60으로 나눈 몫(`/`)이 분(14), 나머지(`%`)가 초(40)예요. (참고: 위 예시의 1080초는 설명용 예시이고, 이 배열의 합계는 880초예요.)

### 흐름제어 정답
```c
#include <stdio.h>
int main(void) {
    int len[5] = {180, 240, 200, 0, 260};
    int total = 0;
    for (int i = 0; i < 5; i++) {
        if (len[i] == 0) {
            continue;                       // 오류 곡 건너뛰기
        }
        total += len[i];
        if (total > 600) {
            printf("%d번째 곡에서 10분 초과! 재생 종료\n", i + 1);
            break;
        }
        printf("%d번째 곡 재생\n", i + 1);
    }
    return 0;
}
```
출력:
```
1번째 곡 재생
2번째 곡 재생
3번째 곡에서 10분 초과! 재생 종료
```
**쉬운 설명:** 10분짜리 놀이기구 이용권을 쓰는 것과 같아요. 곡을 하나 틀 때마다 사용한 시간을 더해요(180 → 420 → 620). 세 번째 곡을 더하니 620초로 600초를 넘었어요! 그래서 "그만!"(`break`) 하고 멈춰요. 순서가 중요해요: **먼저 더하고, 그다음에 넘었는지 확인**해야 해요. 반대로 하면 넘은 곡을 한 곡 더 틀어 버려요. 길이가 0인 곡은 더할 필요도 없으니 맨 앞에서 `continue`로 건너뛰어요.
