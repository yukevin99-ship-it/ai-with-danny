## 🏢 엔지니어가 직면한 가상의 문제 1 — Meta(인스타그램): 스팸 댓글 폭탄 막기

Meta 엔지니어는 게시물에 스팸 댓글이 몰리면 그 게시물을 "검토 대기"로 돌려야 합니다.
최근 댓글 8개의 검사 결과가 `int spam[8]`에 들어 있습니다. (`1` = 스팸, `0` = 정상)
**스팸이 3개 이상이면 검토 대기**로 보내야 합니다.

### ① 조건문 퀴즈
스팸 개수 `cnt`가 3 이상이면 `"검토 대기"`, 아니면 `"정상 게시"`를 출력하는 코드를 작성하세요.

### ② 반복문 퀴즈
`spam[8]`을 처음부터 끝까지 살펴보고, 스팸(1)의 개수를 `cnt`에 세는 코드를 작성하세요.

### ③ 흐름제어 퀴즈 (조건문 + 반복문)
스팸이 3번째로 발견되는 **순간 바로** 검사를 멈추고(`break`) `"검토 대기"`를 출력하세요. 3개 미만이면 끝까지 본 뒤 `"정상 게시"`를 출력하세요.

# ✅ 정답 & 쉬운 해설

## 🏢 문제 1 — Meta 스팸 댓글

### ① 조건문
```c
if (cnt >= 3) {
    printf("검토 대기\n");
} else {
    printf("정상 게시\n");
}
```
**왜?** 조건문은 *갈림길 표지판*이에요. "스팸이 3개 이상이야?" 하고 물어서 **예**면 검토 길, **아니오**면 정상 길로 가요. `>=`는 "크거나 같다"라서 딱 3개일 때도 검토로 가요. `>`만 쓰면 3개일 때 놓치는 실수가 생겨요!

### ② 반복문
```c
int cnt = 0;
for (int i = 0; i < 8; i++) {
    if (spam[i] == 1) {
        cnt++;
    }
}
```
**왜?** 8칸을 하나하나 보는 건 *출석 부르기*와 같아요. 1번부터 8번까지 부르면서 "스팸이면 막대기 하나 긋기" 하는 거죠. `i < 8`인 이유: 칸 번호가 0~7이라서 8에서 멈춰야 해요. (`i <= 8`이면 없는 9번째 칸을 봐서 오류가 나요!) `cnt = 0`은 막대기를 긋기 전에 공책이 깨끗해야 하니까요.

### ③ 흐름제어
```c
int cnt = 0;
int review = 0;
for (int i = 0; i < 8; i++) {
    if (spam[i] == 1) {
        cnt++;
        if (cnt == 3) {
            review = 1;
            break;
        }
    }
}
if (review) printf("검토 대기\n");
else        printf("정상 게시\n");
```
**왜?** 반복문 안에 조건문이 들어가 "세다가, 3이 되면 멈추기"를 해요. 숨바꼭질에서 술래가 3명을 찾으면 "그만!" 하는 것과 같아요. `break`는 **반복문을 완전히 나가는 비상구**예요. 이미 스팸이 3개면 나머지 댓글은 볼 필요가 없어서 시간을 아껴요. 반복이 끝난 뒤 `review`로 "멈춰서 나왔는지, 끝까지 봤는지" 구분해요.

## 💻 문제 2 — 삼성 걸음 수 앱

### ① 조건문
```c
if (today >= 8000) {
    printf("목표 달성!\n");
} else if (today >= 5000) {
    printf("조금만 더!\n");
} else {
    printf("더 걸어요\n");
}
```
**왜?** 갈림길이 세 개예요. 위에서부터 차례로 물어봐요. 점수표에서 "90점 이상이면 A, 아니면 80점 이상이면 B…" 하는 것과 같죠. **큰 기준(8000)을 먼저** 물어야 해요. 5000을 먼저 물으면 10000걸음도 "조금만 더!"가 나와 버려요.

### ② 반복문
```c
int total = 0;
for (int i = 0; i < 7; i++) {
    total += steps[i];
}
printf("총 %d걸음\n", total);
```
**왜?** 돼지 저금통에 7일 동안 매일 동전을 넣는 것과 같아요. `total`은 저금통이고 처음엔 0원이에요. 매번 `steps[i]`를 넣으면(`+=`) 마지막엔 전부 모여 있어요. 출력은 **반복이 끝난 뒤** 해야 해요. 안에서 하면 7번이나 중간 합계가 나와요!

### ③ 흐름제어
```c
int days = 0;
for (int i = 0; i < 7; i++) {
    if (steps[i] == 0) {
        continue;
    }
    if (steps[i] >= 8000) {
        days++;
    }
}
printf("목표 달성 %d일\n", days);
```
**왜?** `continue`는 **"이번 차례만 건너뛰고 다음 친구로 가!"** 라는 뜻이에요. 급식 줄에서 오늘 안 먹는 친구는 건너뛰고 다음 친구에게 가는 것과 같아요. `break`는 줄 자체를 떠나는 것이고, `continue`는 그 친구 한 명만 패스하는 거예요. 둘의 차이가 핵심이에요!

---

## 📌 오늘의 한 줄 정리
- `if` = 갈림길 고르기
- `for` = 정해진 횟수만큼 반복
- `break` = 반복 탈출, `continue` = 이번 차례만 건너뛰기
