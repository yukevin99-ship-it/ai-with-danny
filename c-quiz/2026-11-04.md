## 엔지니어가 직면한 가상의 문제 1

**[Stripe 결제팀]** 고객이 환불을 요청했어요. 결제 5건이 있고, 각 결제는 번호(`id`), 금액(`amount`, 달러), 결제 후 지난 날(`days`), 이미 환불했는지(`refunded`, 1이면 환불 완료)를 가져요. 규칙: 이미 환불된 결제는 다시 처리하지 않아요. 결제 후 30일을 넘으면 "기간 초과"예요. 30일 이내라도 1000달러 이상이면 사람이 확인하는 "수동 승인"이고, 그 밖에는 "자동 환불"이에요.

```c
int amounts[5] = {50, 2000, 80, 30, 700};
// 결제 5건: {id, amount, days, refunded}
// {101,50,3,0} {102,2000,10,0} {103,80,45,0} {104,30,5,1} {105,700,29,0}
```

- **조건문 퀴즈 1:** 결제 하나의 `days`와 `amount`를 보고 "기간 초과", "수동 승인", "자동 환불" 중 하나를 출력하는 코드를 작성하세요. (기간 검사를 먼저!)
- **반복문 퀴즈 1:** 구조체 배열 `pays[5]`를 처음부터 끝까지 돌면서 `"1번 결제: 50달러"` 모양으로 출력하는 코드를 작성하세요. (번호는 1부터)
- **흐름제어 퀴즈 1:** 위 반복문에서 이미 환불된 결제(`refunded == 1`)는 건너뛰고, `days`가 30을 넘는 결제를 처음 발견하면 "만료 결제: (id)"를 출력하고 반복을 멈추는 코드를 작성하세요.
- **배열 퀴즈 1:** `amounts` 배열에서 100달러 미만인 결제가 몇 건인지 세어 `small`에 저장하고 출력하세요.
- **포인터 변수 퀴즈 1:** 포인터 `p`가 `amounts` 배열의 처음부터 끝까지 한 칸씩 이동하며(`p++`), 가리키는 값에서 수수료 5를 빼되 **0보다 큰 칸만** 빼는 코드를 작성하세요. (`amounts[i]`가 아니라 `*p`를 사용)
- **구조체 퀴즈 1:** 번호(`id`), 금액(`amount`), 지난 날(`days`), 환불 여부(`refunded`)를 가진 구조체 `struct Payment`를 정의하세요.
- **함수 퀴즈 1:** 결제 배열의 시작 주소 `p`와 개수 `n`을 받아서, 아직 환불되지 않았고 30일 이내이며 1000달러 미만인(= 자동 환불 가능한) 결제의 개수를 반환하는 함수 `count_auto`를 작성하세요.
- **흐름제어 퀴즈 2 (종합):** `main`에서 결제 5건짜리 구조체 배열과 `count_auto`를 사용해, 개수가 0이면 "자동 환불 없음", 아니면 "자동 환불 가능: N건"을 출력하는 코드를 작성하세요.

## 엔지니어가 창작해야 하는 가상의 프로그램 1

**[Epic Games 포트나이트 팀]** 배틀로얄 게임의 '안전지대' 피해 시스템을 만들어요. 지도 중심 (0,0)에서 반지름 10 안쪽이 안전지대예요. 플레이어는 이름(`name`), 위치(`x`, `y`), 체력(`hp`)을 가져요. 중심에서 거리의 제곱은 `x*x + y*y`이고, 이것이 `r*r`(=100)보다 **크면** 안전지대 밖이에요. (딱 100이면 아직 안쪽!) 체력이 0 이하인 플레이어는 이미 탈락했으니 검사하지 않아요.

int xs[5]  = {3, 9, -6, 12, 0};
int ys[5]  = {4, 8, 8, 0, 0};

- **배열 퀴즈 1:** `xs`, `ys`, `hps` 배열을 이용해, 살아 있는(`hps[i] > 0`) 플레이어 중 안전지대 밖에 있는 사람 수를 `out_cnt`에 저장하고 출력하세요. (반지름은 10)
- **포인터 변수 퀴즈 1:** 포인터 `p`가 `hps` 배열의 처음부터 끝까지 한 칸씩 이동하며(`p++`), 체력이 0보다 큰 칸만 `10`을 빼는 코드를 작성하세요. (`*p` 사용, 이미 0인 칸은 그대로)
- **구조체 퀴즈 1:** 이름(`char name[20]`), 위치(`int x`, `int y`), 체력(`int hp`)을 가진 구조체 `struct Player`를 정의하고, 변수 `one`을 `"Neo"`, `5`, `12`, `80`으로 만들어 이름과 "안전" 또는 "밖"을 출력하는 코드를 작성하세요.
- **함수 퀴즈 1:** 플레이어 배열 시작 주소 `p`, 개수 `n`, 반지름 `r`을 받아, 살아 있고 안전지대 밖에 있는 플레이어 중 체력이 가장 낮은 플레이어의 **주소**를 반환하는 함수 `find_weakest_outside`를 작성하세요. 대상이 없으면 `NULL`을 반환하세요.
- **흐름제어 퀴즈 2 (종합):** `main`에서 `find_weakest_outside`를 호출해 `NULL`이면 "모두 안전", 아니면 "가장 위험: 이름 (체력)"을 출력하는 코드를 작성하세요.

# 정답 및 해설 (초등학교 5학년 눈높이)

## 문제 1: Stripe 결제 환불 자격 검사

### 조건문 정답
```c
if (days > 30) {
    printf("기간 초과\n");
} else if (amount >= 1000) {
    printf("수동 승인\n");
} else {
    printf("자동 환불\n");
}
```
**왜 이렇게?** 놀이공원 입장권을 생각해 보세요. 입장권 기간이 지났으면 큰돈이든 작은돈이든 들어갈 수 없죠? 그래서 "기간이 지났니?"를 **맨 먼저** 물어봐요. 기간이 안 지났을 때만 "금액이 큰가?"를 물어보고, 둘 다 아니면 마지막 `else`로 자동 환불이에요. 순서를 바꾸면 기간이 지난 2000달러가 "수동 승인"이 되어 버려요.

### 반복문 정답
```c
for (int i = 0; i < 5; i++) {
    printf("%d번 결제: %d달러\n", i + 1, pays[i].amount);
}
```
**왜 이렇게?** 결제가 5건으로 정해져 있어서 `for`가 딱이에요. 컴퓨터는 0부터 세지만 사람은 1번부터 부르니까, 화면에 보일 때만 `i + 1`을 써요. `i < 5`라야 0~4, 딱 5칸만 열어요.

### 흐름제어 정답 (1)
```c
for (int i = 0; i < 5; i++) {
    if (pays[i].refunded == 1) {
        continue;
    }
    if (pays[i].days > 30) {
        printf("만료 결제: %d\n", pays[i].id);
        break;
    }
}
```
**왜 이렇게?** `continue`는 "이 친구는 패스, 다음 친구!"이고, `break`는 "찾았다! 이제 그만 찾아도 돼!"예요. 이미 환불한 결제는 숙제를 이미 낸 친구 같아서 다시 볼 필요가 없고, 만료된 결제를 하나 찾으면 바로 알리고 멈춰요. 정답 출력은 `만료 결제: 103`이에요. (104번은 환불 완료라 건너뛰고, 그 앞의 103번이 먼저 걸려요.)

### 배열 정답
```c
int small = 0;
for (int i = 0; i < 5; i++) {
    if (amounts[i] < 100) {
        small++;
    }
}
printf("%d\n", small);   // 3
```
**왜 이렇게?** 반에서 "키 140 미만 손들어!" 하고 손든 사람 수를 세는 것과 같아요. 조건에 맞을 때만 `small++`로 막대기를 하나 더 그어요. 50, 80, 30 세 개라서 답은 3이에요.

### 포인터 정답
```c
int *p = amounts;
for (int i = 0; i < 5; i++) {
    if (*p > 0) {
        *p = *p - 5;
    }
    p++;
}
```
**왜 이렇게?** 배열 이름 `amounts`는 "첫 칸의 주소"예요. `p`는 손가락, `*p`는 손가락이 가리키는 칸 안의 값이에요. 값을 바꾼 뒤 `p++`로 손가락을 다음 칸으로 옮겨요. `p++`는 `if` 바깥에 두어야 해요! 안에 두면 값이 0인 칸에서 손가락이 못 움직여서 계속 같은 칸만 보게 돼요.

### 구조체 정답
```c
struct Payment {
    int id;
    int amount;
    int days;
    int refunded;
};
```
**왜 이렇게?** 결제 한 건에는 번호, 금액, 지난 날, 환불 여부가 항상 같이 다녀요. 배열 4개로 따로 두면 짝이 어긋나기 쉬워서, 하나의 "결제 영수증 카드"로 묶어요.

### 함수 정답
```c
int count_auto(struct Payment *p, int n) {
    int cnt = 0;
    for (int i = 0; i < n; i++) {
        if (p[i].refunded == 1) {
            continue;
        }
        if (p[i].days <= 30 && p[i].amount < 1000) {
            cnt++;
        }
    }
    return cnt;
}
```
**왜 이렇게?** 조건 두 개(`30일 이내` 그리고 `1000달러 미만`)를 **모두** 만족해야 하니까 `&&`를 써요. `return cnt;`는 반드시 **반복문이 끝난 뒤**에 둬요. 안에 두면 첫 결제만 세고 돌아가 버려요. 배열을 받을 때는 통째로 복사하지 않고 시작 주소(`p`)와 개수(`n`)만 받는 게 C언어의 약속이에요.

### 흐름제어 정답 (종합)
```c
struct Payment pays[5] = {
    {101, 50, 3, 0}, {102, 2000, 10, 0}, {103, 80, 45, 0},
    {104, 30, 5, 1}, {105, 700, 29, 0}
};
int n = count_auto(pays, 5);
if (n == 0) {
    printf("자동 환불 없음\n");
} else {
    printf("자동 환불 가능: %d건\n", n);
}
```
**왜 이렇게?** 101번(3일, 50달러)과 105번(29일, 700달러)만 자동 환불이 돼요. 102는 금액이 커서, 103은 기간이 지나서, 104는 이미 환불해서 빠져요. 출력은 `자동 환불 가능: 2건`이에요. 결과를 변수 `n`에 한 번 받아 두면 `if`에서 여러 번 쓸 수 있어요.

## 프로그램 1: Epic Games 안전지대 피해 시스템

### 조건문 정답
```c
if (d2 > r * r) {
    printf("밖: 피해\n");
} else {
    printf("안전\n");
}
```
**왜 이렇게?** 운동장에 그린 큰 원 안에서 술래잡기를 한다고 생각해 보세요. 원의 선 위에 서 있으면 아직 안쪽이에요. 그래서 `>=`가 아니라 `>`를 써요. `d2`는 `x*x + y*y`로 구하고, 제곱끼리 비교하면 어려운 제곱근 계산을 하지 않아도 돼요.

### 반복문 정답
```c
for (int i = 0; i < 5; i++) {
    printf("%d번 플레이어: %s (%d,%d)\n", i + 1, players[i].name, players[i].x, players[i].y);
}
```
**왜 이렇게?** 글자(이름)는 `%s`, 숫자는 `%d`로 출력해요. 번호는 사람 눈높이에 맞춰 `i + 1`!

### 흐름제어 정답 (1)
```c
for (int i = 0; i < 5; i++) {
    if (players[i].hp <= 0) {
        continue;
    }
    int d2 = players[i].x * players[i].x + players[i].y * players[i].y;
    if (d2 > 100 && players[i].hp <= 10) {
        printf("탈락 임박: %s\n", players[i].name);
        break;
    }
}
```
**왜 이렇게?** 이미 탈락한 친구는 `continue`로 건너뛰어요. "밖에 있고" 그리고 "체력이 10 이하"인 친구는 곧 쓰러질 친구라서, 찾으면 `break`로 바로 알려요. 이 데이터에서는 D(12,0,체력 10)가 걸려서 `탈락 임박: D`가 나와요.

### 배열 정답
```c
int out_cnt = 0;
for (int i = 0; i < 5; i++) {
    if (hps[i] > 0 && xs[i] * xs[i] + ys[i] * ys[i] > 10 * 10) {
        out_cnt++;
    }
}
printf("%d\n", out_cnt);   // 2
```
**왜 이렇게?** 같은 번호 칸끼리(`xs[i]`, `ys[i]`, `hps[i]`)가 한 사람의 정보예요. 거리 제곱은 A=25, B=145, C=100, D=144, E=0이에요. 100보다 큰 B, D가 밖이고 둘 다 살아 있어서 답은 2예요. C는 딱 100이라 안쪽이에요!

### 포인터 정답
```c
int *p = hps;
for (int i = 0; i < 5; i++) {
    if (*p > 0) {
        *p = *p - 10;
    }
    p++;
}
// hps: {90, 40, 90, 0, 0}
```
**왜 이렇게?** 손가락(`p`)이 가리키는 칸의 값이 0보다 클 때만 10을 빼요. 이미 0인 친구에게 또 빼면 체력이 마이너스가 되어 이상해져요. 마지막의 `p++`는 `if` 바깥에서 꼭 손가락을 옮겨 줘요.

### 구조체 정답
```c
#include <string.h>

struct Player {
    char name[20];
    int x;
    int y;
    int hp;
};

struct Player one;
strcpy(one.name, "Neo");
one.x = 5;
one.y = 12;
one.hp = 80;
if (one.x * one.x + one.y * one.y > 100) {
    printf("%s 밖\n", one.name);
} else {
    printf("%s 안전\n", one.name);
}
// Neo 밖  (25 + 144 = 169 > 100)
```
**왜 이렇게?** 글자 배열은 `=`로 한 번에 넣을 수 없어서 `strcpy`로 복사해요. 구조체 안의 값은 점(`.`)으로 꺼내요: `one.x`.

### 함수 정답
```c
struct Player *find_weakest_outside(struct Player *p, int n, int r) {
    struct Player *weakest = NULL;
    for (int i = 0; i < n; i++) {
        if (p[i].hp <= 0) {
            continue;
        }
        if (p[i].x * p[i].x + p[i].y * p[i].y > r * r) {
            if (weakest == NULL || p[i].hp < weakest->hp) {
                weakest = &p[i];
            }
        }
    }
    return weakest;
}
```
**왜 이렇게?** `weakest`를 `NULL`("아직 아무도 없음")로 시작해서, 자격 있는 사람(살아 있고 밖에 있는 사람)이 나올 때마다 비교해요. 첫 사람은 비교 상대가 없으니 `weakest == NULL`이면 무조건 뽑아요. 이 조건을 `||`의 **앞**에 둬야 해요. 뒤에 두면 `NULL`을 열어 보다가 프로그램이 멈춰요. `&p[i]`는 "i번 칸의 주소"예요.

### 흐름제어 정답 (종합)
```c
struct Player *w = find_weakest_outside(players, 5, 10);
if (w == NULL) {
    printf("모두 안전\n");
} else {
    printf("가장 위험: %s (%d)\n", w->name, w->hp);
}
// 가장 위험: D (10)
```
**왜 이렇게?** 주소를 받았으면 쓰기 전에 **반드시** `NULL`인지 먼저 확인해요. 빈 상자를 열면 프로그램이 멈춰요. 구조체를 가리키는 포인터에서는 `w->name`처럼 화살표로 안의 값을 읽어요. 밖에 있는 살아 있는 사람은 B(체력 50)와 D(체력 10)이고, 더 약한 D가 뽑혀요.
