# ✅ 정답과 해설 (초등학교 5학년 눈높이)

## 엔지니어가 직면한 가상의 문제 1 (Tesla)

### 조건문 정답
```c
if (s == 1) {
    printf("go\n");
} else if (s == 2) {
    printf("slow\n");
} else if (s == 3) {
    printf("stop\n");
} else {
    printf("check\n");
}
```
**왜?** 신호등 앞에서 "초록이야? 아니면 노랑이야? 아니면 빨강이야?" 하고 차례로 물어보는 거예요. `else if`는 "앞에서 아니었으면 그다음 질문!"이라는 뜻이고, `else`는 "다 아니면 이거!"예요. 그래서 못 읽은 0이나 이상한 숫자도 "check"로 안전하게 잡혀요. 그리고 같은지 물어볼 땐 `=`가 아니라 `==`(등호 두 개)를 써야 해요!

### 반복문 정답
```c
int green = 0;
for (int i = 0; i < 6; i++) {
    if (sig[i] == 1) {
        green++;
    }
}
printf("초록불 %d번\n", green);
```
**왜?** 교실에서 "초록색 좋아하는 사람 손 들어!" 하고 한 명씩 보면서 세는 것과 같아요. `green`은 세는 숫자 칸이고 처음엔 0이에요. 6개를 하나씩 보다가(`for`) 초록이면(`if`) 1씩 올려요(`green++`). 정답은 3번이에요. `i < 6`이니까 0~5번 칸만 봐서 딱 6개를 봐요.

### 흐름제어 정답
```c
for (int i = 0; i < 6; i++) {
    if (sig[i] == 0) {
        printf("%d번째: 못 읽음\n", i + 1);
        continue;
    }
    if (sig[i] == 3) {
        printf("%d번째: 정지!\n", i + 1);
        break;
    }
    printf("%d번째: 주행\n", i + 1);
}
```
출력: `1번째: 주행` → `2번째: 주행` → `3번째: 못 읽음` → `4번째: 주행` → `5번째: 정지!` (6번째는 안 봐요)

**왜?** `continue`는 "이번 것만 패스하고 다음으로 가!", `break`는 "여기서 멈춰, 끝!"이에요. 앞이 빨간불인데 더 확인할 필요는 없죠? 그래서 `break`로 바로 멈춰요. 그리고 사람은 "1번째"부터 세지만 컴퓨터 칸 번호 `i`는 0부터라서 출력할 땐 `i + 1`을 써요. 또 `continue`는 `printf("주행")`보다 **위에** 있어야 해요. 아래에 두면 못 읽은 것도 "주행"이라고 해 버려요!

## 엔지니어가 창작해야 하는 가상의 프로그램 1 (배달의민족)

### 조건문 정답
```c
if (total >= 30000) {
    printf("3000원 할인\n");
} else if (total >= 20000) {
    printf("1000원 할인\n");
} else {
    printf("할인 없음\n");
}
```
**왜?** **큰 금액부터** 물어봐야 해요. 만약 20000 이상을 먼저 물으면 35000원인 손님도 "20000 이상이네!" 하고 1000원 할인만 받고 끝나 버려요. 놀이공원에서 "키 150cm 넘으면 큰 롤러코스터, 120cm 넘으면 중간 놀이기구"를 확인할 때 큰 기준부터 보는 것과 같아요.

### 반복문 정답
```c
int i = 0;
int sum = 0;
while (i < 5) {
    sum += price[i];
    i++;
}
printf("합계 %d원\n", sum);
```
정답은 34000원이에요.

**왜?** `while`은 "조건이 맞는 동안 계속 해!"예요. 그런데 `i++`(다음 칸으로 가기)를 깜빡하면 `i`가 계속 0이라서 **영원히 끝나지 않아요**(무한 반복). 계단을 오를 때 한 칸씩 올라가야 꼭대기에 도착하는 것과 같아요. `sum`은 0에서 시작하는 빈 장바구니 합계 칸이에요.

### 흐름제어 정답
```c
int sum = 0;
for (int i = 0; i < 5; i++) {
    if (price[i] == 0) {
        continue;
    }
    sum += price[i];
    if (sum >= 25000) {
        printf("무료배달 달성!\n");
        break;
    }
}
printf("합계 %d원\n", sum);
```
출력: `무료배달 달성!` → `합계 25000원` (8000 → 20000 → 25000에서 멈춰요. 2번 메뉴 0원은 건너뛰고, 마지막 9000원은 더하지 않아요.)

**왜?** 취소된 메뉴(0원)는 `continue`로 패스해요. 그리고 **더한 다음에** 25000이 넘었는지 확인해야 해요. 저금통에 동전을 넣고 나서 "목표 금액 모였나?" 하고 세어 보는 것과 같아요. 넣기 전에 확인하면 한 박자 늦어요. 목표를 채우면 `break`로 반복을 끝내요. 이미 목표를 이뤘는데 계속 더할 필요는 없으니까요!

## 📌 오늘의 한 줄 정리
- `if / else if / else` = 순서대로 묻는 갈림길 (큰 기준부터!)
- `while` = 조건이 맞는 동안 반복 (`i++` 잊지 말기)
- `continue` = 이번만 패스, `break` = 반복 끝!
