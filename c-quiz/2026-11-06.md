## 엔지니어가 직면한 가상의 문제 1

**[Discord 안전팀]** 서버 멤버 5명이 메시지를 보내려 해요. 각 멤버는 번호(`id`), 역할(`role`, 0=게스트 1=멤버 2=관리자), 보내려는 메시지 길이(`len`), 차단 여부(`banned`, 1이면 차단)를 가져요. 규칙: 차단된 멤버는 "차단"이에요. 관리자(2)는 길이와 상관없이 "전송 허용"이에요. 멤버(1)는 길이가 2000 **이하**면 "전송 허용", 넘으면 "길이 초과"예요. 게스트(0)는 "읽기 전용"이에요.

```c
int lens[5] = {3000, 2500, 50, 100, 2000};
// 멤버 5명: {id, role, len, banned}
// {1,2,3000,0} {2,1,2500,0} {3,0,50,0} {4,1,100,1} {5,1,2000,0}
```

- **조건문 퀴즈 1:** 멤버 하나의 `banned`, `role`, `len`을 보고 "차단", "전송 허용", "길이 초과", "읽기 전용" 중 하나를 출력하는 코드를 작성하세요. (차단 검사를 먼저!)
- **반복문 퀴즈 1:** 구조체 배열 `members[5]`를 처음부터 끝까지 돌면서 `"1번 멤버: 역할 2"` 모양으로 출력하는 코드를 작성하세요. (번호는 1부터)
- **흐름제어 퀴즈 1:** 위 반복문에서 차단된 멤버(`banned == 1`)는 건너뛰고, 멤버(`role == 1`)이면서 `len`이 2000을 넘는 사람을 처음 발견하면 "길이 초과 멤버: (id)"를 출력하고 반복을 멈추는 코드를 작성하세요.
- **배열 퀴즈 1:** `lens` 배열에서 2000을 **넘는** 메시지가 몇 개인지 세어 `cnt`에 저장하고 출력하세요.
- **포인터 변수 퀴즈 1:** 포인터 `p`가 `lens` 배열의 처음부터 끝까지 한 칸씩 이동하며(`p++`), 가리키는 값이 2000보다 **큰 칸만** 2000으로 잘라내는 코드를 작성하세요. (`lens[i]`가 아니라 `*p`를 사용)
- **구조체 퀴즈 1:** 번호(`id`), 역할(`role`), 길이(`len`), 차단 여부(`banned`)를 가진 구조체 `struct Member`를 정의하세요.
- **함수 퀴즈 1:** 멤버 배열의 시작 주소 `m`과 개수 `n`을 받아서, 차단되지 않았고 "전송 허용"이 되는 멤버의 수를 반환하는 함수 `count_allowed`를 작성하세요.
- **흐름제어 퀴즈 2 (종합):** `main`에서 멤버 5명짜리 구조체 배열과 `count_allowed`를 사용해, 개수가 0이면 "전송 가능 없음", 아니면 "전송 가능: N명"을 출력하는 코드를 작성하세요.

## 엔지니어가 창작해야 하는 가상의 프로그램 1

**[Waymo 자율주행팀]** 자율주행차가 주변 차 5대와 안전거리를 지키는지 점검하는 프로그램을 만들어요. 주변 차의 속도가 `speed`(km/h)이면 안전거리는 `speed / 2`(m)예요. 차와의 간격 `gap`이 안전거리보다 **작으면** "위험"이에요. (딱 같으면 아직 안전!) 주차된 차(`parked == 1`)는 움직이지 않으니 검사하지 않아요.

```c
int gaps[5]   = {30, 20, 50, 5, 10};
int speeds[5] = {80, 60, 100, 40, 120};
int parks[5]  = {0, 0, 0, 0, 1};
// 이름: Sedan, Truck, Bus, Bike, Van
```

- **조건문 퀴즈 1:** 안전거리 `safe`(= `speed / 2`)보다 `gap`이 작으면 "위험", 아니면 "안전"을 출력하는 코드를 작성하세요.
- **반복문 퀴즈 1:** 구조체 배열 `cars[5]`를 돌면서 `"1번 차량: Sedan (간격 30m)"` 모양으로 출력하는 코드를 작성하세요. (번호는 1부터)
- **흐름제어 퀴즈 1:** 위 반복문에서 주차된 차는 건너뛰고, 위험한 차를 처음 발견하면 "급감속: 이름"을 출력하고 반복을 멈추는 코드를 작성하세요.
- **배열 퀴즈 1:** `gaps`, `speeds`, `parks` 배열을 이용해, 주행 중(`parks[i] == 0`)이면서 위험한 차가 몇 대인지 `danger`에 저장하고 출력하세요.
- **포인터 변수 퀴즈 1:** 포인터 `p`가 `gaps` 배열의 처음부터 끝까지 한 칸씩 이동하며(`p++`), 값이 10 **미만인 칸만** 10으로 올리는(최소 간격 보정) 코드를 작성하세요. (`*p` 사용, 10 이상인 칸은 그대로)
- **구조체 퀴즈 1:** 이름(`char name[20]`), 간격(`int gap`), 속도(`int speed`), 주차 여부(`int parked`)를 가진 구조체 `struct Car`를 정의하고, 변수 `one`을 `"Cone"`, `15`, `40`, `0`으로 만들어 이름과 "위험" 또는 "안전"을 출력하는 코드를 작성하세요.
- **함수 퀴즈 1:** 차량 배열 시작 주소 `p`와 개수 `n`을 받아, 주행 중이면서 위험한 차 중 간격이 가장 작은 차의 **인덱스(번호표)** 를 반환하는 함수 `find_closest_danger`를 작성하세요. 대상이 없으면 `-1`을 반환하세요.
- **흐름제어 퀴즈 2 (종합):** `main`에서 `find_closest_danger`를 호출해 `-1`이면 "모두 안전", 아니면 "가장 가까운 위험: 이름 (간격m)"을 출력하는 코드를 작성하세요.

# 정답 및 해설 (초등학교 5학년 눈높이)

## 문제 1: Discord 서버 메시지 권한 검사

### 조건문 정답
```c
if (banned == 1) {
    printf("차단\n");
} else if (role == 2) {
    printf("전송 허용\n");
} else if (role == 1) {
    if (len <= 2000) {
        printf("전송 허용\n");
    } else {
        printf("길이 초과\n");
    }
} else {
    printf("읽기 전용\n");
}
```
**왜 이렇게?** 놀이공원 입구를 떠올려 보세요. 먼저 "입장 금지 명단에 있니?"(차단)를 확인해요. 명단에 있으면 더 물어볼 필요가 없어요. 그다음 "특별 안내원(관리자)이니?" → 통과! 아니면 "일반 손님(멤버)이니?" → 짐 크기(길이)가 2000 **이하**일 때만 통과예요. 딱 2000도 통과니까 `<`가 아니라 `<=`예요. 나머지(게스트)는 구경만 해요.

### 반복문 정답
```c
for (int i = 0; i < 5; i++) {
    printf("%d번 멤버: 역할 %d\n", i + 1, members[i].role);
}
```
**왜 이렇게?** 멤버가 5명으로 정해져 있어서 `for`가 딱이에요. 컴퓨터는 0부터 세지만 사람은 1번부터 부르니까, 화면에 보일 때만 `i + 1`을 써요. `i < 5`라야 0~4, 딱 5칸만 열어요.

### 흐름제어 정답 (1)
```c
for (int i = 0; i < 5; i++) {
    if (members[i].banned == 1) {
        continue;
    }
    if (members[i].role == 1 && members[i].len > 2000) {
        printf("길이 초과 멤버: %d\n", members[i].id);
        break;
    }
}
```
**왜 이렇게?** `continue`는 "이 친구는 입장 금지니까 패스, 다음 친구!"이고, `break`는 "찾았다! 이제 그만 찾아도 돼!"예요. 정답 출력은 `길이 초과 멤버: 2`예요. 1번은 관리자라서 해당이 없고, 2번(멤버, 길이 2500)이 처음으로 걸려요. `&&`(그리고)는 두 조건이 **모두** 맞아야 해요.

### 배열 정답
```c
int cnt = 0;
for (int i = 0; i < 5; i++) {
    if (lens[i] > 2000) {
        cnt++;
    }
}
printf("%d\n", cnt);   // 2
```
**왜 이렇게?** "긴 편지 몇 통이야?" 하고 막대기를 그어 세는 것과 같아요. 조건에 맞을 때만 `cnt++`로 하나 더 그어요. 3000, 2500 두 개가 넘어서 답은 2예요. 딱 2000인 마지막 칸은 "넘는" 게 아니라서 세지 않아요!

### 포인터 정답
```c
int *p = lens;
for (int i = 0; i < 5; i++) {
    if (*p > 2000) {
        *p = 2000;
    }
    p++;
}
// lens는 {2000, 2000, 50, 100, 2000}이 돼요
```
**왜 이렇게?** 배열 이름 `lens`는 "첫 칸의 주소"예요. `p`는 손가락, `*p`는 손가락이 가리키는 칸 안의 값이에요. 2000보다 큰 칸만 2000으로 잘라 내고, 손가락은 `p++`로 다음 칸으로 옮겨요. `p++`는 `if` 바깥에 둬야 해요. 안에 두면 작은 값 칸에서 손가락이 못 움직여서 계속 같은 칸만 보게 돼요.

### 구조체 정답
```c
struct Member {
    int id;
    int role;
    int len;
    int banned;
};
```
**왜 이렇게?** 멤버 한 명에게는 번호, 역할, 길이, 차단 여부가 항상 같이 다녀요. 배열 4개로 따로 두면 짝이 어긋나기 쉬워서, 하나의 "이름표 카드"로 묶어요.

### 함수 정답
```c
int count_allowed(struct Member *m, int n) {
    int cnt = 0;
    for (int i = 0; i < n; i++) {
        if (m[i].banned == 1) {
            continue;
        }
        if (m[i].role == 2) {
            cnt++;
        } else if (m[i].role == 1 && m[i].len <= 2000) {
            cnt++;
        }
    }
    return cnt;
}
```
**왜 이렇게?** 앞에서 쓴 "차단 → 관리자 → 멤버" 순서를 그대로 함수에 담았어요. `return cnt;`는 반드시 **반복문이 끝난 뒤**에 둬요. 안에 두면 첫 멤버만 세고 돌아가 버려요. 배열을 받을 때는 통째로 복사하지 않고 시작 주소(`m`)와 개수(`n`)만 받는 게 C언어의 약속이에요.

### 흐름제어 정답 (종합)
```c
struct Member members[5] = {
    {1, 2, 3000, 0}, {2, 1, 2500, 0}, {3, 0, 50, 0},
    {4, 1, 100, 1}, {5, 1, 2000, 0}
};
int n = count_allowed(members, 5);
if (n == 0) {
    printf("전송 가능 없음\n");
} else {
    printf("전송 가능: %d명\n", n);
}
```
**왜 이렇게?** 1번(관리자)과 5번(멤버, 딱 2000)만 보낼 수 있어요. 2번은 길이 초과, 3번은 게스트, 4번은 차단이라 빠져요. 출력은 `전송 가능: 2명`이에요. 결과를 변수 `n`에 한 번 받아 두면 `if`에서 여러 번 쓸 수 있어요.

## 프로그램 1: Waymo 자율주행 안전거리 점검

### 조건문 정답
```c
int safe = speed / 2;
if (gap < safe) {
    printf("위험\n");
} else {
    printf("안전\n");
}
```
**왜 이렇게?** 달리는 친구 뒤를 따라갈 때, 그 친구가 빠를수록 더 멀리 떨어져야 안전해요. 딱 안전거리만큼 떨어져 있다면 아직 괜찮으니 `<=`가 아니라 `<`를 써요.

### 반복문 정답
```c
for (int i = 0; i < 5; i++) {
    printf("%d번 차량: %s (간격 %dm)\n", i + 1, cars[i].name, cars[i].gap);
}
```
**왜 이렇게?** 글자(이름)는 `%s`, 숫자는 `%d`로 출력해요. 번호는 사람 눈높이에 맞춰 `i + 1`!

### 흐름제어 정답 (1)
```c
for (int i = 0; i < 5; i++) {
    if (cars[i].parked == 1) {
        continue;
    }
    if (cars[i].gap < cars[i].speed / 2) {
        printf("급감속: %s\n", cars[i].name);
        break;
    }
}
```
**왜 이렇게?** 주차된 차는 움직이지 않으니 `continue`로 넘어가요. 정답 출력은 `급감속: Sedan`이에요. Sedan은 안전거리가 80/2=40m인데 간격이 30m라서 첫 번째부터 걸려요. 찾았으니 `break`로 멈춰요.

### 배열 정답
```c
int danger = 0;
for (int i = 0; i < 5; i++) {
    if (parks[i] == 1) {
        continue;
    }
    if (gaps[i] < speeds[i] / 2) {
        danger++;
    }
}
printf("%d\n", danger);   // 3
```
**왜 이렇게?** 세 배열의 같은 번호 칸은 같은 차의 정보예요. Sedan(30<40), Truck(20<30), Bike(5<20)이 위험하고 Bus(50 = 50)는 안전, Van은 주차라서 빼요. 그래서 답은 3이에요.

### 포인터 정답
```c
int *p = gaps;
for (int i = 0; i < 5; i++) {
    if (*p < 10) {
        *p = 10;
    }
    p++;
}
// gaps는 {30, 20, 50, 10, 10}이 돼요
```
**왜 이렇게?** 10보다 작은 칸(5)만 10으로 올려요. 이미 10인 칸(마지막)은 `<`라서 그대로예요. 손가락 `p`는 매 칸마다 `p++`로 한 칸씩 옮겨요.

### 구조체 정답
```c
struct Car {
    char name[20];
    int gap;
    int speed;
    int parked;
};

struct Car one = {"Cone", 15, 40, 0};
if (one.gap < one.speed / 2) {
    printf("%s: 위험\n", one.name);
} else {
    printf("%s: 안전\n", one.name);
}
```
**왜 이렇게?** 이름은 글자 칸(`char name[20]`), 나머지는 숫자 칸이에요. 값은 선언한 순서대로 채워져요. 안전거리는 40/2=20인데 간격이 15라서 `Cone: 위험`이 출력돼요. 구조체 안의 값은 점(`.`)으로 꺼내요.

### 함수 정답
```c
int find_closest_danger(struct Car *p, int n) {
    int best = -1;
    for (int i = 0; i < n; i++) {
        if (p[i].parked == 1) {
            continue;
        }
        if (p[i].gap < p[i].speed / 2) {
            if (best == -1 || p[i].gap < p[best].gap) {
                best = i;
            }
        }
    }
    return best;
}
```
**왜 이렇게?** `best`는 "지금까지 1등 후보의 번호표"예요. 처음엔 후보가 없으니 -1이에요(0번도 진짜 번호라서 -1로 "없음"을 표시해요). 위험한 차를 만날 때마다 "후보가 없거나, 후보보다 더 가까우면" 번호표를 바꿔요. `best == -1 ||`가 앞에 와야 해요. 뒤에 오면 `p[-1]`이라는 없는 칸을 들여다보게 돼요! 결과는 Bike의 번호표 `3`이에요.

### 흐름제어 정답 (종합)
```c
struct Car cars[5] = {
    {"Sedan", 30, 80, 0}, {"Truck", 20, 60, 0}, {"Bus", 50, 100, 0},
    {"Bike", 5, 40, 0}, {"Van", 10, 120, 1}
};
int idx = find_closest_danger(cars, 5);
if (idx == -1) {
    printf("모두 안전\n");
} else {
    printf("가장 가까운 위험: %s (간격 %dm)\n", cars[idx].name, cars[idx].gap);
}
```
**왜 이렇게?** 함수가 번호표 `3`을 돌려주면 `cars[3]`이 Bike예요. 번호표가 -1이면 "위험한 차 없음"이니까 안전 메시지를 보여요. 출력은 `가장 가까운 위험: Bike (간격 5m)`이에요. Van은 간격이 10m로 더 위험해 보이지만 주차 중이라 처음부터 후보에서 빠져요!
