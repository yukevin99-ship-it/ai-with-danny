## 엔지니어가 직면한 가상의 문제 1

**[YouTube 댓글 관리팀]** 영상 하나에 댓글 5개가 달렸어요. 각 댓글은 번호(`id`), 신고 수(`reports`), 좋아요 수(`likes`), 고정 여부(`pinned`, 1이면 고정)를 가져요. 규칙: 고정된 댓글은 신고가 아무리 많아도 "고정"이에요. 그 밖에는 신고가 10 **이상**이면 "숨김", 3 이상 10 미만이면 "검토", 그보다 적으면 "표시"예요.

```c
int reports[5] = {2, 4, 15, 0, 11};
// 댓글 5개: {id, reports, likes, pinned}
// {1,2,5,0} {2,4,80,0} {3,15,900,1} {4,0,30,0} {5,11,7,0}
```

- **조건문 퀴즈 1:** 댓글 하나의 `pinned`, `reports`를 보고 "고정", "숨김", "검토", "표시" 중 하나를 출력하는 코드를 작성하세요. (고정 검사를 먼저!)
- **반복문 퀴즈 1:** 구조체 배열 `comments[5]`를 처음부터 끝까지 돌면서 `"1번 댓글: 신고 2"` 모양으로 출력하는 코드를 작성하세요. (번호는 1부터)
- **흐름제어 퀴즈 1:** 위 반복문에서 고정된 댓글(`pinned == 1`)은 건너뛰고, 신고가 10 이상인 댓글을 처음 발견하면 "숨김 댓글: (id)"를 출력하고 반복을 멈추는 코드를 작성하세요.
- **배열 퀴즈 1:** `reports` 배열에서 10 **이상**인 값이 몇 개인지 세어 `cnt`에 저장하고 출력하세요.
- **포인터 변수 퀴즈 1:** 포인터 `p`가 `reports` 배열의 처음부터 끝까지 한 칸씩 이동하며(`p++`), 가리키는 값이 10보다 **큰 칸만** 10으로 줄이는 코드를 작성하세요. (`reports[i]`가 아니라 `*p`를 사용)
- **구조체 퀴즈 1:** 번호(`id`), 신고 수(`reports`), 좋아요 수(`likes`), 고정 여부(`pinned`)를 가진 구조체 `struct Comment`를 정의하세요.
- **함수 퀴즈 1:** 댓글 배열의 시작 주소 `c`와 개수 `n`을 받아서, 고정되지 않았고 신고가 10 이상인 댓글의 수를 반환하는 함수 `count_hidden`을 작성하세요.
- **흐름제어 퀴즈 2 (종합):** `main`에서 댓글 5개짜리 구조체 배열과 `count_hidden`을 사용해, 개수가 0이면 "숨길 댓글 없음", 아니면 "숨길 댓글: N개"를 출력하는 코드를 작성하세요.

## 엔지니어가 창작해야 하는 가상의 프로그램 1

**[Steam 게임 상점팀]** 장바구니 게임 5개 중 내 예산(`budget` = 15, 단위: 천원)으로 살 수 있는 게임을 골라 주는 프로그램을 만들어요. 할인가는 `price * (100 - discount) / 100`이에요. 할인가가 예산 **이하**이면 "구매 가능"이고, 이미 가진 게임(`owned == 1`)은 검사하지 않아요.

```c
int prices[5]    = {40, 30, 15, 60, 20};
int discounts[5] = {50, 0, 20, 75, 10};
int owned[5]     = {0, 0, 0, 0, 1};
// 이름: Rocket, Farm, Puzzle, Space, Chess
```

- **조건문 퀴즈 1:** 할인가 `sale`(= `price * (100 - discount) / 100`)이 `budget` 이하면 "구매 가능", 아니면 "예산 초과"를 출력하는 코드를 작성하세요.
- **반복문 퀴즈 1:** 구조체 배열 `games[5]`를 돌면서 `"1번 게임: Rocket (정가 40)"` 모양으로 출력하는 코드를 작성하세요. (번호는 1부터)
- **흐름제어 퀴즈 1:** 위 반복문에서 이미 가진 게임은 건너뛰고, 구매 가능한 게임을 처음 발견하면 "첫 추천: 이름"을 출력하고 반복을 멈추는 코드를 작성하세요.
- **배열 퀴즈 1:** `prices`, `discounts`, `owned` 배열을 이용해, 아직 없는(`owned[i] == 0`) 게임 중 구매 가능한 게임이 몇 개인지 `buy`에 저장하고 출력하세요.
- **포인터 변수 퀴즈 1:** 포인터 `p`가 `discounts` 배열의 처음부터 끝까지 한 칸씩 이동하며(`p++`), 값이 10 **미만인 칸만** 10으로 올리는(최소 할인 보정) 코드를 작성하세요. (`*p` 사용, 10 이상인 칸은 그대로)
- **구조체 퀴즈 1:** 이름(`char name[20]`), 정가(`int price`), 할인율(`int discount`), 보유 여부(`int owned`)를 가진 구조체 `struct Game`을 정의하고, 변수 `one`을 `"Maze"`, `20`, `50`, `0`으로 만들어 이름과 "구매 가능" 또는 "예산 초과"를 출력하는 코드를 작성하세요. (예산은 15)
- **함수 퀴즈 1:** 게임 배열 시작 주소 `g`, 개수 `n`, 예산 `budget`을 받아, 아직 없고 구매 가능한 게임 중 할인가가 가장 싼 게임의 **인덱스(번호표)** 를 반환하는 함수 `find_best_deal`을 작성하세요. 대상이 없으면 `-1`을 반환하세요.
- **흐름제어 퀴즈 2 (종합):** `main`에서 `find_best_deal`을 호출해 `-1`이면 "살 수 있는 게임 없음", 아니면 "추천: 이름 (할인가 N천원)"을 출력하는 코드를 작성하세요.

# 정답 및 해설 (초등학교 5학년 눈높이)

## 문제 1: YouTube 댓글 신고 관리

### 조건문 정답
```c
if (pinned == 1) {
    printf("고정\n");
} else if (reports >= 10) {
    printf("숨김\n");
} else if (reports >= 3) {
    printf("검토\n");
} else {
    printf("표시\n");
}
```
**왜 이렇게?** 학급 게시판을 떠올려 보세요. 선생님이 "이건 항상 붙여 둬!" 하고 고정해 둔 쪽지는 누가 뭐라 해도 그대로 두죠? 그래서 고정 검사가 **맨 먼저**예요. 그다음엔 "많이 신고 → 가리기", "조금 신고 → 살펴보기", "깨끗 → 보여주기" 순서로, **큰 기준부터** 물어봐요. 작은 기준(3 이상)을 먼저 물으면 신고 15개도 "검토"에서 걸려 버려요. 딱 10도 숨겨야 하니까 `>=`예요.

### 반복문 정답
```c
for (int i = 0; i < 5; i++) {
    printf("%d번 댓글: 신고 %d\n", i + 1, comments[i].reports);
}
```
**왜 이렇게?** 댓글이 5개로 정해져 있으니 `for`가 딱이에요. 컴퓨터는 0부터 세지만 사람은 1번부터 부르니까, 보여줄 때만 `i + 1`을 써요. `i < 5`라야 0~4, 딱 5칸만 열어요.

### 흐름제어 정답 (1)
```c
for (int i = 0; i < 5; i++) {
    if (comments[i].pinned == 1) {
        continue;
    }
    if (comments[i].reports >= 10) {
        printf("숨김 댓글: %d\n", comments[i].id);
        break;
    }
}
```
**왜 이렇게?** `continue`는 "이 쪽지는 고정이니까 패스, 다음 쪽지!", `break`는 "찾았다! 이제 그만 찾아도 돼!"예요. 정답 출력은 `숨김 댓글: 5`예요. 3번 댓글은 신고가 15개로 많지만 고정이라 건너뛰고, 5번(신고 11)이 처음으로 걸려요.

### 배열 정답
```c
int cnt = 0;
for (int i = 0; i < 5; i++) {
    if (reports[i] >= 10) {
        cnt++;
    }
}
printf("%d\n", cnt);   // 2
```
**왜 이렇게?** 조건에 맞는 칸을 만날 때마다 막대기를 하나씩 긋는(`cnt++`) 거예요. 15와 11, 두 칸이 10 이상이라 답은 2예요. 이 문제는 "고정 여부"를 묻지 않았으니 3번 댓글(15)도 센다는 점이 포인트예요!

### 포인터 정답
```c
int *p = reports;
for (int i = 0; i < 5; i++) {
    if (*p > 10) {
        *p = 10;
    }
    p++;
}
// reports는 {2, 4, 10, 0, 10}이 돼요
```
**왜 이렇게?** 배열 이름 `reports`는 "첫 칸의 주소"예요. `p`는 손가락, `*p`는 손가락이 가리키는 칸 안의 값이에요. 10보다 큰 칸만 10으로 줄이고, 손가락은 `p++`로 한 칸씩 옮겨요. `p++`는 `if` 바깥에 둬야 해요. 안에 두면 작은 값 칸에서 손가락이 못 움직여서 같은 칸만 계속 보게 돼요.

### 구조체 정답
```c
struct Comment {
    int id;
    int reports;
    int likes;
    int pinned;
};
```
**왜 이렇게?** 댓글 하나에는 번호, 신고 수, 좋아요, 고정 여부가 항상 같이 다녀요. 배열 4개로 따로 두면 짝이 어긋나기 쉬우니, 하나의 "댓글 카드"로 묶어요.

### 함수 정답
```c
int count_hidden(struct Comment *c, int n) {
    int cnt = 0;
    for (int i = 0; i < n; i++) {
        if (c[i].pinned == 1) {
            continue;
        }
        if (c[i].reports >= 10) {
            cnt++;
        }
    }
    return cnt;
}
```
**왜 이렇게?** `return cnt;`는 반드시 **반복문이 끝난 뒤**에 둬요. 안에 두면 첫 댓글만 보고 돌아가 버려요. 배열을 받을 때는 통째로 복사하지 않고 시작 주소(`c`)와 개수(`n`)만 받는 게 C언어의 약속이에요.

### 흐름제어 정답 (종합)
```c
struct Comment comments[5] = {
    {1, 2, 5, 0}, {2, 4, 80, 0}, {3, 15, 900, 1},
    {4, 0, 30, 0}, {5, 11, 7, 0}
};
int n = count_hidden(comments, 5);
if (n == 0) {
    printf("숨길 댓글 없음\n");
} else {
    printf("숨길 댓글: %d개\n", n);
}
```
**왜 이렇게?** 고정인 3번은 빠지고, 신고 11인 5번만 숨길 대상이에요. 출력은 `숨길 댓글: 1개`예요. (배열 퀴즈의 2와 다른 이유: 거기서는 고정 댓글도 셌고, 여기서는 빼기 때문이에요.) 결과를 변수 `n`에 한 번 받아 두면 `if`에서 여러 번 쓸 수 있어요.

## 프로그램 1: Steam 게임 할인 장바구니

### 조건문 정답
```c
int sale = price * (100 - discount) / 100;
if (sale <= budget) {
    printf("구매 가능\n");
} else {
    printf("예산 초과\n");
}
```
**왜 이렇게?** 용돈이 15천원인데 딱 15천원짜리 과자는 살 수 있죠? 그래서 `<`가 아니라 `<=`예요. 할인가는 "정가의 (100-할인율)%"만 내는 거라서 `price * (100 - discount) / 100`이에요. 곱셈을 먼저 하고 나중에 100으로 나눠야 소수점이 사라지는 일이 줄어요.

### 반복문 정답
```c
for (int i = 0; i < 5; i++) {
    printf("%d번 게임: %s (정가 %d)\n", i + 1, games[i].name, games[i].price);
}
```
**왜 이렇게?** 글자(이름)는 `%s`, 숫자는 `%d`로 출력해요. 번호는 사람 눈높이에 맞춰 `i + 1`!

### 흐름제어 정답 (1)
```c
for (int i = 0; i < 5; i++) {
    if (games[i].owned == 1) {
        continue;
    }
    int sale = games[i].price * (100 - games[i].discount) / 100;
    if (sale <= 15) {
        printf("첫 추천: %s\n", games[i].name);
        break;
    }
}
```
**왜 이렇게?** 이미 가진 게임은 `continue`로 넘어가요. Rocket 할인가는 20, Farm은 30이라 둘 다 예산 초과예요. Puzzle은 15 × 80 ÷ 100 = 12라서 처음으로 통과! 정답 출력은 `첫 추천: Puzzle`이고 `break`로 멈춰요.

### 배열 정답
```c
int buy = 0;
for (int i = 0; i < 5; i++) {
    if (owned[i] == 1) {
        continue;
    }
    int sale = prices[i] * (100 - discounts[i]) / 100;
    if (sale <= 15) {
        buy++;
    }
}
printf("%d\n", buy);   // 2
```
**왜 이렇게?** 세 배열의 같은 번호 칸은 같은 게임의 정보예요. Puzzle(12)과 Space(60×25÷100=15, 딱 예산이라 통과!)가 구매 가능이에요. Chess는 할인가 18이지만 이미 가지고 있어서 처음부터 빠져요. 답은 2예요.

### 포인터 정답
```c
int *p = discounts;
for (int i = 0; i < 5; i++) {
    if (*p < 10) {
        *p = 10;
    }
    p++;
}
// discounts는 {50, 10, 20, 75, 10}이 돼요
```
**왜 이렇게?** 10보다 작은 칸(Farm의 0)만 10으로 올려요. 이미 10인 마지막 칸은 `<`라서 그대로예요. 손가락 `p`는 매 칸마다 `p++`로 한 칸씩 옮겨요.

### 구조체 정답
```c
struct Game {
    char name[20];
    int price;
    int discount;
    int owned;
};

struct Game one = {"Maze", 20, 50, 0};
int sale = one.price * (100 - one.discount) / 100;
if (sale <= 15) {
    printf("%s: 구매 가능\n", one.name);
} else {
    printf("%s: 예산 초과\n", one.name);
}
```
**왜 이렇게?** 이름은 글자 칸(`char name[20]`), 나머지는 숫자 칸이에요. 값은 선언한 순서대로 채워져요. 할인가는 20 × 50 ÷ 100 = 10이라 15 이하이므로 `Maze: 구매 가능`이 출력돼요. 구조체 안의 값은 점(`.`)으로 꺼내요.

### 함수 정답
```c
int find_best_deal(struct Game *g, int n, int budget) {
    int best = -1;
    int best_sale = 0;
    for (int i = 0; i < n; i++) {
        if (g[i].owned == 1) {
            continue;
        }
        int sale = g[i].price * (100 - g[i].discount) / 100;
        if (sale <= budget) {
            if (best == -1 || sale < best_sale) {
                best = i;
                best_sale = sale;
            }
        }
    }
    return best;
}
```
**왜 이렇게?** `best`는 "지금까지 1등 후보의 번호표"예요. 처음엔 후보가 없으니 -1이에요(0번도 진짜 번호라서 -1로 "없음"을 표시해요). 구매 가능한 게임을 만날 때마다 "후보가 없거나, 후보보다 더 싸면" 번호표와 가격을 같이 바꿔요. `best == -1 ||`가 앞에 와야 해요. 이렇게 하면 `best_sale`의 처음 값(0)과 비교하는 실수를 막아 줘요. 결과는 Puzzle의 번호표 `2`예요.

### 흐름제어 정답 (종합)
```c
struct Game games[5] = {
    {"Rocket", 40, 50, 0}, {"Farm", 30, 0, 0}, {"Puzzle", 15, 20, 0},
    {"Space", 60, 75, 0}, {"Chess", 20, 10, 1}
};
int idx = find_best_deal(games, 5, 15);
if (idx == -1) {
    printf("살 수 있는 게임 없음\n");
} else {
    int sale = games[idx].price * (100 - games[idx].discount) / 100;
    printf("추천: %s (할인가 %d천원)\n", games[idx].name, sale);
}
```
**왜 이렇게?** 함수가 번호표 `2`를 돌려주면 `games[2]`가 Puzzle이에요. 번호표가 -1이면 살 수 있는 게임이 없다는 뜻이니 안내 문구를 보여요. 출력은 `추천: Puzzle (할인가 12천원)`이에요. Space(15)도 살 수 있지만 Puzzle(12)이 더 싸서 1등이에요!
