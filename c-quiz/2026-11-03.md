## 엔지니어가 직면한 가상의 문제 1

**[Airbnb 예약 시스템 팀]** 숙소 하나에 이미 들어온 예약이 4건 있어요. 각 예약은 체크인 날(`in`)과 체크아웃 날(`out`)을 가져요. (예: 3일 체크인, 5일 체크아웃 = 3일, 4일 밤을 묵음) 새 예약 요청이 기존 예약과 하루라도 겹치면 거절해야 해요. 단, 앞 손님이 나가는 날(`out`)에 다음 손님이 들어오는(`in`) 것은 괜찮아요. 겹치는 조건은 `새in < 기존out` 그리고 `기존in < 새out`이에요.

```c
int ins[4]  = {1, 5, 10, 14};   // 체크인 날 배열
int outs[4] = {3, 8, 12, 17};   // 체크아웃 날 배열
```

- **조건문 퀴즈 1:** 새 예약의 체크인 `nin`, 체크아웃 `nout`과 기존 예약 하나(`in`, `out`)가 겹치면 "겹침", 아니면 "OK"를 출력하는 코드를 작성하세요.
- **반복문 퀴즈 1:** 구조체 배열 `books[4]`를 처음부터 끝까지 돌면서 `"1번 예약: 1일~3일"` 모양으로 출력하는 코드를 작성하세요. (번호는 1부터)
- **흐름제어 퀴즈 1:** 위 반복문에서 취소된 예약(`canceled == 1`)은 건너뛰고, 새 예약과 겹치는 예약을 처음 발견하면 "충돌: (번호)번 예약"을 출력하고 반복을 멈추는 코드를 작성하세요.
- **배열 퀴즈 1:** `ins`, `outs` 배열을 이용해 각 예약의 숙박일 수(`out - in`)를 구해 가장 길게 묵는 예약의 숙박일 수를 `longest`에 저장하고 출력하세요.
- **포인터 변수 퀴즈 1:** 포인터 `p`가 `outs` 배열의 처음부터 끝까지 한 칸씩 이동하며(`p++`), 가리키는 값에 1을 더해(청소 시간 1일 추가) 바꾸는 코드를 작성하세요. (`outs[i]`가 아니라 `*p`를 사용)
- **구조체 퀴즈 1:** 체크인(`in`), 체크아웃(`out`), 취소 여부(`canceled`)를 가진 구조체 `struct Booking`을 정의하세요.
- **함수 퀴즈 1:** 예약 배열의 시작 주소 `b`, 개수 `n`, 새 체크인 `nin`, 새 체크아웃 `nout`을 받아서, 취소되지 않은 예약 중 겹치는 예약이 하나라도 있으면 `1`, 없으면 `0`을 반환하는 함수 `has_conflict`를 작성하세요.
- **흐름제어 퀴즈 2 (종합):** `main`에서 예약 4건짜리 구조체 배열과 `has_conflict`를 사용해, 새 예약(8일~11일)이 가능하면 "예약 확정", 아니면 "예약 거절"을 출력하는 코드를 작성하세요.

# 정답 및 해설 (초등학교 5학년 눈높이)

## 문제 1: Airbnb 예약 날짜 겹침 검사

### 조건문 정답
```c
if (nin < out && in < nout) {
    printf("겹침\n");
} else {
    printf("OK\n");
}
```
**왜 이렇게?** 두 친구가 같은 의자에 앉는 시간을 생각해 보세요. 내가 앉는 시간이 친구가 일어나기 전에 시작하고(`nin < out`), 친구가 앉는 시간이 내가 일어나기 전에 시작하면(`in < nout`) 둘이 동시에 앉아 있는 순간이 생겨요. 두 조건이 **모두** 참이어야 하니까 `&&`를 써요. `<`라서 친구가 일어나는 날 내가 앉는 것은 OK예요.

### 반복문 정답
```c
for (int i = 0; i < 4; i++) {
    printf("%d번 예약: %d일~%d일\n", i + 1, books[i].in, books[i].out);
}
```
**왜 이렇게?** 예약이 4개로 정해져 있어서 `for`가 딱이에요. 컴퓨터는 0부터 세지만 사람은 1번부터 부르니까 화면에 보일 때만 `i + 1`을 써요. `i < 4`라야 0~3, 딱 4칸만 열어요.

### 흐름제어 정답 (1)
```c
for (int i = 0; i < 4; i++) {
    if (books[i].canceled == 1) {
        continue;
    }
    if (nin < books[i].out && books[i].in < nout) {
        printf("충돌: %d번 예약\n", i + 1);
        break;
    }
}
```
**왜 이렇게?** `continue`는 "이 친구는 패스, 다음 친구!"이고, `break`는 "찾았다! 이제 그만 찾아도 돼!"예요. 취소된 예약은 이미 비어 있는 자리라서 볼 필요가 없고, 충돌을 하나라도 찾으면 거절이 확정이라 더 돌 필요가 없어요.

### 배열 정답
```c
int longest = 0;
for (int i = 0; i < 4; i++) {
    int nights = outs[i] - ins[i];
    if (nights > longest) {
        longest = nights;
    }
}
printf("%d\n", longest);   // 3
```
**왜 이렇게?** 달리기 1등을 가리는 방법이에요. 일단 "지금까지 1등 기록"을 0으로 두고, 더 긴 기록이 나오면 바꿔 적어요. 숙박일은 (2, 3, 2, 3)이라 답은 3이에요.

### 포인터 정답
```c
int *p = outs;
for (int i = 0; i < 4; i++) {
    *p = *p + 1;
    p++;
}
```
**왜 이렇게?** 배열 이름 `outs`는 "첫 칸의 주소"예요. `p`는 손가락, `*p`는 손가락이 가리키는 칸 안의 값이에요. 값을 바꾸고 `p++`로 손가락을 다음 칸으로 옮겨요. 손가락을 옮기는 것을 잊으면 같은 칸만 4번 바뀌어요!

### 구조체 정답
```c
struct Booking {
    int in;
    int out;
    int canceled;
};
```
**왜 이렇게?** 예약 한 건에는 체크인, 체크아웃, 취소 여부가 항상 같이 다녀요. 따로 배열 3개를 쓰면 짝이 어긋나기 쉬워서, 하나의 "예약 카드"로 묶어요.

### 함수 정답
```c
int has_conflict(struct Booking *b, int n, int nin, int nout) {
    for (int i = 0; i < n; i++) {
        if (b[i].canceled == 1) {
            continue;
        }
        if (nin < b[i].out && b[i].in < nout) {
            return 1;
        }
    }
    return 0;
}
```
**왜 이렇게?** 겹치는 예약을 하나라도 만나면 바로 `return 1`로 끝내요. `return 0`은 반드시 **반복문이 끝난 뒤**에 둬야 해요. 안에 두면 첫 예약만 보고 "없음"이라고 성급하게 답해 버려요.

### 흐름제어 정답 (종합)
```c
struct Booking books[4] = {{1,3,0}, {5,8,0}, {10,12,0}, {14,17,0}};
if (has_conflict(books, 4, 8, 11)) {
    printf("예약 거절\n");
} else {
    printf("예약 확정\n");
}
```
**왜 이렇게?** 8일~11일은 5~8일 예약과 8일에 딱 만나기만 하고(OK), 10~12일 예약과는 10일이 겹쳐서(`8 < 12` 그리고 `10 < 11`) 거절이에요. 정답 출력은 "예약 거절"이에요.

## 프로그램 1: Riot Games 챔피언 승률 랭킹

### 조건문 정답
```c
if (rate >= 60) {
    printf("사기 챔피언\n");
} else if (rate >= 50) {
    printf("좋음\n");
} else {
    printf("분발\n");
}
```
**왜 이렇게?** 높은 기준부터 차례로 물어야 해요. 65%가 먼저 "50 이상?"에 걸리면 "좋음"이 되어 버려요.

### 반복문 정답
```c
for (int i = 0; i < 5; i++) {
    printf("%d위 후보: %s\n", i + 1, champs[i].name);
}
```
**왜 이렇게?** 문자열(이름)은 `%s`로 출력해요. 번호는 사람 눈높이에 맞춰 `i + 1`!

### 흐름제어 정답 (1)
```c
for (int i = 0; i < 5; i++) {
    if (champs[i].games < 10) {
        continue;
    }
    if (champs[i].wins == champs[i].games) {
        printf("전승 챔피언!\n");
        break;
    }
}
```
**왜 이렇게?** 시험 점수가 너무 적게 모인 반은 평균을 믿기 어렵죠? 그래서 10판 미만은 `continue`로 건너뛰고, 전승을 찾으면 `break`로 끝내요.

### 배열 정답
```c
int sum_g = 0, sum_w = 0;
for (int i = 0; i < 5; i++) {
    sum_g += games[i];
    sum_w += wins[i];
}
double total_rate = 0.0;
if (sum_g > 0) {
    total_rate = (double)sum_w / sum_g * 100;
}
printf("%.1f%%\n", total_rate);   // 51/90*100 = 56.7%
```
**왜 이렇게?** 케이크 51조각 중 90조각... 아니, 정수끼리 나누면 `51/90`이 0이 되어 소수점이 사라져요. 한쪽을 `(double)`로 바꿔 줘야 0.566...이 나와요. 0으로 나누면 프로그램이 터지니까 `sum_g > 0`을 먼저 확인해요. `%%`는 퍼센트 기호 자체를 출력하는 표기예요.

### 포인터 정답
```c
int *top = &wins[0];
for (int i = 1; i < 5; i++) {
    if (wins[i] > *top) {
        top = &wins[i];
    }
}
printf("%d\n", *top);   // 24
```
**왜 이렇게?** "지금까지 1등 칸"을 손가락(`top`)으로 가리키고 있다가, 더 큰 칸을 만나면 손가락만 옮겨요. 값을 복사하는 게 아니라 **어느 칸인지**를 기억하는 거예요. 첫 칸은 이미 가리키고 있으니 `i`는 1부터 시작해요.

### 구조체 정답
```c
#include <string.h>

struct Champ {
    char name[20];
    int games;
    int wins;
};

struct Champ one;
strcpy(one.name, "Ahri");
one.games = 30;
one.wins = 18;
printf("%s %.1f%%\n", one.name, (double)one.wins / one.games * 100);   // Ahri 60.0%
```
**왜 이렇게?** 글자 배열은 `=`로 한 번에 넣을 수 없어서 `strcpy`로 복사해요. 승률도 정수 나눗셈 함정이 있으니 `(double)`을 꼭 붙여요.

### 함수 정답
```c
struct Champ *find_top(struct Champ *c, int n) {
    struct Champ *best = NULL;
    double best_rate = -1.0;
    for (int i = 0; i < n; i++) {
        if (c[i].games < 10) {
            continue;
        }
        double rate = (double)c[i].wins / c[i].games * 100;
        if (rate > best_rate) {
            best_rate = rate;
            best = &c[i];
        }
    }
    return best;
}
```
**왜 이렇게?** `best`를 `NULL`("아직 아무도 없음")로 시작해서, 자격 있는 챔피언이 나올 때마다 주소를 갈아 끼워요. 끝까지 아무도 없으면 `NULL` 그대로 돌아가서 "없음"을 알려 줄 수 있어요. 승률 비교를 위해 `best_rate`를 -1로 시작하면 어떤 승률(0% 포함)도 이겨요.

### 흐름제어 정답 (종합)
```c
struct Champ *top = find_top(champs, 5);
if (top == NULL) {
    printf("랭킹 없음\n");
} else {
    printf("1위: %s (%.1f%%)\n", top->name,
           (double)top->wins / top->games * 100);
}
```
**왜 이렇게?** 주소를 받았으면 쓰기 전에 **반드시** `NULL`인지 먼저 확인해야 해요. 빈 상자를 열면 프로그램이 멈춰요. 구조체를 가리키는 포인터에서는 `top->name`처럼 화살표로 안의 값을 읽어요. (예시 데이터라면 Ahri-like 20판 55%, 50판 48%, 12판 75% → 12판 75% 챔피언이 1위)
