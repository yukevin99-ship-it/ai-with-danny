## 📌 엔지니어가 직면한 가상의 문제 1
**[Google 계정 보안팀]** 로그인 실패가 너무 많이 반복되는 계정을 잠가서 해커를 막아야 해요.

### 조건문 퀴즈1
정수 `fail`(연속 실패 횟수)이 있을 때, 5 이상이면 "계정 잠금", 3 이상 5 미만이면 "추가 인증 요구", 그 밖에는 "정상"을 출력하는 코드를 작성하세요.

### 반복문 퀴즈1
`int log[6] = {1, 0, 1, 1, 0, 1};` (1 = 로그인 실패, 0 = 성공) 에서 실패(1)가 몇 번인지 for문으로 세어 출력하세요.

### 흐름제어 퀴즈1
비밀번호 입력 기회는 최대 3번입니다. `int pw[3] = {1111, 2222, 4321};` 이 입력한 비밀번호들이고 정답은 `4321`입니다. `do-while`(또는 for)로 한 번씩 확인해서, 틀리면 "N번째 실패", 맞으면 "N번째 성공! 로그인"을 출력하고 반복을 끝내세요(`break`). 3번 모두 틀리면 "계정 잠금"을 출력합니다.

## 📌 엔지니어가 창작해야 하는 가상의 프로그램 1
**[네이버 웹툰]** 독자가 매긴 별점을 별(★) 모양으로 보여주는 기능을 만들어요.

### 조건문 퀴즈1
정수 `day`(1~7)가 있을 때 `switch`문으로 1이면 "월요 웹툰", 2면 "화요 웹툰", 3이면 "수요 웹툰", 그 외 숫자는 "다른 요일"을 출력하세요.

### 반복문 퀴즈1
정수 `rating = 4`일 때, `while`문으로 ★을 rating개만큼 한 줄에 출력하세요. (`★★★★`)

### 흐름제어 퀴즈1
`int stars[3] = {3, 5, 2};` (1~3화의 별점)을 이중 for문(반복문 안의 반복문)으로, 각 화마다 "N화: ★★★" 모양으로 출력하세요. 별점이 4 미만인 화는 줄 끝에 " (아쉬워요)"를 붙이세요.

## ✅ 정답 및 해설 (먼저 직접 풀어본 뒤 보세요!)

### 문제1 - 조건문
```c
if (fail >= 5) printf("계정 잠금\n");
else if (fail >= 3) printf("추가 인증 요구\n");
else printf("정상\n");
```
👉 문 지키는 경비 아저씨를 떠올려 보세요. "5번 이상 실패했어요? 그럼 문 잠금!" 아니라면 "그럼 3번 이상이에요? 신분증 보여주세요." 그것도 아니면 "들어오세요." 가장 심한 경우부터 물어봐야 7번 실패한 사람이 "3번 이상" 칸에서 걸리지 않아요.

### 문제1 - 반복문
```c
int count = 0;
for (int i = 0; i < 6; i++) {
    if (log[i] == 1) count++;
}
printf("실패 %d번\n", count);
```
출력: `실패 4번`

👉 출석부에서 결석한 친구를 세는 것과 같아요. 한 칸씩 보면서(`for`), 결석(1)일 때만 손가락을 하나 접어요(`count++`). 0일 때는 아무것도 안 해요. 6칸이라서 `i < 6`까지만 돌아요.

### 문제1 - 흐름제어
```c
int pw[3] = {1111, 2222, 4321};
int i = 0, ok = 0;
do {
    if (pw[i] == 4321) {
        printf("%d번째 성공! 로그인\n", i + 1);
        ok = 1;
        break;
    }
    printf("%d번째 실패\n", i + 1);
    i++;
} while (i < 3);
if (!ok) printf("계정 잠금\n");
```
출력: `1번째 실패` / `2번째 실패` / `3번째 성공! 로그인`

👉 문 앞에서 비밀번호를 **일단 한 번은 눌러 봐야** 하니까 `do-while`이 딱이에요(먼저 하고, 나중에 "더 해도 돼?" 확인). 맞으면 더 눌러볼 필요가 없어서 `break`로 바로 나와요. `ok`는 "성공했어요" 깃발이에요. 깃발이 안 올라가 있을 때(=3번 다 틀림)만 "계정 잠금"을 알려 줘요. 깃발이 없으면 성공한 사람한테도 잠금이 뜰 수 있어요!

### 문제2 - 조건문
```c
switch (day) {
    case 1: printf("월요 웹툰\n"); break;
    case 2: printf("화요 웹툰\n"); break;
    case 3: printf("수요 웹툰\n"); break;
    default: printf("다른 요일\n");
}
```
👉 `switch`는 엘리베이터 버튼판 같아요. 숫자(층)를 누르면 그 `case`로 쏙 들어가요. 각 `case` 끝의 `break`는 "여기서 내려요!"라는 뜻이에요. 빼먹으면 다음 층까지 줄줄이 따라가 버려요. `default`는 어느 버튼도 아닐 때의 "그 밖의 층"이에요.

### 문제2 - 반복문
```c
int rating = 4;
int i = 0;
while (i < rating) {
    printf("★");
    i++;
}
printf("\n");
```
출력: `★★★★`

👉 별 스티커를 4장 붙이는 일이에요. 몇 장 붙였는지 `i`로 세다가 4장이 되면(`i < rating`이 거짓) 멈춰요. `i++`를 빼먹으면 영원히 스티커를 붙이는 무한 반복이 되니 조심! 마지막 `\n`은 줄을 바꾸는 역할로, 반복문 밖에 한 번만 써요.

### 문제2 - 흐름제어
```c
int stars[3] = {3, 5, 2};
for (int i = 0; i < 3; i++) {          // 바깥: 화(회차)
    printf("%d화: ", i + 1);
    for (int j = 0; j < stars[i]; j++) // 안쪽: 별 찍기
        printf("★");
    if (stars[i] < 4) printf(" (아쉬워요)");
    printf("\n");
}
```
출력:
```
1화: ★★★ (아쉬워요)
2화: ★★★★★
3화: ★★ (아쉬워요)
```
👉 시계를 생각해 보세요. 바깥 반복은 "시침"(화 번호), 안쪽 반복은 "분침"(별 개수)이에요. 시침이 한 칸 움직일 때마다 분침이 처음부터 다시 돌아요. 안쪽 반복은 `stars[i]`번만 돌기 때문에 화마다 별 개수가 달라요. 별을 다 찍은 **뒤에** `if`로 별점을 확인해 꼬리말을 붙이고, 마지막에 `\n`으로 다음 화를 새 줄에서 시작해요.
