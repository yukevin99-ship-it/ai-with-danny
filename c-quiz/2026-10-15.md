# ✅ 정답과 해설 (초등학교 5학년 눈높이)

## 📌 문제 1: 쿠팡 물류센터

### 조건문 정답
```c
if (x >= 50) {
    printf("위험\n");
} else if (x > 20) {
    printf("중량\n");
} else {
    printf("일반\n");
}
```
**왜 이렇게?** 갈림길에서 "제일 무거운 사람부터" 물어보는 거예요. 만약 `x > 20`을 먼저 물어보면 60kg 상자도 "중량"이라고 대답하고 끝나 버려요. 그래서 **가장 특별한 조건(50 이상)을 맨 위**에 둬야 해요. `else if`는 "위에서 아니었으면 다음 질문!"이라는 뜻이고, `else`는 "다 아니면 이거!"예요.

### 반복문 정답
```c
int sum = 0;
for (int i = 0; i < 6; i++) {
    sum += w[i];
}
printf("총합: %d\n", sum);
```
**왜 이렇게?** 저금통에 동전을 하나씩 넣는 것과 같아요. `sum`은 빈 저금통(0에서 시작!)이고, 상자가 올 때마다 `+=`로 넣어요. 상자가 6개라서 `i`는 0,1,2,3,4,5까지만 돌아야 해요. 그래서 `i < 6`이에요(`i <= 6`이면 없는 7번째 상자를 건드려 버려요). 정답은 108이에요.

### 흐름제어 정답
```c
int heavy = 0;
for (int i = 0; i < 6; i++) {
    if (w[i] >= 50) {
        printf("벨트 정지!\n");
        break;
    }
    if (w[i] > 20) {
        heavy++;
    }
}
printf("중량 상자: %d개\n", heavy);
```
**왜 이렇게?** 반복문(상자를 하나씩 보기) 안에 조건문(무거운지 물어보기)이 들어 있어요. `break`는 "비상 정지 버튼"이에요. 위험 상자(55kg)를 만나면 뒤에 상자가 남아 있어도 바로 멈춰요. 위험 검사를 **먼저** 하니까 55kg 상자는 중량 개수에 안 세어져요. 결과: 25kg 상자 1개만 세고 멈추므로 "중량 상자: 1개"예요.

## 📌 프로그램 1: 넥슨 레벨업 시스템

### 조건문 정답
```c
if (cur >= 100) {
    printf("레벨업!\n");
} else {
    printf("아직 부족해요\n");
}
```
**왜 이렇게?** "100점이 되면 별 하나!" 같은 규칙이에요. 딱 100일 때도 레벨업이어야 해서 `>`가 아니라 `>=`(이상)를 써요.

### 반복문 정답
```c
int total = 0;
for (int i = 0; i < 5; i++) {
    total += exp[i];
}
printf("총 경험치: %d\n", total);
```
**왜 이렇게?** 몬스터 5마리를 한 마리씩 만나며 경험치를 주머니(`total`)에 담아요. 주머니는 처음에 비어 있어야 하니 0으로 시작해요. 총합은 280이에요.

### 흐름제어 정답
```c
int level = 1, cur = 0;
for (int i = 0; i < 5; i++) {
    cur += exp[i];
    if (cur >= 100) {
        level++;
        cur -= 100;
        printf("레벨업! 현재 레벨 %d\n", level);
    }
    if (level == 3) {
        printf("최대 레벨 도달!\n");
        break;
    }
}
```
**왜 이렇게?** 게임에서 경험치 바가 가득 차면 레벨이 오르고 바가 줄어들죠? `cur -= 100`이 그 역할이에요. 남은 경험치를 버리지 않고 다음 레벨로 넘겨주는 거예요.
따라가 보면: 40 → 110(레벨2, 남은 10) → 40 → 130(레벨3, 남은 30) → 최대 레벨이라 `break`로 멈춰요. 레벨업을 확인한 **다음에** 최대 레벨을 검사해야 방금 올라간 레벨(3)을 바로 알아챌 수 있어요.
