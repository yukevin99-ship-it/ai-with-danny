## 📌 문제 1: 토스 송금 한도

### 조건문 정답
```c
if (n >= 100) {
    printf("추가 인증\n");
} else if (n >= 10) {
    printf("바로 송금\n");
} else {
    printf("소액\n");
}
```
**왜?** 놀이공원 키 제한과 같아요. 가장 큰 기준(100 이상)부터 물어봐야 해요. "10 이상?"을 먼저 물으면 500도 "바로 송금"이 되어 버려요. 앞 질문이 "아니오"일 때만 다음 `else if`로 내려가는 거예요.

### 반복문 정답
```c
int count = 0;
for (int i = 0; i < 6; i++) {
    if (amount[i] >= 40) {
        count++;
    }
}
printf("%d\n", count);
```
**왜?** 저금통 속 동전을 하나씩 꺼내 보며 "큰 동전"만 세는 것과 같아요. 처음엔 0개에서 시작하고, 조건에 맞을 때만 하나씩 올려요. 칸이 6개(번호 0~5)라서 `i < 6`이에요. 50, 40, 80이 해당되어 결과는 **3**이에요.

### 흐름제어 정답
```c
int total = 0;
for (int i = 0; i < 6; i++) {
    if (amount[i] == 0) {
        continue;
    }
    total += amount[i];
    if (total > 150) {
        printf("한도 초과, 번호: %d\n", i);
        break;
    }
}
```
**출력:** `한도 초과, 번호: 5`

**왜?** 취소된 송금(0)은 "없던 일이야" 하고 `continue`로 휙 넘어가요. 나머지는 용돈 장부처럼 `total`에 차곡차곡 더해요. 30 → 80 → 120까지는 괜찮지만, 번호 5에서 80을 더하면 200이 되어 150을 넘어요. 그 순간 `break`로 멈춰요. 더하고 나서 검사하는 순서가 중요해요!

## 📌 프로그램 1: LG 스마트 에어컨

### 조건문 정답
```c
if (t >= 28) {
    printf("강한 냉방\n");
} else if (t >= 25) {
    printf("약한 냉방\n");
} else {
    printf("꺼짐\n");
}
```
**왜?** 선풍기 "강·약·꺼짐" 버튼과 같아요. 가장 더운 경우(28 이상)부터 먼저 물어봐요. 순서를 바꿔 "25 이상?"을 먼저 물으면 31℃인데도 "약한 냉방"이 되어 방이 계속 더워요.

### 반복문 정답
```c
int count = 0;
for (int i = 0; i < 5; i++) {
    if (temp[i] >= 26) {
        count++;
    }
}
printf("%d\n", count);
```
**왜?** 하루 다섯 번 체온계를 보며 "더웠던 횟수"에 막대기를 긋는 것과 같아요. 27, 31, 29가 26 이상이라 결과는 **3**이에요.

### 흐름제어 정답
```c
for (int i = 0; i < 5; i++) {
    if (temp[i] < 25) {
        continue;
    }
    if (temp[i] >= 30) {
        printf("폭염 경보, 번호: %d\n", i);
        break;
    }
}
```
**출력:** `폭염 경보, 번호: 3`

**왜?** 24℃, 22℃는 시원하니 `continue`로 넘어가요. 27℃(번호 1)는 검사는 받지만 30 미만이라 그냥 지나가요. 번호 3의 31℃에서 경보를 울리고 `break`로 멈춰요. "처음 발견한 것"만 알려 주는 방식이라 뒤의 29℃는 보지 않아요.
