## 엔지니어가 직면한 가상의 문제 1

**[삼성전자 반도체 공장 검사팀]** 웨이퍼(반도체 원판)에서 잘라 낸 칩 6개를 검사 기계가 확인했어요. 각 칩은 칩 번호(`id`), 결함 수(`defects`), 검사 때 온도(`temp`, ℃), 검사를 받았는지(`tested`, 1이면 받음)를 가져요. 규칙: 검사를 안 받았으면 무조건 "미검사"예요. 그 밖에는 결함이 3개 **이상**이면 "불량", 온도가 85 **초과**면 "과열 재검사", 나머지는 "합격"이에요. 합격률이 낮으면 공장 라인을 멈춰야 해요!

```c
int temp[6]    = {70, 0, 90, 60, 80, 95};   // 0 = 온도를 못 잼
int defects[6] = {0, 0, 1, 4, 2, 5};
// 칩 6개: {id, defects, temp, tested}
// {101,0,70,1} {102,0,0,0} {103,1,90,1} {104,4,60,1} {105,2,80,1} {106,5,95,1}
```

- **조건문 퀴즈 1:** 칩 하나의 `tested`, `defects`, `temp`를 보고 "미검사", "불량", "과열 재검사", "합격" 중 하나를 출력하는 코드를 작성하세요. (어떤 순서로 물어봐야 할까요?)
- **반복문 퀴즈 1:** 구조체 배열 `chips[6]`을 처음부터 끝까지 돌면서 `"101번 칩: 결함 0개"` 모양으로 출력하는 코드를 작성하세요.
- **흐름제어 퀴즈 1:** 위 반복문에서 검사를 안 받은 칩(`tested == 0`)은 건너뛰고, "불량" 칩(결함 3개 이상)을 처음 발견하면 `"첫 불량 칩: N번"`을 출력하고 반복을 멈추는 코드를 작성하세요.
- **배열 퀴즈 1:** `temp` 배열에서 0(못 잼)인 칸은 빼고 **가장 높은 온도**와 그게 **몇 번째 칩**인지 찾아 `"최고 온도: 95도 (6번째 칩)"`처럼 출력하세요. (최댓값 `max`와 위치 `where`를 같이 기억해요)
- **포인터 변수 퀴즈 1:** 포인터 `p`를 `defects` 배열의 처음에 두고, `while (p < defects + 6)`으로 끝까지 이동하면서 결함이 3 이상인 칸을 `-1`(폐기 표시)로 바꾸고 폐기한 개수를 세어 출력하세요. (`defects + 6`은 어디를 가리킬까요?)
- **구조체 퀴즈 1:** 칩 번호(`id`), 결함 수(`defects`), 온도(`temp`), 검사 여부(`tested`)를 가진 구조체 `struct Chip`을 정의하고, 변수 `one`을 `{107, 2, 88, 1}`로 만들어 `"107번: 과열 재검사"`처럼 판정 결과를 출력하세요.
- **함수 퀴즈 1:** 칩 배열 시작 주소 `c`와 개수 `n`을 받아, **검사를 받은 칩 중** 합격한 칩의 비율(%)을 정수로 돌려주는 함수 `yield_percent`를 작성하세요. 검사받은 칩이 하나도 없으면 `-1`을 돌려주세요. (왜 `-1`이 필요할까요?)
- **흐름제어 퀴즈 2 (종합):** `main`에서 `yield_percent`의 결과가 `-1`이면 `"검사 데이터 없음"`, 90 이상이면 `"출하 승인"`, 50 이상이면 `"부분 출하 (N%)"`, 그 밖에는 `"라인 정지: 합격률 N%"`를 출력하세요. 실제로 무엇이 출력될까요?

## 엔지니어가 창작해야 하는 가상의 프로그램 1

**[현대엘리베이터 스마트 제어팀]** 10층짜리 건물의 엘리베이터 1대가 호출 5개를 처리하는 프로그램을 만들어요. 각 호출은 부른 층(`floor`), 기다리는 사람 수(`people`, 0이면 **취소된 호출**), 처리했는지(`done`)를 가져요. 엘리베이터는 1층에서 출발하고, 정원은 **8명**이에요.

```c
int call_floor[5] = {7, 3, 5, 9, 2};
int people[5]     = {3, 0, 4, 2, 5};
// 호출 5개: {floor, people, done}
// {7,3,0} {3,0,0} {5,4,0} {9,2,0} {2,5,0}
// 엘리베이터: {now(현재 층), load(탄 사람), moves(지금까지 움직인 층 수)}
```

- **조건문 퀴즈 1:** 현재 층 `now`와 호출 하나의 `floor`, `people`을 보고, 사람이 0명이면 "취소된 호출", 호출 층이 더 위면 "▲ 올라가요", 더 아래면 "▼ 내려가요", 같은 층이면 "문 열림"을 출력하는 코드를 작성하세요.
- **반복문 퀴즈 1:** `call_floor`와 `people` 배열을 함께 돌면서 `"7층 호출: 3명"` 모양으로 5줄을 출력하세요.
- **흐름제어 퀴즈 1:** 호출 순서대로 사람을 태워요. 취소된 호출은 건너뛰고(`continue`), 태웠을 때 정원 8명을 **넘게 되면** `"정원 초과: N층 손님은 다음 차례"`를 출력하고 멈추세요(`break`). 태울 때마다 `"N층 탑승 (총 M명)"`을 출력해요.
- **배열 퀴즈 1:** 엘리베이터가 1층에서 출발해 취소된 호출을 빼고 순서대로 갈 때 **모두 몇 층을 움직이는지** 구하세요. 내려가면 차이가 음수가 되니까 `if`로 양수로 바꿔 주세요. (`abs` 함수 없이!)
- **포인터 변수 퀴즈 1:** 엘리베이터가 꼭대기 **10층**에 있어요. 포인터 `best`를 `call_floor`의 첫 칸에 두고, 포인터 `q`로 나머지 칸을 돌면서 10층에서 **가장 가까운 호출**을 `best`가 가리키게 하세요. 그리고 `best - call_floor`를 이용해 `"가장 가까운 호출: 9층 (4번째 호출)"`을 출력하세요.
- **구조체 퀴즈 1:** 현재 층(`now`), 탄 사람(`load`), 움직인 층 수(`moves`)를 가진 `struct Elevator`를 정의하고 `ev`를 `{1, 0, 0}`으로 만드세요. 그다음 **구조체 포인터** `e = &ev`를 통해서(`->` 사용) 7층으로 옮기고, 3명 태우고, 이동 거리 6을 더한 뒤 `"현재 7층, 탑승 3명, 이동 6층"`을 출력하세요.
- **함수 퀴즈 1:** 엘리베이터 주소 `e`와 목표 층 `floor`를 받아, 이동 거리(항상 양수)를 계산해서 `e->moves`에 더하고 `e->now`를 목표 층으로 바꾼 뒤, 이번에 움직인 거리를 돌려주는 함수 `move_to`를 작성하세요.
- **흐름제어 퀴즈 2 (종합):** `main`에서 호출 구조체 배열을 돌며 취소된 호출은 건너뛰고, `move_to`로 이동한 뒤 `done = 1`로 표시하고 `"N층 도착 (이동 D층)"`을 출력하세요. 총 이동이 **10층을 넘으면** `"점검 필요: 총 이동 M층"`을 출력하고 멈추세요. 반복이 끝나면 처리 못 한 호출(취소 제외) 수를 `"남은 호출: K개"`로 출력하세요. 실제 출력은?

## 문제 1: 삼성전자 반도체 칩 검사

### 조건문 정답
```c
if (tested == 0) {
    printf("미검사\n");
} else if (defects >= 3) {
    printf("불량\n");
} else if (temp > 85) {
    printf("과열 재검사\n");
} else {
    printf("합격\n");
}
```
**왜 이렇게?** 시험지를 아직 안 냈는데 "0점!"이라고 하면 억울하죠? 그래서 "검사를 받았나?"를 **맨 먼저** 물어요. 다음은 "결함이 너무 많나?"예요. 결함이 많은 칩은 온도가 어떻든 어차피 버려야 하니까 온도보다 먼저 물어요. 그래서 106번은 온도도 높지만(95도) "과열"이 아니라 "불량"이 돼요. 결과: 101 합격, 102 미검사, 103 과열 재검사, 104 불량, 105 합격, 106 불량.

### 반복문 정답
```c
for (int i = 0; i < 6; i++) {
    printf("%d번 칩: 결함 %d개\n", chips[i].id, chips[i].defects);
}
```
**왜 이렇게?** 칩이 딱 6개라서 몇 번 돌지 정해진 `for`가 딱 맞아요. `chips[i]`는 "i번째 칩 카드", `.id`는 "그 카드의 번호 칸"이에요.

### 흐름제어 정답 (1)
```c
for (int i = 0; i < 6; i++) {
    if (chips[i].tested == 0) {
        continue;
    }
    if (chips[i].defects >= 3) {
        printf("첫 불량 칩: %d번\n", chips[i].id);
        break;
    }
}
```
**왜 이렇게?** `continue`는 "검사 안 받은 칩은 판단할 수 없으니 다음 칩으로!", `break`는 "불량 찾았다! 공장에 알리러 가자!"예요. 101(0개), 103(1개)은 통과, 104번(4개)에서 처음 걸려서 `첫 불량 칩: 104번`이 나와요. 106번도 불량이지만 이미 멈췄으니 안 봐요.

### 배열 정답
```c
int max = 0, where = -1;
for (int i = 0; i < 6; i++) {
    if (temp[i] == 0) {
        continue;
    }
    if (temp[i] > max) {
        max = temp[i];
        where = i;
    }
}
printf("최고 온도: %d도 (%d번째 칩)\n", max, where + 1);
```
**왜 이렇게?** "키 제일 큰 친구 찾기"랑 똑같아요. 지금까지 본 제일 큰 값을 `max`에 적어 두고, 더 큰 값이 나오면 바꿔 적어요. 이때 **누구였는지**(`where`)도 같이 적어야 나중에 "6번째 칩!"이라고 말할 수 있어요. 배열 칸 번호는 0부터 세니까 사람한테 말할 땐 `+ 1`을 해 줘요. 결과: `최고 온도: 95도 (6번째 칩)`.

### 포인터 정답
```c
int *p = defects;
int bad = 0;
while (p < defects + 6) {
    if (*p >= 3) {
        *p = -1;      // 폐기 표시
        bad++;
    }
    p++;
}
printf("폐기: %d개\n", bad);   // 2개, defects는 {0, 0, 1, -1, 2, -1}
```
**왜 이렇게?** `defects + 6`은 배열의 **마지막 칸 바로 다음 자리**, 즉 "결승선"이에요. 손가락 `p`가 결승선에 닿기 **전**(`<`)까지만 걸어가면 배열 밖으로 안 나가요. 이번에는 `i` 같은 번호 없이 **손가락 위치만으로** 반복을 멈춰요. 4개와 5개인 칸이 `-1`로 바뀌어서 폐기 2개예요. `-1`처럼 "진짜로는 나올 수 없는 값"을 표시로 쓰는 건 현업에서 자주 쓰는 방법이에요.

### 구조체 정답
```c
struct Chip {
    int id;
    int defects;
    int temp;
    int tested;
};

struct Chip one = {107, 2, 88, 1};
if (one.tested == 0) {
    printf("%d번: 미검사\n", one.id);
} else if (one.defects >= 3) {
    printf("%d번: 불량\n", one.id);
} else if (one.temp > 85) {
    printf("%d번: 과열 재검사\n", one.id);
} else {
    printf("%d번: 합격\n", one.id);
}
```
**왜 이렇게?** 칩 하나의 정보 4개를 "칩 성적표" 한 장에 묶었어요. 결함은 2개라 괜찮지만 온도가 88도(85 초과)라서 `107번: 과열 재검사`가 나와요.

### 함수 정답
```c
int yield_percent(struct Chip *c, int n) {
    int tested = 0, pass = 0;
    for (int i = 0; i < n; i++) {
        if (c[i].tested == 0) {
            continue;
        }
        tested++;
        if (c[i].defects < 3 && c[i].temp <= 85) {
            pass++;
        }
    }
    if (tested == 0) {
        return -1;
    }
    return pass * 100 / tested;
}
```
**왜 이렇게?** 합격률은 "합격한 수 ÷ 검사한 수 × 100"이에요. 그런데 검사한 칩이 0개면 **0으로 나누기**가 돼서 프로그램이 터져 버려요! 그래서 나누기 전에 "0개면 -1 돌려주고 끝!"이라고 막아 둬요. 그리고 `pass / tested * 100`으로 쓰면 2/5가 정수 나눗셈이라 0이 돼 버리니까, **먼저 100을 곱하고**(`pass * 100`) 나눠요. 검사받은 칩 5개 중 합격 2개(101, 105) → 200 / 5 = **40**.

### 흐름제어 정답 (2, 종합)
```c
int main(void) {
    struct Chip chips[6] = {
        {101, 0, 70, 1}, {102, 0, 0, 0}, {103, 1, 90, 1},
        {104, 4, 60, 1}, {105, 2, 80, 1}, {106, 5, 95, 1}
    };
    int y = yield_percent(chips, 6);
    if (y == -1) {
        printf("검사 데이터 없음\n");
    } else if (y >= 90) {
        printf("출하 승인\n");
    } else if (y >= 50) {
        printf("부분 출하 (%d%%)\n", y);
    } else {
        printf("라인 정지: 합격률 %d%%\n", y);
    }
    return 0;
}
```
**왜 이렇게?** `-1`은 "특별한 신호"라서 **제일 먼저** 확인해요. 안 그러면 `-1`이 "50 미만"으로 빠져서 "라인 정지: 합격률 -1%"라는 이상한 말이 나와요. 그다음 큰 숫자부터 차례로 물어요. `printf`에서 `%` 글자를 그대로 찍으려면 `%%`라고 두 번 써야 해요. 결과: `라인 정지: 합격률 40%`.

## 문제 2: 현대엘리베이터 스마트 엘리베이터

### 조건문 정답
```c
if (people == 0) {
    printf("취소된 호출\n");
} else if (floor > now) {
    printf("▲ 올라가요\n");
} else if (floor < now) {
    printf("▼ 내려가요\n");
} else {
    printf("문 열림\n");
}
```
**왜 이렇게?** 누가 버튼을 눌렀다가 그냥 계단으로 가 버렸으면(0명) 갈 필요가 없어요. 그래서 취소부터 확인해요. 그다음 "위냐, 아래냐, 같은 층이냐" 세 경우 중 하나는 꼭 맞으니까 마지막은 `else`로 받아요.

### 반복문 정답
```c
for (int i = 0; i < 5; i++) {
    printf("%d층 호출: %d명\n", call_floor[i], people[i]);
}
```
**왜 이렇게?** 두 배열이 **같은 번호 `i`** 로 짝을 이뤄요. `call_floor[0]`과 `people[0]`이 첫 번째 호출의 짝꿍이에요. 그래서 하나의 `i`로 두 배열을 같이 읽어요.

### 흐름제어 정답 (1)
```c
int total = 0;
for (int i = 0; i < 5; i++) {
    if (people[i] == 0) {
        continue;
    }
    if (total + people[i] > 8) {
        printf("정원 초과: %d층 손님은 다음 차례\n", call_floor[i]);
        break;
    }
    total += people[i];
    printf("%d층 탑승 (총 %d명)\n", call_floor[i], total);
}
```
출력:
```
7층 탑승 (총 3명)
5층 탑승 (총 7명)
정원 초과: 9층 손님은 다음 차례
```
**왜 이렇게?** 핵심은 **태우기 전에** "이 사람들까지 타면 8명 넘나?"(`total + people[i] > 8`)를 미리 계산하는 거예요. 먼저 태우고 나서 확인하면 이미 9명이 탄 뒤라 엘리베이터가 "삐-!" 울려요. 3층은 취소라 `continue`로 넘어가고, 9층 2명을 더하면 9명이라 멈춰요.

### 배열 정답
```c
int now = 1, dist = 0;
for (int i = 0; i < 5; i++) {
    if (people[i] == 0) {
        continue;
    }
    int d = call_floor[i] - now;
    if (d < 0) {
        d = -d;          // 음수면 양수로 뒤집기
    }
    dist += d;
    now = call_floor[i];
}
printf("총 이동: %d층\n", dist);   // 19
```
**왜 이렇게?** 7층에서 5층으로 가면 `5 - 7 = -2`인데, 엘리베이터가 "-2층 움직였어요"라고 하진 않죠? 거리는 늘 양수니까 음수면 `-`를 붙여 뒤집어요. 그리고 도착할 때마다 `now`를 **새 층으로 바꿔 줘야** 다음 거리를 맞게 재요. 1→7(6), 7→5(2), 5→9(4), 9→2(7) → 합계 **19층**.

### 포인터 정답
```c
int top = 10;
int *best = call_floor;
int *q;
for (q = call_floor + 1; q < call_floor + 5; q++) {
    if (top - *q < top - *best) {
        best = q;
    }
}
printf("가장 가까운 호출: %d층 (%ld번째 호출)\n", *best, (long)(best - call_floor + 1));
```
**왜 이렇게?** `best`는 "지금까지 제일 가까운 층을 가리키는 손가락"이에요. 값을 복사하는 대신 **손가락으로 가리키기**만 해서, 나중에 "몇 번째 칸이었지?"도 알 수 있어요. 손가락끼리 빼면(`best - call_floor`) "출발점에서 몇 칸 떨어져 있나"가 나와요. 9층은 3번 칸(0부터 셈)이니까 `+ 1` 해서 4번째 호출! 10층에서 거리는 7층 3, 3층 7, 5층 5, **9층 1**, 2층 8이에요. (꼭대기 10층이라 `10 - 층`은 항상 0 이상이에요.)

### 구조체 정답
```c
struct Elevator {
    int now;
    int load;
    int moves;
};

struct Elevator ev = {1, 0, 0};
struct Elevator *e = &ev;
e->now = 7;
e->load = 3;
e->moves += 6;
printf("현재 %d층, 탑승 %d명, 이동 %d층\n", e->now, e->load, e->moves);
```
**왜 이렇게?** `e`는 엘리베이터 카드를 가리키는 손가락이에요. 카드를 직접 들고 있을 땐 점(`ev.now`)을 쓰고, **손가락으로 가리킬 땐 화살표**(`e->now`)를 써요. `e->now`는 `(*e).now`를 짧게 쓴 거예요. 손가락으로 바꿨으니 진짜 `ev`가 바뀌어서 `ev.now`도 7이 돼요.

### 함수 정답
```c
int move_to(struct Elevator *e, int floor) {
    int d = floor - e->now;
    if (d < 0) {
        d = -d;
    }
    e->moves += d;
    e->now = floor;
    return d;
}
```
**왜 이렇게?** 이 함수는 "엘리베이터 리모컨"이에요. 엘리베이터 **주소**를 받았으니 함수 안에서 바꾼 층(`now`)과 이동 거리(`moves`)가 바깥의 진짜 엘리베이터에 그대로 남아요. 만약 주소가 아니라 `struct Elevator e`(복사본)로 받으면, 함수 안에서만 엘리베이터가 움직이고 진짜는 1층에 그대로 있는 사고가 나요!

### 흐름제어 정답 (2, 종합)
```c
int main(void) {
    struct Elevator ev = {1, 0, 0};
    struct Call calls[5] = {
        {7, 3, 0}, {3, 0, 0}, {5, 4, 0}, {9, 2, 0}, {2, 5, 0}
    };
    for (int i = 0; i < 5; i++) {
        if (calls[i].people == 0) {
            continue;
        }
        int d = move_to(&ev, calls[i].floor);
        calls[i].done = 1;
        printf("%d층 도착 (이동 %d층)\n", calls[i].floor, d);
        if (ev.moves > 10) {
            printf("점검 필요: 총 이동 %d층\n", ev.moves);
            break;
        }
    }
    int left = 0;
    for (int i = 0; i < 5; i++) {
        if (calls[i].people > 0 && calls[i].done == 0) {
            left++;
        }
    }
    printf("남은 호출: %d개\n", left);
    return 0;
}
```
(`struct Call { int floor; int people; int done; };`도 위에 정의해 둬요.)

출력:
```
7층 도착 (이동 6층)
5층 도착 (이동 2층)
9층 도착 (이동 4층)
점검 필요: 총 이동 12층
남은 호출: 1개
```
**왜 이렇게?** `move_to(&ev, ...)`에서 `&`는 "엘리베이터 주소를 넘겨줘!"라는 뜻이에요. 그래서 함수가 부를 때마다 `ev.moves`가 6 → 8 → 12로 쌓여요. 12는 10보다 커서 `break`! 2층 손님은 아직 `done == 0`이라서 두 번째 반복문이 "남은 호출 1개"라고 세어 줘요. 3층은 취소(0명)라서 남은 호출에 넣지 않아요(`people > 0 &&`). 이렇게 **처리했는지 표시(`done`)를 남겨 두는 것** 덕분에, 점검 뒤에 다시 운행할 때 어디부터 가야 할지 알 수 있어요. 진짜 엘리베이터 회사도 이렇게 "못 끝낸 일 목록"을 꼭 남겨 둬요!
