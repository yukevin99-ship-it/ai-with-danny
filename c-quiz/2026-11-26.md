## 엔지니어가 직면한 가상의 문제 1

**[코레일 KTX 운행관제팀 — 가상]** 오늘 아침 눈이 많이 와서 KTX 열차들이 늦게 도착하고 있어요. 손님들이 "제 기차 얼마나 늦어요? 환불 받을 수 있나요?" 하고 묻는 전화가 쏟아지고 있어요. 그런데 옛날 프로그램이 **고장 난 센서가 보낸 `-1`(정보 없음)** 값까지 "1분 일찍 도착"이라고 잘못 안내하고 있었어요! 엔지니어인 너는 **열차별 지연 시간을 확인하고, 환불 금액을 계산하는 프로그램**을 새로 만들어야 해요.

**오늘의 규칙**

| 지연 시간(`delay`, 분) | 안내 문구 | 환불 |
|---|---|---|
| `-1` (음수) | 정보 오류 (센서 고장) | 계산 안 함 |
| `0` | 정시 도착 | 0원 |
| `1` ~ `19` | 조금 늦어요 | 0원 |
| `20` ~ `59` | 환불 대상 | 승차권값의 **4분의 1** |
| `60` 이상 | 많이 늦어요 (긴급) | 승차권값의 **절반** |

**오늘의 데이터** (모든 퀴즈에서 같이 써요)

```c
// 열차 5대의 지연 시간(분). -1은 센서 고장으로 정보 없음
int delays[5] = {0, 12, 25, -1, 60};

// 승차권 값(원)
int price = 40000;
```

### 조건문 퀴즈1

**📘 개념 설명 — 조건문 (`if / else if / else`)**
- **정의**: "만약 ~라면 이걸 하고, 아니면 저걸 해"라고 컴퓨터에게 **갈림길**을 알려주는 문법이에요.
- **적용 논리**: 위에서부터 차례로 검사하다가 **처음으로 참(true)인 곳 하나만** 실행하고 나머지는 건너뛰어요. 그래서 **이상한 값(음수)을 맨 먼저** 걸러내야 해요.
- **응용 가능성**: 온도에 따라 에어컨 켜기, 점수에 따라 등급 매기기, 로그인 비밀번호 맞는지 확인하기 등 **모든 "판단"** 에 쓰여요.

```c

    /* 여기에 코드를 작성하세요 */
    // 출력 예: delay = 25 이면 "환불 대상"

    return 0;
}
```

- **응용 가능성**: 열차 1000대 검사, 학생 30명 성적 출력, 사진의 모든 점(픽셀) 바꾸기 등 **"여러 개를 하나씩 다 보기"** 에 항상 쓰여요.

**문제**: `for` 문으로 열차 5대의 지연 시간을 `"1번 열차: 0분"` 처럼 한 줄씩 출력하세요. (열차 번호는 1번부터 시작해요!)

```c
#include <stdio.h>

int main(void) {
    int delays[5] = {0, 12, 25, -1, 60};

    /* 여기에 코드를 작성하세요 */

    return 0;
}
```

### 흐름제어 퀴즈1

**📘 개념 설명 — 흐름제어 (`continue`, `break`)**
- **정의**: 반복문 안에서 **"이번 것만 건너뛰기"(`continue`)** 와 **"반복 완전히 멈추기"(`break`)** 를 하는 명령이에요.
- **적용 논리**: `continue`를 만나면 아래 코드를 무시하고 **다음 차례로** 넘어가요. `break`를 만나면 반복문을 **바로 빠져나가요**.
- **응용 가능성**: 고장 난 데이터는 건너뛰기(`continue`), 위험한 상황을 발견하면 즉시 멈추고 알리기(`break`) — 실제 관제 시스템이 이렇게 움직여요.

**문제**: 열차를 1번부터 차례로 검사하세요.
1. 지연 시간이 **음수**면 `"3번 열차: 정보 오류, 건너뜀"`처럼 출력하고 **건너뛰기**(`continue`)
2. 지연 시간이 **60분 이상**이면 `"5번 열차: 긴급! 관제실 호출"`을 출력하고 **검사를 멈추기**(`break`)
3. 그 밖에는 `"1번 열차: 0분 지연"`처럼 출력

```c
#include <stdio.h>

int main(void) {
    int delays[5] = {0, 12, 25, -1, 60};

    for (int i = 0; i < 5; i++) {
        /* 여기에 코드를 작성하세요 */
    }
    printf("검사 끝\n");
    return 0;
}
```

### 배열 퀴즈1

**📘 개념 설명 — 배열**
- **정의**: 같은 종류의 값 여러 개를 **번호 붙은 칸**에 나란히 담는 상자예요. `delays[0]`이 첫 번째 칸이에요 (**0번부터** 시작!).
- **적용 논리**: 칸 번호(인덱스)만 바꾸면 모든 값을 꺼낼 수 있어서 **반복문과 짝꿍**이에요.
- **응용 가능성**: 하루 기온 24개, 게임 점수 랭킹, 장바구니 가격 목록 등 **"같은 종류 여러 개"** 는 거의 다 배열로 저장해요.

**문제**: 배열 `delays`에서 **정보 오류(-1)는 빼고**,
1. 정상 정보가 있는 열차 수(`count`)
2. 지연 시간의 합계(`total`)
3. 가장 많이 늦은 시간(`maxDelay`)
를 구해서 출력하세요.

```c
#include <stdio.h>

int main(void) {
    int delays[5] = {0, 12, 25, -1, 60};
    int count = 0, total = 0, maxDelay = 0;

    /* 여기에 코드를 작성하세요 */

    printf("정상 정보 열차: %d대\n", count);
    printf("지연 합계: %d분\n", total);
    printf("가장 긴 지연: %d분\n", maxDelay);
    return 0;
}
```

### 흐름제어 퀴즈2 (종합)

**📘 개념 설명 — 모두 합친 흐름제어**
- **정의**: 지금까지 배운 조건문·반복문·배열·포인터·구조체·함수를 **한 프로그램 안에서 같이** 쓰는 거예요.
- **적용 논리**: ① **구조체 배열**에 열차들을 담고 → ② **for**로 하나씩 보면서 → ③ **포인터**로 그 열차를 가리키고 → ④ 정보 오류는 **continue**로 건너뛰고 → ⑤ **함수**로 환불을 계산해서 → ⑥ **조건문**으로 환불이 있을 때만 합계에 더해요.
- **응용 가능성**: 실제 회사 프로그램은 거의 다 이런 모양(**데이터 묶음 + 반복 + 판단 + 함수**)이에요.

**문제**: 열차 5대 모두에 대해 환불 금액을 계산해서
- 환불이 있는 열차만 `"105호 강릉행: 10000원 환불"` 처럼 출력하고
- 정보 오류 열차는 `"107호 목포행: 정보 오류, 나중에 다시 확인"` 을 출력하고 건너뛰고
- 마지막에 **환불 열차 수**와 **환불 총액**을 출력하세요.
- 반복문 안에서는 꼭 `Train *t = &trains[i];` 처럼 **포인터**로 열차를 가리켜서 `t->delay` 로 값을 꺼내세요.

```c
#include <stdio.h>

typedef struct {
    int  no;
    char dest[12];
    int  delay;
} Train;

int refund(int price, int delay) {
    if (delay >= 60) return price / 2;
    else if (delay >= 20) return price / 4;
    else return 0;
}

int main(void) {
    Train trains[5] = {
        {101, "부산", 0},
        {103, "광주", 12},
        {105, "강릉", 25},
        {107, "목포", -1},
        {109, "대구", 60},
    };
    int price = 40000;
    int refundCount = 0;
    int refundTotal = 0;

    /* 여기에 코드를 작성하세요 */

    printf("환불 열차: %d대, 환불 총액: %d원\n", refundCount, refundTotal);
    return 0;
}
```

### 반복문 퀴즈1

## 문제 1 — KTX 열차 지연 환불

### 조건문 퀴즈1 정답

```c
#include <stdio.h>

int main(void) {
    int delay = 25;

    if (delay < 0) {
        printf("정보 오류 (센서 고장)\n");
    } else if (delay == 0) {
        printf("정시 도착\n");
    } else if (delay < 20) {
        printf("조금 늦어요\n");
    } else if (delay < 60) {
        printf("환불 대상\n");
    } else {
        printf("많이 늦어요 (긴급)\n");
    }
    return 0;
}
```

출력: `환불 대상`

**🧒 쉽게 설명하면**
놀이공원 입구에서 키를 재는 아저씨를 생각해 봐요. "먼저 **이상한 손님**(키가 마이너스? 말도 안 돼!)부터 걸러내고, 그다음 순서대로 확인하는" 거예요.
- **왜 `delay < 0` 을 맨 앞에?** 옛날 프로그램은 이걸 안 해서 `-1`을 "1분 일찍 왔어요"로 안내했어요. 이상한 값은 **제일 먼저** 막아야 뒤의 검사들이 헷갈리지 않아요.
- **왜 `delay < 20` 만 써도 될까?** `else if` 는 "앞의 것이 다 아니었을 때만" 검사해요. 여기까지 왔다는 건 이미 0보다 크다는 뜻이니까 `1~19` 를 따로 안 써도 돼요.
- **`==` 는 "같아요?"** 라는 질문이고, `=` 는 "넣어라!"라는 명령이에요. `if (delay = 0)` 이라고 쓰면 delay에 0을 넣어 버리는 큰 실수가 돼요!

### 흐름제어 퀴즈1 정답

```c
#include <stdio.h>

            printf("%d번 열차: 긴급! 관제실 호출\n", i + 1);
            break;
        }
        printf("%d번 열차: %d분 지연\n", i + 1, delays[i]);

    printf("검사 끝\n");
    return 0;
}
```

출력:
```

2번 열차: 12분 지연
3번 열차: 25분 지연
4번 열차: 정보 오류, 건너뜀
5번 열차: 긴급! 관제실 호출
검사 끝
```

**🧒 쉽게 설명하면**
- `continue` = **"이 문제는 패스! 다음 문제로"**. 시험 볼 때 모르는 문제는 건너뛰고 다음 문제를 푸는 것처럼, 4번 열차는 정보가 없으니 아래 출력 코드를 건너뛰고 5번 열차로 가요.
- `break` = **"시험 끝! 연필 내려놓기"**. 화재경보가 울리면 문제를 더 풀지 않고 바로 나가는 것처럼, 60분 넘게 늦은 열차를 보면 바로 관제실을 불러야 하니까 반복을 멈춰요.
- **왜 `continue` 가 먼저?** `-1` 은 60보다 작아서 상관없지만, 일반적으로 **"이상한 값 거르기"를 먼저** 해야 그 뒤 검사가 안전해요.
- `break` 로 나가도 반복문 **밖의** `printf("검사 끝\n")` 은 실행돼요. `break` 는 반복문만 빠져나가는 거지 프로그램을 끝내는 게 아니에요.

### 배열 퀴즈1 정답

```c
#include <stdio.h>

int main(void) {
    int delays[5] = {0, 12, 25, -1, 60};
    int count = 0, total = 0, maxDelay = 0;

    for (int i = 0; i < 5; i++) {
        if (delays[i] < 0) continue;      // 정보 오류는 빼기

        count++;                          // 정상 열차 1대 추가
        total += delays[i];               // 합계에 더하기
        if (delays[i] > maxDelay) {       // 지금까지 최고보다 크면
            maxDelay = delays[i];         // 새 최고 기록!
        }
    }

    printf("정상 정보 열차: %d대\n", count);
    printf("지연 합계: %d분\n", total);
    printf("가장 긴 지연: %d분\n", maxDelay);
    return 0;
}
```

출력:
```
정상 정보 열차: 4대
지연 합계: 97분
가장 긴 지연: 60분
```
(0 + 12 + 25 + 60 = 97)

**🧒 쉽게 설명하면**
- **세기(`count++`)**: 사탕을 하나 넣을 때마다 손가락을 하나씩 펴는 것.
- **더하기(`total += ...`)**: 저금통에 동전을 하나씩 넣는 것. `total += x` 는 `total = total + x` 를 짧게 쓴 거예요.
- **최댓값 찾기**: 줄 선 친구들 키를 재면서 "지금까지 제일 큰 친구"를 기억하다가, 더 큰 친구가 나오면 바꿔 기억하는 거예요.
- **왜 `-1` 을 빼야 해?** 빼지 않으면 합계가 96분이 되고 "정상 열차 5대"라고 거짓말을 하게 돼요. 고장 난 값이 섞이면 **통계 전체가 틀려져요**.

### 포인터 변수 퀴즈1 정답

```c
#include <stdio.h>

void addDelay(int *d, int minutes) {
    *d = *d + minutes;     // d가 가리키는 "진짜 칸"의 값을 바꾸기
}

int main(void) {
    int delays[5] = {0, 12, 25, -1, 60};

    printf("바뀌기 전: %d분\n", delays[1]);
    addDelay(&delays[1], 15);              // 2번 열차 칸의 "주소"를 넘기기
    printf("바뀐 후: %d분\n", delays[1]);
    return 0;
}
```

출력:
```
바뀌기 전: 12분
바뀐 후: 27분
```

**🧒 쉽게 설명하면**
친구에게 내 공책을 **복사해서** 주면 친구가 거기에 낙서해도 내 공책은 그대로죠? 그런데 **"내 공책은 3번 사물함에 있어"라고 주소를 알려주면** 친구가 사물함에 가서 **진짜 내 공책**에 써요.
- `&delays[1]` = "2번 열차 칸이 있는 사물함 번호(주소)"
- `int *d` = "사물함 번호를 받아 적는 쪽지"
- `*d` = "쪽지에 적힌 사물함을 열어서 안에 든 값"
- 만약 `void addDelay(int d, int minutes)` 로 만들었다면 **복사본**만 바뀌고 `delays[1]` 은 계속 12분이에요. 관제실 화면에는 계속 "12분 늦어요"라고 틀리게 나오겠죠!

### 구조체 퀴즈1 정답

```c
#include <stdio.h>

struct Train {
    int  no;
    char dest[12];
    int  delay;
};

int main(void) {
    struct Train t = {105, "강릉", 25};

    printf("%d호 %s행: %d분 지연\n", t.no, t.dest, t.delay);
    return 0;
}
```

출력: `105호 강릉행: 25분 지연`

**🧒 쉽게 설명하면**
포켓몬 카드 한 장에 **이름, HP, 기술**이 같이 적혀 있죠? 구조체는 이런 **"정보 카드"를 직접 디자인**하는 거예요.
- `struct Train { ... };` = 카드 디자인(틀) 만들기 — 아직 카드는 없어요.
- `struct Train t = {...};` = 그 틀로 **진짜 카드 한 장** 만들기.
- `t.no`, `t.dest` = 카드에서 원하는 칸 읽기. 점(`.`)은 "~의"라고 읽으면 돼요. "t의 번호".
- 따로따로 `int no; char dest[12]; int delay;` 변수 세 개를 만들면, 열차가 100대가 될 때 변수가 300개가 돼서 엉켜요. 구조체로 묶으면 **열차 하나 = 카드 하나**라서 깔끔해요.
- `%s` 는 글자들(문자열)을 출력할 때 쓰는 표시예요.

### 함수 퀴즈1 정답

```c
#include <stdio.h>

int refund(int price, int delay) {
    if (delay >= 60) {
        return price / 2;
    } else if (delay >= 20) {
        return price / 4;
    } else {
        return 0;
    }
}

int main(void) {
    printf("%d원\n", refund(40000, 12));
    printf("%d원\n", refund(40000, 25));
    printf("%d원\n", refund(40000, 60));
    return 0;
}
```

출력:
```
0원
10000원
20000원
```

**🧒 쉽게 설명하면**
함수는 **자판기**예요. 돈(승차권값)과 버튼(지연 시간)을 넣으면 음료(환불 금액)가 `return` 으로 툭 나와요.
- **왜 `delay >= 60` 을 먼저?** 큰 것부터 검사하면 60분은 첫 번째 칸에서 바로 걸려요. 만약 `delay >= 20` 을 먼저 쓰면 60분 열차도 거기서 걸려서 **절반 대신 4분의 1만** 환불하는 버그가 생겨요!
- **`return` 을 만나면 함수는 그 자리에서 끝나요.** 그래서 뒤쪽 조건은 검사하지 않아요.
- 함수로 만들어 두면 매표소 프로그램, 앱, 홈페이지가 **모두 같은 자판기**를 써서 환불 금액이 서로 달라지는 일이 없어요.

### 흐름제어 퀴즈2 (종합) 정답

```c
#include <stdio.h>

typedef struct {
    int  no;
    char dest[12];
    int  delay;
} Train;

int refund(int price, int delay) {
    if (delay >= 60) return price / 2;
    else if (delay >= 20) return price / 4;
    else return 0;
}

int main(void) {
    Train trains[5] = {
        {101, "부산", 0},
        {103, "광주", 12},
        {105, "강릉", 25},
        {107, "목포", -1},
        {109, "대구", 60},
    };
    int price = 40000;
    int refundCount = 0;
    int refundTotal = 0;

    for (int i = 0; i < 5; i++) {
        Train *t = &trains[i];                 // ① i번째 열차 카드를 가리키기

        if (t->delay < 0) {                    // ② 정보 오류는 건너뛰기
            printf("%d호 %s행: 정보 오류, 나중에 다시 확인\n", t->no, t->dest);
            continue;
        }

        int money = refund(price, t->delay);   // ③ 함수로 환불 계산

        if (money > 0) {                       // ④ 환불이 있을 때만
            printf("%d호 %s행: %d원 환불\n", t->no, t->dest, money);
            refundCount++;
            refundTotal += money;
        }
    }

    printf("환불 열차: %d대, 환불 총액: %d원\n", refundCount, refundTotal);
    return 0;
}
```

출력:
```
105호 강릉행: 10000원 환불
107호 목포행: 정보 오류, 나중에 다시 확인
109호 대구행: 20000원 환불
환불 열차: 2대, 환불 총액: 30000원
```

**🧒 쉽게 설명하면**
택배 아저씨가 상자 5개를 하나씩 확인하는 모습이에요.
1. **상자를 손가락으로 가리켜요** (`Train *t = &trains[i];`) — 상자를 통째로 복사하지 않고 "이거!" 하고 가리키기만 해요.
2. **주소가 지워진 상자는 옆으로 빼 둬요** (`continue`).
3. **무게를 저울(함수)에 올려요** (`refund(...)`).
4. **배달비가 있는 상자만 장부에 적어요** (`if (money > 0)`).
- **`t->delay` 는 뭐예요?** `t` 는 카드 자체가 아니라 카드를 **가리키는 손가락**이에요. 손가락이 가리키는 카드의 칸을 읽을 때는 점(`.`) 대신 **화살표(`->`)** 를 써요.
- **typedef** 는 `struct Train` 이라고 매번 길게 쓰기 귀찮으니 그냥 `Train` 이라고 부르자는 **별명 붙이기**예요.

### 반복문 퀴즈1 정답

```c
#include <stdio.h>

int main(void) {
    int left = 3;

    while (left > 0) {
        printf("반납까지 %d일 남았어요\n", left);
        left--;                       // 하루 줄이기 (이게 없으면 무한 반복!)

```

**🧒 쉽게 설명하면**
로켓 발사 카운트다운 "3, 2, 1, 발사!"랑 같아요.
- `while (left > 0)` = "남은 날이 0보다 크면 계속해."

- **for 대신 while을 쓰는 이유**: "조건이 맞는 동안"이라는 느낌이 더 잘 드러나요. 둘 다 같은 일을 할 수 있어요.

### 흐름제어 퀴즈1 정답

```c
#include <stdio.h>

int main(void) {
    int shelf[8] = {11, 0, 27, 0, 35, 42, 0, 58};
    int want = 42;
    int found = 0;

    for (int i = 0; i < 8; i++) {
        if (shelf[i] == 0) continue;          // 빈칸은 건너뛰기

        if (shelf[i] == want) {
            printf("%d번 책은 %d번째 칸에 있어요\n", want, i + 1);
            found = 1;                        // 깃발 올리기!
            break;                            // 찾았으니 그만
        }
    }

    if (found == 0) {
        printf("%d번 책은 지금 없어요\n", want);
    }
    return 0;
}
```

출력: `42번 책은 6번째 칸에 있어요`

**🧒 쉽게 설명하면**
숨바꼭질이에요! 술래가 방을 하나씩 열어 봐요.
- **빈방(0)** 은 볼 것도 없으니 바로 다음 방으로 (`continue`).
- **친구를 찾으면** "찾았다!" 하고 깃발을 들고(`found = 1`) 더 안 찾아요 (`break`). 이미 찾았는데 나머지 방까지 다 열어 보면 시간 낭비죠.
- **깃발(`found`)이 왜 필요해?** 반복이 끝났을 때 "찾아서 멈춘 건지, 끝까지 다 봤는데 없던 건지" 구별해야 하거든요. 깃발이 내려가 있으면(0) "없어요"를 알려줘요.
- `want` 를 99로 바꿔 보세요. 깃발이 안 올라가서 "99번 책은 지금 없어요"가 나와요.

### 배열 퀴즈1 정답

```c
#include <stdio.h>

int main(void) {

    int totalFine = 0;

    for (int i = 0; i < 5; i++) {
        if (days[i] > 14) {
            lateBooks++;

        }
    }

    printf("연체된 책: %d권\n", lateBooks);

```

```
연체료 합계: 900원
```

- **왜 `> 14`?** 14일째는 아직 괜찮고, 15일째부터 연체예요. "초과"는 `>`, "이상"은 `>=` — 이 한 글자 차이로 14일째 손님이 억울하게 100원을 낼 수도 있어요!

### 포인터 변수 퀴즈1 정답

```c
#include <stdio.h>

int payFine(int *money, int fine) {
    if (*money >= fine) {          // 진짜 지갑에 돈이 충분하면
        *money = *money - fine;    // 진짜 지갑에서 빼기
        return 1;                  // 성공
    }
    return 0;                      // 부족하면 그대로, 실패
}

int main(void) {
    int point = 500;

    if (payFine(&point, 300)) printf("결제 성공! 남은 포인트: %d\n", point);
    else                      printf("포인트가 부족해요. 남은 포인트: %d\n", point);

    if (payFine(&point, 600)) printf("결제 성공! 남은 포인트: %d\n", point);
    else                      printf("포인트가 부족해요. 남은 포인트: %d\n", point);
    return 0;
}
```

출력:
```
결제 성공! 남은 포인트: 200
포인트가 부족해요. 남은 포인트: 200
```

**🧒 쉽게 설명하면**
엄마한테 "내 저금통 **책상 위에 있어**"라고 위치를 알려주고, 엄마가 거기서 돈을 꺼내 가는 거예요.
- `&point` = 저금통 위치 알려주기
- `*money >= fine` = 저금통을 열어 보고 "돈이 충분해?" 확인
- **왜 먼저 확인해?** 확인 안 하고 빼면 포인트가 **−100** 이 돼요. 실제 은행이라면 없는 돈을 써 버리는 큰 사고예요! 그래서 **조건문으로 지키고 → 포인터로 바꾸는** 순서가 중요해요.
- 함수가 1(성공)/0(실패)을 돌려주니까 `main` 에서 `if (payFine(...))` 로 바로 결과를 보고 메시지를 고를 수 있어요. C에서는 **0이 아니면 참, 0이면 거짓**이에요.

### 구조체 퀴즈1 정답

```c

typedef struct {
    int  id;
    char title[20];

    int  returned;
} Book;

void returnBook(Book *b) {
    b->returned = 1;
    printf("%s 반납 완료!\n", b->title);
}

int main(void) {
    Book myBook = {7, "어린왕자", 12, 0};
```

```
어린왕자 반납 완료!

```

**🧒 쉽게 설명하면**
도서관 사서 선생님께 책 카드를 **직접 건네서** "반납" 도장을 찍어 받는 거예요.
- `returnBook(&myBook)` = 카드의 **위치(주소)** 를 알려줘서 선생님이 **진짜 카드**에 도장을 찍게 하기.
- 함수 안에서는 `b` 가 카드를 **가리키는 손가락**이니까 `b->returned` 처럼 **화살표**로 칸을 열어요.
- `main` 에서는 `myBook` 이 카드 **그 자체**니까 `myBook.returned` 처럼 **점**을 써요.
- 만약 `void returnBook(Book b)` 로 주소 없이 넘기면, 선생님은 **복사한 카드**에 도장을 찍어서 내 진짜 카드는 계속 `returned = 0` 이에요. 앱에서는 "반납했는데 아직 빌린 걸로 나와요!" 하는 버그가 돼요.

### 함수 퀴즈1 정답

```c
#include <stdio.h>

#define LOAN_DAYS    14
#define FINE_PER_DAY 100

int lateFee(int days) {
    if (days > LOAN_DAYS) {
        return (days - LOAN_DAYS) * FINE_PER_DAY;
    }
    return 0;
}

int main(void) {
    printf("%d원\n", lateFee(12));
    printf("%d원\n", lateFee(14));
    printf("%d원\n", lateFee(17));
    printf("%d원\n", lateFee(20));
    return 0;
}
```

출력:
```
0원
0원
300원
600원
```

**🧒 쉽게 설명하면**
- `#define LOAN_DAYS 14` 는 **"14라는 숫자에 이름표 붙이기"** 예요. 코드 여기저기 `14` 가 흩어져 있으면 도서관이 "이제 21일까지 빌려줘요!" 할 때 하나하나 찾아 고쳐야 하지만, 이름표를 쓰면 **맨 위 한 줄만** 바꾸면 끝이에요.
- 이름표 덕분에 코드를 읽는 사람도 "14가 뭐지?" 대신 "아, 대출 기간이구나" 하고 바로 알아요.
- `if` 안에서 `return` 하면 함수가 바로 끝나니까, `else` 없이 아래에 `return 0;` 만 써도 "아니면 0원"이 돼요.

### 흐름제어 퀴즈2 (종합) 정답

```c
#include <stdio.h>

#define LOAN_DAYS    14
#define FINE_PER_DAY 100

typedef struct {
    int  id;
    char title[20];
    int  days;
    int  returned;
} Book;

int lateFee(int days) {
    if (days > LOAN_DAYS) return (days - LOAN_DAYS) * FINE_PER_DAY;
    return 0;
}

int main(void) {
    Book books[5] = {
        {1, "어린왕자",   3, 0},
        {2, "마법천자문", 12, 1},
        {3, "해리포터",   17, 0},
        {4, "수학귀신",   14, 0},
        {5, "갈매기",     20, 0},
    };
    int lateCount = 0;
    int totalFine = 0;

    for (int i = 0; i < 5; i++) {
        Book *b = &books[i];                  // ① i번째 책 가리키기

        if (b->returned == 1) continue;       // ② 반납한 책은 건너뛰기

        int fee = lateFee(b->days);           // ③ 함수로 연체료 계산
        printf("[%d] %s - %d일째, 연체료 %d원\n", b->id, b->title, b->days, fee);

        if (fee > 0) {                        // ④ 연체된 책이면
            lateCount++;
            totalFine += fee;
        }
    }

    printf("총 연체료: %d원\n", totalFine);
    if (lateCount >= 2) {                     // ⑤ 반복이 끝난 뒤 최종 판단
        printf("대출 정지: 연체된 책을 먼저 반납해 주세요\n");
    } else {
        printf("새 책을 빌릴 수 있어요\n");
    }
    return 0;
}
```

출력:
```
[1] 어린왕자 - 3일째, 연체료 0원
[3] 해리포터 - 17일째, 연체료 300원
[4] 수학귀신 - 14일째, 연체료 0원
[5] 갈매기 - 20일째, 연체료 600원
총 연체료: 900원
대출 정지: 연체된 책을 먼저 반납해 주세요
```

**🧒 쉽게 설명하면**
내 책가방을 정리하는 순서랑 같아요.
1. 책을 하나씩 **손가락으로 가리켜요** (`Book *b = &books[i]`).
2. **이미 돌려준 책**(마법천자문)은 가방에 없으니까 넘어가요 (`continue`).
3. 남은 책마다 **연체료 계산기(함수)** 를 눌러요.
4. 연체료가 있는 책은 **"늦은 책" 개수에 하나 더하고** 돈도 합쳐요.
5. 책가방을 **다 정리한 뒤에** "늦은 책이 2권 이상이네? 그럼 새 책은 못 빌려요!" 하고 결정해요.
- **왜 대출 정지 판단은 반복문 밖에서?** 책을 다 세어 봐야 몇 권이 늦었는지 알 수 있어요. 반복문 **안에서** 판단하면 첫 번째 책만 보고 "빌릴 수 있어요!"를 여러 번 외치는 이상한 앱이 돼요.
- 수학귀신은 14일째라 연체료 0원 — 배열 퀴즈에서 배운 **경계값** 규칙이 함수 안에서도 그대로 지켜졌어요.

## 📝 오늘의 핵심 정리

| 도구 | 한 줄 요약 | 오늘 쓴 곳 |
|---|---|---|
| `if / else if / else` | 위에서부터 처음 맞는 것 하나만 실행 | 지연 안내, 반납 상태 신호등 |
| `for` | 정해진 횟수만큼 반복 (배열과 짝꿍) | 열차 5대, 책 5권 검사 |
| `while` | 조건이 참인 동안 반복 (값을 꼭 바꿔 줘야 함) | 반납 카운트다운 |
| `continue` | 이번 것만 건너뛰기 | 센서 고장 열차, 빈 책장 칸, 반납한 책 |
| `break` | 반복 즉시 멈추기 | 긴급 열차 발견, 책 찾기 |
| 배열 | 번호 붙은 칸 (0번부터!) | 지연 시간 목록, 책장 |
| 포인터 `*` `&` | 주소를 넘겨서 원본을 바꾸기 | 지연 추가, 포인트 결제 |
| 구조체 `.` `->` | 여러 정보를 카드 한 장으로 | 열차 카드, 책 카드 |
| 함수 `return` | 규칙을 이름 붙인 기계로 | 환불 계산, 연체료 계산 |

**오늘의 버그 사냥 포인트 🐛**
1. **이상한 값(음수)은 맨 먼저 거르기** — 안 그러면 "-1분 = 1분 일찍 도착" 같은 엉터리 안내가 나와요.
2. **경계값(`<` vs `<=`, `>` vs `>=`)** — 14일째 손님에게 연체료를 받는 실수!
3. **큰 조건부터 검사하기** — 60분 지연을 20분 규칙으로 계산하는 실수!
4. **while 안에서 값 바꾸기** — 무한 알림 폭탄!
5. **원본을 바꾸려면 주소(`&`)를 넘기기** — "반납했는데 안 된 걸로 나와요" 버그!
