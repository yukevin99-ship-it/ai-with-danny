## 📌 엔지니어가 직면한 가상의 문제 1
**[Uber 배차팀]** 손님이 택시를 불렀어요. 근처 기사님 5명의 거리(km)를 보고, 가까운 기사님을 빨리 찾아 배정해야 해요.

### 조건문 퀴즈1
정수 `dist`(기사님까지 거리, km)가 있을 때, 1 이하이면 "바로 배차", 1 초과 3 이하이면 "배차 가능", 그 밖에는 "너무 멀어요"를 출력하는 코드를 작성하세요.

### 반복문 퀴즈1
`int dist[5] = {5, 3, 8, 2, 6};` 에서 가장 짧은 거리를 for문으로 찾아 출력하세요.

### 흐름제어 퀴즈1
`int dist[5] = {5, 0, 3, 1, 2};` (0은 GPS 오류로 위치를 모르는 기사님)
기사 번호는 1번부터입니다. 0이면 건너뛰고(`continue`), 거리가 1 이하인 기사님을 처음 발견하면 "N번 기사 배정!"을 출력하고 반복을 끝내세요(`break`). 나머지는 "N번 기사 대기"를 출력합니다.

# ✅ 정답과 해설

## 📌 엔지니어가 직면한 가상의 문제 1 (Uber 배차)

### 조건문 정답
```c
#include <stdio.h>
int main(void) {
    int dist = 2;
    if (dist <= 1) {
        printf("바로 배차\n");
    } else if (dist <= 3) {
        printf("배차 가능\n");
    } else {
        printf("너무 멀어요\n");
    }
    return 0;
}
```
**쉬운 설명:** 학교 앞 문방구가 얼마나 가까운지 정하는 것과 같아요. 가장 가까운 "1 이하"를 먼저 물어봐요. 그다음 줄에서는 이미 1보다 크다는 걸 알기 때문에 "3 이하"만 물으면 돼요. `else if`는 앞의 질문에서 떨어진 친구들만 받는 두 번째 줄이에요.

### 반복문 정답
```c
#include <stdio.h>
int main(void) {
    int dist[5] = {5, 3, 8, 2, 6};
    int min = dist[0];
    for (int i = 1; i < 5; i++) {
        if (dist[i] < min) {
            min = dist[i];
        }
    }
    printf("가장 가까운 거리: %d km\n", min);   // 2 km
    return 0;
}
```
**쉬운 설명:** 키 작은 친구를 찾는 달리기 시합 같아요. 처음엔 첫 번째 친구(`dist[0]`)가 "지금까지 1등"이에요. 다음 친구를 볼 때마다 "나 더 작은데?" 하면 1등을 바꿔요. 끝까지 보면 진짜 1등이 남아요. 처음 값을 `0`으로 두면 0보다 작은 값이 없어서 답이 틀려요. 그래서 배열의 첫 값으로 시작해요!

### 흐름제어 정답
```c
#include <stdio.h>
int main(void) {
    int dist[5] = {5, 0, 3, 1, 2};
    for (int i = 0; i < 5; i++) {
        if (dist[i] == 0) {
            continue;                       // GPS 오류 기사님 건너뛰기
        }
        if (dist[i] <= 1) {
            printf("%d번 기사 배정!\n", i + 1);
            break;                          // 찾았으니 바로 끝
        }
        printf("%d번 기사 대기\n", i + 1);
    }
    return 0;
}
```
출력:
```
1번 기사 대기
3번 기사 대기
4번 기사 배정!
```
**쉬운 설명:** 술래잡기에서 숨은 친구를 찾는 것과 같아요. 안 보이는 자리(0)는 그냥 지나가고(`continue`), 한 명을 찾으면 바로 "찾았다!" 하고 게임을 끝내요(`break`). 그래서 5번 기사님은 확인하지 않아요. 손님은 기다리고 있으니까 빨리 정하는 게 중요해요!

## 📌 엔지니어가 창작해야 하는 가상의 프로그램 1 (Duolingo 연속 출석)

### 조건문 정답
```c
#include <stdio.h>
int main(void) {
    int minutes = 45;
    if (minutes >= 30) {
        printf("목표 달성\n");
    } else if (minutes >= 1) {
        printf("조금 했어요\n");
    } else {
        printf("오늘은 쉬었어요\n");
    }
    return 0;
}
```
**쉬운 설명:** 선생님이 숙제 도장을 찍어 주는 것과 같아요. 많이 했으면 큰 도장, 조금 했으면 작은 도장, 안 했으면 도장 없음! 가장 높은 기준(30 이상)부터 차례로 물어보면 빠짐없이 나눌 수 있어요.

### 반복문 정답
```c
#include <stdio.h>
int main(void) {
    int study[7] = {30, 0, 45, 20, 60, 15, 40};
    int sum = 0;
    int i = 0;
    while (i < 7) {
        sum += study[i];
        i++;
    }
    printf("일주일 합계: %d분\n", sum);   // 210분
    return 0;
}
```
**쉬운 설명:** 일주일 동안 먹은 간식 개수를 모두 더하는 거예요. 합계 주머니(`sum`)는 0으로 시작하고, 하루씩 넘기면서(`i++`) 주머니에 넣어요. `while`에서는 `i++`를 잊으면 같은 날만 영원히 더하는 무한 반복이 돼요. 조심해요!

### 흐름제어 정답
```c
#include <stdio.h>
int main(void) {
    int study[7] = {30, 0, 45, 20, 60, 15, 40};
    int streak = 0;
    for (int i = 0; i < 7; i++) {
        if (study[i] == 0) {
            streak = 0;                     // 연속 기록 끊김
            printf("%d일차 쉼\n", i + 1);
            continue;
        }
        streak++;
        printf("%d일차 연속 %d일\n", i + 1, streak);
        if (streak == 3) {
            printf("연속 3일 달성! 뱃지 획득\n");
            break;
        }
    }
    return 0;
}
```
출력:
```
1일차 연속 1일
2일차 쉼
3일차 연속 1일
4일차 연속 2일
5일차 연속 3일
연속 3일 달성! 뱃지 획득
```
**쉬운 설명:** 줄넘기를 쉬지 않고 몇 번 넘었는지 세는 것과 같아요. 발이 걸리면(0분) 처음부터 다시 세야 해서 `streak = 0`으로 되돌리고, 그날은 더 할 일이 없으니 다음 날로 넘어가요(`continue`). 계속 성공하면 숫자가 1, 2, 3으로 올라가고, 3이 되면 상을 주고 끝내요(`break`). 1일차의 1일은 2일차에 끊겨서 다시 1부터 시작하는 게 포인트예요!
