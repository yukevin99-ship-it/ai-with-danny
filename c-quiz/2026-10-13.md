## ✅ 정답 및 해설 (먼저 직접 풀어본 뒤 보세요!)

### 문제1 - 조건문
```c
if (psi < 50) printf("부족\n");
else if (psi <= 100) printf("정상\n");
else printf("과압\n");
```
👉 놀이공원 키 제한처럼 "너무 작아도, 너무 커도 안 돼요". 먼저 "50보다 작아?"를 묻고 아니라면 "100 이하야?"를 물어요. 앞에서 걸러진 값은 뒤 질문에 오지 않으니 범위를 두 번 쓸 필요가 없어요. 경계값(50, 100)이 어느 쪽인지 `<`와 `<=`로 꼼꼼히 정해야 해요.

### 문제1 - 반복문
```c
for (int i = 10; i >= 1; i--) {
    printf("%d\n", i);
}
printf("발사!\n");
```
👉 계단을 내려가는 것과 같아요. 10에서 시작해서 한 칸씩 내려가요(`i--`). 1까지 말해야 하니까 `i >= 1`이에요. "발사!"는 반복문 **밖**에 써야 마지막에 딱 한 번만 나와요. 안에 쓰면 숫자마다 발사해 버려요!

### 문제1 - 흐름제어
```c
for (int i = 0; i < 6; i++) {
    if (psi[i] == 0) continue;
    if (psi[i] > 100) { printf("%d번 탱크 과압! 발사 중단\n", i + 1); break; }
    printf("%d번 탱크 OK\n", i + 1);
}
```
출력: `1번 탱크 OK` / `2번 탱크 OK` / `4번 탱크 과압! 발사 중단` (3번은 건너뛰고, 5·6번은 검사하지 않음)

👉 `continue`는 "꺼진 센서는 패스, 다음!", `break`는 "위험한 걸 찾았으니 당장 멈춰!"예요. 하나라도 과압이면 발사를 못 하니 나머지를 볼 필요가 없죠. 컴퓨터는 0번부터 세지만 사람은 1번부터 부르니 출력할 땐 `i + 1`을 해요.

### 문제2 - 조건문
```c
if (battery <= 10) printf("충전 필요!\n");
else if (battery <= 30) printf("절전 모드 추천\n");
else printf("충분해요\n");
```
👉 가장 급한 것(10 이하)부터 물어야 해요. 5%인데 "30 이하"를 먼저 물으면 "절전 모드 추천"만 나오고 "충전 필요!"는 영영 못 봐요.

### 문제2 - 반복문
```c
int total = 0, i = 0;
while (i < 5) {
    total += usage[i];
    i++;
}
printf("총합 %d%%\n", total);
```
출력: `총합 85%`

👉 `while`은 "조건이 참인 동안 계속"이에요. 장바구니에 물건 값을 하나씩 더하는 것과 같죠. `i++`를 잊으면 같은 칸만 계속 더하는 무한 반복이 돼요. 그리고 `%`를 화면에 찍으려면 `%%`라고 두 번 써야 해요.

### 문제2 - 흐름제어
```c
for (int i = 0; i < 5; i++) {
    if (usage[i] == 0) continue;
    if (usage[i] >= 35) { printf("%d번 앱 배터리 과소비!\n", i + 1); break; }
    printf("%d번 앱: %d%%\n", i + 1, usage[i]);
}
```
출력: `1번 앱: 12%` / `3번 앱: 25%` / `4번 앱 배터리 과소비!`

👉 순서가 중요해요: 0 거르기(`continue`) → 과소비 확인(`break`) → 일반 출력. 일반 출력을 먼저 하면 0인 앱도 나오고, 과소비 앱도 평범하게 출력돼요.
