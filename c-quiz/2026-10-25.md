```c
int speed[6] = {8, 0, 15, 0, 22, 0};
```

### 흐름제어 퀴즈1
0번부터 차례로 보면서 속도가 0이 아니면 `continue`로 건너뛰고, 0인 기록(끊김)을 만날 때마다 끊김 횟수를 1 늘리세요. 끊김이 **3번째**가 되는 순간 "다운로드 실패, 번호: ○" 를 출력하고 바로 멈추는 코드를 작성하세요. 출력은?

# ✅ 정답과 해설 (초등학교 5학년 버전)

## 📌 문제 1: 윈도우 업데이트 다운로드

### 조건문 정답
```c
if (n >= 20) {
    printf("빠름\n");
} else if (n >= 5) {
    printf("보통\n");
} else {
    printf("느림\n");
}
```
**왜?** 달리기 시합을 생각해 보세요. 아주 빠른 친구부터 "1등급!", 그다음 "2등급!", 나머지는 "연습 더 하자!"라고 나누죠? 큰 기준부터 물어봐야 해요. "5 이상?"을 먼저 물으면 22도 "보통"이 되어 버려요. 앞 질문이 "아니오"일 때만 `else if`로 넘어가는 거예요.

### 반복문 정답
```c
int cut = 0;
for (int i = 0; i < 6; i++) {
    if (speed[i] == 0) {
        cut++;
    }
}
printf("%d\n", cut);
```
**왜?** 출석부를 보며 "결석한 친구 몇 명?"을 세는 것과 같아요. 처음엔 결석 0명(`cut = 0`)에서 시작해서, 한 칸씩 보다가 0이 나올 때만 하나 올려요. 배열 번호는 0~5라서 `i < 6`이에요. `==`(같다)와 `=`(넣는다)를 헷갈리지 마세요! 결과는 **3**이에요.

### 흐름제어 정답
```c
int cut = 0;
for (int i = 0; i < 6; i++) {
    if (speed[i] != 0) {
        continue;
    }
    cut++;
    if (cut == 3) {
        printf("다운로드 실패, 번호: %d\n", i);
        break;
    }
}
```
**출력:** `다운로드 실패, 번호: 5`

**왜?** 속도가 0이 아니면 "잘 되고 있네, 다음!" 하고 `continue`로 넘어가요. 0이면 끊긴 거니까 끊김 카운터를 올려요. 카운터가 3이 되면 "더 기다려도 소용없어" 하고 `break`로 반복을 완전히 끝내요. 번호 1, 3은 1번째, 2번째 끊김이라 조용히 지나가고, 번호 5에서 3번째라서 멈춰요.

## 📌 프로그램 1: 삼성 스마트 냉장고

### 조건문 정답
```c
if (d <= 0) {
    printf("버리세요\n");
} else if (d <= 3) {
    printf("빨리 드세요\n");
} else {
    printf("신선\n");
}
```
**왜?** 우유 팩의 날짜를 확인하는 것과 같아요. 가장 위험한 "이미 지났어요"부터 먼저 물어봐요. 만약 "3 이하?"를 먼저 물으면 0도 "빨리 드세요"가 되어서 상한 음식을 먹을 수 있어요. 위험한 경우를 먼저 검사하는 게 안전해요.

### 반복문 정답
```c
int count = 0;
for (int i = 0; i < 5; i++) {
    if (days[i] <= 3) {
        count++;
    }
}
printf("%d\n", count);
```
**왜?** 장바구니를 하나씩 보며 "곧 먹어야 하는 것"에 스티커를 붙이고, 마지막에 스티커 개수를 세는 것과 같아요. 3, 0, 1이 3 이하라서 결과는 **3**이에요.

### 흐름제어 정답
```c
for (int i = 0; i < 5; i++) {
    if (days[i] >= 7) {
        continue;
    }
    if (days[i] <= 0) {
        printf("상한 음식 번호: %d\n", i);
        break;
    }
}
```
**출력:** `상한 음식 번호: 2`

**왜?** 10일, 7일 남은 음식은 걱정 없으니 `continue`로 휙 넘어가요. 3일 남은 음식(번호 1)은 검사를 받지만 0 이하가 아니라 그냥 지나가요. 번호 2는 0일이라 상한 음식이에요! 알림을 주고 `break`로 멈춰요. 이 코드는 "처음 발견한 것"만 알려 주는 방식이라, 뒤의 음식은 확인하지 않아요.
