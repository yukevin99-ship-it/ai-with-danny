## 엔지니어가 직면한 가상의 문제 1
**상황:** 네이버 쇼핑몰 주문 서버 담당 엔지니어. 주문 금액에 따라 할인율을 정하고, 오늘 들어온 주문 5개의 합계를 구해야 한다. 그런데 금액이 0원 이하인 주문은 오류 데이터라 합계에서 빼야 하고, 합계가 100만 원을 넘으면 "일일 한도 초과"라 더 계산하지 않는다.

- **조건문 퀴즈 1:** 변수 `amount`(주문 금액)가 10만 원 이상이면 `rate`를 20, 5만 원 이상이면 10, 그 외에는 0으로 정하는 코드를 작성하세요.
- **반복문 퀴즈 1:** 배열 `int orders[5]`에 담긴 주문 5개의 금액을 모두 더해 `sum`에 저장하는 코드를 작성하세요.
- **흐름제어 퀴즈 1:** 위 반복문 안에서 0원 이하 주문은 건너뛰고(더하지 않기), 합계가 1000000을 넘으면 반복을 멈추는 코드를 작성하세요.

## 엔지니어가 창작해야 하는 가상의 프로그램 1
**프로그램:** 스페이스X 로켓 발사 카운트다운 프로그램. 연료 상태를 확인하고, 10초부터 1초까지 세고, 도중에 위험 신호가 오면 발사를 취소한다.

- **조건문 퀴즈 1:** 변수 `fuel`(연료 %)이 80 이상이면 "발사 가능", 30 이상이면 "연료 보충 필요", 그 외에는 "발사 불가"를 출력하는 코드를 작성하세요.
- **반복문 퀴즈 1:** 10부터 1까지 1씩 줄이며 숫자를 출력하고, 끝나면 "발사!"를 출력하는 코드를 작성하세요.
- **흐름제어 퀴즈 1:** 카운트다운 중 5초가 되면 "엔진 점화"를 출력하고, 3초에 `danger`가 1이면 "발사 취소!"를 출력하며 카운트다운을 멈추세요. 멈췄다면 "발사!"는 출력하지 않아야 합니다.

# 정답 및 해설 (초등학교 5학년 눈높이)

## 문제 1: 쇼핑몰 주문 서버

### 조건문 정답
```c
int rate;
if (amount >= 100000) {
    rate = 20;
} else if (amount >= 50000) {
    rate = 10;
} else {
    rate = 0;
}
```
**왜 이렇게?** 놀이공원 키 재기랑 똑같아요. 키가 제일 큰 사람 줄부터 먼저 물어봐요. "10만 원 이상이야? 그럼 20%!" 아니면 "5만 원 이상이야? 그럼 10%!" 둘 다 아니면 "할인 없음!"
큰 숫자부터 물어봐야 해요. 만약 5만 원부터 물으면 15만 원짜리도 "5만 원 이상이네?" 하고 10%만 받아요. 억울하죠? `else if`는 "앞에서 이미 정해졌으면 나는 볼 필요 없어"라는 뜻이에요.

### 반복문 정답
```c
int sum = 0;
for (int i = 0; i < 5; i++) {
    sum += orders[i];
}
```
**왜 이렇게?** 저금통에 동전 5개를 하나씩 넣는 것과 같아요. `sum`은 빈 저금통이라 처음엔 0으로 시작해야 해요(안 비우면 이상한 돈이 들어 있어요). `i`는 "몇 번째 동전이야?" 하는 번호표인데, 컴퓨터는 0번부터 세서 0, 1, 2, 3, 4 총 5번 돌아요. 그래서 `i < 5`예요(`i <= 5`로 쓰면 없는 6번째 칸을 열어 버려요!).

### 흐름제어 정답
```c
int sum = 0;
for (int i = 0; i < 5; i++) {
    if (orders[i] <= 0) {
        continue;
    }
    sum += orders[i];
    if (sum > 1000000) {
        break;
    }
}
```
**왜 이렇게?**
- `continue`는 "이 친구는 패스! 다음 친구로 가자"예요. 고장 난 동전(0원 이하)은 저금통에 안 넣고 다음 동전으로 넘어가요.
- `break`는 "그만! 오늘은 끝!"이에요. 저금통이 100만 원을 넘으면 남은 동전은 볼 필요가 없으니 반복 전체를 끝내요.
- 순서가 중요해요. 더한 다음에 넘었는지 확인해야 "방금 넣은 동전 때문에 넘었는지" 알 수 있어요. 그리고 `continue`를 맨 위에 둬야 고장 난 동전이 더하기까지 못 가요.

## 프로그램 1: 로켓 발사 카운트다운

### 조건문 정답
```c
if (fuel >= 80) {
    printf("발사 가능\n");
} else if (fuel >= 30) {
    printf("연료 보충 필요\n");
} else {
    printf("발사 불가\n");
}
```
**왜 이렇게?** 자동차 기름 게이지랑 같아요. 기름이 가득(80 이상)이면 출발, 반쯤(30 이상)이면 주유소에 가고, 거의 없으면 못 가요. 이번에도 큰 숫자부터 물어봐야 해요. 90%인 로켓이 "30 이상이네, 보충 필요!"라고 하면 안 되니까요.

### 반복문 정답
```c
for (int t = 10; t >= 1; t--) {
    printf("%d\n", t);
}
printf("발사!\n");
```
**왜 이렇게?** 술래잡기 숫자 세기와 같아요. 10에서 시작해서(`t = 10`), 1까지 세고(`t >= 1`), 한 번 셀 때마다 1씩 줄여요(`t--`). 거꾸로 세니까 `++`가 아니라 `--`예요. "발사!"는 반복문 밖에 있어서 숫자를 다 센 뒤 딱 한 번만 나와요. 안에 넣으면 10번이나 "발사!"가 나와서 큰일 나요!

### 흐름제어 정답
```c
int aborted = 0;
for (int t = 10; t >= 1; t--) {
    printf("%d\n", t);
    if (t == 5) {
        printf("엔진 점화\n");
    }
    if (t == 3 && danger == 1) {
        printf("발사 취소!\n");
        aborted = 1;
        break;
    }
}
if (aborted == 0) {
    printf("발사!\n");
}
```
**왜 이렇게?**
- 반복문 안에 `if`를 넣으면 "5초일 때만 특별한 일 하기"를 할 수 있어요. 학교 종이 매 시간 울리지만 12시에만 급식 방송이 나오는 것과 비슷해요.
- `t == 3 && danger == 1`에서 `&&`는 "그리고"예요. 3초이면서 위험 신호도 켜졌을 때만 취소해요. `=`가 아니라 `==`(같니?)를 쓰는 것도 꼭 기억하세요.
- `break`로 멈추면 반복문 뒤의 "발사!"도 그냥 실행돼 버려요. 그래서 `aborted`라는 깃발을 세워 두고, 깃발이 안 올라갔을 때(0일 때)만 "발사!"를 출력해요. "취소했는데 발사!"가 나오면 큰 사고니까요.
