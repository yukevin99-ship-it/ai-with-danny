# ⚡ 회로 퀴즈 — 테브닌 · 분압 · 중첩 (2026-11-16)

> 공통 주제: 전압원과 저항이 직렬·병렬로 얽혀 **복잡해 보이지만**,
> 테브닌 정리 · 분압 법칙 · 중첩의 원리를 쓰면 **몇 줄로 끝나는** 회로들입니다.
> 단위: 저항 kΩ, 전류 mA → (kΩ × mA = V) 로 계산하면 편합니다.

---

## 문제 1 (초급) — 전위 따라가기

전압원 2개와 저항 2개로 된 단일 루프입니다. 점 **P의 전위가 V_P = −3 V** 일 때 다음을 구하세요.

```
               I  (시계 방향, →)
     X ─────────[ R1 = 1 kΩ ]───────── Q
     │                                 │
    (+)                               (+)
   ─────  E1 = 12 V                  ─────  E2 = 4 V
    ───                               ───
    (−)                               (−)
     │                                 │
     P ─────────[ R2 = 3 kΩ ]───────── Y
               ←  I

   · 두 전원 모두 (+)극이 위쪽 (X쪽, Q쪽)
   · V_P = −3 V (기준점 아님! 접지는 따로 정해져 있음)
```

1. 루프 전류 I의 크기와 방향은?
2. 점 Q의 전위 V_Q는?
3. 점 Y의 전위 V_Y는? 그리고 E2는 전력을 공급하나요, 흡수하나요?

🔑 핵심 개념: 전위차는 루프를 따라 **전원에서 +E(−→+ 통과)**, **저항에서 −IR(전류 방향 통과)** 로 더해 가면 되고, 두 전원이 서로 반대로 미므로 I는 (12−4)/(1+3)으로 "차이"만 남습니다. 또 V_Q−V_P는 E1 단독 기여 + E2 단독 기여의 합(중첩)으로도 같은 값이 나옵니다.

## 문제 2 (중급) — 불평형 브리지를 테브닌으로 자르기

```
                  T  (+12 V)
                  │
           ┌──────┴──────┐
           │             │
       [R1 = 3 kΩ]   [R3 = 6 kΩ]
           │             │
           A ──[ R5 ]─── B
           │   I5 → (A에서 B로)
       [R2 = 6 kΩ]   [R4 = 2 kΩ]
           │             │
           └──────┬──────┘
                  │
                 GND (0 V)

   · 전압원 Vs = 12 V : (+)극 → 노드 T, (−)극 → GND
   · 브리지 저항 R5 가 중간 노드 A–B 를 연결
```

1. R5를 떼어 낸 뒤 A–B 단자에서 본 테브닌 등가 V_th(= V_A − V_B, 개방)와 R_th를 구하세요.
2. R5 = 1.5 kΩ일 때 R5의 전류 I5(방향 포함)와 V_AB는?
3. R5를 **6.5 kΩ**으로 바꾸면 I5는?
4. V_AB가 정확히 **4 V**가 되게 하려면 R5는 몇 kΩ이어야 하나요?
5. (생각해 보기) 3번·4번을 노드 해석으로 푼다면 매번 무엇을 다시 해야 하나요?

🔑 핵심 개념: R5만 떼면 두 갈래는 **독립된 분압기**라 V_A·V_B가 분압 법칙 한 줄로 나오고, 전원을 단락하면 R_th = (R1‖R2) + (R3‖R4)입니다. 일단 V_th·R_th를 구하면 R5가 어떤 값이든 I5 = V_th/(R_th+R5) 한 식으로 끝나므로, R5가 바뀔 때마다 2원 연립방정식을 다시 풀 필요가 없습니다.

## 문제 3 (고급) — 3단 분압기 사다리와 부하 효과

```
          Ra1 = 6 kΩ          Rb1 = 8 kΩ          Rc1 = 12 kΩ
  Vin ──[==========]──── A ──[==========]──── B ──[==========]──── C ───○ Vout
  (+)                    │                    │                    │
  36 V               [Ra2 =              [Rb2 =               [Rc2 =
  (−)                 12 kΩ]              12 kΩ]               12 kΩ]
   │                     │                    │                    │
   └─────────────────────┴────────────────────┴────────────────────┴───○ GND

   ├──── A단 ────┤     ├──── B단 ────┤     ├──── C단 ────┤
   (출력 Vout은 처음엔 개방, 마지막 보너스에서만 부하 R_L 연결)
```

1. **R_in(B):** 노드 A에서 오른쪽(B단 입력)을 들여다본 입력저항은? (뒤의 C단 부하 포함)
2. **R_out(B):** C단을 떼어 냈을 때 노드 B에서 왼쪽(전원 쪽)을 본 출력저항은? (전압원은 단락)
3. 테브닌 등가를 **A단 → B단 → C단** 순서로 단계별로 적용하여 정확한 Vout(개방)을 구하세요.
4. 부하 효과를 무시하고 각 단의 분압비만 곱한 "순진한 값"은? 정확한 값 대비 오차(%)는?
5. **(보너스)** 출력에 R_L = 7.2 kΩ을 달면 Vout은?

🔑 핵심 개념: 각 단의 분압비는 **뒤 단이 개방일 때만** 성립합니다. 앞 단을 테브닌 등가(V_th, R_th)로 바꾸면 그 R_th가 다음 단의 직렬저항에 그냥 더해지므로(예: 4k + 8k), "분압 → 테브닌 → 분압"을 세 번 반복하는 것만으로 부하 효과가 정확히 반영됩니다.

# 📘 정답 및 해설 (교수용)

## 문제 1 해설

**① 루프 전류**
시계 방향(P→X→Q→Y→P)으로 KVL:

```
+12 − 1·I − 4 − 3·I = 0   →   I = 8 / 4 = 2 mA  (시계 방향: R1에서 X→Q, R2에서 Y→P)
```

**② V_Q — 방법 A: 왼쪽 경로 (P → X → Q)**

```
V_X = V_P + 12 = −3 + 12 = 9 V
V_Q = V_X − I·R1 = 9 − 2·1 = 7 V
```

**검산 — 방법 B: 오른쪽 경로 (P → Y → Q)**
R2에서 전류는 Y→P로 흐르므로 Y가 P보다 높습니다.

```
V_Y = V_P + I·R2 = −3 + 6 = 3 V
V_Q = V_Y + 4 (E2를 −→+ 방향으로 통과) = 7 V   ✓
```

**검산 — 방법 C: 중첩의 원리 (V_Q − V_P를 구함)**

| 켜진 전원 | 회로 상태 | 전류 | V_Q − V_P |
|---|---|---|---|
| E1만 (E2 단락) | Q = Y | 12/4 = 3 mA, 시계 방향 | 12 − 3·1 = **9 V** |
| E2만 (E1 단락) | X = P | 4/4 = 1 mA, 반시계 방향 (Q→X→P→Y) | R1 전압강하 1·1 = **1 V** (Q가 높음) |
| 합 | | 3 − 1 = 2 mA 시계 방향 ✓ | **10 V** |

→ V_Q = V_P + 10 = **7 V** ✓

**③ V_Y와 E2의 역할**
V_Y = **3 V**. 전류 2 mA가 E2의 **(+)극(Q)으로 들어가서 (−)극(Y)으로 나오므로** E2는 **전력을 흡수**(충전 중)합니다: P = 4 V × 2 mA = **8 mW 흡수**.
(전력 검산: E1 공급 24 mW = E2 흡수 8 mW + R1 4 mW + R2 12 mW ✓)

> 📝 지도 포인트: V_P가 0이 아니어도 **전위차**만 따라가면 된다는 점, 그리고 결과가 경로와 무관하다는 점(KVL)을 강조하세요.

## 문제 2 해설

**① 테브닌 등가 (R5 제거)**

분압 법칙:

```
V_A = 12 × R2/(R1+R2) = 12 × 6/9 = 8 V
V_B = 12 × R4/(R3+R4) = 12 × 2/8 = 3 V
V_th = V_A − V_B = 5 V   (A가 +)
```

전원 단락 → T와 GND가 한 점:

```
R_th = (R1 ‖ R2) + (R3 ‖ R4) = (3‖6) + (6‖2) = 2 + 1.5 = 3.5 kΩ
```

**검산 (I_sc 방법):** A–B를 단락하면 A=B=V_x인 한 노드가 됩니다.

```
(12−V_x)/3 + (12−V_x)/6 = V_x/6 + V_x/2
(12−V_x)/2 = 2V_x/3   →   V_x = 36/7 V
I_sc (A→B) = (12−V_x)/3 − V_x/6 = 16/7 − 6/7 = 10/7 mA
R_th = V_th / I_sc = 5 / (10/7) = 3.5 kΩ  ✓
```

**② R5 = 1.5 kΩ**

```
I5 = V_th/(R_th + R5) = 5/(3.5 + 1.5) = 1 mA   (A → B)
V_AB = I5 × R5 = 1.5 V
```

검산(노드 해석, 2원 연립): V_A = 6 V, V_B = 4.5 V → V_AB = 1.5 V, I5 = 1.5/1.5 = 1 mA ✓

**③ R5 = 6.5 kΩ**

```
I5 = 5/(3.5 + 6.5) = 0.5 mA ,   V_AB = 3.25 V
```

검산(노드 해석): V_A = 7 V, V_B = 3.75 V → 3.25/6.5 = 0.5 mA ✓

**④ V_AB = 4 V가 되는 R5**

```
4 = 5 × R5/(3.5 + R5)   →   14 + 4R5 = 5R5   →   R5 = 14 kΩ
```

검산: I5 = 5/17.5 = 2/7 mA, V_AB = (2/7)·14 = 4 V ✓

**⑤ 테브닌 정리의 장점**
노드 해석은 R5 값이 바뀔 때마다 **2원 연립방정식(V_A, V_B)** 을, 메시 해석은 **3원 연립방정식**을 새로 풀어야 합니다. 테브닌은 V_th·R_th를 **한 번만** 구해 두면 이후 질문은 전부 **1차식 하나**로 끝납니다. ④처럼 "역으로 R5를 설계"하는 문제는 특히 테브닌이 압도적으로 편합니다.

## 문제 3 해설

**① R_in(B) — 뒤에서부터 접어 오기**

```
C단 (출력 개방):  Rc1 + Rc2 = 12 + 12 = 24 kΩ
B단 노드에서:     Rb2 ‖ 24 = 12 ‖ 24 = 8 kΩ
R_in(B) = Rb1 + 8 = 8 + 8 = 16 kΩ
```

**② R_out(B) — 앞에서부터 접어 오기 (Vin 단락, C단 분리)**

```
A단: R_th1 = Ra1 ‖ Ra2 = 6 ‖ 12 = 4 kΩ
B단: R_out(B) = (R_th1 + Rb1) ‖ Rb2 = (4 + 8) ‖ 12 = 12 ‖ 12 = 6 kΩ
```

**③ 단계별 테브닌으로 정확한 Vout**

| 단계 | V_th (개방 전압) | R_th |
|---|---|---|
| A단 | 36 × 12/(6+12) = **24 V** | 6‖12 = **4 kΩ** |
| B단 (24 V, 4k 를 입력으로) | 24 × 12/(4+8+12) = **12 V** | (4+8)‖12 = **6 kΩ** |
| C단 (12 V, 6k 를 입력으로) | 12 × 12/(6+12+12) = **4.8 V** | (6+12)‖12 = **7.2 kΩ** |

→ **Vout = 4.8 V** (출력 테브닌: 4.8 V, 7.2 kΩ)

**검산 — 다른 방법: 입력저항으로 앞에서부터 부하 분압**

```
노드 A의 등가 부하: Ra2 ‖ R_in(B) = 12 ‖ 16 = 48/7 kΩ
V_A = 36 × (48/7) / (6 + 48/7) = 36 × 48/90 = 19.2 V
V_B = 19.2 × (Rb2‖24) / (Rb1 + Rb2‖24) = 19.2 × 8/16 = 9.6 V
V_C = 9.6 × 12/24 = 4.8 V   ✓
```

(노드 해석 3원 연립으로도 V_A = 19.2 V, V_B = 9.6 V, V_C = 4.8 V 확인.)

**④ 순진한 값과 오차**

```
순진한 값 = 36 × (12/18) × (12/20) × (12/24) = 36 × 2/3 × 3/5 × 1/2 = 7.2 V
오차 = (7.2 − 4.8)/4.8 = +50 %   (2.4 V 과대평가)
```

원인: A단은 개방이면 24 V지만, 실제로는 R_in(B) = 16 kΩ이 Ra2와 병렬로 붙어 19.2 V로 내려앉습니다(B단도 마찬가지로 12 V → 9.6 V). 각 단의 R_th(4k, 6k)가 다음 단 직렬저항과 비교해 작지 않기 때문에 부하 효과가 큽니다.

**⑤ 보너스 — R_L = 7.2 kΩ 연결**

```
Vout = 4.8 × 7.2/(7.2 + 7.2) = 2.4 V
```

R_L = R_th3이므로 정확히 절반이 되고, 이때 R_L에 최대 전력 (2.4²/7.2 = 0.8 mW)이 전달됩니다.
검산(노드 해석, R_L 포함): V_A = 18.93 V, V_B = 8.8 V, V_C = 2.4 V ✓
(참고: 단계별 테브닌을 썼다면 C단 테브닌 등가 하나만으로 계산 끝 — 앞 단을 다시 풀 필요 없음.)

> 📝 지도 포인트: "분압비를 곱하면 된다"는 직관은 **각 단의 입력저항 ≫ 앞 단의 출력저항**일 때만 맞습니다. 버퍼(전압 폴로어)가 왜 필요한지로 자연스럽게 연결하세요.
