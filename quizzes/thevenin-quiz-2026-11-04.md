# ⚡ 회로 퀴즈: 테브닌 · 분압 · 중첩 (2026-11-04)

> 공통 주제: 전압원과 저항이 얽혀 복잡해 보이지만, **테브닌 정리 / 분압 법칙 / 중첩의 원리**로 간단히 풀리는 회로.
> 표기: kΩ·mA·V 단위를 함께 쓰면 계산이 깔끔합니다.

## 🟢 문제 1 (초급) — 두 전원이 마주 보는 단일 루프

```
        A        R1 = 4kΩ        P
        o───────/\/\/\/─────────o───── (+)
        │          ──► I        │            V_P = +3 V (주어짐)
     (+)│                       │(+)
   V1 = 14V  ( ↑ )            V2 = 4V  ( ↓ )
     (–)│                       │(–)
        │                       │
        o───────/\/\/\/─────────o
        Q        R2 = 6kΩ       S
```
- 루프 전류 I는 시계 방향(A→P→S→Q→A)을 양(+)으로 정의
- V1: Q(–) → A(+) 로 14 V 상승, V2: P(+) → S(–) 로 4 V

**문제.** P점의 전위가 V_P = +3 V일 때,
1. 루프 전류 I를 구하시오.
2. Q점의 전위 V_Q를 구하시오. (KVL로 전위를 따라가는 방법, 중첩의 원리 두 가지로)

🔑 **핵심 개념:** *KVL/중첩의 원리.* 전류 I는 두 전원이 만드는 전류의 **대수합**이다. 14 V가 만드는 1.4 mA(시계 방향)와 4 V가 만드는 0.4 mA(반시계 방향, V2가 반대 방향으로 밀기 때문)를 더해 1 mA를 얻는다. 또한 전위는 "한 점의 값을 알면 소자 하나씩 건너며 ±IR 또는 ±V를 더해 이어 가는" 것이므로 기준점이 0이 아니어도 풀린다.

## 🟡 문제 2 (중급) — 불평형 브리지와 테브닌 정리

```
                    + 12V (Vs)
              ┌──────────┴──────────┐
              │                     │
           R1=2kΩ                R3=6kΩ
              │                     │
   A o────────●─────── R5=1.5kΩ ────●────────o B
              │       (I: A → B)    │
           R2=6kΩ                R4=3kΩ
              │                     │
              └──────────┬──────────┘
                        GND (0 V)
```

**문제.**
1. R5를 떼어 낸 양단 A–B에서 본 테브닌 등가회로(V_th, R_th)를 구하시오.
2. R5 = 1.5 kΩ일 때 R5에 흐르는 전류 I와 V_AB(R5 양단 전압)를 구하시오.
3. R5를 6.5 kΩ으로 바꾸면 전류는? (등가회로를 다시 풀지 않고 구하시오)

🔑 **핵심 개념:** *테브닌 정리.* R5를 뗀 나머지(전원 + 분압기 2개)는 어떤 R5에 대해서도 "V_th 전원 + R_th 직렬" 하나로 대체된다. 따라서 R5를 바꿀 때마다 I = V_th/(R_th+R5)만 다시 계산하면 되어, 노드/메시 해석처럼 2원 연립식을 매번 풀 필요가 없다.

## 🔴 문제 3 (고급) — 3단 분압기의 부하 효과

```
          Rs1=4kΩ        Rs2=3kΩ        Rs3=2kΩ
 +32V o───/\/\/\──(A)───/\/\/\──(B)───/\/\/\──(C)──o Vout
 Vin               │               │              │
                 Rp1=12kΩ        Rp2=12kΩ       Rp3=6kΩ   [ RL ]
                   │               │              │         (보너스)
 GND  o────────────┴───────────────┴──────────────┴──────────o
```
- 단자: A(1단 출력), B(2단 출력), C(3단 출력 = Vout), 전원은 이상적 32 V

**문제.**
1. B단 입력저항 R_in(B): B단의 직렬저항 Rs2부터 뒤쪽(3단)을 부하로 포함하여 A–GND 사이 B단 입력으로 본 저항.
2. B단 출력(노드 B)에서 전원 쪽을 본 출력저항 R_out(B).
3. 테브닌 등가를 단계별(1단→2단→3단)로 적용해 정확한 Vout (무부하)을 구하시오.
4. 부하 효과를 무시하고 각 단의 분압비만 곱한 "순진한 값"과, 그 오차를 구하시오.
5. (보너스) 출력에 RL = 3 kΩ을 달았을 때 Vout은?

🔑 **핵심 개념:** *테브닌 정리 + 분압 법칙.* 각 단을 "앞단 테브닌 등가(V, R) → 직렬 Rs → 분압 Rp"로 보면, 다음 단의 V_th = V·Rp/(R+Rs+Rp), R_th = (R+Rs)∥Rp 라는 **같은 공식의 반복**이 된다. 순진한 곱셈은 뒷단이 앞단의 Rp에 병렬로 걸려 분압비를 낮추는 **부하 효과**를 빠뜨려서 틀린다.

# 📘 정답 및 해설 (교수용)

## 문제 1 해설
**KVL(전위 따라가기):** 시계 방향 1바퀴: +14 − I·4k − 4 − I·6k = 0 → I = 10/10k = **1 mA** (A→P 방향).
V_P = 3 V이므로 V_A = V_P + I·R1 = 3 + 4 = 7 V (전류는 높은 곳에서 낮은 곳으로 흐름), V1이 Q→A로 +14 V이므로 V_Q = 7 − 14 = **−7 V**.
검산(다른 경로): P→S는 V2 = 4 V 강하 → V_S = −1 V, S→Q는 R2에서 I·6k = 6 V 강하 → V_Q = −1 − 6 = **−7 V** ✓

**중첩의 원리:** (기준: V_P − V_Q를 구함)
- V1만(V2 단락): I = 14/10k = 1.4 mA (시계 방향). V_P − V_Q = R2 쪽 경로(P→S→Q) 강하 = 1.4 × 6 = 8.4 V.
- V2만(V1 단락): I = 4/10k = 0.4 mA(반시계 방향, P→A→Q 쪽으로 R1을 거쳐 흐름). V_P − V_Q = P→A 강하 = 0.4 × 4 = 1.6 V.
- 합: 8.4 + 1.6 = 10 V → V_Q = 3 − 10 = **−7 V** ✓, 전류 합 1.4 − 0.4 = **1 mA** ✓

## 문제 2 해설
**V_th:** V_A = 12 × 6/(2+6) = 9 V, V_B = 12 × 3/(6+3) = 4 V → **V_th = V_AB = 5 V** (A가 +).
**R_th:** 전원 단락 → R1∥R2 = 2·6/8 = 1.5 kΩ, R3∥R4 = 6·3/9 = 2 kΩ, 직렬 → **R_th = 3.5 kΩ**.
**(2)** I = 5/(3.5+1.5) = **1 mA**, V_AB(R5 양단) = 1 mA × 1.5k = **1.5 V**.
**(3)** I = 5/(3.5+6.5) = **0.5 mA** (R5 양단 전압 3.25 V).
검산(다른 방법): 노드 해석으로 R5=1.5k에서 V_A = 7.5 V, V_B = 6 V, I = 1.5/1.5k = 1 mA ✓ (R5=6.5k: V_A=8.25, V_B=5 → 3.25/6.5k = 0.5 mA ✓). 또 I_sc = V_th/R_th = 5/3.5k = 1.43 mA 이므로 R_th = V_th/I_sc = 3.5k ✓.
**교육 포인트:** 노드 해석은 R5가 바뀔 때마다 2×2 연립식을 다시 풀어야 하지만, 테브닌은 한 줄 계산이다.

## 문제 3 해설
**(1) R_in:** 3단 R_in(C) = Rs3 + Rp3 = 2 + 6 = 8 kΩ. B단 입력: Rs2 + (Rp2 ∥ R_in(C)) = 3 + (12 ∥ 8 = 4.8) = **7.8 kΩ**. (참고: 1단 R_in = 4 + 12∥7.8 = 4 + 4.727 = 8.727 kΩ.)
**(2) R_out(B):** 전원을 단락하고 노드 B에서 전원 쪽을 본 저항 = (Rs1∥Rp1 + Rs2)∥Rp2 (아래 표 참조).
**(3) 단계별 테브닌:**
| 단 | V_th | R_th |
|---|---|---|
| 1단 (A) | 32 × 12/16 = **24 V** | 4∥12 = **3 kΩ** |
| 2단 (B) | 24 × 12/(3+3+12) = **16 V** | (3+3)∥12 = **4 kΩ** |
| 3단 (C) | 16 × 6/(4+2+6) = **8 V** | (4+2)∥6 = **3 kΩ** |

→ R_out(B) = **4 kΩ**, 정확한 **Vout = 8 V**, 최종 R_out = 3 kΩ.
**(4) 순진한 값:** 12/16 × 12/15 × 6/8 = 0.75 × 0.8 × 0.75 = 0.45 → 32 × 0.45 = **14.4 V**. 오차 = +6.4 V (정확한 값의 **180%**, 즉 80 % 과대평가).
**(5) 보너스:** RL = 3k: Vout = 8 × 3/(3+3) = **4 V**.
검산(노드 해석, 연립 풀이): 무부하 V_A = 17.33 V, V_B = 10.67 V, V_C = **8 V** ✓; RL=3k일 때 V_A=16, V_B=8, V_C=**4 V** ✓. (또한 Vout/Vin = 1/4 = 0.25 — 순진한 0.45와 큰 차이)
