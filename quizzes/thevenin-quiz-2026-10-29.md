# 테브닌 정리 · 분압 · 중첩 회로 퀴즈 (2026-10-29)

> 공통 주제: 직렬·병렬로 얽혀 복잡해 보이는 회로를 **테브닌 정리 / 분압 법칙 / 중첩의 원리**로 간단히 푼다.
> 모든 저항은 kΩ, 전류는 mA 단위(kΩ × mA = V).

---

## 문제 1 (초급) — 두 전원이 있는 단일 루프

전압원 2개와 저항 2개가 한 루프를 이룬다. 점 P의 전위는 **V_P = +5 V** (접지 기준)이다.

```
        N1 ──── R1 = 4kΩ ──── N2 (=Q)
        │   ──►  I (시계방향)    │
     V1 = 15V                 V2 = 3V
     (+ 위쪽 N1)              (+ 위쪽 N2)
        │                       │
 P=N4 ──┴──── R2 = 2kΩ ───── N3
 (V_P = 5V)
```

- V1: 아래(P=N4)가 −, 위(N1)가 +, 15 V
- V2: 아래(N3)가 −, 위(N2)가 +, 3 V
- 루프 전류 I는 시계방향(N1→N2→N3→N4)을 양(+)으로 한다.

**(a)** 루프 전류 I를 구하시오.
**(b)** 점 Q(= N2)의 전위 V_Q를 KVL로 전위를 따라가며 구하시오.
**(c)** 중첩의 원리로 V_Q − V_P를 구해 (b)와 일치함을 확인하시오.

🔑 **핵심 개념 — KVL 전위 추적 + 중첩의 원리:** 전위는 "기준점 전위 + (전원 상승) − (저항 강하)"를 한 칸씩 더해 가면 되므로 P의 값이 0이 아니어도 모든 노드가 한 번에 정해진다(전원 +15V 상승, 4kΩ에서 −8V, V2에서 −3V, 2kΩ에서 −4V로 N4에 정확히 돌아옴). 중첩은 "전원 하나만 살리고 나머지 전압원은 단락"하여 Q−P 전압을 각각 구해 더하는 것으로, V1만 살리면 2kΩ의 강하(5V), V2만 살리면 4kΩ의 강하(2V)가 Q−P가 되어 합이 7V다. P의 절대 전위 5V는 Q−P 차이에 그대로 더해질 뿐이다.

## 문제 2 (중급) — 불평형 브리지와 테브닌 등가

12 V 전원에 분압기 두 갈래가 붙고, 중간 노드 A–B 사이를 R5가 잇는다.

```
          +12V
      ┌─────┴─────┐
      │           │
    R1=3kΩ      R3=6kΩ
      │           │
      A ─ R5 ───→ B       (R5 = 1.5kΩ, 전류 I는 A→B 방향)
      │   (A→B)   │
    R2=6kΩ      R4=2kΩ
      │           │
      └─────┬─────┘
           GND (0V)
```

**(a)** R5를 떼어 낸 상태에서 단자 A–B의 개방전압 V_th = V_AB(oc)를 구하시오.
**(b)** 전원을 단락(0V)하고 A–B에서 본 R_th를 구하시오.
**(c)** R5 = 1.5 kΩ일 때 R5를 흐르는 전류 I와 V_AB를 구하시오.
**(d)** R5를 6.5 kΩ으로 바꾸면 전류는? (회로를 다시 풀지 않고 구하시오.) 또, A–B를 단락했을 때의 전류 I_sc는?

🔑 **핵심 개념 — 테브닌 정리:** R5를 부하로 보고 나머지 회로 전체를 "V_th 직렬 R_th" 하나로 바꾼다. V_th는 각 갈래의 분압기(A=12·6/9, B=12·2/8) 출력 차이이고, R_th는 전원을 단락했을 때 두 분압기의 병렬 저항(3∥6, 6∥2)이 A와 B쪽에서 직렬로 이어진 값이다. 한 번 등가를 만들면 R5가 바뀔 때마다 I = V_th/(R_th+R5)만 계산하면 되므로 노드 해석(연립 2원)을 반복하지 않아도 된다.

## 문제 3 (고급) — 3단 분압기의 부하 효과

3단 분압기(A→B→C)를 직렬로 이었다. 각 단은 위쪽 저항(직렬)과 아래쪽 저항(접지로)로 구성된다.

```
 Vin=60V      n1                 n2                 n3 = Vout
  o──[12kΩ]──┬──[ 4kΩ]──────┬──[ 2kΩ]──────┬─── o  Vout
   (A단)     │   (B단)       │   (C단)      │
           [ 6kΩ]          [ 8kΩ]          [ 6kΩ]      (┬ 오른쪽 끝: 문제 (e)에서 R_L 연결)
             │               │               │
  GND ──────┴───────────────┴───────────────┴──── GND
```

- A단: 12 kΩ(직렬) / 6 kΩ(접지)
- B단: 4 kΩ(직렬) / 8 kΩ(접지)
- C단: 2 kΩ(직렬) / 6 kΩ(접지)
- 출력 Vout = n3 (무부하)

**(a)** B단의 **입력저항 R_in(B)** (n1에서 오른쪽을 본 저항, 뒤 단 C 포함)을 구하시오.
**(b)** A단의 테브닌 등가(V_th, R_th)를 구하고, 이를 이용해 **B단 출력(n2)에서 본 R_out(B)** 를 구하시오.
**(c)** 테브닌 등가를 A → B → C 순으로 단계적으로 적용하여 **정확한 V_out**을 구하시오.
**(d)** 부하 효과를 무시하고 각 단의 분압비만 곱한 **순진한 값**을 구하고, 정확한 값과의 **오차(%)** 를 구하시오.
**(e) (보너스)** 출력에 R_L = 3 kΩ을 달았을 때 V_out은?

🔑 **핵심 개념 — 테브닌 등가의 단계적 적용 + 분압의 부하 효과:** 뒤 단은 앞 단 출력에 병렬 부하(R_in)로 걸리므로 분압비는 "아래 저항 ÷ 전체"가 아니라 "(아래 저항 ∥ 뒤 단 R_in) ÷ 전체"가 된다. 그래서 앞 단을 (V_th, R_th)로 바꾸면 그 R_th가 다음 단의 직렬 저항에 더해지는 형태가 되어, A→B→C로 한 단씩 "전압원 + 직렬저항"으로 접어 가며 풀 수 있다. 순진한 곱셈은 R_in이 무한대라고 가정한 값이므로 실제와 크게 어긋난다.

# 📘 정답 및 해설 (교수용)

## 문제 1 해설

**(a)** KVL(시계방향): +15 − 4I − 3 − 2I = 0 → **I = 12/6 = 2 mA** (시계방향, 양수).

**(b) 전위 추적** (V_P = V_N4 = 5 V에서 출발):
- N1 = 5 + 15 = **20 V** (V1 상승)
- N2 = 20 − (2 mA·4 kΩ) = 20 − 8 = **12 V** → **V_Q = 12 V**
- N3 = 12 − 3 = 9 V (V2는 N2가 +이므로 내려감)
- N4 = 9 − (2 mA·2 kΩ) = 9 − 4 = 5 V ✓ (출발점으로 복귀)

**(c) 중첩** (Q−P 전압):
- V1만 (V2 단락): I₁ = 15/(4+2) = 2.5 mA, N2와 N3가 같은 점이므로 Q−P = I₁·R2 = 2.5·2 = **5 V**
- V2만 (V1 단락): I₂ = 3/6 = 0.5 mA (N2→R1→N1=N4→R2→N3 방향, 반시계), Q−P = I₂·R1 = 0.5·4 = **2 V**
- 합: V_Q − V_P = 5 + 2 = **7 V** → V_Q = 5 + 7 = **12 V** ✓

**검산 2가지:** ① 반대 방향(N4→N3→N2) 추적: N3 = 5 + 2·2 = 9, N2 = 9 + 3 = 12 ✓ ② 중첩 결과와 KVL 결과 일치.

## 문제 2 해설

**(a)** 개방 시 A = 12·6/(3+6) = 8 V, B = 12·2/(6+2) = 3 V → **V_th = V_AB = 5 V** (A가 더 높음).

**(b)** 전원 단락 시 A에서 접지까지 R1∥R2 = 3∥6 = 2 kΩ, B에서 접지까지 R3∥R4 = 6∥2 = 1.5 kΩ. 두 접지가 같은 점이므로 A–B 사이 직렬 → **R_th = 2 + 1.5 = 3.5 kΩ**.

**(c)** I = V_th/(R_th + R5) = 5/(3.5 + 1.5) = **1 mA**, V_AB = I·R5 = 1·1.5 = **1.5 V**.

**(d)** R5 = 6.5 kΩ: I = 5/(3.5 + 6.5) = **0.5 mA** (V_AB = 3.25 V). 단락: I_sc = 5/3.5 = **10/7 ≈ 1.43 mA**.

**검산:**
- 노드 해석(A, B 두 미지수): R5=1.5kΩ일 때 A = 6 V, B = 4.5 V → V_AB = 1.5 V, I = 1.5/1.5 = 1 mA ✓ (R5=6.5kΩ일 때 A=7 V, B=3.75 V, V_AB=3.25 V, I=0.5 mA ✓)
- V_th / I_sc 방식: R_th = V_th/I_sc = 5/(10/7) = 3.5 kΩ ✓

**강조점:** 노드 해석은 R5가 바뀔 때마다 2원 연립을 새로 풀어야 하지만, 테브닌 등가는 (5 V, 3.5 kΩ)을 한 번 구해 두면 R5가 무엇이든 한 줄로 끝난다.

## 문제 3 해설

**(a)** C단 입력 R_in(C) = 2 + 6 = 8 kΩ. B단 아래 저항과의 병렬: 8∥8 = 4 kΩ. → **R_in(B) = 4 + 4 = 8 kΩ.**

**(b)** A단 테브닌: V_th(A) = 60·6/(12+6) = **20 V**, R_th(A) = 12∥6 = **4 kΩ** → A단은 "20 V + 4 kΩ".
B단 출력(n2)에서 앞쪽을 본 R_out(B) = 8 ∥ (4 + 4) = 8∥8 = **4 kΩ**.

**(c) 단계적 적용:**
- B단 테브닌 (20V/4kΩ 위에 B단): V_th(B) = 20·8/(8+4+4) = **10 V**, R_th(B) = **4 kΩ**
- C단 테브닌 (10V/4kΩ 위에 C단): V_th(C) = 10·6/(6+2+4) = **5 V**, R_th(C) = 6∥(2+4) = **3 kΩ**
- **무부하 V_out = 5 V** (출력 R_out = 3 kΩ)

(참고 중간 노드: n2 = 10·8/12 = 20/3 ≈ 6.67 V, n1 = n2·(4+4)/4 = 40/3 ≈ 13.3 V)

**(d)** 순진한 값 = 60·(6/18)·(8/12)·(6/8) = 60·(1/3)(2/3)(3/4) = **10 V**. 오차 = (10 − 5)/5 = **+100 %** (순진한 값은 정확한 값의 2배).

**(e)** R_L = 3 kΩ: V_out = V_th(C)·R_L/(R_L + R_out) = 5·3/(3+3) = **2.5 V**.

**검산 (노드 해석, 3원 연립):** 무부하에서 n1 = 40/3, n2 = 20/3, n3 = 5 V ✓. R_L=3kΩ 부하 시 n1 = 12.5, n2 = 5, n3 = 2.5 V ✓. 또 다른 경로: 뒤에서 앞으로 누적 분압 n3/n2 = 6/8 = 0.75, n2/n1 = (8∥8)/(4+8∥8) = 0.5, n1/Vin = (6∥8)/(12+6∥8) = (24/7)/(108/7) = 2/9 → 60·(2/9)(1/2)(3/4) = 5 V ✓.
