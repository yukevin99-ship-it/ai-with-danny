# 회로 퀴즈: 테브닌 정리 · 분압 법칙 · 중첩의 원리 (2026-11-03)

> 공통 주제: 직렬·병렬로 얽혀 복잡해 보이지만 **테브닌 정리 / 분압 / 중첩**으로 간단히 풀리는 회로.
> 단위: V, kΩ, mA (kΩ × mA = V). 계산기 없이 풀 수 있는 값으로 설계됨.

## 문제 1 (초급) — 전위를 따라가기

전압원 2개와 저항 2개가 하나의 루프를 이룹니다. 점 P의 전위는 **V_P = 3 V** 로 고정(기준)되어 있습니다.

```
        P ──────[ V1 = 15V ]────── S
        │        (+ 쪽이 S)        │
        │                          │
     R2 = 7kΩ                   R1 = 3kΩ
        │                          │
        T ──────[ V2 = 5V ]─────── Q
                 (+ 쪽이 Q)

   루프 전류 I : P → S → Q → T → P (시계방향) 를 양(+)으로 정의
   V_P = 3 V (주어짐),  V_Q = ?
```

**(a)** 루프 전류 I를 구하세요.
**(b)** KVL로 P에서 출발해 전위를 따라가며 V_Q를 구하세요.
**(c)** 중첩의 원리(전원을 하나씩 단락)로 V_Q − V_P를 구해 (b)와 비교하세요.

🔑 **핵심 개념:** 직렬 루프에서는 모든 소자에 **같은 전류**가 흐르므로 I = (ΣV)/(ΣR) 한 줄로 끝납니다. 전위는 "전원을 지나면 ±V만큼 오르내리고, 저항을 전류 방향으로 지나면 IR만큼 내려간다"는 규칙으로 P→Q 경로를 따라 더하면 되고, 중첩에서는 V1만 있을 때와 V2만 있을 때 P–Q 사이 전압을 각각 구해 합치면 같은 결과가 나옵니다(선형성).

## 문제 2 (중급) — 불평형 브리지와 테브닌

24 V 전압원에 분압기 두 갈래가 붙어 있고, 중간 노드 A와 B 사이를 저항 R5가 잇습니다.

```
              +24V
        ┌───────┴────────┐
        │                │
      R1=3kΩ           R3=4kΩ
        │                │
        A ──── R5 ────── B        (전류 I : A → B 방향 정의)
        │     = 6kΩ      │
      R2=6kΩ           R4=4kΩ
        │                │
        └───────┬────────┘
               GND (0V)
```

**(a)** R5를 떼어 낸 뒤 A-B 단자에서 본 테브닌 등가 (V_th = V_A − V_B, R_th)를 구하세요.
**(b)** R5 = 6 kΩ일 때 R5에 흐르는 전류 I와 전압 V_AB를 구하세요.
**(c)** R5를 12 kΩ으로 바꾸면 전류는? 1 kΩ이면? (회로를 다시 풀지 말 것)
**(d)** (선택) 노드 해석으로 (b)를 검산하고, 테브닌 방식이 연립식을 몇 개 줄였는지 말해 보세요.

🔑 **핵심 개념:** 부하(R5)를 떼어 내고 나머지 회로를 "전압원 V_th + 직렬저항 R_th" 하나로 바꿉니다. V_th는 각 분압기 출력의 차(V_A − V_B), R_th는 전원을 단락했을 때 두 분압기의 병렬저항 (R1∥R2) + (R3∥R4) 가 직렬로 보이는 값입니다. 이후 R5가 바뀌어도 I = V_th/(R_th+R5) 한 줄로 끝나는 점이 장점입니다.

## 문제 3 (고급) — 3단 분압기의 부하 효과

분압기 3단(A→B→C)을 직렬로 이었습니다. 각 단은 "직렬저항 + 접지로 가는 션트저항"입니다. 출력은 C단 션트저항 양단 전압입니다.

```
 +48V ──[Ra1=12kΩ]──●n1──[Rb1=4kΩ]──●n2──[Rc1=2kΩ]──●n3 ─── V_out
                     │                │                │        │
                  [Ra2=6kΩ]       [Rb2=8kΩ]        [Rc2=6kΩ]   (R_L, 보너스)
                     │                │                │        │
 GND  ───────────────●────────────────●────────────────●────────●

   A단: Ra1/Ra2     B단: Rb1/Rb2     C단: Rc1/Rc2
```

**(a)** B단의 입력저항 R_in(B) = Rb1 + (Rb2 ∥ R_in(C)) 를 구하세요. (R_in(C) = Rc1 + Rc2, 뒤 단 부하 포함)
**(b)** B단 출력(Rb2 양단)에서 본 테브닌 등가 (V_th,B , R_out,B)를 앞 단부터 단계별로 구하세요.
**(c)** 이를 C단에 적용해 정확한 V_out 과 출력저항 R_out 을 구하세요.
**(d)** 부하 효과를 무시하고 각 단 분압비만 곱한 "순진한 값"과 정확한 V_out의 오차(V, %)를 구하세요.
**(e)** (보너스) 출력에 R_L = 9 kΩ을 달면 V_out은?

🔑 **핵심 개념:** 각 단을 "앞 단의 테브닌 등가(V, R)를 직렬저항에 합친 뒤 션트로 분압 → 새 테브닌 등가"로 한 단씩 줄이면 연립방정식 없이 풉니다. 뒤 단은 앞 단에 R_in 으로 부하를 주기 때문에 분압비만 곱하면 틀리며(부하 효과), 이 오차가 테브닌 단계 계산에서 자동으로 반영됩니다. 출력에 R_L을 달 때도 마지막 테브닌 등가에 R_L 분압을 한 번만 하면 됩니다.

# 📘 정답 및 해설 (교수용)

## 문제 1 해설

**(a)** 루프 KVL (P→S→Q→T→P): +15 − I·3 − 5 − I·7 = 0 → **I = 10/10 = 1 mA** (시계방향).

**(b) KVL 전위 추적** (P에서 출발)
- P → S (V1, 상승): V_S = 3 + 15 = 18 V
- S → Q (R1, 전류 방향): V_Q = 18 − 1·3 = **15 V**
- 검산(반대 방향): Q → T (V2, +가 Q이므로 5 V 하강) V_T = 10 V, T → P (R2) V_P = 10 − 7 = 3 V ✓ (주어진 값과 일치)

**(c) 중첩**
- V1만 (V2 단락): I₁ = 15/10 = 1.5 mA, V_Q − V_P = 15 − 1.5·3 = 10.5 V
- V2만 (V1 단락): I₂ = 5/10 = 0.5 mA, R1을 통해 Q→P 방향 전류 → V_Q − V_P = 0.5·3 = 1.5 V
- 합: 10.5 + 1.5 = 12 V → V_Q = 3 + 12 = **15 V** ✓

**답:** I = 1 mA, V_Q = 15 V.
(자주 하는 실수: V2의 극성을 반대로 놓아 I = 20/10 = 2 mA 로 계산 → V_Q 오답)

## 문제 2 해설

**(a)** 무부하 분압: V_A = 24·6/(3+6) = **16 V**, V_B = 24·4/(4+4) = **12 V** → **V_th = 4 V**.
전원 단락 시 R_th = (3∥6) + (4∥4) = 2 + 2 = **4 kΩ**.
검산(단락전류): A-B를 단락하면 상단 노드는 하나로 합쳐짐 → 전류 I_sc = V_th/R_th = 1 mA. 노드 해석 R5 = 0 일 때도 같은 값이 나오는지 확인 가능(아래 (d)).

**(b)** I = 4/(4+6) = **0.4 mA** (A→B), V_AB = 0.4·6 = **2.4 V**.

**(c)** R5 = 12 kΩ: I = 4/16 = **0.25 mA**, V_AB = 3 V.
R5 = 1 kΩ: I = 4/5 = **0.8 mA**, V_AB = 0.8 V.
(R5 개방: V_AB = 4 V, R5 단락: I = 1 mA)

**(d) 노드 해석 검산** (미지수 V_A, V_B 2개):
- A: (V_A−24)/3 + V_A/6 + (V_A−V_B)/6 = 0
- B: (V_B−24)/4 + V_B/4 + (V_B−V_A)/6 = 0
- 풀면 V_A = 15.2 V, V_B = 12.8 V → V_AB = 2.4 V, I = 0.4 mA ✓
- R5가 바뀔 때마다 위 연립식을 다시 풀어야 하지만, 테브닌에서는 한 줄 계산으로 끝납니다.

**답:** V_th = 4 V, R_th = 4 kΩ, I = 0.4 mA, V_AB = 2.4 V. (R5=12k → 0.25 mA, R5=1k → 0.8 mA)

## 문제 3 해설

**(a)** R_in(C) = 2 + 6 = 8 kΩ. R_in(B) = 4 + (8 ∥ 8) = 4 + 4 = **8 kΩ**.
(참고: R_in(A) = 12 + (6 ∥ 8) = 12 + 24/7 — 필요 없음.)

**(b) 단계별 테브닌**
- A단: V_th,A = 48·6/(12+6) = **16 V**, R_th,A = 12∥6 = **4 kΩ**
- B단: 직렬 합 4+4 = 8 kΩ, 션트 8 kΩ → V_th,B = 16·8/(8+8) = **8 V**, R_out,B = 8∥8 = **4 kΩ**
- 즉 **B단 출력에서 본 R_out = 4 kΩ**

**(c)** C단: 직렬 합 4+2 = 6 kΩ, 션트 6 kΩ → V_th,C = 8·6/(6+6) = **4 V = V_out**, R_out = 6∥6 = **3 kΩ**.

**(d)** 순진한 값 = 48 · (6/18) · (8/12) · (6/8) = 48 · 1/3 · 2/3 · 3/4 = **8 V**.
정확값 4 V 와의 차이 = 4 V → 순진한 값이 **100 % 과대**(정확값의 2배).

**(e)** R_L = 9 kΩ: V_out = 4·9/(3+9) = **3 V**.

**검산 (노드 해석, 단위 V·kΩ·mA):** n1 = 32/3 V, n2 = 16/3 V, n3 = V_out = 4 V (무부하) ✓.
R_L = 9 kΩ 연결 시 n3 = 3 V, n2 = 14/3 V, n1 = 31/3 V → V_out = 3 V ✓.
전류 검산: 무부하에서 Rc1 전류 = (16/3 − 4)/2 = 2/3 mA, Rc2 전류 = 4/6 = 2/3 mA ✓.
(모든 계산은 Python 분수 연산으로도 확인함.)
