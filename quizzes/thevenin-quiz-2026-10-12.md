# 테브닌·분압·중첩 회로 퀴즈 (2026-10-12)

> 공통 주제: 직렬·병렬이 얽혀 복잡해 보이는 회로를 **테브닌 정리 / 분압 법칙 / 중첩의 원리**로 간단히 푼다.
> 저항 단위는 kΩ, 전류 단위는 mA, 전압 단위는 V (kΩ·mA = V).

---

## 문제 1 (초급) — 두 전원이 마주 보는 단일 루프

전압원 2개와 저항 2개가 하나의 루프를 이룬다. 회로 어딘가가 접지되어 있어 노드 P의 전위는 **V_P = +7 V**로 측정되었다.

```
      N1 (= P)        I →        N2
       o──────────[ R1 = 2kΩ ]──────────o
       │                                │
     (+)                              (+)  ← V2 = 6V, + 단자가 N2(위)
     ( V1 = 12V )                     ( V2 )
     (−)                              (−)
       │                                │
       o──────────[ R2 = 4kΩ ]──────────o N3 (= Q)
      N4         ← 루프 전류 I (시계방향)
```

정확한 연결: V1의 (+)는 N1, (−)는 N4 / R1은 N1–N2 / V2의 (+)는 N2, (−)는 N3 / R2는 N3–N4.
기준 전류 I는 N1 → R1 → N2 → V2 → N3 → R2 → N4 → V1 방향(시계방향)이다.

**(a)** 루프 전류 I를 구하시오.
**(b)** Q(=N3)의 전위 V_Q와 N4의 전위 V_N4를 구하시오. (KVL로 전위를 따라가는 방법)
**(c)** 중첩의 원리로 V_Q − V_P를 다시 구하여 (b)와 일치함을 확인하시오.

🔑 **핵심 개념:** 중첩의 원리 + KVL 전위 추적. 전원을 하나씩 죽이면(V=0 → 단락) 각 전원이 만드는 전류는 단순한 직렬 옴의 법칙(V/ΣR)이 되고, 두 전원이 서로 **반대 방향**으로 전류를 밀기 때문에 부분 효과가 부호를 달리하며 더해진다. 주어진 한 점의 전위(V_P)는 "전위 기준"일 뿐이므로, 나머지 점은 소자를 지날 때의 전압 상승·강하를 누적하면 된다.

## 문제 2 (중급) — 불평형 브리지와 테브닌 등가

12 V 전원에 분압기 두 갈래가 붙어 있고, 중간 노드 A와 B 사이를 R5가 잇는다.

```
                    +12V (Vs)
        ┌──────────────┴──────────────┐
        │                             │
     [R1 = 3kΩ]                    [R3 = 6kΩ]
        │                             │
        o A ────[ R5 = 1.5kΩ ]──── o B
        │         I → (A에서 B로)     │
     [R2 = 6kΩ]                    [R4 = 2kΩ]
        │                             │
        └──────────────┬──────────────┘
                      GND (0V)
```

**(a)** R5를 떼어 낸 뒤 A–B 단자에서 본 테브닌 등가 V_th(= V_A − V_B)와 R_th를 구하시오.
**(b)** R5 = 1.5 kΩ일 때 R5에 흐르는 전류 I와 V_AB를 구하시오.
**(c)** R5를 6.5 kΩ, 0.5 kΩ으로 바꾸면 전류는 각각 얼마인가? 노드 해석으로 처음부터 다시 풀 필요가 있는가?
**(d)** 단락전류 I_sc 방식으로 R_th를 검산하시오.

🔑 **핵심 개념:** 테브닌 정리. 부하(R5)를 분리하면 회로가 "독립된 두 분압기"로 쪼개져 V_A, V_B를 분압 법칙으로 즉시 구하고(V_th = V_A − V_B), 전원을 단락하면 각 분압기의 R1∥R2, R3∥R4가 직렬로 놓여 R_th가 된다. 한 번 만든 (V_th, R_th)에 R5만 갈아 끼우면 I = V_th/(R_th+R5)로 끝나, 노드 해석처럼 R5가 바뀔 때마다 2원 연립방정식을 다시 풀 필요가 없다.

## 문제 3 (고급) — 3단 분압기의 부하 효과

입력 V_in = 36 V에 분압기 3단(A→B→C)이 직렬로 이어져 있다. 각 단은 "직렬 저항 + 접지로 가는 병렬(션트) 저항"이다.

```
 Vin=36V      Rs1=3k       Rs2=4k        Rs3=4k
  o───────────/\/\/──o A───/\/\/──o B───/\/\/──o C ──(출력, 무부하)
  │                  │             │             │
 (+)               [Rp1=6k]     [Rp2=12k]     [Rp3=8k]
 (−)                 │             │             │
  └──────────────────┴─────────────┴─────────────┴── GND

  ←── 1단 ────→  ←──── 2단(B단) ────→  ←──── 3단 ────→
```

(노드 A = 1단 출력, B = 2단 출력, C = 3단 출력 = V_out)

**(a)** 2단(B단) 입력에서 본 입력저항 R_in(B)를 구하시오. (뒤 3단 부하 포함)
**(b)** 2단 출력(노드 B)에서 전원 쪽을 본 출력저항 R_out(B)를 구하시오.
**(c)** 1단 → 2단 → 3단 순으로 테브닌 등가를 단계적으로 적용하여 정확한 V_out을 구하시오.
**(d)** 부하 효과를 무시하고 각 단의 분압비만 곱한 "순진한" 값을 구하고, 정확한 값과의 오차를 구하시오.
**(보너스)** 출력(C)에 R_L = 4 kΩ을 달았을 때의 V_out은?

🔑 **핵심 개념:** 단계적 테브닌 등가. 앞단의 출력은 "(V_th, R_th) 전원"으로 대체되어 다음 단의 직렬 저항에 R_th가 더해지고 분압을 한 번 더 한다. 뒷단이 앞단에 주는 부하(R_in)는 앞단의 분압비를 바꾸므로 분압비를 단순 곱하면 틀린다. 반대로 마지막 단의 (V_th, R_th)를 알면 부하를 달 때도 분압 법칙 한 줄로 끝난다.

# 📘 정답 및 해설 (교수용)

## 문제 1 해설

**(a) I = 1 mA.** 루프 KVL (N1에서 출발, 시계방향 전위 강하의 합 = V1):
12 = I·2 + 6 + I·4 → 6I = 6 → **I = 1 mA** (양수 → 시계방향 가정이 맞음).
V2는 전류가 (+)단자로 들어가므로 전력을 흡수(= V1에 맞서는 방향)한다.

**(b) V_Q = −1 V, V_N4 = −5 V.** (KVL 전위 추적)
- V_N1 = V_P = 7 V
- R1 지나며 강하: V_N2 = 7 − 1·2 = 5 V
- V2를 (+)→(−)로 지나며 6 V 강하: V_N3 = V_Q = 5 − 6 = **−1 V**
- R2 지나며 강하: V_N4 = −1 − 1·4 = **−5 V**
- 검산: V1 = V_N1 − V_N4 = 7 − (−5) = 12 V ✓

**(c) 중첩.** V_Q − V_P = (N1→N2 강하) + (V2 강하)를 전원별로 분리.
- V1만 (V2 단락): I' = 12/(2+4) = 2 mA (시계방향). V2가 단락이므로 V_N3 = V_N2, V_N2 − V_N1 = −2·2 = −4 V → ΔV' = **−4 V**
- V2만 (V1 단락): V2가 N2 쪽으로 밀어내는 전류 I'' = 6/6 = 1 mA는 **반시계방향**(N2→R1→N1). R1에서 V_N2 − V_N1 = +1·2 = +2 V, V2 자체 강하 −6 V → ΔV'' = **−4 V**
- 합: −4 + (−4) = **−8 V** → V_Q = 7 − 8 = **−1 V** ✓ (전류도 2 − 1 = 1 mA ✓)

## 문제 2 해설

**(a)** R5 제거 시 (분압):
- V_A = 12·6/(3+6) = 8 V, V_B = 12·2/(6+2) = 3 V → **V_th = 5 V** (A가 +)
- 전원 단락: R_th = (3∥6) + (6∥2) = 2 + 1.5 = **3.5 kΩ**

**(b)** I = 5/(3.5+1.5) = **1 mA** (A → B), V_AB = 1·1.5 = **1.5 V**.
검산(노드 해석): V_A = 6 V, V_B = 4.5 V → (6−4.5)/1.5 = 1 mA ✓

**(c)** R5 = 6.5 kΩ → I = 5/10 = **0.5 mA** (V_AB = 3.25 V)
R5 = 0.5 kΩ → I = 5/4 = **1.25 mA** (V_AB = 0.625 V)
노드 해석 검산: 6.5k → V_A=7, V_B=3.75 → 3.25/6.5 = 0.5 ✓ / 0.5k → V_A=5.5, V_B=4.875 → 0.625/0.5 = 1.25 ✓.
**장점:** 테브닌은 한 번의 계산(V_th, R_th)으로 R5의 모든 값에 답하며 계산은 나눗셈 한 번. 노드 해석은 R5가 바뀔 때마다 2×2 연립식을 다시 풀어야 한다.

**(d)** A–B 단락: 노드 전압 V에서 (12−V)/3 + (12−V)/6 = V/6 + V/2 → V = 36/7 V.
I_sc = (12−V)/3 − V/6 = 16/7 − 6/7 = 10/7 mA → R_th = V_th/I_sc = 5/(10/7) = **3.5 kΩ** ✓

## 문제 3 해설

단계별 테브닌 (각 단: V_th' = V_th·Rp/(R_th+Rs+Rp), R_th' = Rp ∥ (R_th+Rs)):

| 단 | 계산 | V_th | R_th |
|---|---|---|---|
| 1단 | Rs1=3k, Rp1=6k, 내부저항 0 | 36·6/9 = **24 V** | 3∥6 = **2 kΩ** |
| 2단 | 2k+4k = 6k 직렬, Rp2=12k | 24·12/18 = **16 V** | 6∥12 = **4 kΩ** |
| 3단 | 4k+4k = 8k 직렬, Rp3=8k | 16·8/16 = **8 V** | 8∥8 = **4 kΩ** |

**(a)** R_in(C) = Rs3 + Rp3 = 4 + 8 = 12 kΩ → R_in(B) = Rs2 + (Rp2 ∥ R_in(C)) = 4 + (12∥12) = 4 + 6 = **10 kΩ**
**(b)** R_out(B) = Rp2 ∥ (R_th1 + Rs2) = 12 ∥ (2+4) = **4 kΩ** (= 2단 R_th)
**(c)** **V_out = 8 V** (무부하, 3단 테브닌 전압). 검산(노드 해석): V_A = 20 V, V_B = 12 V, V_C = 8 V ✓.
  전류 경로 검산: 3단 전류 = I_C 직렬 = V_B/R_in(C) = 12/12 = 1 mA, V_out = 1·8 = 8 V ✓. 2단 입력전류 = V_A/R_in(B) = 20/10 = 2 mA, V_B = 20 − 2·4 = 12 V ✓.
**(d)** 순진한 값 = 36·(6/9)·(12/16)·(8/12) = 36·(2/3)·(3/4)·(2/3) = **12 V**. 오차 = 12 − 8 = **4 V** (정확한 값 대비 +50 %, 순진한 값 대비 약 33 %). 이유: 뒷단이 앞단 션트와 병렬로 붙어 실제 분압비가 훨씬 작아진다.
**(보너스)** R_L = 4k: V_out = 8·4/(4+4) = **4 V**. 노드 해석 검산: V_A = 58/3 V, V_B = 10 V, V_C = 4 V ✓.
