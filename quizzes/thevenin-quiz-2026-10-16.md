# 테브닌·분압·중첩 회로 퀴즈 (2026-10-16)

> 공통 주제: 겉보기엔 복잡하지만 **분압 법칙 · 중첩의 원리 · 테브닌 정리**로 간단히 풀리는 회로
> 모든 저항 단위는 kΩ, 전압은 V, 전류는 mA (kΩ·mA = V)

---

## 🟢 문제 1 (초급) — 두 전원이 마주 보는 단일 루프

```
        A ──────[ R1 = 3kΩ ]────── Q
        │   →I(시계방향)            │
     V1 = 12V  (+ 위)           V2 = 4V (+ 위)
        │                           │
        P ──────[ R2 = 1kΩ ]────── B
```

- V1의 (+)는 A 쪽, V2의 (+)는 Q 쪽(위)입니다.
- 점 P의 전위는 **V_P = +5 V** (기준점 0V는 회로 밖 어딘가).

**문제**
1. 루프 전류 I의 크기와 방향을 구하시오.
2. KVL로 전위를 따라가며 **V_Q**를 구하시오.
3. 중첩의 원리로 V_Q − V_P를 다시 구해 확인하시오.

🔑 **핵심 개념:** 루프에는 전류가 하나뿐이므로 "전위 = 시작 전위 + 전원 상승 − 저항 강하(IR)"를 한 칸씩 이어 가면 연립식 없이 어느 노드든 구할 수 있다. 중첩에서는 한 전원만 살리고 다른 전원은 단락시켜 각 전원이 Q−P에 기여하는 전압을 더한다 — 여기서는 V1이 R2 전압강하로, V2가 R1 전압강하로 각각 3V씩 기여한다.

## 🟡 문제 2 (중급) — 불평형 브리지

```
              Vs = 18V (+ 위)
        ┌────────┴────────┐
        │                 │
     [R1=3kΩ]          [R3=12kΩ]
        │                 │
        A ──[R5 = 6kΩ]──→ B      (I5: A → B 방향 기준)
        │                 │
     [R2=6kΩ]          [R4=6kΩ]
        │                 │
        └────────┬────────┘
                GND (0V)
```

**문제**
1. R5를 떼어 낸 개방 상태에서 V_A, V_B, 그리고 테브닌 전압 V_th = V_AB를 구하시오.
2. 전원을 단락시켰을 때 A-B에서 본 테브닌 저항 R_th를 구하시오.
3. R5 = 6kΩ일 때 R5를 흐르는 전류 I와 V_AB를 구하시오.
4. **(추가)** R5를 12kΩ, 3kΩ으로 바꾸면 I와 V_AB는? R5를 단락(0Ω)하면?
5. (생각해 보기) 노드 해석으로 풀 때와 비교해 테브닌 방식이 어떤 점에서 유리한가?

🔑 **핵심 개념:** A-B 왼쪽 전체(전원+분압기 두 개)를 "V_th 하나와 R_th 하나"로 압축하면 R5가 무엇이든 I = V_th/(R_th+R5) 한 줄로 끝난다. 분압기 두 개는 각각 V_th의 한 항(18·6/9 = 12V, 18·6/18 = 6V)과 R_th의 한 항(3∥6 = 2k, 12∥6 = 4k)을 주고, 전원 단락 시 두 분압기가 A-B 사이에서 **직렬**로 보이는 구조가 포인트다.

## 🔴 문제 3 (고급) — 3단 분압기 캐스케이드와 부하 효과

```
 Vin=36V        Rs1=6k        Rs2=8k        Rs3=6k
 (+)──────┬────[////]──●N1──[////]──●N2──[////]──●N3 (V_out)
          │             │             │             │
        (36V)        Rp1=12k       Rp2=12k       Rp3=12k
          │             │             │             │
 (−)──────┴─────────────┴─────────────┴─────────────┴── GND
        A단            B단            C단     (V_out 개방, 필요시 R_L 연결)
```

- 각 단 = 직렬 저항 Rs(k) + 병렬(션트) 저항 Rp(k). 1단 입력은 Vin=36V 이상적 전압원.

**문제**
1. A단 출력까지의 테브닌 등가 (V_th1, R_th1)을 구하시오.
2. **B단의 입력저항 R_in(B)** (뒤 단 C단과 부하 포함)와 **B단 출력에서 본 R_out(B)** 를 구하시오.
3. 단계별 테브닌 등가로 **정확한 V_out** 을 구하시오.
4. 부하 효과를 무시하고 각 단 분압비 Rp/(Rs+Rp)만 곱한 **순진한 값**을 구하고 정확값과의 오차를 구하시오.
5. **(보너스)** 출력에 R_L = 12kΩ을 달았을 때의 출력 전압은?

🔑 **핵심 개념:** 단마다 "앞까지의 테브닌 등가"를 다음 단의 전원으로 삼아 (V_th, R_th)를 갱신하면 연립식 없이 앞에서 뒤로 한 줄씩 풀린다. 이때 앞 단의 R_th가 다음 단의 직렬 저항에 **더해져** 분압비가 달라지는 것이 곧 부하 효과이며, 순진한 곱셈은 각 단이 뒤 단 입력저항에 의해 끌려 내려가는 효과를 빠뜨려 크게 틀린다.

# 📘 정답 및 해설 (교수용)

## 문제 1 해설

**정답:** I = 2 mA (시계방향), **V_Q = 11 V**

**풀이 ① KVL 전위 추적** (P에서 시계방향)
- 루프 EMF 합: V1 − V2 = 12 − 4 = 8 V (V2는 시계방향으로 내려가며 (+)→(−) 통과 → 반대 방향), R = 3 + 1 = 4 kΩ → I = 8/4 = **2 mA**
- V_P = 5 V → V1 통과(+12) → V_A = 17 V
- R1 통과: 강하 3k × 2mA = 6 V → **V_Q = 11 V**
- 검산: V2 통과(−4) → V_B = 7 V, R2 강하 1k×2mA = 2 V → 5 V = V_P ✓ (루프가 닫힘)

**풀이 ② 중첩**
- V1만(V2 단락): I' = 12/4 = 3 mA, B와 Q가 같은 점 → Q−P = R2 전압강하 = 3 V
- V2만(V1 단락): I'' = 4/4 = 1 mA, A=P → Q−P = R1 전압강하 = 1×3 = 3 V
- 합: Q − P = 3 + 3 = 6 V → V_Q = 5 + 6 = **11 V** ✓

**채점 포인트:** 전원 극성에 따른 부호, 중첩 시 전압원 단락/전류원 개방.

## 문제 2 해설

**정답:** V_A = 12 V, V_B = 6 V (개방), **V_th = 6 V, R_th = 6 kΩ**, R5=6k일 때 **I = 0.5 mA, V_AB = 3 V**

1. 개방 시: V_A = 18 × 6/(3+6) = 12 V, V_B = 18 × 6/(12+6) = 6 V → V_th = V_A − V_B = **6 V** (A가 높음)
2. 전원 단락 시 A-B에서: 왼쪽 3∥6 = 2k, 오른쪽 12∥6 = 4k, 직렬 → **R_th = 6 kΩ**
3. I = 6/(6+6) = **0.5 mA** (A→B), V_AB = I·R5 = **3 V**
4. R5 변화표

| R5 | I = V_th/(R_th+R5) | V_AB = I·R5 |
|---|---|---|
| 3 kΩ | 6/9 = 0.667 mA | 2 V |
| 6 kΩ | 0.5 mA | 3 V |
| 12 kΩ | 6/18 = 0.333 mA | 4 V |
| 0 (단락) | 6/6 = 1 mA (= I_sc) | 0 V |
| ∞ (개방) | 0 | 6 V (= V_th) |

5. 테브닌은 식 한 줄(I = V_th/(R_th+R5))로 R5가 바뀔 때마다 즉시 답이 나온다. 노드 해석은 R5마다 2원 연립(V_A, V_B)을 다시 풀어야 한다.

**검산 ① (I_sc 방법):** A-B를 단락해 한 노드(V)로 만들면 (V−18)/3 + V/6 + (V−18)/12 + V/6 = 0 → V = 10 V. 단락선 전류 = 왼쪽에서 들어오는 (18−10)/3 − 10/6 = 1 mA = I_sc → R_th = V_th/I_sc = 6/1 = 6 kΩ ✓
**검산 ② (노드 해석, R5=6k):** 노드 A: (V_A−18)/3 + V_A/6 + (V_A−V_B)/6 = 0, 노드 B: (V_B−18)/12 + V_B/6 + (V_B−V_A)/6 = 0 → V_A = 11 V, V_B = 8 V, V_AB = 3 V, I = 0.5 mA ✓ (Python 분수 연산으로 확인; R5=12k → 4V, 3k → 2V 일치)

(참고: R5를 연결하면 V_A, V_B는 개방 때와 달라진다 — 12/6V → 11/8V. V_AB만 테브닌이 직접 답한다.)

## 문제 3 해설

**정답:** R_th1 = 4k, V_th1 = 24 V / **R_in(B) = 15.2 kΩ, R_out(B) = 6 kΩ** / **V_out = 6 V** / 순진한 값 9.6 V (오차 +3.6 V, 정확값 대비 +60%) / R_L=12k → **4 V**

**단계별 테브닌**

| 단 | 직렬 합 (앞 R_th + Rs) | V_th | R_th |
|---|---|---|---|
| A | 0 + 6 = 6k | 36·12/(6+12) = **24 V** | 6∥12 = **4k** |
| B | 4 + 8 = 12k | 24·12/(12+12) = **12 V** | 12∥12 = **6k** |
| C | 6 + 6 = 12k | 12·12/(12+12) = **6 V** | 12∥12 = **6k** |

- R_in(B) = Rs2 + Rp2 ∥ (Rs3 + Rp3) = 8 + 12∥18 = 8 + 7.2 = **15.2 kΩ**
- R_out(B) = (Rs2 + R_th1) ∥ Rp2 = 12∥12 = **6 kΩ**
- 정확한 V_out(개방) = **6 V**, R_out(전체) = 6k
- 순진한 값: 36 × (12/18) × (12/20) × (12/18) = 36 × 2/3 × 3/5 × 2/3 = **9.6 V**. 오차 = 9.6 − 6 = 3.6 V (60% 과대평가). 원인: 단 B의 실제 분압비는 12/(12+12)=1/2 (앞 R_th 4k가 더해짐)인데 순진하게는 12/20(=0.6)로 계산했고, 부하(뒤 단)가 Rp2를 끌어내리는 효과도 무시했다.
- 보너스: R_L = 12k → V = 6 × 12/(6+12) = **4 V**

**검산 (노드 해석 3원 연립, KCL):** N1, N2, N3 = 19 V, 9 V, 6 V → V_out = 6 V ✓. (역방향 확인: N3=6V → Rs3·전류 = (9−6)=3V → 0.5mA = 6/12 ✓, N2=9V → Rp2에 9/12=0.75mA, 직렬 Rs2 전류 (19−9)/8=1.25mA = 0.75+0.5 ✓.)
(별도 확인: 부하 시 N3 = 4 V, 전류 4/12 = 0.333 mA)
