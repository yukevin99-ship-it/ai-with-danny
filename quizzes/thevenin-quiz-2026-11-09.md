# 테브닌·분압·중첩 회로 퀴즈 (2026-11-09)

> 공통 주제: 전압원과 저항이 직렬·병렬로 얽혀 복잡해 보이지만, **분압 법칙 / 중첩의 원리 / 테브닌 정리**로 간단히 풀리는 회로.

---

## 🟢 문제 1 (초급) — 떠 있는 단일 루프의 전위

접지가 없는 단일 루프입니다. 점 P의 전위가 **V_P = +5 V** 로 주어졌습니다.

```
          X ────── R1 = 4 kΩ ────── Q
          │        ──► I (시계 방향)  │
       V1 = 15 V                 V2 = 3 V
       (+ 위, - 아래)             (+ 위, - 아래)
          │                          │
          P ────── R2 = 2 kΩ ────── Y
         (V_P = +5 V)
```

1. 루프 전류 I (크기와 방향)를 구하시오.
2. 점 X, Q, Y의 전위를 구하시오. (특히 **V_Q**)
3. 중첩의 원리로 V_Q를 다시 구하시오.

🔑 **핵심 개념:** 전위는 기준점에서 소자를 따라가며 "전원은 −→+ 로 올라가면 +V, 저항은 전류 방향으로 가면 −IR" 로 더해 가면 되고(KVL), 중첩의 원리는 전원을 하나씩만 살리고(나머지 전압원은 단락) 구한 P 기준 전위 변화량을 더하는 것이다. 여기서는 V1이 만드는 5 V와 V2가 만드는 2 V를 P 기준값 5 V에 더해 12 V가 되는 과정이 그 적용이다.

---

## 🟡 문제 2 (중급) — 불평형 브리지

12 V 전원 하나에 분압기 두 갈래가 붙고, 중간 노드 A–B 사이를 R5가 잇습니다.

```
            +12 V
        ┌─────┴──────┐
        │            │
      R1=3kΩ       R3=6kΩ
        │            │
        A ──[ R5 ]── B      (I: A → B)
        │            │
      R2=6kΩ       R4=2kΩ
        │            │
        └─────┬──────┘
             GND (0 V)
```

1. R5를 떼어 낸 개방 상태에서 V_A, V_B, 테브닌 전압 V_th = V_A − V_B 를 구하시오.
2. 전원을 단락하고 A–B에서 본 테브닌 저항 R_th 를 구하시오.
3. R5 = 6.5 kΩ 일 때 R5에 흐르는 전류 I와 V_AB 를 구하시오.
4. **추가:** R5를 1.5 kΩ 으로 바꾸면 전류는? 다시 회로를 풀어야 하는가?

🔑 **핵심 개념:** A–B 두 단자 왼쪽의 회로 전체를 "V_th 하나 + R_th 하나"로 바꾸면, R5를 어떤 값으로 바꾸어도 I = V_th/(R_th+R5) 한 줄로 끝난다. 노드 해석은 R5가 바뀔 때마다 2원 연립식을 다시 풀어야 하지만, 테브닌은 한 번만 구해 두면 된다는 점이 장점이다.

## 🔴 문제 3 (고급) — 3단 분압기의 부하 효과

Vin = 36 V 를 직렬 저항(Rs)과 접지 쪽 저항(Rp)으로 이루어진 분압기 3단(A→B→C)에 연속으로 인가합니다.

```
 Vin=36V      Rs1=6kΩ    n1    Rs2=2kΩ    n2    Rs3=3kΩ    n3 = V_out
   ●───────────/\/\/──────●──────/\/\/──────●──────/\/\/──────●────
                          │                 │                 │
                        Rp1=12kΩ          Rp2=6kΩ          Rp3=3kΩ
                          │                 │                 │
                         GND               GND               GND
        [   A단   ]     [   B단   ]      [   C단   ]
```

1. B단 입력저항 R_in(B) (Rs2 + 뒤 단 C 포함, n2 이후를 모두 본 저항)
2. B단 출력(n2)에서 본 테브닌 저항 R_out(B)
3. A→B→C 순서로 테브닌 등가를 단계별로 적용해 **정확한 V_out** (개방)
4. 부하 효과를 무시하고 분압비만 곱한 **순진한 값**과 오차
5. (보너스) 출력에 R_L = 2 kΩ 을 달았을 때의 V_out

🔑 **핵심 개념:** 각 단의 왼쪽 전체를 (V_th, R_th)로 접어 가면 다음 단은 "내부저항이 있는 전원 + Rs + Rp" 라는 한 단짜리 분압 문제가 된다. 분압비를 그냥 곱하면 뒤 단 Rp가 앞 단의 Rp와 병렬로 걸려 전압을 끌어내리는 부하 효과가 빠지므로 틀리고, 테브닌은 이 효과를 R_th 가 다음 단 분압에 들어가는 형태로 자동 반영한다.

# 📘 정답 및 해설 (교수용)

## 문제 1 해설

**KVL(전위 따라가기).** 시계 방향 I로 두면 V1은 위로(+15), V2는 내려가며 −3:
`15 − I·4k − 3 − I·2k = 0` → I = 12/6k = **2 mA (시계 방향)**.

P(5 V) → V1 통과 +15 → V_X = 20 V → R1에서 −2mA·4k = −8 → **V_Q = 12 V** → V2 통과 −3 → V_Y = 9 V → R2에서 −4 → 5 V = V_P ✓ (닫힘 확인).

**중첩(P 기준).**
- V1만(V2 단락): I₁ = 15/6k = 2.5 mA → V_Q − V_P = I₁·R2 = **+5 V** (반대 경로: 15 − 2.5·4 = 5 ✓)
- V2만(V1 단락, X≡P): I₂ = 3/6k = 0.5 mA, Q→R1→P→R2→Y 로 흐름 → V_Q − V_P = I₂·R1 = **+2 V** (반대 경로: Y가 Q보다 3 V 낮고 R2 강하 1 V → V_Q−V_P = 3 − 0.5·2 = 2 ✓)
- 합: V_Q = 5 + 5 + 2 = **12 V** ✓

**답:** I = 2 mA, V_X = 20 V, **V_Q = 12 V**, V_Y = 9 V.

## 문제 2 해설

1. V_A = 12·6/(3+6) = 8 V, V_B = 12·2/(6+2) = 3 V → **V_th = 5 V** (A가 높음)
2. 전원 단락 → R1∥R2 = 2 kΩ, R3∥R4 = 1.5 kΩ, 직렬 → **R_th = 3.5 kΩ**
3. I = 5/(3.5+6.5) = **0.5 mA** (A→B), V_AB = 0.5·6.5 = **3.25 V**
4. R5 = 1.5 kΩ: I = 5/(3.5+1.5) = **1 mA**, V_AB = 1.5 V. 회로를 다시 풀 필요 없이 R_th, V_th 재사용.

**검산.**
- 단락전류법: A–B 단락 시 합쳐진 노드 전압 36/7 V → I_sc = 4 − (36/7)(1/3+1/6) = 10/7 mA, V_th/I_sc = 5/(10/7) = 3.5 kΩ ✓
- 노드 해석(R5=6.5k): V_A = 7 V, V_B = 3.75 V, V_AB = 3.25 V, I = 0.5 mA ✓ (R5=1.5k: V_A=6, V_B=4.5, I=1 mA ✓)

## 문제 3 해설

**단계별 테브닌 (개방 출력 기준).**
- A단: V_th,A = 36·12/(6+12) = 24 V, R_th,A = 6∥12 = 4 kΩ
- B단: V_th,B = 24·6/(4+2+6) = 12 V, R_th,B = (4+2)∥6 = **3 kΩ**
- C단: V_th,C = 12·3/(3+3+3) = **4 V**, R_th,C = (3+3)∥3 = 2 kΩ

1. **R_in(B)** = Rs2 + Rp2∥(Rs3+Rp3) = 2 + 6∥6 = **5 kΩ**
2. **R_out(B)** = (Rs1∥Rp1 + Rs2)∥Rp2 = **3 kΩ**
3. **V_out = 4 V** (이때 n2 = 12·6/(3+6) = 8 V)
4. 순진한 값 = 36·(12/18)·(6/8)·(3/6) = **9 V**. 오차 = +5 V (정확값의 125 %, 순진한 값 기준 55.6 %).
5. 부하 R_L = 2 kΩ: V_out = 4·2/(2+2) = **2 V** (Th_C = 4V/2k).

**검산 (노드 해석, 3원 연립).** 개방: n1 = 13.33 V, n2 = 8 V, n3 = 4 V ✓. R_L=2k: n1 = 12.67 V, n2 = 7 V, n3 = 2 V ✓. 전류 검산: 개방 시 Rs3 전류 (8−4)/3k = 4/3 mA = Rp3 전류 4/3k ✓.
