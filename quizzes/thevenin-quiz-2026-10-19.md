# 회로 퀴즈: 테브닌·분압·중첩으로 푸는 "복잡해 보이는" 회로 (2026-10-19)

> 단위: V, kΩ, mA (kΩ × mA = V). 모든 문제는 연립방정식을 세우지 않고도 풀 수 있도록 설계되었습니다.

---

## 문제 1 (초급) — 두 전원의 단일 루프

```
            P ●──────[ R1 = 3kΩ ]──────● Q
              │    I → (시계방향)        │
        E1 = 12V  (+ 위)          E2 = 4V  (+ 위)
              │                            │
            a ●──────[ R2 = 5kΩ ]──────● b
                                 (V_P = +5V 로 주어짐)
```

(정리) 시계방향 루프: `a →(E1: +12V 상승)→ P →R1→ Q →(E2: 아래로 내려가며 −4V)→ b →R2→ a`
E1은 (+)가 위쪽(P쪽), E2도 (+)가 위쪽(Q쪽)이므로 두 전원은 루프에서 **서로 반대 방향**입니다.
점 P의 전위가 **V_P = +5 V** 로 측정되었습니다.

**(1)** 루프 전류 I (크기와 방향)를 구하시오.
**(2)** 점 Q의 전위 V_Q와 점 a, b의 전위를 구하시오.
**(3)** 중첩의 원리로 R1 양단 전압을 다시 구해 (1)과 비교하시오.

🔑 **핵심 개념:** KVL(전위를 따라가며 더하기)과 중첩의 원리 — 전원 E1, E2가 만드는 전류는 각각 독립적으로 계산해 더할 수 있다. 여기서는 E1만 켜면 12V/8kΩ=1.5mA(시계), E2만 켜면 4V/8kΩ=0.5mA(반시계)이므로 두 기여가 **부호까지 포함해** 겹쳐져 순 전류 1mA가 되고, "P의 전위가 주어지면 그 점을 기준으로 전위를 따라 내려가면 된다"는 점이 핵심이다.

## 문제 2 (중급) — 불평형 브리지

```
              +12V (Vs)
                ●
         ┌──────┴──────┐
         │             │
     [R1=4kΩ]      [R3=6kΩ]
         │             │
       A ●──[ R5 = 20kΩ ]──● B
         │      I →        │
     [R2=12kΩ]     [R4=3kΩ]
         │             │
         └──────┬──────┘
                ⏚ (0V)
```

| 소자 | 값 | 위치 |
|---|---|---|
| Vs | 12 V | 상단 레일 − 접지 |
| R1 | 4 kΩ | 레일 ~ 노드 A |
| R2 | 12 kΩ | 노드 A ~ 접지 |
| R3 | 6 kΩ | 레일 ~ 노드 B |
| R4 | 3 kΩ | 노드 B ~ 접지 |
| R5 | 20 kΩ | 노드 A ~ 노드 B (전류 I는 A→B 방향 정의) |

**(1)** R5를 떼어 낸 개방 상태에서 V_A, V_B, 테브닌 전압 V_th = V_A − V_B 를 구하시오.
**(2)** 전원을 단락했을 때 A-B에서 본 R_th를 구하시오.
**(3)** R5 = 20kΩ일 때 전류 I와 V_AB를 구하시오.
**(4)** R5를 5kΩ으로 바꾸면 I는? 또 R5 = 0(단락)일 때 I는?

🔑 **핵심 개념:** 테브닌 정리 — 브리지 저항 R5를 "부하"로 보고, 나머지 회로(전원+분압기 두 개)를 V_th=5V, R_th=5kΩ 하나로 치환한다. 이렇게 하면 R5가 바뀔 때마다 I = V_th/(R_th+R5) 한 줄로 계산되므로, 노드 해석(미지수 2개 연립)을 R5 값마다 다시 풀 필요가 없다.

## 문제 3 (고급) — 3단 분압기의 부하 효과

```
        A단            B단            C단
     R1=3kΩ   n1    R3=4kΩ   n2    R5=4kΩ   n3 (=Vout)
 ●──[████]──┬──────[████]──┬──────[████]──┬────●
 │+         │              │              │      │
Vin=36V   R2=6kΩ        R4=12kΩ        R6=8kΩ  [R_L = 12kΩ]  ← 보너스(점선 연결 시)
 │-         │              │              │      │
 ⏚──────────┴──────────────┴──────────────┴──────┘
```

**(1)** B단의 입력저항 R_in(B) (R3의 왼쪽 단자에서 오른쪽을 본 저항, 뒤 단 C단 포함, R_L 없음)을 구하시오.
**(2)** B단 출력(노드 n2)에서 왼쪽을 본 R_out(= B단까지의 테브닌 저항)을 구하시오.
**(3)** A→B→C 순서로 테브닌 등가를 단계별로 적용해 정확한 V_out을 구하시오.
**(4)** 부하 효과를 무시하고 각 단의 무부하 분압비만 곱한 "순진한 값"을 구하고 오차(V, %)를 계산하시오.
**(5)** (보너스) 출력에 R_L = 12kΩ을 달았을 때 V_out은?

🔑 **핵심 개념:** 테브닌 등가의 연쇄 적용과 분압 법칙 — 앞 단을 (V_th, R_th)로 바꾸면 그 R_th가 다음 단의 직렬 저항에 **더해져** 다음 분압비가 달라진다. 즉 각 분압기는 뒤 단을 부하로 끌어 쓰므로 분압비를 단순히 곱하면 안 되고, 부하 저항(R_in)과 전원 쪽 R_th를 매 단계 반영해야 한다.

---

# 📘 정답 및 해설 (교수용)

## 문제 1 해설

**KVL 풀이.** 순 기전력 = 12 − 4 = 8 V, 루프 저항 = 3 + 5 = 8 kΩ → **I = 1 mA (시계방향, P→Q 방향)**.
전위 따라가기: V_Q = V_P − I·R1 = 5 − 3 = **2 V**.
V_a = V_P − 12 = **−7 V** (E1의 (+)가 P쪽).
V_b = V_a + I·R2 = −7 + 5 = **−2 V** (시계방향이므로 b→a로 흐르며 b가 a보다 5V 높음).

**검산 (다른 경로):** E2를 거쳐 Q를 계산: V_Q = V_b + 4 = −2 + 4 = **2 V** ✓ (같은 값).

**중첩 풀이.**
- E1만 (E2 단락): I₁ = 12/8 = 1.5 mA 시계 → R1 전압강하(P→Q) = +4.5 V
- E2만 (E1 단락): I₂ = 4/8 = 0.5 mA 반시계 → R1 전압강하(P→Q) = −1.5 V
- 합: 4.5 − 1.5 = **3 V** → V_Q = 5 − 3 = **2 V** ✓

참고: 문제에서 V_P를 주지 않으면 전위는 정해지지 않고 V_PQ=3V만 결정됩니다. "기준점이 있어야 전위가 정해진다"를 짚을 것.

## 문제 2 해설

(1) V_A = 12·12/(4+12) = **9 V**, V_B = 12·3/(6+3) = **4 V**, **V_th = 5 V**.
(2) R_th = (4∥12) + (6∥3) = 3 + 2 = **5 kΩ** (전원 단락 시 A쪽·B쪽 분압기가 각각 접지와 레일로 묶여 직렬로 보임).
(3) R5=20kΩ: I = 5/(5+20) = **0.2 mA** (A→B), V_AB = I·R5 = **4 V**.
(4) R5=5kΩ: I = 5/10 = **0.5 mA**, V_AB = 2.5 V. R5=0: I_sc = 5/5 = **1 mA**.

**검산 1 (노드 해석, 연립):** 노드 A: (V_A−12)/4 + V_A/12 + (V_A−V_B)/20 = 0, 노드 B: (V_B−12)/6 + V_B/3 + (V_B−V_A)/20 = 0 → V_A = 8.4 V, V_B = 4.4 V, V_AB = **4 V**, I = 4/20 = **0.2 mA** ✓
R5=5kΩ으로 같은 연립을 다시 풀면 V_AB = 2.5 V, I = 0.5 mA ✓ (R5가 바뀔 때마다 연립을 다시 풀어야 함 — 테브닌은 한 줄).
**검산 2 (V_th / I_sc):** R5 단락 시 I_sc = 1 mA, R_th = V_th/I_sc = 5/1 = 5 kΩ ✓

## 문제 3 해설

**단계별 테브닌 (R_L 없음).**
- A단: V_th,A = 36·6/(3+6) = **24 V**, R_th,A = 3∥6 = **2 kΩ**
- B단: 직렬 저항 = R_th,A + R3 = 2 + 4 = 6 kΩ. V_th,B = 24·12/(6+12) = **16 V**, R_th,B = 6∥12 = **4 kΩ**
- C단: 직렬 저항 = R_th,B + R5 = 4 + 4 = 8 kΩ. V_th,C = 16·8/(8+8) = **8 V**, R_th,C = 8∥8 = **4 kΩ**

**(1)** R_in(B) = R3 + R4∥(R5+R6) = 4 + 12∥12 = 4 + 6 = **10 kΩ**
**(2)** R_out(B) = R_th,B = **4 kΩ**
**(3)** **V_out = 8 V** (R_out = 4 kΩ)
**(4)** 순진한 값 = 36 × (6/9) × (12/16) × (8/12) = 36 × (2/3)(3/4)(2/3) = **12 V**. 오차 = +4 V (정확값 대비 **+50 %**, 순진한 값 기준 −33 %로 과대평가).
**(5)** R_L = 12kΩ: V_out = 8·12/(4+12) = **6 V**.

**검산 (앞에서 뒤로 직접 KVL/KCL):**
노드 n1 = 36·(6∥10)/(3 + 6∥10) = 36·3.75/6.75 = **20 V**
n2 = 20·(12∥12)/(4 + 12∥12) = 20·6/10 = **12 V**, n3 = 12·8/(4+8) = **8 V** ✓ (테브닌 결과와 동일).
전체 연립(노드 3개) 풀이: n1=20, n2=12, n3=8 ✓. R_L=12kΩ 포함 시 n1=59/3 V, n2=11 V, n3=6 V ✓.
