# ⚡ 회로 퀴즈: 복잡해 보여도 간단히 풀리는 회로 (2026-11-11)

> 공통 주제: 전압원과 저항이 직렬·병렬로 얽혀 복잡해 보이는 회로를 **테브닌 정리·분압 법칙·중첩의 원리**로 간단히 푼다.
> 단위: V, kΩ, mA (kΩ × mA = V)

---

## 문제 1 (초급): 두 전원이 같은 방향으로 미는 루프

전압원 2개와 저항 2개가 단일 루프를 이룹니다. 점 P의 전위는 **V_P = +1 V** 입니다(기준 0 V는 회로 밖 어딘가에 있음).
이번 회로에서는 E2의 극성이 **아래가 +** 라는 점에 주의하세요.

```
            N2 ───────[ R1 = 3kΩ ]─────── N3  (= Q)
            │          ──► I               │
           (+)                            (−)
        E1 = 12 V                      E2 = 8 V
           (−)                            (+)
            │          ◄── I               │
   (= P)    N1 ───────[ R2 = 1kΩ ]─────── N4

   V_P = V_N1 = +1 V (주어짐),   V_Q = V_N3 = ?
   I : 시계방향 (N1 → E1 → N2 → R1 → N3 → E2 → N4 → R2 → N1) 을 (+)로 정의
```

**(1)** 루프 전류 I 를 구하시오. (두 전원은 서로 돕는가, 상쇄하는가?)

**(2)** 점 Q의 전위 V_Q 를 **KVL(전위 따라가기)** 로 구하시오. 서로 다른 두 경로로 구해 확인하시오.

**(3)** 같은 V_Q 를 **중첩의 원리**로 다시 구하시오. (P 기준 전위차 V_QP = V_Q − V_P 를 전원별로 구해 더한 뒤 V_P 를 더할 것)

🔑 **핵심 개념:** 루프를 시계방향으로 돌 때 E1은 −→+ 로(+12 V), E2도 N3(−)→N4(+) 로(+8 V) 지나므로 두 전원이 **같은 방향으로 전류를 밀어** 순기전력이 12 + 8 = 20 V가 되고, 단일 루프이므로 전류는 I = 20/4 = 5 mA 하나뿐이다. 그다음 이미 아는 P(+1 V)에서 출발해 "전원은 극성대로 ±E, 저항은 전류 방향으로 지나면 −IR"을 더해 가면 Q가 **P보다 낮은 음의 전위**가 될 수 있음을 확인한다. 중첩에서는 한 전원을 단락하면 Q가 P와 같은 저항 하나의 양 끝에 놓여 V_QP가 저항 하나의 전압강하로 바로 나온다.

## 문제 2 (중급): B 쪽이 더 높은 불평형 브리지

20 V 전원에 분압기 두 갈래가 붙어 있고, 중간 노드 A와 B를 R5가 잇습니다.

```
                        +20 V (Vs, + 위 / − 접지)
                 ┌─────────────┴─────────────┐
                 │                           │
              R1 = 8kΩ                    R3 = 4kΩ
                 │                           │
                 A ──────[ R5 = 4kΩ ]─────── B
                 │       I_5 : A → B (+)     │
              R2 = 2kΩ                    R4 = 6kΩ
                 │                           │
                 └─────────────┬─────────────┘
                              GND (0 V)

   I_5 : A → B 방향을 (+)로 정의,  V_AB = V_A − V_B
```

**(1)** R5를 떼어 낸 뒤, A-B 단자에서 본 테브닌 등가전압 V_th(= V_A − V_B, 개방)와 등가저항 R_th 를 구하시오.

**(2)** R5 = 4 kΩ일 때 I_5 와 V_AB 를 구하시오. 전류의 **실제 방향**은 어느 쪽인가?

**(3)** R5 를 **12 kΩ** 으로 바꾸면 I_5 와 V_AB 는? (회로를 다시 풀지 말고 (1)의 결과를 재사용할 것)

**(4)** 노드 해석으로 같은 문제를 풀 때와 비교해, 테브닌 정리가 왜 유리한지 설명하시오.

🔑 **핵심 개념:** R5를 "부하"로 떼어 내면 남는 것은 서로 독립된 분압기 두 개다. 분압 법칙으로 V_A = 20·2/10 = 4 V, V_B = 20·6/10 = 12 V를 구하면 V_th = −8 V(B가 더 높음)이므로 전류는 **B → A**로 흐름을 바로 안다. 전원을 단락하면 Vs 노드가 접지와 같아져 R1∥R2(1.6 kΩ)와 R3∥R4(2.4 kΩ)가 A-B 사이에 직렬로 보이고 R_th = 4 kΩ이다. 이 (V_th, R_th) 한 쌍만 있으면 R5가 무엇이든 I = V_th/(R_th + R5) 나눗셈 한 번으로 끝난다.

## 문제 3 (고급): 3단 분압기의 부하 효과

입력 **Vin = 45 V** 를 분압기 3단(A → B → C)에 연속으로 인가합니다. 각 단은 "직렬 저항 + 접지로 가는 션트 저항"입니다.

```
           ┌─── 단 A ───┐       ┌─── 단 B ───┐       ┌─── 단 C ───┐
  Vin ──[ R1 = 9kΩ ]──┬──[ R3 = 6kΩ ]──┬──[ R5 = 8kΩ ]──┬──── V_out (N3)
  45V                 N1               N2               N3        │
  (+)                 │                │                │      [ R_L ]  (보너스)
                  R2 = 18kΩ        R4 = 24kΩ        R6 = 16kΩ     │
  (−)                 │                │                │         │
  GND ────────────────┴────────────────┴────────────────┴─────────┘

  전류는 Vin → N1 → N2 → N3 방향(왼→오른쪽)으로, 각 션트에서는 위→아래(접지)로 흐름
```

**(1)** B단의 **입력저항 R_in(B)** : N1에서 B단 쪽(R3 방향)으로 들여다본 저항을 구하시오(뒤 단 C의 부하 포함).

**(2)** B단 출력(N2)에서 본 **R_out(B)** 를 구하시오(입력 전원은 단락, C단은 분리).

**(3)** 테브닌 등가를 A → B → C 순서로 **단계별** 적용하여 정확한 V_out 을 구하시오(각 단의 V_th, R_th 표 작성).

**(4)** 부하 효과를 무시하고 각 단의 분압비만 곱한 **"순진한 값"** 을 구하고, 정확한 값과의 오차(V, %)를 구하시오.

**(5) (보너스)** 출력에 **R_L = 8 kΩ** 을 달면 V_out 은? 이 값이 왜 하필 개방 전압의 절반인지 설명하시오.

🔑 **핵심 개념:** 각 단의 왼쪽 전체를 "(전압원 V_th) + (직렬 R_th)"로 바꾸면 다음 단은 다시 "전원 1개짜리 분압기"가 되므로 같은 식 V_th,next = V_th·R_shunt/(R_th + R_series + R_shunt), R_th,next = (R_th + R_series)∥R_shunt 를 세 번 반복하면 된다. 순진한 계산은 B단의 R_in(18 kΩ)이 A단의 션트 18 kΩ에 병렬로 붙어 A단 분압비를 2/3 → 1/2로 떨어뜨리는 "부하 효과"를 무시하기 때문에 틀린다.

# 📘 정답 및 해설 (교수용)

## 문제 1 해설

**(1) 루프 전류.** 시계방향으로 돌면 E1: −→+ 로 +12 V, E2: N3(−)→N4(+) 로 +8 V. 두 전원이 **같은 방향**으로 돕는다.
순기전력 = 12 + 8 = 20 V, 직렬저항 = 3 + 1 = 4 kΩ → **I = 20/4 = 5 mA** (시계방향, 양수).

**(2) KVL 전위 따라가기.**

경로 ① P(N1) → E1 → N2 → R1 → N3(=Q) (전류 방향과 같은 방향)
- N1 → N2: E1의 − 에서 + 로 → +12 V → V_N2 = 1 + 12 = 13 V
- N2 → N3: R1을 전류 방향으로 지남 → −I·R1 = −5 × 3 = −15 V → V_N3 = 13 − 15 = **−2 V**

경로 ② (검산) P(N1) → R2 → N4 → E2 → N3 (전류 반대 방향)
- N1 → N4: R2를 전류 반대 방향으로 지남 → +I·R2 = +5 V → V_N4 = 6 V
- N4 → N3: E2의 + 에서 − 로 → −8 V → V_N3 = 6 − 8 = **−2 V** ✓

**V_Q = −2 V** (P보다 3 V 낮다. 전원이 있어도 어떤 점은 음의 전위가 될 수 있다.)

**(3) 중첩의 원리 (V_QP = V_Q − V_P).**
- **E1만** (E2 단락 → N3 = N4): I₁ = 12/4 = 3 mA 시계방향. N4 → R2 → N1 으로 흐르므로 V_N4 − V_N1 = 3 × 1 = 3 V. N3 = N4 이므로 V_QP = **+3 V**
- **E2만** (E1 단락 → N1 = N2): E2는 + 단자(N4)로 전류를 내보내므로 N4 → R2 → N1 → N2 → R1 → N3, 즉 역시 시계방향 I₂ = 8/4 = 2 mA. N1 = N2 이므로 V_QP = V_N3 − V_N2 = −I₂·R1 = −2 × 3 = **−6 V**
- **합:** V_QP = 3 + (−6) = −3 V → V_Q = V_P + V_QP = 1 − 3 = **−2 V** ✓ (KVL과 일치)
- 전류 검산: I = I₁ + I₂ = 3 + 2 = 5 mA ✓

**지도 포인트:** 학생들은 습관적으로 "두 전원은 빼야 한다"고 생각해 12 − 8 = 4 V, I = 1 mA로 계산하기 쉽다. 이 경우 V_Q = 1 + 12 − 3 = 10 V라는 오답이 나온다. 극성을 루프 방향으로 하나씩 읽게 할 것.

## 문제 2 해설

**(1) 테브닌 등가 (R5 제거).**
- V_A = 20 × 2/(8 + 2) = **4 V**, V_B = 20 × 6/(4 + 6) = **12 V**
- V_th = V_A − V_B = **−8 V** (B가 8 V 더 높음)
- R_th = (R1∥R2) + (R3∥R4) = (8·2/10) + (4·6/10) = 1.6 + 2.4 = **4 kΩ**

**(2) R5 = 4 kΩ.**
I_5 = V_th/(R_th + R5) = −8/(4 + 4) = **−1 mA** → 실제로는 **B → A 방향 1 mA**.
V_AB = I_5 · R5 = **−4 V** (B가 A보다 4 V 높음).

- **검산 1 (노드 해석).**
  A: (20 − V_A)/8 = V_A/2 + (V_A − V_B)/4
  B: (20 − V_B)/4 = V_B/6 + (V_B − V_A)/4
  → V_A = 5.6 V, V_B = 9.6 V, V_AB = −4 V, I_5 = −1 mA ✓
  (R5가 A를 끌어올리고 B를 끌어내려 개방 시 4 V/12 V에서 5.6 V/9.6 V로 가까워짐)
- **검산 2 (노턴, 단락전류).** A-B를 단락하면 V_A = V_B = X:
  (20 − X)/8 + (20 − X)/4 = X/2 + X/6 → X = 7.2 V.
  A → B 단락전류 I_sc = (20 − X)/8 − X/2 = 1.6 − 3.6 = −2 mA.
  V_th/R_th = −8/4 = −2 mA ✓. 부하전류 = I_sc · R_th/(R_th + R5) = −2 × 4/8 = −1 mA ✓

**(3) R5 = 12 kΩ.** I_5 = −8/(4 + 12) = **−0.5 mA** (B → A 0.5 mA), V_AB = −0.5 × 12 = **−6 V**.
(노드 해석으로 검산: V_A = 4.8 V, V_B = 10.8 V ✓. R5 → ∞이면 V_AB → V_th = −8 V로 수렴.)

**(4) 테브닌의 장점.** 노드 해석은 미지수 V_A, V_B의 **2원 연립방정식**이고, R5가 바뀔 때마다 처음부터 다시 풀어야 한다. 테브닌은 분압 2번 + 병렬 2번으로 (V_th, R_th)를 **한 번만** 구하면 이후 어떤 R5든 나눗셈 한 번이다. 부하를 바꿔 가며 보는 문제(센서 브리지의 검류계 저항 선택, 최대전력 전달)에서 차이가 커진다.

> 추가 토론: R5 = R_th = 4 kΩ일 때 R5의 전력이 최대 → P_max = V_th²/(4R_th) = 64/16 = **4 mW**. (2)의 조건이 바로 최대전력 전달점이다: 1 mA × 4 V = 4 mW ✓

## 문제 3 해설

**단계별 테브닌 등가 (Vin = 45 V)**

| 단 | 계산 | V_th | R_th |
|---|---|---|---|
| A (N1, 개방) | V = 45 × 18/(9+18), R = 9∥18 | **30 V** | **6 kΩ** |
| B (A의 등가 + R3, R4) | 직렬 6+6 = 12 kΩ, V = 30 × 24/(12+24), R = 12∥24 | **20 V** | **8 kΩ** |
| C (B의 등가 + R5, R6) | 직렬 8+8 = 16 kΩ, V = 20 × 16/(16+16), R = 16∥16 | **10 V** | **8 kΩ** |

**(1) R_in(B)** = R3 + R4 ∥ (R5 + R6) = 6 + 24 ∥ 24 = 6 + 12 = **18 kΩ**
(C단 입력저항 R5 + R6 = 24 kΩ이 R4 = 24 kΩ에 병렬로 붙어 션트가 절반인 12 kΩ으로 줄어든다.)

**(2) R_out(B)** = (A단 R_th + R3) ∥ R4 = (6 + 6) ∥ 24 = **8 kΩ** (= 표의 B단 R_th)

**(3) 정확한 V_out** = C단 V_th = **10 V** (출력 저항 R_th,out = 8 kΩ)

- **검산 1 (노드 해석, 개방 출력).**
  N1: (45 − V1)/9 = V1/18 + (V1 − V2)/6
  N2: (V1 − V2)/6 = V2/24 + (V2 − V3)/8
  N3: (V2 − V3)/8 = V3/16
  → V1 = 22.5 V, V2 = 15 V, **V3 = 10 V** ✓
- **검산 2 (단락전류).** 출력 N3를 접지에 단락하면 노드 해석으로 V1 = 20 V, V2 = 10 V, I_sc = V2/R5 = 10/8 = 1.25 mA.
  V_th/R_th = 10/8 = 1.25 mA ✓
- **검산 3 (입력 쪽에서 R_in으로).** 전체 입력저항 = R1 + R2 ∥ R_in(B) = 9 + 18 ∥ 18 = 18 kΩ → 입력 전류 2.5 mA → V1 = 45 − 2.5 × 9 = 22.5 V ✓. 이후 V2 = 22.5 × 12/18 = 15 V, V3 = 15 × 16/24 = 10 V ✓

**(4) 순진한 값** = 45 × (18/27) × (24/30) × (16/24) = 45 × 2/3 × 4/5 × 2/3 = **16 V**
오차 = 16 − 10 = **6 V**, 정확한 값 대비 **+60 %** 과대.

| 단 | 순진한 분압비 (무부하) | 실제 비 (부하 포함) |
|---|---|---|
| A: V1/Vin | 18/27 = 2/3 | 22.5/45 = 1/2 |
| B: V2/V1 | 24/30 = 4/5 | 15/22.5 = 2/3 |
| C: V3/V2 | 16/24 = 2/3 | 10/15 = 2/3 |

C단만 두 값이 같은 이유: C단 뒤에는 부하가 없기 때문이다(개방 출력). 앞 두 단은 뒤 단이 션트에 병렬로 붙어 실제 분압비가 낮아진다.

**(5) 보너스: R_L = 8 kΩ.** V_out = 10 × 8/(8 + 8) = **5 V**.
R_L = R_th,out = 8 kΩ이므로 정확히 절반 → 이 조건은 최대전력 전달점이기도 하다(P_L = 5²/8 = 3.125 mW).
(노드 해석 검산: N3 식에 V3/8 항 추가 → V1 = 21.25 V, V2 = 12.5 V, V3 = 5 V ✓)

**지도 포인트:** "분압기를 이어 붙이면 비율만 곱하면 된다"는 직관이 왜 틀렸는지 보여 주는 문제. 실무에서는 단 사이에 버퍼(전압 폴로워)를 넣거나 R_in(다음 단) ≫ R_out(앞 단)이 되도록 설계해야 순진한 값에 가까워진다. 이 회로는 R_in(B)/R_out(A) = 18/6 = 3배에 불과해 오차가 크다.
