# ⚡ 테브닌·분압·중첩 회로 퀴즈 (2026-10-17)

> 공통 주제: 전압원과 저항이 직렬·병렬로 얽혀 복잡해 보여도, **테브닌 정리 · 분압 법칙 · 중첩의 원리**를 쓰면 간단히 풀린다.
> 전위는 모두 접지(0V, GND) 기준이며, 소자 값의 단위는 V, kΩ, mA이다.

---

## 🟢 문제 1 (초급) — 두 전원이 마주 보는 단일 루프

15V 전원(E1), 5V 전원(E2), 저항 R1 = 3kΩ, R2 = 2kΩ이 아래와 같이 하나의 루프를 이룬다. 점 P의 전위는 V_P = +8V이다.

```
          P ────────[ R1 = 3kΩ ]──────── Q
          │   ──►I(시계방향, 가정)        │
        (+)                              (+)
       E1 = 15V                        E2 = 5V
        (−)                              (−)
          │                               │
          T ────────[ R2 = 2kΩ ]──────── S

  ※ E1: + 단자가 P쪽(위), E2: + 단자가 Q쪽(위)
  ※ V_P = +8V (T, S, Q의 전위는 모르는 상태)
```

**(1)** 루프에 흐르는 전류 I의 크기와 방향을 구하시오.
**(2)** 점 Q의 전위 V_Q를 **KVL로 전위를 따라가는 방법**으로 구하시오.
**(3)** 같은 V_Q를 **중첩의 원리**로 다시 구하시오. (V_P는 고정된 값으로 취급)

🔑 **핵심 개념:** 단일 루프에서는 모든 소자에 같은 전류가 흐르므로 *전원들의 대수합 ÷ 저항 합*으로 I가 먼저 정해지고, 전위는 "알려진 점에서 출발해 소자를 지날 때마다 ±전압을 더하는" 방식으로 따라간다. 중첩의 원리에서는 전원을 하나씩만 살리고(나머지 전압원은 단락) 각 전원이 R1 양단에 만드는 전압 기여분을 더하면 같은 답이 나온다 — 두 방법의 일치가 KVL의 선형성을 보여준다.

## 🟡 문제 2 (중급) — 불평형 브리지와 테브닌 정리

12V 전원에 두 갈래의 분압기가 연결되어 있고, 두 중간 노드 A, B 사이를 브리지 저항 R5가 잇는다.

```
                 +12V
         ┌─────────┴─────────┐
         │                   │
       [R1=3kΩ]            [R3=6kΩ]
         │                   │
         A ──►I──[ R5 ]──── B          (I: A→B 방향 가정)
         │                   │
       [R2=6kΩ]            [R4=2kΩ]
         │                   │
         └─────────┬─────────┘
                  GND (0V)
```

**(1)** R5를 떼어낸 상태에서 A, B에서 본 **테브닌 등가회로** (V_th = V_A − V_B, R_th)를 구하시오.
**(2)** R5 = 1.5kΩ일 때 R5를 흐르는 전류 I와 V_AB를 구하시오.
**(3)** R5를 6.5kΩ으로 바꾸면 I와 V_AB는 어떻게 되는가? (회로를 다시 풀지 말고 (1)의 결과를 재사용)
**(4)** 노드 해석으로 (2)를 검산하고, 테브닌 방법과 필요한 연립식의 개수를 비교하시오.

🔑 **핵심 개념:** 브리지 저항 R5만 "부하"로 떼어내면 나머지는 **분압기 두 개**이므로 A점·B점 개방전압은 각각 분압 법칙 한 줄로 나온다(V_th = V_A − V_B). 전압원을 단락하면 두 분압기가 모두 (위·아래 저항의 병렬)이 되어 R_th = (R1∥R2) + (R3∥R4)이다. 이후 R5가 무엇이든 I = V_th/(R_th + R5)만 계산하면 되므로, 노드 해석처럼 R5를 바꿀 때마다 연립방정식을 다시 풀 필요가 없다.

## 🔴 문제 3 (고급) — 3단 분압기의 부하 효과

Vin = 36V 전원에 분압기 3단(A→B→C)이 직렬로 연결되어 있다. 각 단은 직렬저항(R_s)과 병렬(접지) 저항(R_p)으로 이루어진다.

```
        Rs1=6kΩ       Rs2=8kΩ        Rs3=6kΩ
 Vin ──/\/\/──┬──────/\/\/──┬──────/\/\/──┬──── V_out
 36V          │             │             │
 (+)        [Rp1=12kΩ]    [Rp2=12kΩ]    [Rp3=6kΩ]
 (−)          │             │             │
 GND ─────────┴─────────────┴─────────────┘
              노드 A         노드 B         출력 C

  ※ V_A, V_B, V_out은 모두 GND 기준 전위, 출력 C는 처음에는 개방(무부하)
```

**(1)** B단의 **입력저항 R_in(B)** (= Rs2 쪽에서 오른쪽을 본 저항, 뒤 단 C의 부하 포함)을 구하시오.
**(2)** 노드 B에서 **왼쪽을 본 출력저항 R_out(B)** 를 구하시오. (전원 Vin은 단락)
**(3)** 테브닌 등가를 **단계별(A단 → B단 → C단)** 로 적용하여 각 단의 (V_th, R_th)와 **정확한 V_out**을 구하시오.
**(4)** 부하 효과를 무시하고 각 단의 무부하 분압비만 곱한 **순진한 값**을 구하고, 정확값과의 오차(V, %)를 구하시오.
**(5)** (보너스) 출력 C에 R_L = 12kΩ을 연결했을 때의 출력 전압을 구하시오.

🔑 **핵심 개념:** 각 단의 왼쪽 전체를 **(V_th, R_th) 하나의 전원+직렬저항**으로 바꾸면, 다음 단은 "새 전원 + (R_th + Rs) 직렬저항 + Rp 분압기"라는 똑같은 문제가 반복된다(R_th,new = (R_th,old + Rs)∥Rp, V_th,new = V_th,old·Rp/(R_th,old + Rs + Rp)). 즉 분압 법칙을 단마다 한 번씩 쓰되, 앞 단의 출력저항이 다음 단의 직렬저항에 합쳐진다는 점(= 부하 효과)을 반영하는 것이 테브닌 정리의 역할이다. 순진한 값은 이 합산을 빼먹어서 틀린다.

# 📘 정답 및 해설 (교수용)

## 문제 1 해설

**(1) 전류.** 시계방향(P→R1→Q→E2→S→R2→T→E1→P)을 I의 양의 방향으로 둔다.
E1은 T→P로 지날 때 +15V 상승, E2는 Q→S로 지날 때(+에서 −로) 5V 강하이므로

15 − 5 = I(3k + 2k) → **I = 10V / 5kΩ = 2mA (시계방향)**

**(2) KVL로 전위 따라가기** (V_P = 8V에서 출발, 루프를 한 바퀴 돌아 검산까지)

| 구간 | 계산 | 결과 |
|---|---|---|
| P → Q (R1, 전류 방향으로 통과) | 8 − 2mA·3k = 8 − 6 | **V_Q = 2V** |
| Q → S (E2, + → −) | 2 − 5 | V_S = −3V |
| S → T (R2) | −3 − 2mA·2k = −3 − 4 | V_T = −7V |
| T → P (E1, − → +) | −7 + 15 | V_P = 8V ✔ (출발점 복귀) |

**(3) 중첩의 원리** (구하려는 양: V_Q − V_P = −(R1 양단 전압, P→Q 방향))
- E1만 (E2 단락): I₁ = 15/5k = 3mA 시계방향 → V_Q − V_P = −3mA·3k = **−9V**
- E2만 (E1 단락): E2의 + 단자(Q)에서 나온 전류가 R1을 Q→P로 흘러 반시계방향 I₂ = 5/5k = 1mA → V_Q − V_P = +1mA·3k = **+3V**
- 합: V_Q − V_P = −9 + 3 = −6V → **V_Q = 8 − 6 = 2V** ✔ (KVL 결과와 일치)

**검산:** 전류는 두 방법 모두 2mA(= 3mA − 1mA). 루프 복귀 검산 완료.
**답: I = 2mA(시계방향), V_Q = 2V.**

## 문제 2 해설

**(1) 테브닌 등가 (R5 제거)**
- V_A = 12·6/(3+6) = **8V**, V_B = 12·2/(6+2) = **3V** → **V_th = V_A − V_B = 5V**
- 전원 단락 시 R_th = (3k∥6k) + (6k∥2k) = 2k + 1.5k = **3.5kΩ**

**(2) R5 = 1.5kΩ:** I = 5V/(3.5k + 1.5k) = **1mA (A→B)**, V_AB = 1mA·1.5k = **1.5V**

**(3) R5 = 6.5kΩ:** I = 5/(3.5 + 6.5) = **0.5mA**, V_AB = 0.5mA·6.5k = **3.25V** (한 줄 계산, 회로 재해석 없음)

**(4) 검산**
- 방법 ① V_th/I_sc: R5를 단락하면 I_sc = V_th/R_th = 5/3.5 ≈ 1.4286mA. 노드식을 R5→0으로 풀어도 같은 값이 나오며, R_th = V_th/I_sc = 3.5k로 일관된다.
- 방법 ② 노드 해석 (R5 = 1.5k, 전도도 mS):
  - A: (1/3 + 1/6 + 1/1.5)V_A − (1/1.5)V_B = 12/3 → 1.5V_A − 0.6667V_B = 4
  - B: −(1/1.5)V_A + (1/6 + 1/2 + 1/1.5)V_B = 12/6 → −0.6667V_A + 1.3333V_B = 2
  - 풀이: V_A = 6V, V_B = 4.5V → I = (6 − 4.5)/1.5k = 1mA, V_AB = 1.5V ✔
  - R5 = 6.5k도 노드해석으로 V_A = 7V, V_B = 3.75V → I = 0.5mA ✔ (Python 정확분수 계산으로도 확인)
- **장점 비교:** 노드 해석은 R5가 바뀔 때마다 2원 연립식을 새로 풀어야 하지만, 테브닌은 (V_th, R_th)를 한 번 구하면 이후는 나눗셈 한 번이다.

**답: V_th = 5V, R_th = 3.5kΩ, I = 1mA, V_AB = 1.5V; R5 = 6.5kΩ이면 I = 0.5mA, V_AB = 3.25V.**

## 문제 3 해설

**(1) R_in(B)**
- 단 C 입력저항: Rs3 + Rp3 = 6k + 6k = 12k
- 노드 B에서 본 저항: Rp2 ∥ 12k = 12k∥12k = 6k
- **R_in(B) = Rs2 + 6k = 8k + 6k = 14kΩ**

**(2) R_out(B)** (Vin 단락 → Rs1과 Rp1이 병렬)
- A단 쪽: Rs1∥Rp1 = 6k∥12k = 4k
- 노드 B에서 왼쪽: Rp2 ∥ (Rs2 + 4k) = 12k ∥ 12k = **6kΩ**

**(3) 단계별 테브닌**

| 단 | 계산 | V_th | R_th |
|---|---|---|---|
| A | V_th = 36·12/(6+12), R_th = 6k∥12k | **24V** | **4kΩ** |
| B | 직렬합 = 4k + 8k = 12k, 분압 12/(12+12), R_th = 12k∥12k | **12V** | **6kΩ** |
| C | 직렬합 = 6k + 6k = 12k, 분압 6/(12+6), R_th = 12k∥6k | **4V** | **4kΩ** |

**V_out(무부하) = 4V** (C단 테브닌 전압), 출력저항 4kΩ.

**(4) 순진한 값**
- 무부하 분압비: A 12/18 = 2/3, B 12/20 = 3/5, C 6/12 = 1/2
- 36 × 2/3 × 3/5 × 1/2 = **7.2V**
- 오차: 7.2 − 4 = **+3.2V**, 정확값 대비 **+80%**
- 이유: 뒤 단이 앞 단에 부하(예: B단 입력 14k가 Rp1에 병렬)로 걸려 실제 전압이 훨씬 낮아진다.

**(5) 보너스: R_L = 12k** → 테브닌 (4V, 4k)에 12k 부하: V = 4·12/(4+12) = **3V**

**검산 (다른 경로: 전위를 앞에서 뒤로 직접 계산)**
- R_in(B) = 14k → A단 오른쪽 부하 = 12k∥14k = 84/13 ≈ 6.4615k
- V_A = 36·6.4615/(6 + 6.4615) ≈ 18.667V
- V_B = V_A·6/14 = **8V** (Rs2와 [12k∥12k = 6k]의 분압)
- V_out = V_B·6/12 = **4V** ✔ (테브닌 결과와 일치)
- 부하 12k: C 입력 = 6k + (6k∥12k = 4k) = 10k, Rp2∥10k = 5.4545k → V_A = 18.5V, V_B = 7.5V, V_out = 7.5·4/(6+4) = **3V** ✔ (Python 정확분수 계산으로도 확인)

> 참고: V_B = 8V는 부하가 걸린 실제 노드 전압이고, 단계별 테브닌의 V_th(B) = 12V는 "C단을 뗀 개방 전압"이다. 둘을 혼동하지 말 것.

**답: R_in(B) = 14kΩ, R_out(B) = 6kΩ, V_out = 4V, 순진한 값 7.2V (오차 +3.2V, +80%), R_L = 12k 부하 시 3V.**
