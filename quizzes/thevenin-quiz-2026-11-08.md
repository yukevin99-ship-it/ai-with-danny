# ⚡ 회로 퀴즈: 복잡해 보이는 회로, 간단히 풀기 (2026-11-08)

> 공통 주제: 전압원과 저항이 직렬·병렬로 얽혀 있어도 **테브닌 정리 · 분압 법칙 · 중첩의 원리**를 쓰면 연립방정식 없이 풀립니다.

## 🟢 문제 1 (초급) — 전위를 따라가는 단일 루프

전압원 2개와 저항 2개가 하나의 루프를 이룹니다. 점 P의 전위가 외부 기준에 의해 **V_P = +2 V** 로 고정되어 있을 때, 점 Q의 전위 V_Q를 구하세요.

```
        a ──────[ R1 = 2kΩ ]────── Q
        │   I → (시계방향)         │
     (+)│                       (+)│
   V1 = 12V                    V2 = 6V
     (−)│                       (−)│
        │                          │
        P ──────[ R2 = 4kΩ ]────── b
      (V_P = 2V)
```

(V1: P가 −, a가 +  /  V2: Q가 +, b가 −  /  전류 I는 시계방향 P→a→Q→b→P를 양(+)으로 정의)

**(1)** 루프 전류 I를 구하세요.
**(2)** 전위를 따라가는 KVL 방식으로 V_a, V_Q, V_b를 구하세요.
**(3)** 중첩의 원리로 V_Q − V_P를 다시 구해 (2)와 비교하세요.

> 🔑 **핵심 개념:** 전위는 "소자를 지날 때마다 더하고 빼는 값"입니다. V1을 −→+로 지나면 +12 V, 저항을 전류 방향으로 지나면 −IR, V2를 +→−로 지나면 −6 V로 기준점 P의 값(2 V)에서 출발해 차례로 더하면 Q에 도달합니다. 중첩의 원리에서는 전원을 하나씩 켜고(다른 전압원은 단락) 각 전원이 만드는 V_Q−V_P를 더하는데, 두 전원이 서로 **반대 방향으로 전류를 밀기** 때문에 루프 전류에서는 상쇄(12−6)되지만, Q-P 사이 전압에서는 각각 +8 V, +2 V로 **같은 부호로 더해진다**는 점이 포인트입니다.

## 🟡 문제 2 (중급) — 불평형 브리지와 테브닌 정리

**12 V** 전원에 분압기 두 갈래가 연결되고, 중간 노드 A와 B 사이를 R5가 잇고 있습니다.

```
              +12V (Vs)
        ┌───────┴────────┐
        │                │
     [R1=3kΩ]         [R3=12kΩ]
        │                │
        A ──[ R5=2kΩ ]── B
        │   I_5 → (A→B)  │
     [R2=6kΩ]         [R4=6kΩ]
        │                │
        └───────┬────────┘
               GND
```

**(1)** R5를 떼어 낸 뒤 A, B에서 본 테브닌 등가 V_th(= V_A − V_B)와 R_th를 구하세요.
**(2)** R5 = 2 kΩ 일 때 R5에 흐르는 전류 I_5와 V_AB를 구하세요.
**(3)** R5를 10 kΩ으로 바꾸면 I_5와 V_AB는? (테브닌 등가를 다시 쓰세요.)
**(4)** (검산) A, B 두 노드에 대한 노드 방정식을 세워 (2)를 확인하세요. 테브닌 방법과 비교해 어느 쪽이 연립식이 적은지 설명하세요.

> 🔑 **핵심 개념:** 브리지 저항 R5만 "부하"로 보고 나머지 회로를 **하나의 전압원 V_th + 직렬저항 R_th**로 압축합니다. 왼쪽 분압기는 V_A = 12·6/(3+6) = 8 V, 오른쪽은 V_B = 12·6/(12+6) = 4 V이므로 V_th = 4 V, 전원을 단락하면 R_th = (3‖6) + (12‖6) = 2k + 4k = 6 kΩ. 이후 R5가 바뀌어도 I = V_th/(R_th+R5) 한 줄이면 끝나므로, R5를 바꿀 때마다 2원 연립방정식을 다시 푸는 노드 해석보다 훨씬 효율적입니다.

## 🔴 문제 3 (고급) — 3단 분압기의 부하 효과

입력 V_in = 48 V에 분압기 3단(A→B→C)이 직렬로 이어져 있습니다. 모든 단은 "직렬 저항 + 접지로 가는 병렬 저항" 구조입니다.

```
 Vin=48V      Ra1=6kΩ        Rb1=9kΩ        Rc1=6kΩ
  (+)●────────[////]──●1────[////]──●2────[////]──●3 (V_out)
                      │              │              │
                   [Ra2=6kΩ]      [Rb2=12kΩ]     [Rc2=6kΩ]
                      │              │              │
  (−)●────────────────┴──────────────┴──────────────┴───── GND
                      └─ A단 ─┘      └─ B단 ─┘      └─ C단 ─┘
```
(출력 V_out은 노드 3, 무부하 상태. 보너스에서만 R_L을 노드 3–GND 사이에 연결)

**(1)** C단의 입력저항 R_in(C)와, B단의 입력저항 **R_in(B)** (뒤 단 C 포함)를 구하세요. (R_in(B)는 Rb1 + [Rb2 ‖ R_in(C)])
**(2)** B단 출력(노드 2)에서 전원 쪽을 본 **R_out(B)** 를 구하세요.
**(3)** 테브닌 등가를 A→B→C 순서로 단계별 적용해 **정확한 V_out**을 구하세요. (각 단의 V_th, R_th를 표로)
**(4)** 부하 효과를 무시하고 각 단의 무부하 분압비만 곱한 **순진한 값**과 정확한 값의 오차를 구하세요.
**(5) (보너스)** 출력에 R_L = 4 kΩ을 달았을 때의 V_out은?

> 🔑 **핵심 개념:** 분압기를 이어 붙이면 **뒤 단이 앞 단의 부하(병렬 저항)가 되어** 분압비가 달라집니다. 그래서 앞에서부터 "지금까지의 회로 = V_th + R_th"로 압축한 뒤, 이 R_th를 다음 단의 직렬 저항에 더해 다시 분압하는 과정을 반복합니다(테브닌 단계 적용). 반대로 뒤에서부터 R_in을 구해 앞 단의 분압에 쓰면 같은 결과를 얻으므로, 두 방향 풀이가 서로 검산이 됩니다.

# 📘 정답 및 해설 (교수용)

## 🟢 문제 1 해설

**(1) 루프 전류.** 시계방향(P→a→Q→b→P)으로 KVL:
12 − I·2k − 6 − I·4k = 0 → I = 6 V / 6 kΩ = **1 mA** (시계방향, +).

**(2) 전위 따라가기** (V_P = 2 V에서 출발):
- P→a (V1, −→+): V_a = 2 + 12 = **14 V**
- a→Q (R1, 전류 방향): V_Q = 14 − 1mA·2k = **12 V** ✅
- Q→b (V2, +→−): V_b = 12 − 6 = **6 V**
- b→P (R2): V_P = 6 − 1mA·4k = 2 V ✔ (출발점으로 복귀 → 일관)

**(3) 중첩의 원리** (구하는 양: V_Q − V_P)
- V1만 (V2 단락): I = 12/6k = 2 mA (시계). V_Q−V_P = 12 − 2mA·2k = **+8 V**
- V2만 (V1 단락, 즉 a=P): V2의 +단자 Q에서 전류가 R1을 통해 a로, V1(단락)을 지나 P, R2를 거쳐 b로 돌아옴 (반시계 1 mA). V_Q − V_a = 1mA·2k = **+2 V**, V_a = V_P → +2 V
- 합: 8 + 2 = **10 V** → V_Q = 2 + 10 = **12 V** ✅ (KVL 결과와 일치)

**검산 2:** Q에서 b, P 쪽으로 거꾸로 가면 V_P = V_Q − 6 − 1mA·4k = 12 − 10 = 2 V ✔.

## 🟡 문제 2 해설

**(1)** 무부하 분압: V_A = 12·6/9 = 8 V, V_B = 12·6/18 = 4 V → **V_th = V_A − V_B = 4 V** (A가 높음).
전원 단락: R_th = (3k‖6k) + (12k‖6k) = 2k + 4k = **6 kΩ**.

**(2)** I_5 = 4 / (6k + 2k) = **0.5 mA** (A→B), V_AB = 0.5mA × 2k = **1 V**.

**(3)** R5 = 10k: I_5 = 4 / 16k = **0.25 mA**, V_AB = 0.25mA × 10k = **2.5 V**. (V_th, R_th는 그대로, 나눗셈 한 번)

**(4) 검산 ① 단락 전류법:** A–B 단락 시 한 노드 전압 V: (V−12)/3k + V/6k + (V−12)/12k + V/6k = 0 → V = 20/3 V.
I_sc = (12−V)/3k − V/6k = 1.778 − 1.111 = 0.667 mA → R_th = V_th/I_sc = 4/0.667m = 6 kΩ ✔.

**검산 ② 노드 해석(R5=2k):**
- A: 2V_A − V_B = 8
- B: −2V_A + 3V_B = 4
→ V_B = 6 V, V_A = 7 V → V_AB = **1 V** ✔, I = 1V/2k = 0.5 mA ✔.

**교육 포인트:** 노드 해석은 R5 값이 바뀔 때마다 2×2 연립을 다시 풀어야 하지만(R5=10k이면 계수가 바뀜), 테브닌은 (V_th, R_th)를 한 번 구하면 R5별 답이 분수 한 줄. 또한 V_A, V_B가 무부하 8 V/4 V에서 R5 연결 후 7 V/6 V로 이동한다는 "부하 효과"도 확인할 수 있다.

## 🔴 문제 3 해설

**(1) 입력저항 (뒤에서 앞으로)**
- R_in(C) = Rc1 + Rc2 = 6k + 6k = **12 kΩ** (무부하)
- Rb2 ‖ R_in(C) = 12k‖12k = 6k
- **R_in(B) = Rb1 + 6k = 9k + 6k = 15 kΩ**

**(2) R_out(B)** (노드 2에서 전원 쪽):
R_out(B) = [(Ra1‖Ra2) + Rb1] ‖ Rb2 = [(6k‖6k) + 9k] ‖ 12k = 12k‖12k = **6 kΩ**

**(3) 테브닌 단계 적용** (앞→뒤)

| 단 | 직렬 합 (이전 R_th + 직렬 R) | 병렬(분압) 저항 | V_th | R_th |
|---|---|---|---|---|
| A | Ra1 = 6k | Ra2 = 6k | 48·6/12 = **24 V** | 6k‖6k = **3 kΩ** |
| B | 3k + 9k = 12k | Rb2 = 12k | 24·12/24 = **12 V** | 12k‖12k = **6 kΩ** |
| C | 6k + 6k = 12k | Rc2 = 6k | 12·6/18 = **4 V** | 12k‖6k = **4 kΩ** |

→ **V_out = 4 V** (무부하), 출력 R_th = 4 kΩ.

**검산 (뒤→앞, 각 노드 전압):**
- 노드 1: Ra2 ‖ R_in(B) = 6k‖15k = 30/7 k → V1 = 48·(30/7)/(6+30/7) = **20 V**
- 노드 2: V2 = V1 · 6k/(9k+6k) = 20·0.4 = **8 V**
- 노드 3: V3 = V2 · 6k/12k = **4 V** ✔ (두 방향 일치)

**(4) 순진한 값:** 무부하 분압비 A: 6/12 = 1/2, B: 12/(9+12) = 4/7, C: 6/12 = 1/2
V_naive = 48 × 1/2 × 4/7 × 1/2 = 48/7 ≈ **6.86 V**
오차 = 6.86 − 4 = **+2.86 V** (정확한 값 대비 약 **71 % 과대**). 부하 효과(뒤 단이 앞 단 분압기와 병렬로 붙어 전압을 끌어내림)를 무시한 결과.

**(5) 보너스 (R_L = 4k):** 출력 테브닌 (4 V, 4 kΩ)에 부하 연결:
V_out = 4 · 4k/(4k+4k) = **2 V**.
검산(뒤→앞): 뒤→앞으로 계산하면 Rc2‖R_L = 2.4k, R_in(C) = 8.4k, 노드 전압 V1 = 19.75 V, V2 = 7 V, V3 = 7·2.4/8.4 = **2 V** ✔ (테브닌 결과와 일치).
