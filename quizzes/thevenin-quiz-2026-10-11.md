# ⚡ 테브닌·분압·중첩 회로 퀴즈 (2026-10-11)

> 공통 주제: 전압원과 저항이 얽혀 복잡해 보이지만, **중첩의 원리 · 분압 법칙 · 테브닌 정리**로 연립방정식 없이 풀리는 회로.
> 단위: V, kΩ, mA (kΩ × mA = V)

---

## 문제 1 (초급) — 전압원 2개 단일 루프

전압원 두 개가 서로 **반대 방향**으로 연결된 단일 루프입니다. 접지는 없고, 점 P의 전위가 **V_P = +4 V**로 주어져 있습니다.

```
   P ●──────[ R1 = 4kΩ ]──────● Q
     │      I ──────►          │
    (+)                       (+)      E1, E2 모두 + 단자가 위쪽
   E1 = 18V                  E2 = 6V
    (−)                       (−)
     │      ◄────── I          │
   G ●──────[ R2 = 2kΩ ]──────● S

   V_P = +4 V (주어짐, 접지 기호 없음)
   전류 I 는 시계 방향(P→R1→Q→E2→S→R2→G→E1→P)을 +로 정의
```

**(a)** 루프 전류 I 를 구하시오.
**(b)** 점 Q, S, G 의 전위 V_Q, V_S, V_G 를 구하시오. (KVL 로 전위를 따라가는 방법)
**(c)** 중첩의 원리로 I 를 다시 구하여 (a)와 일치하는지 확인하시오.

🔑 **핵심 개념: KVL 전위 추적 + 중첩의 원리.** 전위는 "기준점에서 출발해 소자를 지날 때마다 +전압원은 올라가고, 전류 방향 저항은 IR 만큼 내려간다"로 따라가면 접지가 없어도 한 점의 전위만 알면 모두 결정됩니다. 중첩은 이 선형 회로에서 전원 1개씩만 살리고(다른 전압원은 단락) 구한 전류를 더하는 것으로, 여기서는 E1 이 만드는 전류와 E2 가 만드는 (반대 방향) 전류의 합이 I 입니다.

## 문제 2 (중급) — 불평형 브리지와 테브닌 정리

12 V 전압원에 분압기 두 갈래(왼쪽 6k/3k, 오른쪽 3k/6k)가 연결되고, 중간 노드 A–B 사이를 R5 가 잇습니다.

```
              +12V (전압원 Vs, + 위)
        ┌──────────┴──────────┐
        │                     │
      R1=6kΩ                R3=3kΩ
        │                     │
        A o──────/\/\/\───────o B        전류 I5 : B → A 방향을 +로 정의
        │        R5=6kΩ       │          V_AB = V_A − V_B
      R2=3kΩ                R4=6kΩ
        │                     │
        └──────────┬──────────┘
                  GND (0V)
```

**(a)** R5 를 떼어 낸 A–B 양단에서 본 테브닌 등가 V_th(= V_B − V_A), R_th 를 구하시오.
**(b)** R5 = 6 kΩ 일 때 R5 에 흐르는 전류 I5 (B→A)와 V_AB 를 구하시오.
**(c)** R5 를 **12 kΩ** 으로 바꾸면 I5 는? 이 계산이 노드/메시 해석에 비해 얼마나 간단한지 설명하시오.

🔑 **핵심 개념: 테브닌 정리 (+ 분압 법칙).** 분압 법칙으로 개방전압 V_A = 12·3/9 = 4 V, V_B = 12·6/9 = 8 V 를 즉시 얻고, 전압원을 단락하면 R_th = (6‖3) + (3‖6) 로 두 분압기가 직렬이 됩니다. 브리지 저항 R5 는 단순히 "부하"가 되므로 (V_th, R_th) 한 번의 계산으로 R5 를 바꿔도 I = V_th/(R_th+R5) 한 줄로 끝납니다.

## 문제 3 (고급) — 3단 분압기의 부하 효과

각 단이 "직렬 저항 + 접지로 가는 병렬 저항"인 분압기 3단(A→B→C)을 직렬로 연결했습니다. V_in = 42 V.

```
 Vin=42V(+)   Ra1=8kΩ    node1     Rb1=2kΩ    node2     Rc1=4kΩ     Vout
  o────────/\/\/\/────●────/\/\/\/────●────/\/\/\/────●────o
  │                    │                │                │      (┌─ RL = 4kΩ, 보너스 문제에서만 연결)
 (−)                 Ra2=8kΩ         Rb2=12kΩ        Rc2=8kΩ
  │                    │                │                │
 GND ──────────────────┴────────────────┴────────────────┴─── GND

   [   A단   ]        [      B단      ]        [      C단      ]
   (Ra1,Ra2)           (Rb1,Rb2)               (Rc1,Rc2)
```

**(a)** C단의 입력저항 R_in(C), 그리고 뒤 단 부하를 모두 포함한 **B단의 입력저항 R_in(B)** (node1 에서 오른쪽을 본 저항)을 구하시오.
**(b)** A단, B단의 테브닌 등가 (V_th, R_th)를 단계별로 구하고, **B단 출력(node2)에서 본 R_out** 을 쓰시오.
**(c)** 테브닌 등가를 C단까지 적용해 **정확한 V_out** 을 구하시오.
**(d)** 부하 효과를 무시하고 각 단의 무부하 분압비(Ra2/(Ra1+Ra2), Rb2/(Rb1+Rb2), Rc2/(Rc1+Rc2))만 곱한 **순진한 값**과 비교하여 오차(V, %)를 구하시오.
**(e) 보너스:** 출력에 R_L = 4 kΩ 을 달았을 때의 V_out 은?

🔑 **핵심 개념: 단계별 테브닌 등가 + 부하 효과.** 앞 단 전체를 (V_th, R_th) 전원 하나로 바꿔 "다음 단의 입력 전원"으로 쓰면 3단 회로가 3번의 분압 계산으로 줄어듭니다. 뒤 단은 앞 단에 R_in 이라는 부하로 걸리므로 분압비가 무부하 값과 달라지고, 이를 무시한 순진한 곱셈이 크게 틀리는 이유가 곧 이 "부하 효과"입니다.

# 📘 정답 및 해설 (교수용)

## 문제 1 해설

**정답:** (a) I = 2 mA (b) V_Q = −4 V, V_S = −10 V, V_G = −14 V (c) 3 mA + (−1 mA) = 2 mA

**방법 1 – KVL (전위 추적):** 두 전원이 반대 방향이므로 순기전력 = 18 − 6 = 12 V, 총저항 = 4 + 2 = 6 kΩ.
I = 12 V / 6 kΩ = **2 mA** (시계 방향, E1 이 이김).
- P → R1 (전류 방향, 강하): V_Q = 4 − (2mA)(4k) = 4 − 8 = **−4 V**
- Q → E2 (+가 Q쪽이므로 S가 6V 낮음): V_S = −4 − 6 = **−10 V**
- S → R2 (강하): V_G = −10 − (2mA)(2k) = **−14 V**
- 검산: G → E1 (+ 상승 18V) : −14 + 18 = 4 V = V_P ✓ (루프가 닫힘)

**방법 2 – 중첩의 원리:**
- E1 만 (E2 단락): I₁ = 18/6 = +3 mA
- E2 만 (E1 단락): I₂ = −6/6 = −1 mA (E2 는 반시계 방향으로 밀어냄)
- I = I₁ + I₂ = **2 mA** ✓ → V_Q = 4 − 4·2 = −4 V 로 방법 1과 일치.

**교수 포인트:** 전위가 음수가 되어도 당황하지 않게 하기(접지가 없고 P만 기준). "P→Q 전위차 = IR1 = 8V"는 전원 개수와 무관하게 전류만 알면 나온다는 점을 강조.

## 문제 2 해설

**정답:** (a) V_th = +4 V (B가 높음), R_th = 4 kΩ (b) I5 = 0.4 mA (B→A), V_AB = −2.4 V (c) I5 = 0.25 mA

**(a)** R5 개방: V_A = 12·3/(6+3) = 4 V, V_B = 12·6/(3+6) = 8 V → V_th = V_B − V_A = **4 V**.
전압원 단락 시 A에서 접지 방향 6‖3 = 2 kΩ, B에서 접지 방향 3‖6 = 2 kΩ, 두 개가 접지를 통해 직렬 → R_th = **4 kΩ**.

**(b)** I5 = V_th/(R_th + R5) = 4/(4+6) = **0.4 mA** (B→A). V_R5 = 0.4·6 = 2.4 V → **V_AB = −2.4 V** (실제 V_A = 4.8 V, V_B = 7.2 V).

**(c)** R5 = 12k: I5 = 4/(4+12) = **0.25 mA**, V_R5 = 3 V (V_A = 4.5 V, V_B = 7.5 V).

**검산 1 (노드 해석):** 노드 A: (V_A−12)/6 + V_A/3 + (V_A−V_B)/6 = 0, 노드 B: (V_B−12)/3 + V_B/6 + (V_B−V_A)/6 = 0 → V_A = 4.8, V_B = 7.2 → I5 = 2.4/6 = 0.4 mA ✓.
**검산 2 (V_th / I_sc):** R5 를 단락하면 A=B=V 이므로 노드 방정식 (12−V)/6 + (12−V)/3 = V/3 + V/6 → V = 6 V. R5 단락선에 흐르는 전류는 I_sc = (12−V)/3 − (12−V)/6 = 2 − 1 = **1 mA** (B→A). 따라서 R_th = V_th / I_sc = 4 V / 1 mA = **4 kΩ** ✓.

**(c)의 교육 포인트:** 노드/메시 해석은 R5 가 바뀔 때마다 2원 연립을 새로 풀어야 하지만, 테브닌은 (V_th, R_th)=(4V, 4k)를 한 번만 구하면 이후 임의의 R5 에 대해 분수 한 줄로 끝남. R5=0 → 1 mA(I_sc), R5=∞ → 0 mA(개방 4 V) 극한도 해석 가능.

## 문제 3 해설

**정답:**

| 항목 | 값 |
|---|---|
| R_in(C) | 12 kΩ |
| R_in(B) | 8 kΩ |
| A단 테브닌 | 21 V / 4 kΩ |
| B단 테브닌 (= R_out) | 14 V / 4 kΩ |
| C단 테브닌 | 7 V / 4 kΩ |
| 정확한 V_out | **7 V** |
| 순진한 값 | 12 V (오차 +5 V, 정확값 대비 +71 %) |
| R_L=4k 연결 시 | 3.5 V |

**(a)** R_in(C) = Rc1 + Rc2 = 4 + 8 = **12 kΩ**. node2 에서 접지까지 Rb2‖R_in(C) = 12‖12 = 6 kΩ → R_in(B) = Rb1 + 6 = **8 kΩ**.

**(b)** 단계별 테브닌:
- A단: V_th,A = 42·8/(8+8) = **21 V**, R_th,A = 8‖8 = **4 kΩ**
- B단: (21V, 4k) 뒤에 Rb1 직렬 → 총 직렬 6k, 병렬 Rb2 = 12k: V_th,B = 21·12/(6+12) = **14 V**, R_th,B = (4+2)‖12 = **4 kΩ** → **R_out(B) = 4 kΩ**
- C단: (14V, 4k)+Rc1 → 직렬 8k, 병렬 Rc2 = 8k: V_th,C = 14·8/(8+8) = **7 V**, R_th,C = 8‖8 = **4 kΩ**

**(c)** 무부하 출력의 테브닌 등가가 곧 출력이므로 **V_out = 7 V**.

**(d)** 순진한 값: 42 × ½ × (12/14) × (8/12) = 42 × 2/7 = **12 V**. 오차 = 12 − 7 = **+5 V (+71.4 %)**. B·A단이 뒤 단 R_in 에 의해 로딩되어 실제 분압비가 작아지기 때문.

**(e)** 부하 R_L = 4k: V = 7·4/(4+4) = **3.5 V** (R_L = R_th 이므로 정확히 절반 — 최대 전력전달 조건도 언급 가능).

**검산 1 (뒤에서 앞으로, 부하 포함 노드 전압):** 전체 입력저항 = Ra1 + Ra2‖R_in(B) = 8 + 8‖8 = 12 kΩ, 전류 3.5 mA → V1 = 42 − 28 = 14 V. 이후 V2 = 14·6/(2+6) = 10.5 V, V_out = 10.5·8/(4+8) = **7 V** ✓.
**검산 2 (노드 해석 3원 연립):** 정확히 풀면 (V1, V2, V_out) = (14, 10.5, 7) V; R_L=4k 연결 시 (77/6, 35/4, 7/2) V ✓. (Python 분수 연산으로 확인)
