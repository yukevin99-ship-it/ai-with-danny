# 테브닌·분압·중첩 회로 퀴즈 (2026-10-27)

> 공통 주제: 복잡해 보이지만 **테브닌 정리 · 분압 법칙 · 중첩의 원리**로 간단히 풀리는 회로
> 단위: V, kΩ, mA (kΩ × mA = V)

---

## 문제 1 (초급) — 두 전원이 마주 보는 단일 루프

전압원 2개와 저항 2개로 된 한 개의 루프이다. 점 P는 기준 설정으로 **V_P = +2 V**이다. (접지는 루프 밖 어딘가에 있고, 우리는 P의 전위만 안다.)

```
          Q (TR)      R1 = 3kΩ      TL
          o─────────/\/\/\/\─────────o
          │   →I(시계방향 가정)       │
        ┌─┴─┐                       ┌─┴─┐
  V2=4V │ + │ (+ 위)        (+ 위)  │ + │ V1 = 10V
        │ - │                       │ - │
        └─┬─┘                       └─┬─┘
          │                           │
          o─────────/\/\/\/\─────────o
         BR         R2 = 2kΩ         BL = P  (V_P = 2V)
```

(전원 극성: V1, V2 모두 **+ 단자가 위쪽**. 전류 I는 시계방향을 양(+)으로 가정.)

1. 루프 전류 I의 크기와 실제 방향은?
2. 점 Q(= V2의 + 단자, 오른쪽 위)의 전위 V_Q는?
3. 같은 값을 **중첩의 원리**로 다시 구하라.

🔑 **핵심 개념:** *KVL + 중첩의 원리* — 한 점의 전위만 주어지면 "그 점에서 출발해 소자의 전압 상승/강하를 차례로 더하며 이동"하면 된다(P에서 V1을 올라 +10, R1에서 I·R1 강하, 또는 반대편 경로로 R2 강하+V2 상승). 선형 회로이므로 전원을 하나씩 켜고(다른 전압원은 단락) 각각이 P 기준 Q에 만드는 전위 차를 더해도 같은 결과가 나온다.

## 문제 2 (중급) — 불평형 브리지와 테브닌 정리

10 V 전압원에 분압기 두 갈래가 병렬로 붙어 있고, 두 중간 노드 A, B 사이를 브리지 저항 R5가 잇는다.

```
              +10V
        ┌───────o───────┐
        │               │
      R1=4kΩ          R3=3kΩ
        │               │
        o A             o B
        │   ←─ I(R5) ──│     (B→A 방향을 양으로 가정)
        ├──── R5=5.5kΩ ─┤
        │               │
      R2=6kΩ          R4=7kΩ
        │               │
        └───────o───────┘
               GND (0V)
```

1. R5를 떼어낸 개방 상태에서 V_A, V_B와 **V_th = V_A − V_B**는?
2. R5를 단락(전원 제거) 후 A–B에서 본 **R_th**는?
3. R5 = 5.5 kΩ일 때 R5에 흐르는 전류 I와 전압 V_AB는?
4. R5를 **0.5 kΩ**과 **15.5 kΩ**으로 바꿨을 때 전류는? (테브닌 등가를 다시 쓰면 몇 줄로 끝나는가?)

🔑 **핵심 개념:** *테브닌 정리 + 분압 법칙* — R5를 부하로 보고 나머지 회로를 (V_th, R_th)로 바꾼다. V_A, V_B는 각각 분압기 공식 하나씩으로 구하고, R_th는 전압원을 단락하면 R1∥R2와 R3∥R4가 **직렬**로 보이는 것을 이용한다. 노드해석은 연립식 2개를 R5가 바뀔 때마다 새로 풀어야 하지만, 테브닌은 한 번 구한 (V_th, R_th)에 I = V_th/(R_th+R5)만 갈아 끼우면 된다.

## 문제 3 (고급) — 3단 분압기의 부하 효과

Vin = 36 V에 분압기 3단(A→B→C)이 직렬로 이어져 있다. 각 단은 (직렬 저항 / 접지로 가는 병렬 저항) 구조이다.

```
 Vin=36V   R1=3k      N1     R3=4k     N2     R5=8k     N3 (V_out)
   o──────/\/\/\──────o─────/\/\/\──────o─────/\/\/\──────o────o  V_out
 (+)                   │                │                 │
                     R2=6k            R4=12k             R6=4k      [R_L(보너스)]
                       │                │                 │
 GND ──────────────────┴────────────────┴─────────────────┴──────── GND
        └──── A단 ────┘└───── B단 ──────┘└───── C단 ─────┘
```

1. A, B, C단까지 **단계별 테브닌 등가**(V_th, R_th)를 구하라. (앞 단 등가의 R_th를 다음 단의 직렬 저항에 더해 이어 간다.)
2. **B단의 입력저항 R_in(B)** — B단의 직렬저항 R3 왼쪽에서 오른쪽을 본 값(뒤 단 C 포함)은?
3. **B단 출력(N2)에서 본 R_out**은?
4. 정확한 **V_out**은? 
5. 부하 효과를 무시하고 각 단의 분압비(R2/(R1+R2) 등)만 곱한 **순진한 값**과 오차는?
6. (보너스) 출력에 R_L = 6 kΩ을 달았을 때의 V_out은?

🔑 **핵심 개념:** *테브닌 정리의 연쇄 적용 + 부하 효과* — 앞 단 전체를 (V_th, R_th) 하나로 줄이면, 다음 단은 "내부저항이 R_th인 전원 + 직렬 R + 병렬 R"로 보여 **한 번의 분압식**으로 끝난다. 뒤 단이 앞 단의 병렬 저항에 **병렬로 붙어** 분압비를 바꾸기 때문에(B단의 4 kΩ 아래 12 kΩ이 C단 12 kΩ과 병렬이 됨), 단순 분압비 곱은 틀린다. 이것이 R_in 개념이다.

# 📘 정답 및 해설 (교수용)

## 문제 1 해설

**답:** I = 1.2 mA (시계방향, V1 쪽이 이김), **V_Q = 8.4 V**

**풀이 ① KVL(전위 따라가기)**
- 루프: V1이 위로 10 V, V2가 반대로 4 V → 알짜 6 V가 R1+R2 = 5 kΩ에 걸림.
- I = (10 − 4)/(3+2) = **1.2 mA**, 시계방향.
- V_BL = 2 V → V_TL = 2 + 10 = 12 V → R1 강하 1.2 mA×3 kΩ = 3.6 V → **V_Q = V_TR = 12 − 3.6 = 8.4 V**.
- 반대 경로로 검산: 아래쪽 R2에서 전류는 BR→BL로 흐르므로 V_BR = 2 + 1.2×2 = 4.4 V, V2 상승 +4 → V_TR = **8.4 V** ✓

**풀이 ② 중첩의 원리 (P=BL 기준, 기준값 2 V 더함)**
- V1만 (V2 단락): I = 10/5 = 2 mA 시계방향. BR에서 R2 강하: V_BR − V_BL = 2×2 = 4 V, V2 단락이므로 V_TR = V_BR → **+4 V**
- V2만 (V1 단락): I = 4/5 = 0.8 mA 반시계방향. V_TR − V_TL = 0.8×3 = 2.4 V, TL = BL(V1 단락) → **+2.4 V**
- V_Q = 2 + 4 + 2.4 = **8.4 V** ✓ (두 방법 일치)

## 문제 2 해설

**답:** V_A = 6 V, V_B = 7 V → **V_th = −1 V**, **R_th = 4.5 kΩ**, I(B→A) = **0.1 mA**, V_AB = **−0.55 V**

**풀이 ① 테브닌**
- V_A = 10×6/(4+6) = 6 V, V_B = 10×7/(3+7) = 7 V → V_th(A−B) = −1 V (B가 더 높음).
- R_th = (4∥6) + (3∥7) = 2.4 + 2.1 = **4.5 kΩ**.
- I = |V_th|/(R_th + R5) = 1/(4.5+5.5) = **0.1 mA**, B→A 방향. V_AB = −0.1×5.5 = **−0.55 V**.

**풀이 ② 검산 — 단락전류 방식**
- A–B를 단락(A=B=V)하면 (10−V)(1/4+1/3) = V(1/6+1/7) → V = 6.533 V. KCL: B→A 단락전류 I_sc = V/6... 정리하면 (10−V)/3 − V/7 = 0.2222 mA (B→A).
- 테브닌 예측: I_sc = |V_th|/R_th = 1/4.5 = **0.2222 mA** ✓ 일치
- (Python 정확 계산: 노드해석 결과 V_A = 6.24 V, V_B = 6.79 V → V_AB = −0.55 V, I = 0.1 mA ✓)

**추가 질문**
- R5 = 0.5 kΩ → I = 1/(4.5+0.5) = **0.2 mA**
- R5 = 15.5 kΩ → I = 1/(4.5+15.5) = **0.05 mA**
- 노드해석은 R5가 바뀔 때마다 2×2 연립식을 다시 푸는 반면, 테브닌은 나눗셈 한 번이다.

## 문제 3 해설

**답:** R_in(B) = **10 kΩ**, R_out(B) = **4 kΩ**, **V_out = 4 V** (순진한 값 6 V, 오차 +2 V = 정답의 50 %), R_L=6 kΩ → **8/3 ≈ 2.67 V**

**① 단계별 테브닌**
- A단: Vin=36 V, 직렬 3k, 병렬 6k → V_th = 36×6/9 = **24 V**, R_th = 3∥6 = **2 kΩ**
- B단: 직렬 = 2+4 = 6k, 병렬 12k → V_th = 24×12/18 = **16 V**, R_th = 6∥12 = **4 kΩ**
- C단: 직렬 = 4+8 = 12k, 병렬 4k → V_th = 16×4/16 = **4 V**, R_th = 12∥4 = **3 kΩ**

**② R_in(B)** = R3 + [R4 ∥ (R5+R6)] = 4 + [12 ∥ 12] = 4 + 6 = **10 kΩ**

**③ R_out(B)** (Vin 단락) = R4 ∥ (R3 + R_th_A) = 12 ∥ (4+2) = **4 kΩ** (= B단 테브닌 R_th)

**④ V_out = 4 V** (위 C단 테브닌 결과, 개방 출력). 

**⑤ 순진한 값:** 각 단 분압비 R_병렬/(R_직렬+R_병렬) = 6/9, 12/16, 4/12 → 36 × (2/3) × (3/4) × (1/3) = **6 V**. 오차 = 6 − 4 = 2 V (+50 %). 원인: 각 분압비는 "뒤 단이 없을 때"의 값이다.

**⑥ 보너스:** V_out = 4 × 6/(3+6) = **8/3 ≈ 2.667 V**

**검산 (노드해석, Python 분수 계산):** 부하 없음 → N1 = 20 V, N2 = 12 V, N3 = **4 V** ✓. R_L=6k 추가 → N3 = **8/3 V** ✓. N1 교차검산: 6∥R_in(B)=6∥10=3.75 kΩ → N1 = 36×3.75/(3+3.75) = 20 V ✓.
