# 테브닌 정리 · 분압 · 중첩 회로 퀴즈 (2026-10-28)

> 공통 주제: 직렬·병렬이 얽혀 복잡해 보이지만, **테브닌 정리 / 분압 법칙 / 중첩의 원리**로 간단히 풀리는 회로.
> 단위: V, kΩ, mA (kΩ × mA = V)

---

## 🟢 문제 1 (초급) — 두 전압원이 있는 단일 루프

```
              P          R1=2kΩ         Q
     +--------o-------/\/\/\/\-------o--------+
     |                                         |
    (+)  E1 = 20V                          (+) | E2 = 8V
     |   (위가 +)                           |  | (위 Q쪽이 +)
    (−)                                    (−)
     |                                         |
     +--------o-------/\/\/\/\-------o--------+
              T          R2=6kΩ         S

  전류 I: 시계방향 가정 (P→Q→S→T→P),  V_P = +5V 로 주어짐
```

**문제.** 위 루프에서 점 P의 전위가 V_P = 5V일 때,
1. 루프 전류 I의 크기와 방향을 구하시오.
2. 점 Q의 전위 V_Q를 **KVL 전위 추적법**으로 구하시오.
3. 같은 V_Q를 **중첩의 원리**(E1만, E2만)로 다시 구하여 확인하시오.

🔑 **핵심 개념:** 중첩의 원리 — 전원이 둘이어도 "한 전원만 살리고 나머지 전압원은 단락(0V)"하면 각각 단순 분압/옴의 법칙 문제가 되고, R1 양단 전압 V_Q−V_P는 두 기여분(E1: −5V, E2: +2V)의 대수합(−3V)으로 얻어진다. 전위가 0이 아닌 P에서 출발해도 "전위차는 선형 합산, 절대값은 기준점에서 더한다"는 점이 적용된다.

## 🟡 문제 2 (중급) — 불평형 브리지와 테브닌 정리

```
                 +12V (Vs)
          +--------+--------+
          |                 |
        R1=6kΩ           R3=12kΩ
          |                 |
          A--------R5-------B      R5 = 3kΩ, 전류 I5: A → B
          |      (3kΩ)      |
        R2=12kΩ           R4=4kΩ
          |                 |
          +--------+--------+
                  GND (0V)
```

**문제.**
1. R5를 떼어낸 상태에서 A, B 양단의 테브닌 등가 V_th(=V_A−V_B)와 R_th를 구하시오.
2. R5 = 3kΩ일 때 R5에 흐르는 전류 I5와 V_AB를 구하시오.
3. R5를 **13kΩ**으로 바꾸면 I5와 V_AB는? (노드/메시 해석을 다시 하지 않고 구하시오.)
4. (검산) A-B를 단락했을 때의 단락전류 I_sc로 R_th를 확인하시오.

🔑 **핵심 개념:** 테브닌 정리 — 브리지 저항 R5만 "부하"로 보고 나머지(분압기 두 갈래)를 하나의 (V_th, R_th)로 압축한다. 각 갈래는 분압 법칙으로 V_A, V_B를, 전원을 단락했을 때 병렬 조합으로 R_A, R_B를 구하면 끝이므로, R5가 바뀌어도 I = V_th/(R_th+R5) 한 줄로 해결된다 (노드해석은 R5마다 2원 연립을 새로 풀어야 함).

## 🔴 문제 3 (고급) — 3단 분압기의 부하 효과

```
 Vin=48V
   (+)--[Ra1=8kΩ]--(N1)--[Rb1=4kΩ]--(N2)--[Rc1=4kΩ]--(N3 = Vout)
                     |                 |                 |
                  [Ra2=8kΩ]        [Rb2=8kΩ]         [Rc2=8kΩ]   (+ 보너스: RL=4kΩ 병렬)
                     |                 |                 |
   (−)---------------+-----------------+-----------------+--- GND
         단 A              단 B              단 C
```

**문제.**
1. 단 B의 입력저항 R_in(B) (N1에서 오른쪽을 본 저항, 뒤 단 C 포함)을 구하시오.
2. 단 B 출력(N2)에서 본 테브닌 등가 (V_th,B, R_out,B)를 구하시오.
3. 테브닌 등가를 A → B → C 순서로 단계 적용하여 **정확한 V_out**을 구하시오.
4. 부하 효과를 무시하고 각 단의 분압비만 곱한 **순진한 값**을 구하고 정확한 값과의 오차를 구하시오.
5. (보너스) 출력에 RL = 4kΩ을 연결했을 때의 V_out은?

🔑 **핵심 개념:** 단계별 테브닌 — 앞 단을 (V, R) 등가원으로 바꾼 뒤 다음 단의 직렬저항에 R을 "합쳐" 다시 분압하면 부하 효과(뒤 단이 앞 단 분압비를 끌어내림)가 자동으로 반영된다. 단 하나의 식 V' = V·R2/(R_th+R1+R2), R' = (R_th+R1)∥R2를 반복할 뿐이라 연립방정식이 필요 없고, 단순 분압비 곱과의 차이가 곧 부하 효과의 크기다.

# 📘 정답 및 해설 (교수용)

## 문제 1 해설

**답: I = 1.5 mA (시계방향), V_Q = 2 V**

**① KVL 전위 추적** (T→E1→P→R1→Q→E2→S→R2→T)
- 루프 방정식: +20 − 8 = I(2k+6k) → I = 12/8 = **1.5 mA** (양수 = 가정한 시계방향)
- V_R1 = 1.5 × 2 = 3V, 전류가 P→Q 방향이므로 V_Q = V_P − 3 = 5 − 3 = **2 V**
- 검산 경로: V_T = V_P − 20 = −15V, R2 전류 S→T이므로 V_S = V_T + 1.5×6 = −6V, E2의 +가 Q이므로 V_Q = V_S + 8 = **2V** ✓

**② 중첩**
- E1만(E2 단락): I₁ = 20/8 = 2.5mA 시계방향 → R1에서 P→Q 쪽으로 V_Q−V_P 기여 = −2.5×2 = −5V
- E2만(E1 단락): I₂ = 8/8 = 1mA 반시계방향 → R1에서 Q→P 쪽 전류이므로 V_Q−V_P 기여 = +1×2 = +2V
- 합: V_Q − V_P = −5 + 2 = −3V → V_Q = 5 − 3 = **2V** ✓ (전류도 2.5 − 1 = 1.5mA)

## 문제 2 해설

**답: V_th = 5V, R_th = 7kΩ, I5(3k) = 0.5mA (V_AB=1.5V), I5(13k) = 0.25mA (V_AB=3.25V), I_sc = 5/7 mA**

- V_A = 12 × 12/(6+12) = **8V**, V_B = 12 × 4/(12+4) = **3V** → V_th = 8 − 3 = **5V**
- R_th (전원 단락): R_A = 6∥12 = 4kΩ, R_B = 12∥4 = 3kΩ → R_th = 4 + 3 = **7kΩ**
- R5 = 3k: I5 = 5/(7+3) = **0.5mA**, V_AB = 0.5 × 3 = **1.5V**
- R5 = 13k: I5 = 5/(7+13) = **0.25mA**, V_AB = 0.25 × 13 = **3.25V** (테브닌 식에 R5만 바꿔 대입)
- **검산 1 (I_sc):** A-B 단락 시 공통 노드 전압 x: (12−x)/6 + (12−x)/12 = x/12 + x/4 → x = 36/7 V. A로 들어오는 전류 = (12−x)/6 − x/12 = 8/7 − 3/7 = 5/7 mA. R_th = V_th/I_sc = 5/(5/7) = **7kΩ** ✓
- **검산 2 (노드 해석):** R5=3k에서 V_A=6, V_B=9/2 → V_AB = 1.5V, I5 = 0.5mA ✓; R5=13k에서 V_A=7, V_B=15/4 → V_AB=3.25V ✓
- **교육 포인트:** 노드해석은 R5가 바뀔 때마다 2×2 연립을 다시 풀지만, 테브닌은 (5V, 7kΩ)을 한 번 구하면 이후 한 줄 계산. (추가: R5 = R_th = 7kΩ이면 최대전력 전달, P = (5/14)²·7k ≈ 0.89mW)

## 문제 3 해설

**답: R_in(B) = 8.8kΩ, B단 출력 등가 12V/4kΩ, V_out = 6V, 순진한 값 10.67V(오차 4.67V), RL=4k 시 3V**

- **R_in(B)** = Rb1 + Rb2∥(Rc1+Rc2) = 4 + 8∥12 = 4 + 4.8 = **8.8kΩ**
- **단계별 테브닌**
  - 단 A: V = 48 × 8/16 = **24V**, R = 8∥8 = **4kΩ**
  - 단 B: (24V, 4k) + Rb1 4k → 직렬 8k, V = 24 × 8/(8+8) = **12V**, R_out,B = (4+4)∥8 = **4kΩ**
  - 단 C: (12V, 4k) + Rc1 4k → 직렬 8k, V = 12 × 8/(8+8) = **6V** = V_out, R_out = (4+4)∥8 = **4kΩ**
- **순진한 값:** 48 × (8/16) × (8/12) × (8/12) = **10.67V** → 부하 효과로 **4.67V 낮아짐** (순진한 값 대비 43.8% 과대평가, 정확한 값 대비 77.8%)
- **보너스 (RL=4k):** V = 6 × 4/(4+4) = **3V**, I_L = 0.75mA
- **검산 (노드 해석, Fraction 계산):** N1 = 16.5V, N2 = 9V, N3 = 6V ✓ (RL=4k: N1=15.75, N2=7.5, N3=3V ✓). 또한 N1에서 본 전류 (48−16.5)/8 = 3.94mA, R_in(B) 경유 16.5/8.8 ≈ 1.875mA + Ra2 전류 2.0625mA 합 ≈ 3.94mA ✓
- **교육 포인트:** 분압기를 단순히 이어 붙여 비를 곱하면 안 되고, 뒤 단이 앞 단의 부하(R_in)가 됨을 보인다.
