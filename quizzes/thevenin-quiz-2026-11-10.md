# 회로 퀴즈: 테브닌 · 분압 · 중첩 (2026-11-10)

> 주제: 직렬·병렬로 얽혀 복잡해 보이는 전압원-저항 회로를 **테브닌 정리, 분압 법칙, 중첩의 원리**로 간단히 푼다.
> 단위: V, kΩ, mA (kΩ × mA = V)

---

## 문제 1 (초급) — 두 전원이 마주 보는 단일 루프

전압원 2개와 저항 2개가 단일 루프를 이룹니다. 점 P의 전위는 **V_P = +3 V** 로 고정되어 있습니다(기준점 0 V는 회로 밖 어딘가).

```
        Q (N2)           R1 = 2kΩ          N3
        o-------------/\/\/\/\-------------o
        |    I = ? →                       |
      ──┴──  +                           ──┴──  +
  E1  ──┬──  15 V  (+ 위)           E2   ──┬──  3 V  (+ 위)
        |                                  |
        o-------------/\/\/\/\-------------o  P (N4)
       N1             R2 = 4kΩ            V_P = +3 V

   (루프 전류 I 는 시계방향: N2 → N3 → N4 → N1 → N2 로 가정)
```

**(1)** 루프 전류 I 를 구하시오.
**(2)** 점 Q의 전위 V_Q 를 **KVL(전위 따라가기)** 로 구하시오.
**(3)** 같은 V_Q 를 **중첩의 원리**로 다시 구하시오(P를 기준으로 한 전위차 V_QP 를 중첩으로 구한 뒤 V_P 를 더함).

🔑 **핵심 개념:** 단일 루프에서는 "전류는 하나"이므로 전류를 먼저 구한 뒤, 이미 아는 점(P)에서 출발해 소자를 지날 때마다 전원은 극성대로 ±E, 저항은 전류 방향이면 −IR 만큼 전위를 더해 가면 어떤 점의 전위든 구해진다. 중첩에서는 전원을 하나씩 살리고(나머지 전압원은 단락) 각각이 만드는 V_QP 를 더한다 — 전위는 기준(P)의 오프셋 3 V 만 더하면 되므로 "절대 전위 = 기준 전위 + 전위차"로 정리된다.

## 문제 2 (중급) — 불평형 브리지와 테브닌 정리

12 V 전원에 분압기 두 갈래가 붙어 있고, 중간 노드 A와 B 사이를 R5 가 잇습니다.

```
              +12 V (Vs)
       o───────────┬───────────────┐
                   │               │
                 R1=2kΩ          R3=6kΩ
                   │               │
          A  o─────┼──── R5 ──────┼─────o  B
                   │   (1.5kΩ) →  │
                   │      I_5      │
                 R2=6kΩ          R4=3kΩ
                   │               │
       o───────────┴───────────────┘
                  GND (0 V)

   I_5 : A → B 방향을 (+)로 정의,  V_AB = V_A − V_B
```

**(1)** R5 를 떼어 낸 뒤 A-B 사이의 테브닌 등가전압 V_th(= V_A − V_B, 개방)와 등가저항 R_th 를 구하시오.
**(2)** R5 = 1.5 kΩ 일 때 R5 에 흐르는 전류 I_5 와 R5 양단 전압 V_AB 를 구하시오.
**(3)** R5 를 **6.5 kΩ** 으로 바꾸면 I_5 와 V_AB 는? (회로를 다시 풀지 말고 (1)의 결과를 재사용할 것)
**(4)** 노드 해석으로 (2)를 풀 때 필요한 연립방정식 개수와 테브닌 방식의 계산량을 비교하시오.

🔑 **핵심 개념:** R5 를 "부하"로 보고 떼어 내면 남는 회로는 두 개의 독립된 분압기뿐이다. 분압 법칙으로 개방전압 V_A = 12·6/8 = 9 V, V_B = 12·3/9 = 4 V 를 구해 V_th = V_A − V_B 를 얻고, 전원을 단락(0 V)하면 R1∥R2 와 R3∥R4 가 직렬로 보여 R_th 가 된다. 이렇게 한 번 구한 (V_th, R_th)는 R5 가 어떤 값이든 재사용된다.

## 문제 3 (고급) — 3단 분압기의 부하 효과

입력 24 V 대신 **30 V** 를 3단 분압기에 인가합니다. 각 단은 "직렬 저항 + 접지로 가는 병렬(션트) 저항"입니다.

```
  Vin=30V      R1=6kΩ        N1        R3=4kΩ        N2        R5=2kΩ        N3 (V_out)
   o──────────/\/\/\/──────┬───────/\/\/\/──────┬───────/\/\/\/──────┬──────o
   (+)                     │                     │                     │
                         R2=12kΩ               R4=8kΩ                R6=6kΩ    [ R_L (보너스) ]
                           │                     │                     │          │
   o───────────────────────┴─────────────────────┴─────────────────────┴──────────┴──o
  GND(0V)
   └──────── A단 ─────────┘ └──────── B단 ─────────┘ └──────── C단 ─────────┘
   (A단: R1,R2 / B단: R3,R4 / C단: R5,R6)
```

**(1)** B단의 입력저항 R_in(B) — 노드 N1 에서 B단 쪽(R3 이후, **뒤 단 C 및 부하 포함**)을 본 저항.
**(2)** B단 출력(노드 N2)에서 앞쪽(전원 쪽)을 본 등가저항 R_out(B).
**(3)** 테브닌 등가를 A → B → C 순서로 **단계별** 적용하여 정확한 V_out 을 구하시오(각 단의 V_th, R_th 표를 작성).
**(4)** 부하 효과를 무시하고 각 단의 분압비만 곱한 "순진한 값"을 구하고, 정확한 값과의 오차(V, %)를 구하시오.
**(5)** (보너스) 출력에 R_L = 3 kΩ 을 달았을 때 V_out 은?

🔑 **핵심 개념:** 각 단을 "(전압원 V_th) + (직렬 R_th)" 로 바꾸면 다음 단은 "전원 한 개를 가진 분압기" 로 다시 보이므로 같은 분압식을 반복 적용할 수 있다(V_th,n+1 = V_th,n · R_shunt/(R_th,n + R_series + R_shunt), R_th,n+1 = (R_th,n + R_series)∥R_shunt). 분압비만 곱하는 순진한 계산은 뒤 단이 앞 단의 션트에 병렬로 걸려 분압비를 바꾸는 "부하 효과"를 무시하기 때문에 틀리다.

# 📘 정답 및 해설 (교수용)

## 문제 1 해설

**(1) 루프 전류.** E1(15 V)과 E2(3 V)가 루프에서 서로 반대 방향이므로 순기전력 = 15 − 3 = 12 V, 직렬저항 = 2 + 4 = 6 kΩ.
I = 12 V / 6 kΩ = **2 mA** (시계방향, 양수).

**(2) KVL 전위 따라가기** (P에서 출발, 시계방향 반대로 가도 되고 같은 방향으로 가도 됨). P(N4) → R2 → N1 → E1 → N2(=Q):
- N4 → N1: R2 를 전류 방향(N4→N1)으로 지나므로 −I·R2 = −2 × 4 = −8 V → V_N1 = 3 − 8 = −5 V
- N1 → N2: E1 의 − 에서 + 로 → +15 V → V_N2 = −5 + 15 = **10 V**

**검산(반대 경로).** P(N4) → E2 → N3 → R1 → N2: N4 → N3 는 E2 의 − 에서 + 로 +3 V → V_N3 = 6 V. N3 → N2 는 전류 반대 방향(전류는 N2→N3)이므로 +I·R1 = +4 V → V_N2 = **10 V** ✓.

**(3) 중첩 (P 를 기준, 즉 V_QP = V_Q − V_P).**
- E1 만 (E2 단락): I1 = 15/(2+4) = 2.5 mA. E2 가 단락이므로 N3 = N4 = P. Q − P = R1 양단 전압 = 2.5 × 2 = **+5 V**
- E2 만 (E1 단락): I2 = 3/6 = 0.5 mA. E2 의 + 단자(N3)에서 전류가 나와 N3 → R1 → N2 로 흐름. 따라서 V_N3 − V_N2 = 0.5 × 2 = 1 V 이므로 V_N2 = V_N3 − 1 이고, V_N3 = V_N4 + 3 이므로 V_QP = 3 − 1 = **+2 V**
- 합: V_QP = 5 + 2 = 7 V → V_Q = V_P + 7 = 3 + 7 = **10 V** ✓ (KVL 결과와 일치)

> 전류 확인: 2.5 − 0.5 = 2 mA ✓.

**지도 포인트:** 학생들이 흔히 (a) E2 의 극성 때문에 전류가 더해진다고 착각하거나, (b) 중첩에서 "전원 제거 = 단락" 대신 개방하는 실수를 한다. V_P=3 V 는 기준이 0 이 아님을 보여 주는 오프셋일 뿐이다.

## 문제 2 해설

**(1) 테브닌 등가 (R5 제거).**
- V_A = 12 × 6/(2+6) = **9 V**, V_B = 12 × 3/(6+3) = **4 V**
- V_th = V_A − V_B = **5 V** (A 가 +)
- R_th = (R1∥R2) + (R3∥R4) = (2·6/8) + (6·3/9) = 1.5 + 2 = **3.5 kΩ**

**(2) R5 = 1.5 kΩ.** I_5 = 5 / (3.5 + 1.5) = **1 mA** (A → B), V_AB = I_5 · R5 = **1.5 V**.

**검산 1 (노드 해석).** 노드 A, B 의 KCL:
(12−V_A)/2 = V_A/6 + (V_A−V_B)/1.5, (12−V_B)/6 = V_B/3 − (V_A−V_B)/1.5
→ V_A = 7.5 V, V_B = 6 V, V_AB = 1.5 V, I_5 = 1 mA ✓

**검산 2 (노턴, 단락전류).** A-B 단락 시 V_A = V_B = X: (12−X)/2 + (12−X)/6 = X/6 + X/3 → X = 48/7 V, I_sc = (12−X)/2 − X/6 = 10/7 mA. 이는 V_th/R_th = 5/3.5 = 10/7 mA 와 같다 ✓. 부하 전류 = I_sc · R_th/(R_th+R5) = (10/7)(3.5/5) = 1 mA ✓.

**(3) R5 = 6.5 kΩ.** I_5 = 5/(3.5+6.5) = **0.5 mA**, V_AB = 0.5 × 6.5 = **3.25 V**. (회로 재해석 없이 한 줄 계산. 참고: R5 → ∞ 이면 V_AB = V_th = 5 V.)

**(4) 계산량 비교.** 노드 해석은 미지수 V_A, V_B 의 **2원 연립방정식**(R5 값이 바뀔 때마다 다시 풀어야 함). 테브닌은 분압 2회 + 병렬 2회로 (V_th, R_th)를 **한 번만** 구하면 이후 어떤 R5 도 나눗셈 한 번이면 된다. 소자가 늘수록 이 차이가 커진다(부하 스윕, 최대전력 전달 문제 등).

> 최대 전력 전달(추가 토론용): R5 = R_th = 3.5 kΩ 에서 P_max = V_th²/(4R_th) = 25/14 ≈ 1.79 mW.

## 문제 3 해설

**단계별 테브닌 등가 (입력 30 V)**

| 단 | 계산 | V_th | R_th |
|---|---|---|---|
| A (노드 N1 기준, 개방) | V = 30·12/(6+12), R = 6∥12 | **20 V** | **4 kΩ** |
| B (A의 등가 + R3, R4) | 직렬 4+4 = 8 kΩ, V = 20·8/(8+8), R = 8∥8 | **10 V** | **4 kΩ** |
| C (B의 등가 + R5, R6) | 직렬 4+2 = 6 kΩ, V = 10·6/(6+6), R = 6∥6 | **5 V** | **3 kΩ** |

**(1) R_in(B)** = R3 + R4 ∥ (R5 + R6) = 4 + 8 ∥ 8 = 4 + 4 = **8 kΩ**.
(뒤 단 C 가 R4 와 병렬로 걸려 R4 단독 8 kΩ → 4 kΩ 으로 줄어든다. 참고: C단 자체 입력저항은 R5+R6 = 8 kΩ.)

**(2) R_out(B)** = Th_A 의 R_th 와 R3 를 직렬한 뒤 R4 와 병렬: (4+4) ∥ 8 = **4 kΩ**.

**(3) 정확한 V_out** = 단계 C 의 V_th = **5 V** (R_th,out = 3 kΩ).

**(4) 순진한 값** = 30 × (12/18) × (8/12) × (6/8) = 30 × 2/3 × 2/3 × 3/4 = **10 V**.
오차 = 10 − 5 = **5 V**, 정확한 값 대비 **+100 %** 과대(순진한 값이 정확한 값의 2배). 이는 단 사이 부하 효과(뒤 단이 앞 단의 션트에 병렬)를 무시했기 때문이다.

**검산 (노드 전압법, 3원 연립).** 노드 N1, N2, N3:
- (30−V1)/6 = V1/12 + (V1−V2)/4
- (V1−V2)/4 = V2/8 + (V2−V3)/2
- (V2−V3)/2 = V3/6
- 풀면 **V1 = 13.33 V, V2 = 6.67 V, V3 = 5 V** ✓ (V_out = 5 V 일치).
- 단계별 테브닌과의 정합: N1 에 B·C 를 연결한 부하 상태 V1 = 20·(R_in(B))/(4 + R_in(B)) = 20·8/12 = 13.33 V ✓ (R_in(B) = 8 kΩ 검증). N2 = 10·(2+6)/(4+8)… 즉 V2 = V_th,B · (R5+R6)/(R_th,B + R5 + R6) = 10·8/12 = 6.67 V ✓.

**(5) 보너스: R_L = 3 kΩ.** 출력 등가 (5 V, 3 kΩ)에 R_L = 3 kΩ 을 달면 V_out = 5 · 3/(3+3) = **2.5 V**. (노드 해석 V3 = 2.5 V ✓ — 최대 전력 전달 조건 R_L = R_th,out 에서 정확히 절반.)
