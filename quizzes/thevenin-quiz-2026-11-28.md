# ⚡ 회로 퀴즈: 복잡해 보여도 간단히 풀리는 회로 (2026-11-28)

> 공통 주제: 전압원과 저항이 직렬·병렬로 얽혀 복잡해 보이지만,
> **테브닌 정리 · 분압 법칙 · 중첩의 원리**를 쓰면 몇 줄 만에 풀리는 회로
>
> 단위 약속: 저항 kΩ, 전류 mA, 전압 V (kΩ × mA = V)

---

## 문제 1 (초급) — 단일 루프에서 전위 따라가기

```
          a       R1 = 2 kΩ        Q
          o────────/\/\/\──────────o
          │      I →  (시계 방향)  │
         (+)                      (+)
     V1 = 15 V                 V2 = 5 V
         (−)                      (−)
          │                        │
          o────────/\/\/\──────────o
          P   ←    R2 = 3 kΩ       b

   V1: + 극이 위쪽(a), − 극이 아래쪽(P)
   V2: + 극이 위쪽(Q), − 극이 아래쪽(b)
   기준 전류 방향 I: 시계 방향 (P → a → Q → b → P)
```

점 P의 전위는 **V_P = −4 V** 입니다 (접지 기준).

1. 루프 전류 I의 크기와 방향을 구하세요.
2. 점 Q의 전위 V_Q를 구하세요.
3. (확인) 점 b의 전위 V_b도 구하고, b를 거쳐 Q로 가는 경로로 V_Q를 다시 확인하세요.

🔑 **핵심 개념:** KVL — 두 전원이 서로 반대 방향으로 밀기 때문에 루프 전류는 전압 *차이* (15 − 5)V를 전체 저항 5 kΩ으로 나눈 값이 되고, 그 뒤에는 P에서 출발해 "전원을 지나면 +/− 만큼, 저항을 전류 방향으로 지나면 IR만큼 내려간다"는 규칙으로 전위를 한 칸씩 더해 Q에 도착합니다. 중첩으로 풀면 V_QP를 15 V 기여분과 5 V 기여분으로 나눠 각각 **분압 법칙** 한 줄로 끝낼 수 있습니다.

## 문제 2 (중급) — 불평형 브리지와 테브닌 정리

```
                    + Vs = 12 V
           ┌─────────────┬─────────────┐
           │             │             │
          (+)           R1 = 4 kΩ     R3 = 6 kΩ
          Vs             │             │
          (−)          A o──/\/\/\──o B
           │             │  R5 = 5 kΩ  │
           │             │   I5 →      │
           │            R2 = 12 kΩ    R4 = 3 kΩ
           │             │             │
           └─────────────┴─────────────┘
                        GND (0 V)

   Vs: + 극이 위쪽 레일, − 극이 GND
   I5: R5를 A → B 방향으로 흐르는 전류를 양(+)으로 정의
```

1. R5를 떼어 낸 상태에서 A-B 단자의 테브닌 등가 (V_th = V_AB,open, R_th)를 구하세요.
2. R5 = 5 kΩ일 때 R5의 전류 I5와 전압 V_AB를 구하세요.
3. R5를 **15 kΩ**으로 바꾸면 I5는 얼마입니까? 또 I5 = 0.2 mA가 되려면 R5는 얼마여야 합니까?
4. R5에 전달되는 전력이 최대가 되는 R5 값과 그때의 최대 전력은?

🔑 **핵심 개념:** 테브닌 정리 + 분압 법칙 — R5를 떼면 두 갈래는 서로 독립된 분압기라서 V_A = 12·12/16 = 9 V, V_B = 12·3/9 = 4 V를 **분압 법칙**으로 바로 얻고, 전원을 단락하면 R_th = (4‖12) + (6‖3) = 3 + 2 = 5 kΩ이 됩니다. 브리지 전체가 "5 V 전원 + 5 kΩ" 하나로 줄어들기 때문에, R5 값이 바뀌어도 I5 = 5/(5 + R5) 한 줄만 다시 계산하면 됩니다. 노드·메시 해석이라면 매번 연립방정식을 새로 풀어야 합니다.

## 문제 3 (고급) — 3단 분압기 사다리와 부하 효과

```
   Vin = 36 V
   (+)       R1 = 6 kΩ       A    R3 = 4 kΩ       B    R5 = 3 kΩ       C
    o────────/\/\/\──────────o────/\/\/\──────────o────/\/\/\──────────o── Vout
    │            I1 →        │       I3 →         │       I5 →         │
   Vin                     R2 = 3 kΩ             R4 = 6 kΩ            R6 = 6 kΩ
    │                        │ I2 ↓               │ I4 ↓               │ I6 ↓
   (−)                       │                    │                    │
    o────────────────────────┴────────────────────┴────────────────────┘
   GND (0 V)

   [  A단: R1/R2  ]─────[  B단: R3/R4  ]─────[  C단: R5/R6  ]
   Vin: + 극이 위쪽, − 극이 GND
```

1. **B단의 입력저항 R_in(B):** 노드 A에서 오른쪽(B단 + C단)을 들여다본 저항을 구하세요.
2. **B단 출력저항 R_out(B):** C단을 떼어 냈을 때 노드 B에서 왼쪽(전원 단락)을 들여다본 저항을 구하세요.
3. 각 단에 테브닌 정리를 **단계별로** 적용해 정확한 V_out을 구하세요.
4. 부하 효과를 무시하고 세 단의 분압비만 곱한 "순진한 값"을 구하고, 정확한 값과의 오차(%)를 구하세요.
5. **(보너스)** 출력 C에 R_L = 6 kΩ 부하를 달면 V_out은 얼마가 됩니까? V_out이 무부하 값의 절반이 되는 R_L은?

🔑 **핵심 개념:** 단계별 테브닌 등가 — 앞 단을 "V_th + R_th"로 바꾸면 그 R_th가 다음 단의 직렬 저항에 **더해진** 채로 다시 분압이 일어납니다 (예: B단은 12 V를 (2+4) kΩ과 6 kΩ으로 분압 → 6 V). 순진한 분압비 곱셈은 이 "앞 단 출력저항"과 "뒤 단 입력저항"을 빠뜨리기 때문에 값이 크게 나옵니다. 그래서 부하 효과를 이해하는 것이 핵심입니다.

# 📘 정답 및 해설 (교수용)

## 문제 1 해설

### (1) 루프 전류
두 전원 모두 + 극이 위쪽이므로 시계 방향으로 돌면 V1은 전위를 올리고(+15 V), V2는 전위를 내립니다(−5 V).

KVL (시계 방향, P에서 출발):
```
+15 − 2k·I − 5 − 3k·I = 0   →   I = 10 V / 5 kΩ = 2 mA (시계 방향)
```

### (2) V_Q — 방법 ①: KVL로 전위 따라가기 (P → a → Q)
```
V_P = −4 V
V_a = V_P + 15        = 11 V      (V1의 − → + 를 지나며 15 V 상승)
V_Q = V_a − I·R1 = 11 − 2·2 = 7 V  (R1을 전류 방향으로 지나며 4 V 하강)
```
**∴ V_Q = 7 V**

### (3) 검산 — 다른 경로 (P → b → Q)
전류는 b → P 방향으로 R2를 흐르므로 b가 P보다 I·R2 = 6 V 높습니다.
```
V_b = V_P + 2·3 = −4 + 6 = 2 V
V_Q = V_b + 5   = 7 V        ✔ (V2의 − → + 를 지나며 5 V 상승)
```

### 방법 ②: 중첩의 원리 (V_QP = V_Q − V_P 를 구함)
- **V1 = 15 V만 (V2 단락 → Q와 b가 같은 노드):**
  15 V가 R1(2k)과 R2(3k)에 분압됩니다. V_QP = V_bP = R2 양단 전압
  ```
  V_QP' = 15 · 3/(2+3) = 9 V
  ```
- **V2 = 5 V만 (V1 단락 → a와 P가 같은 노드):**
  5 V가 R1과 R2에 분압됩니다. V_QP = V_Qa = R1 양단 전압
  ```
  V_QP'' = 5 · 2/(2+3) = 2 V
  ```
  (확인: 이때 전류 1 mA는 반시계 방향, V_bP = −3 V, V_QP = −3 + 5 = 2 V ✔)
- **합:** V_QP = 9 + 2 = 11 V → V_Q = V_P + 11 = −4 + 11 = **7 V** ✔

> 💡 수업 포인트: P가 0 V가 아니어도 상관없습니다. 회로는 **전위차**만 정하고, 절대 전위는 P라는 기준점 하나만 주어지면 그만큼 평행이동할 뿐입니다.

## 문제 2 해설

### (1) 테브닌 등가 (R5 제거)
**V_th — 분압 법칙 두 번:**
```
V_A = 12 · 12/(4+12) = 9 V
V_B = 12 · 3/(6+3)   = 4 V
V_th = V_A − V_B     = 5 V   (A가 +)
```
**R_th — 전원 단락:** 위 레일이 GND와 같아지므로 각 갈래가 병렬이 됩니다.
```
R_th = (R1‖R2) + (R3‖R4) = (4‖12) + (6‖3) = 3 + 2 = 5 kΩ
```

**검산 — I_sc 방법:** A-B를 단락하면 V_A = V_B = V. 노드 식 (kΩ, mA):
```
(12−V)/4 + (12−V)/6 = V/12 + V/3   →  ×12:  60 − 5V = 5V  →  V = 6 V
I_sc(A→B) = (12−6)/4 − 6/12 = 1.5 − 0.5 = 1 mA
R_th = V_th / I_sc = 5 V / 1 mA = 5 kΩ   ✔
```

### (2) R5 = 5 kΩ
```
I5   = V_th/(R_th + R5) = 5/(5+5) = 0.5 mA  (A → B)
V_AB = I5 · R5          = 2.5 V
```
**검산 (노드 해석):** V_A = 7.5 V, V_B = 5.0 V → V_AB = 2.5 V, I5 = 2.5/5 = 0.5 mA ✔
(KCL at A: (12−7.5)/4 = 1.125 mA 유입 = 7.5/12 + 0.5 = 0.625 + 0.5 ✔)

### (3) R5 값 바꾸기
```
R5 = 15 kΩ :  I5 = 5/(5+15) = 0.25 mA   (V_AB = 3.75 V)
I5 = 0.2 mA:  5 + R5 = 5/0.2 = 25  →  R5 = 20 kΩ
```
(노드 해석 검산: R5 = 15k → V_A = 8.25, V_B = 4.5, I5 = 0.25 mA ✔ / R5 = 20k → V_A = 8.4, V_B = 4.4, I5 = 0.2 mA ✔)

### (4) 최대 전력 전달
```
R5 = R_th = 5 kΩ,   P_max = V_th² / (4·R_th) = 25 / 20 = 1.25 mW
```
(확인: 0.5 mA × 2.5 V = 1.25 mW ✔)

> 💡 수업 포인트: 노드 해석으로는 R5가 바뀔 때마다 2×2 연립방정식을 새로 풀어야 합니다. 테브닌 등가를 한 번 구해 두면 I5 = 5/(5+R5) **한 줄**로 끝납니다.

## 문제 3 해설

### (1) R_in(B) — 노드 A에서 오른쪽을 본 저항
C단을 포함하면 R4는 (R5 + R6)와 병렬입니다.
```
R_in(B) = R3 + R4 ‖ (R5 + R6) = 4 + 6‖9 = 4 + 3.6 = 7.6 kΩ
```
→ A단 출력(R2 = 3 kΩ)에 7.6 kΩ이 병렬로 붙으므로, "부하가 약하다"고 볼 수 없습니다.

### (2) R_out(B) — 노드 B에서 왼쪽(전원 단락)을 본 저항
```
A단 테브닌 저항  R_th1 = R1‖R2 = 6‖3 = 2 kΩ
R_out(B) = (R_th1 + R3) ‖ R4 = (2 + 4) ‖ 6 = 3 kΩ
```

### (3) 단계별 테브닌 → 정확한 V_out
| 단 | 왼쪽 테브닌 전원 | 분압 | V_th | R_th |
|---|---|---|---|---|
| A | 36 V, 0 Ω | 36 · 3/(6+3) | **12 V** | 6‖3 = **2 kΩ** |
| B | 12 V, 2 kΩ | 12 · 6/(2+4+6) | **6 V** | (2+4)‖6 = **3 kΩ** |
| C | 6 V, 3 kΩ | 6 · 6/(3+3+6) | **3 V** | (3+3)‖6 = **3 kΩ** |

**∴ V_out(무부하) = 3 V,  출력 테브닌 저항 = 3 kΩ**

**검산 — 출력에서 거꾸로 KCL/KVL:**
```
V_C = 3 V      → I6 = 3/6 = 0.5 mA = I5
V_B = 3 + 3·0.5 = 4.5 V   → I4 = 4.5/6 = 0.75 mA,  I3 = 0.5 + 0.75 = 1.25 mA
V_A = 4.5 + 4·1.25 = 9.5 V → I2 = 9.5/3 = 3.1667 mA, I1 = 1.25 + 3.1667 = 4.4167 mA
Vin = 9.5 + 6·4.4167 = 9.5 + 26.5 = 36 V   ✔
```
(3×3 노드 해석으로도 V_A = 9.5, V_B = 4.5, V_C = 3.0 V 확인)

### (4) 순진한 값과 오차
```
분압비 곱:  36 × (3/9) × (6/10) × (6/9) = 36 × 0.1333 = 4.8 V
오차 = (4.8 − 3) / 3 × 100 = +60 %  (과대평가)
```
원인: ① 앞 단의 출력저항(2k, 3k)이 다음 단 직렬저항에 더해지는 것을 무시했고, ② 뒤 단이 앞 단 출력에 병렬 부하로 걸리는 것(예: R2 3k ‖ R_in(B) 7.6k)을 무시했기 때문입니다.

### (5) 보너스 — 출력 부하
```
R_L = 6 kΩ:   V_out = 3 · 6/(3+6) = 2 V
V_out = 1.5 V (절반):  R_L = R_th = 3 kΩ
```
(노드 해석 검산: R_L = 6k → V_C = 2.0 V ✔, R_L = 3k → V_C = 1.5 V ✔)

> 💡 수업 포인트: 분압비를 그냥 곱해도 되는 경우는 **R_in(다음 단) ≫ R_out(앞 단)** 일 때뿐입니다(보통 10배 이상). 이 회로는 그 비율이 2~3배에 불과해서 오차가 60%나 납니다. 이것이 연산증폭기 버퍼(전압 폴로어)를 단 사이에 넣는 이유입니다.
