# ⚡ 테브닌 정리·분압·중첩 회로 퀴즈 (2026-10-09)

> 공통 주제: 전압원과 저항이 얽혀 복잡해 보이지만, **테브닌 정리 · 분압 법칙 · 중첩의 원리**를 쓰면 간단해지는 회로.
> 단위: V, kΩ, mA (kΩ × mA = V)

---

## 🟢 문제 1 (초급) — 두 전원이 만드는 단일 루프의 전위

전압원 2개와 저항 2개가 하나의 루프를 이룬다. 점 P의 전위가 기준(접지) 대비 **V_P = +5 V**로 주어져 있다.

```
            A ─────[ R1 = 4 kΩ ]───── B (=Q)
            │         I ──►           │
           (+)                       (+)
        E1 = 10 V                 E2 = 4 V
           (−)                       (−)
            │                         │
   V_P=5V   P ─────[ R2 = 2 kΩ ]───── C
   (기준 대비)        ◄── I

   * 루프 전류 I 는 시계방향 (P → A → B → C → P) 을 양(+)으로 정의
   * E1 의 (+)는 A 쪽, E2 의 (+)는 B 쪽 (두 전원이 루프에서 서로 반대로 작용)
```

**(1)** 루프 전류 I [mA]를 구하라.
**(2)** 점 Q(=B)의 전위 V_Q [V]를 **KVL로 전위를 따라가는 방법**으로 구하라.
**(3)** 같은 V_Q를 **중첩의 원리**(전원을 하나씩 살리기)로 다시 구하고 (2)와 일치하는지 확인하라.

🔑 **핵심 개념:** *KVL 전위 추적 + 중첩의 원리* — 루프에서 전위는 "전원을 지나면 ±E 만큼 오르내리고, 저항을 전류 방향으로 지나면 IR 만큼 내려간다". P 전위가 주어졌으므로 P를 출발점으로 삼아 P→A(+10 V)→B(−IR1)로 걸어가면 Q 전위가 바로 나온다. 중첩에서는 각 전원이 단독으로 만드는 "P 대비 Q의 전위차"(E1 단독 +10/3 V, E2 단독 +8/3 V)를 더해 V_P 에 얹는다. 선형 회로이므로 두 방법이 반드시 같아야 한다.

## 🟡 문제 2 (중급) — 불평형 브리지와 테브닌 등가

12 V 전압원에 분압기 두 갈래(왼쪽 3k/6k, 오른쪽 12k/4k)가 붙어 있고, 중간 노드 A–B 사이를 R5 가 잇는다.

```
              +12 V (Vs, 접지 기준)
        ┌───────────┴───────────┐
        │                       │
   [R1 = 3 kΩ]             [R3 = 12 kΩ]
        │                       │
        A ───[ R5 = 5 kΩ ]───►── B        (I5 : A → B 방향 양(+))
        │                       │
   [R2 = 6 kΩ]             [R4 = 4 kΩ]
        │                       │
        └───────────┬───────────┘
                   GND (0 V)
```

**(1)** R5 를 떼어 내고 A–B 단자에서 본 **테브닌 등가** V_th(= V_A − V_B)와 R_th 를 구하라.
**(2)** R5 = 5 kΩ 일 때 R5 에 흐르는 전류 I5 와 전압 V_AB 를 구하라.
**(3)** 단락전류 I_sc 를 직접 구해 V_th/R_th 와 같은지 검산하라.
**(4)** R5 를 **15 kΩ** 으로 바꾸면 I5 는? (회로를 다시 풀지 말고 테브닌 등가만 이용하라.) 노드 해석으로 풀 때와 비교해 연립식이 몇 개 줄어드는지 말하라.

🔑 **핵심 개념:** *테브닌 정리* — 관심 소자(R5)를 떼어 내면 회로는 "독립된 두 분압기"가 되어 V_A=12·6/9, V_B=12·4/16 이 암산으로 나온다(분압 법칙). 전원을 단락하면 각 분압기는 병렬 저항(3k∥6k, 12k∥4k)이 되고 둘이 직렬로 연결된 것이 R_th. 이렇게 한 번 구해 둔 (V_th, R_th)로 R5 가 무엇이든 I = V_th/(R_th+R5) 한 줄로 답이 나온다.

## 🔴 문제 3 (고급) — 3단 분압기 사다리의 부하 효과

Vin = 30 V 를 분압기 3단(A→B→C)에 연결했다. 각 단은 직렬 저항(R1, R3, R5)과 병렬(접지) 저항(R2, R4, R6)으로 구성되며, 출력은 R6 양단이다.

```
 Vin=30V(+)          N1               N2               Vout
   ●───[R1 6k]───┬───●───[R3 4k]───┬───●───[R5 4k]───┬───●────
                 │                 │                 │      │
              [R2 12k]          [R4 8k]           [R6 8k]  (RL, 보너스)
                 │                 │                 │      │
   GND ──────────┴─────────────────┴─────────────────┴──────┴──── GND
        ◄─ A단 ─►        ◄─ B단 ─►        ◄─ C단 ─►
```

**(1)** **B단의 입력저항 R_in(B)** (N1에서 B단 쪽을 들여다본 저항, 뒤 C단 부하 포함)을 구하라.
**(2)** **B단 출력(N2)에서 본 R_out**(전원 단락 시 N2에서 앞쪽을 본 저항)을 구하라.
**(3)** 각 단의 테브닌 등가 (V_th, R_th)를 A→B→C 순서로 단계적으로 구하고, 이로부터 **정확한 V_out**(무부하)을 구하라.
**(4)** 부하 효과를 무시하고 각 단의 분압비 R_shunt/(R_series+R_shunt)만 곱한 **순진한 값**을 구하고, 정확한 값과의 오차(V, %)를 말하라.
**(5)** (보너스) 출력에 **R_L = 12 kΩ** 을 달면 V_out 은?

🔑 **핵심 개념:** *분압 법칙의 부하 의존성 + 단계적 테브닌 등가* — 뒤 단은 앞 단 입장에서 병렬 부하(R4 ∥ R_in(C))이므로 분압비가 바뀐다. 이를 피하려고 앞에서부터 "전원+직렬저항"을 테브닌 등가 하나(V_th, R_th)로 접어 가며 다음 단의 직렬 저항에 R_th 를 더한다. 이렇게 하면 각 단이 "한 줄 분압" 문제가 되고, 마지막 단의 (V_th, R_th)가 곧 출력 단자의 테브닌 등가이므로 부하(R_L)를 달아도 분압 한 번으로 끝난다.

# 📘 정답 및 해설 (교수용)

## 문제 1 해설

**(1) 루프 전류.** 시계방향 KVL: +10 (E1 상승) − 4·I − 4 (E2 : B→C 로 갈 때 (+)에서 (−)로 4 V 하강) − 2·I = 0 → 6 = 6·I → **I = 1 mA** (시계방향, 양수).

**(2) KVL 전위 추적 (V_P = 5 V 에서 출발).**
- P→A : E1 상승 → V_A = 5 + 10 = 15 V
- A→B : R1 에서 I·R1 = 4 V 하강 → V_B = 15 − 4 = **11 V** ⇒ **V_Q = 11 V**
- 검산(반대 방향으로 한 바퀴): B→C : E2 4 V 하강 → V_C = 7 V, C→P : R2 에서 2 V 하강 → 7 − 2 = 5 V = V_P ✓ (루프가 닫힘)

**(3) 중첩 (P 를 기준으로 한 Q 의 전위차 V_QP).**
- E1 만 (E2 단락): I₁ = 10/6 = 5/3 mA(시계방향). V_QP,1 = 10 − I₁·R1 = 10 − 20/3 = **10/3 V**
- E2 만 (E1 단락): I₂ = 4/6 = 2/3 mA(반시계방향, E2 의 (+)에서 R1 쪽으로 나옴). R1 에서 B 가 A(=P) 보다 I₂R1 = 8/3 V 높다 → V_QP,2 = **8/3 V**
- 합: 10/3 + 8/3 = 6 V → V_Q = V_P + 6 = **11 V** ✓ (KVL 결과와 일치)

> 💬 지도 포인트: P 가 접지가 아니어도 "전위 = 기준점 전위 + 전위차" 로 생각하면 된다. 중첩은 전원별 기여를 나눠 보는 도구일 뿐, 결과는 같다.

## 문제 2 해설

**(1) 테브닌 등가 (R5 제거).**
- V_A = 12·6/(3+6) = 8 V, V_B = 12·4/(12+4) = 3 V → **V_th = V_A − V_B = 5 V**
- 전원 단락 → R_th = (3∥6) + (12∥4) = 2 + 3 = **5 kΩ**

**(2) R5 = 5 kΩ.** I5 = 5/(5+5) = **0.5 mA** (A→B), V_AB = 0.5×5 = **2.5 V**.

**(3) 검산 1 — 단락전류.** A–B 를 단락하면 위쪽 R1∥R3 = 2.4k, 아래쪽 R2∥R4 = 2.4k 로 대칭 → 합쳐진 노드 전압 6 V. R1 전류 (12−6)/3 = 2 mA, R2 전류 6/6 = 1 mA (아래로) → 차이 1 mA 가 단락선을 A→B 로 흐른다. **I_sc = 1 mA = V_th/R_th = 5/5** ✓

**검산 2 — 노드 해석(연립 2원).** V_A = 7 V, V_B = 4.5 V → V_AB = 2.5 V, I5 = 2.5/5 = 0.5 mA ✓ (R5 연결 시 V_A: 8→7, V_B: 3→4.5 로 "끌려오는" 모습)

**(4) R5 = 15 kΩ.** I5 = 5/(5+15) = **0.25 mA**, V_AB = 3.75 V. (노드 해석 검산: V_A=7.5 V, V_B=3.75 V → V_AB=3.75 V ✓)
- 노드 해석: R5 가 바뀔 때마다 **2원 연립 방정식을 다시** 풀어야 한다(메시 해석은 3원).
- 테브닌: V_th, R_th 는 **한 번만** 구하면 되고, 이후 R5 값마다 나눗셈 한 번. 참고로 R5=0 → 1 mA(I_sc), R5→∞ → 0, V_AB→5 V(V_th).

## 문제 3 해설

**(1) R_in(B).** C단 입력저항 R_in(C) = R5+R6 = 4+8 = 12 kΩ.
R_in(B) = R3 + (R4 ∥ R_in(C)) = 4 + (8∥12) = 4 + 4.8 = **8.8 kΩ**

**(2) R_out(B).** Vin 단락 → A단 출력 저항 R_th,A = R1∥R2 = 6∥12 = 4 kΩ. N2 에서 앞쪽을 보면 (R_th,A + R3) ∥ R4 = (4+4)∥8 = **4 kΩ**.

**(3) 단계적 테브닌 (무부하).**

| 단 | 계산 | V_th | R_th |
|---|---|---|---|
| A | 30·12/(6+12), 6∥12 | **20 V** | **4 kΩ** |
| B | 20·8/(4+4+8), (4+4)∥8 | **10 V** | **4 kΩ** |
| C | 10·8/(4+4+8), (4+4)∥8 | **5 V** | **4 kΩ** |

→ **V_out(무부하) = 5 V**, 출력저항 4 kΩ.

**검산 (역방향 전류/전위 추적).** V_out = 5 V → I_C = 5/8 = 0.625 mA, N2 = 5·12/8 = 7.5 V. R4 전류 7.5/8 = 0.9375 mA → R3 전류 1.5625 mA → N1 = 7.5 + 4·1.5625 = 13.75 V. R2 전류 13.75/12 = 1.1458 mA → R1 전류 2.7083 mA → Vin = 13.75 + 6·2.7083 = **30.0 V** ✓ (N1=13.75 V, N2=7.5 V, Vout=5 V)

**(4) 순진한 값.** 분압비 A 12/18=2/3, B 8/12=2/3, C 8/12=2/3 → 30·(2/3)³ = **8.89 V**.
오차 = 8.89 − 5 = **3.89 V (정확한 값 대비 약 +78 %, 과대평가)**. 원인: 각 단의 병렬 저항이 뒤 단 입력저항과 병렬이 되어 실제 분압비가 더 작아진다.

**(5) 보너스 R_L = 12 kΩ.** 출력 테브닌 (5 V, 4 kΩ) → V_out = 5·12/(4+12) = **3.75 V**.
검산(전체 풀이): R6∥RL = 4.8k → C단 입력 8.8k → 이하 계산 시 V_N1 = 13.4375 V, V_N2 = 6.875 V, V_out = 6.875·4.8/8.8 = 3.75 V ✓ (Python 정확 분수 계산으로도 확인)
