# 테브닌·분압·중첩 회로 퀴즈 (2026-11-05)

> 공통 주제: 직렬·병렬로 얽혀 복잡해 보이는 회로도, **중첩의 원리 / 분압 법칙 / 테브닌 정리**로 단계적으로 쪼개면 간단해집니다.
> 단위: kΩ, V, mA (V = mA × kΩ)

---

## 문제 1 (초급) — 두 전원이 있는 단일 루프

```
        P ●──────── R1 = 2kΩ ────────● Q
          │            ──► I(시계방향 가정)   │
      ┌───┴───┐                           ┌───┴───┐
      │ V1    │ +(위)                      │ V2    │ +(위)
      │ 15 V  │                           │  6 V  │
      └───┬───┘                           └───┬───┘
          │                                   │
          └──────── R2 = 4kΩ ─────────────────┘
```

- 위쪽 왼쪽 모서리 P의 전위: **V_P = +1 V** (기준점 대비)
- 두 전원의 + 단자는 모두 위쪽, 루프 전류 I는 시계방향(P→R1→Q→V2→R2→V1)을 양(+)으로 한다.

**질문**
1. 루프 전류 I의 크기와 실제 방향은?
2. 점 Q의 전위 V_Q는?
3. 아래쪽 두 모서리(V1의 − 단자, V2의 − 단자)의 전위는?

🔑 **핵심 개념:** 단일 루프에서는 **전위를 한 점에서 출발해 소자를 따라가며 올리고(전원 −→+) 내린다(저항 전류 방향)**. 또 **중첩의 원리**로 전원을 하나씩만 살려(다른 전원은 단락) 각각이 R1 양단에 만드는 전압을 구해 더하면, 15V 전원은 R1에서 5V 강하를, 6V 전원은 반대 방향으로 2V 상승을 만들어 합이 3V 강하가 된다.

## 문제 2 (중급) — 불평형 브리지

```
              Vs = 12 V
        +(위) ┌───┐
     ┌────────┤ ┼ ├────────┐
     │        └───┘        │
     │                     │
  R1 = 6kΩ              R3 = 12kΩ
     │                     │
     ●── A ──── R5 ──── B ──●        (I : A → B 방향 가정)
     │       (3 kΩ)        │
  R2 = 12kΩ             R4 = 4kΩ
     │                     │
     └─────────┬───────────┘
              GND (0 V)
```

**질문**
1. R5 = 3 kΩ일 때 R5에 흐르는 전류 I와 V_AB를 **테브닌 정리**로 구하라.
2. R5를 18 kΩ으로 바꾸면 I와 V_AB는? (회로를 다시 풀지 말고 1번의 결과를 재활용할 것)
3. 노드 해석으로 풀면 미지수가 몇 개 필요한가? 테브닌 방식과 비교하라.

🔑 **핵심 개념:** R5를 떼어 내고 A–B에서 본 회로를 **V_th(개방 전압 = 두 분압기 출력의 차)** 와 **R_th(전원 단락 시 (R1‖R2)+(R3‖R4))** 로 압축한다. 그러면 R5가 바뀌어도 V_th·R_th는 그대로여서 `I = V_th/(R_th+R5)` 한 줄로 해결된다 — 노드 해석은 R5 값이 바뀔 때마다 2원 연립식을 다시 풀어야 한다.

## 문제 3 (고급) — 3단 분압기 (부하 효과)

```
 A단            B단            C단
        R1=8k          R3=6k          R5=4k
 +─────/\/\/──●─────────/\/\/──●─────────/\/\/──●── Vout
 │             │                │                │
Vin=48V      R2=24k           R4=24k           R6=20k
(+위)           │                │                │
 │             │                │                │
 └─────────────┴────────────────┴────────────────┴── GND
        노드 N1          노드 N2          노드 N3(=Vout)
```

(각 단: 직렬 저항 + 접지로 가는 병렬(션트) 저항. 출력은 션트 저항 양단.)

**질문**
1. B단의 입력저항 R_in(B) (B단 직렬저항 R3 + 뒤 단 부하 포함)을 구하라.
2. B단 출력(N2)에서 본 출력저항 R_out(B)를 구하라.
3. 테브닌 등가를 단계별(A→B→C)로 적용하여 정확한 V_out을 구하라.
4. 부하 효과를 무시하고 각 단 분압비만 곱한 값(순진한 값)과 비교하여 오차를 구하라.
5. (보너스) 출력에 R_L = 30 kΩ을 달았을 때 V_out은?

🔑 **핵심 개념:** 뒤 단은 앞 단에서 보면 **부하 저항 R_in** 일 뿐이므로, 앞 단 출력을 **(V_th, R_th)** 로 바꾼 뒤 다음 저항을 직렬로 붙여 다시 분압→테브닌 등가를 반복한다. 각 단의 분압비는 뒤 단 R_in이 션트에 병렬로 걸려 **실제 분압비가 달라지므로** 단순 곱은 틀린다.

# 📘 정답 및 해설 (교수용)

## 문제 1 해설

**정답:** I = 1.5 mA (시계방향), V_Q = −2 V, 아래 모서리는 V1(−) = −14 V, V2(−) = −8 V.

**방법 ① KVL로 전위 따라가기** (P에서 출발)
- 순수 기전력: 15 − 6 = 9 V (V1은 올리고 V2는 반대로 내림), 총 저항 2k+4k = 6k → I = 9/6 = **1.5 mA**, 양수이므로 시계방향 ✔
- V_Q = V_P − I·R1 = 1 − 1.5×2 = **−2 V**
- V2의 +단자가 Q(−2V) → V2(−) = −2 − 6 = **−8 V**
- R2 통과(전류 V2(−)→V1(−) 방향으로 강하): −8 − 1.5×4 = **−14 V**
- V1의 +단자 P = −14 + 15 = **+1 V** ✔ (출발점과 일치 → 검산 완료)

**방법 ② 중첩의 원리** (R1 양단 강하만 추적)
- V1만 작용(V2 단락): I₁ = 15/6 = 2.5 mA → R1 강하 5 V
- V2만 작용(V1 단락): I₂ = 6/6 = 1 mA, 방향은 반시계 → R1에서 +2 V 상승(P→Q 방향으로는 −1×2 = 반대 부호)
- 합: ΔV(P→Q) = −5 + 2 = −3 V → V_Q = 1 − 3 = **−2 V** ✔

**검산:** 전력 균형. V1 공급 15×1.5 = 22.5 mW, V2 흡수 6×1.5 = 9 mW(전류가 +단자로 들어감), 저항 소모 1.5²×6 = 13.5 mW → 22.5 = 9 + 13.5 ✔

## 문제 2 해설

**정답:** (1) V_th = 5 V, R_th = 7 kΩ → R5=3k: **I = 0.5 mA, V_AB = 1.5 V**. (2) R5=18k: **I = 0.2 mA, V_AB = 3.6 V**. (3) 노드 해석은 미지수 2개(V_A, V_B), 테브닌은 연립식 없이 분압 2회 + 직렬 합산.

**방법 ① 테브닌**
- 개방 상태: V_A = 12×12/(6+12) = 8 V, V_B = 12×4/(12+4) = 3 V → **V_th = V_A − V_B = 5 V**
- 전원 단락: R_th = (6‖12) + (12‖4) = 4 + 3 = **7 kΩ**
- R5=3k: I = 5/(7+3) = **0.5 mA**, V_AB = I·R5 = **1.5 V**
- R5=18k: I = 5/(7+18) = **0.2 mA**, V_AB = 0.2×18 = **3.6 V** (재풀이 불필요)

**방법 ② 노드 해석(검산)** — 단위 mS
- A: (1/6+1/12+1/R5)V_A − (1/R5)V_B = 12/6
- B: −(1/R5)V_A + (1/12+1/4+1/R5)V_B = 12/12
- R5=3k → V_A = 6 V, V_B = 4.5 V, I = 1.5/3 = 0.5 mA ✔
- R5=18k → V_A = 7.2 V, V_B = 3.6 V, I = 3.6/18 = 0.2 mA ✔

**방법 ③ V_th/I_sc 검산:** A–B 단락 시 노드 전압 V = 12×(12‖4)/((6‖12)+(12‖4)) = 12×3/7 = 36/7 V.
I_sc = (12−36/7)/6 − (36/7)/12 = 8/7 − 3/7 = 5/7 mA → R_th = V_th/I_sc = 5/(5/7) = **7 kΩ** ✔

**지도 포인트:** R5가 2개 값이면 노드 해석 2번(연립 2원 ×2), 테브닌은 한 번 구한 (5V, 7k)로 즉시 계산 — 부하 값이 많이 바뀌는 설계에서 테브닌이 유리함을 강조.

## 문제 3 해설

**정답:** R_in(B) = **18 kΩ**, R_out(B) = **8 kΩ**, V_out = **15 V**, 순진한 값 24 V(오차 +9 V, 정확값 대비 +60 %, 순진값 대비 37.5 %), R_L=30k일 때 **12 V**.

**1. R_in(C) = R5 + R6 = 4 + 20 = 24 k**
 N2의 션트: R4‖R_in(C) = 24‖24 = 12 k → **R_in(B) = R3 + 12 = 18 kΩ**

**2·3. 테브닌 단계 적용**
- A단: V_th,A = 48×24/(8+24) = **36 V**, R_th,A = 8‖24 = **6 kΩ**
- B단: (V_th,A, R_th,A)에 R3 직렬 → 6+6 = 12k, 션트 R4=24k
  V_th,B = 36×24/(12+24) = **24 V**, R_th,B = 12‖24 = **8 kΩ** ← **R_out(B)**
- C단: (24V, 8k)에 R5 직렬 → 8+4 = 12k, 션트 R6=20k
  V_th,C = 24×20/(12+20) = **15 V**, R_th,C = 12‖20 = **7.5 kΩ**
- 무부하 출력 **V_out = 15 V**

**검산(앞→뒤 직접 분압):**
- N1 = 36 × R_in(B)/(6+R_in(B)) = 36×18/24 = 27 V
- N2 = 27 × (R4‖R_in(C))/(R3 + R4‖R_in(C)) = 27×12/18 = 18 V
- V_out = 18 × 20/(4+20) = **15 V** ✔
- 노드 해석(Python 분수 계산): N1=27, N2=18, N3=15 V ✔

**4. 순진한 값:** (24/32)×(24/30)×(20/24) = 0.75×0.8×0.8333 = 0.5 → 48×0.5 = **24 V**. 오차 = 24 − 15 = **9 V**. 원인: 뒤 단이 션트에 병렬로 걸려 각 단 실제 분압비가 0.75→0.75(A: 부하 시 27/48=0.5625), 0.8→0.667(18/27), 0.833(그대로)로 바뀜: 0.5625×0.6667×0.8333 = 0.3125 → 48×0.3125 = **15 V** ✔

**5. 보너스:** (V_th,C, R_th,C) = (15 V, 7.5 k)에 R_L=30k → V_out = 15×30/(7.5+30) = **12 V**
(검산: 노드 해석 N1=26, N2=16, N3=12 V ✔. 참고: R_L = R_th = 7.5k이면 7.5 V, 최대 전력 전달 조건.)
