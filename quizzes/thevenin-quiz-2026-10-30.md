# 회로 퀴즈: 테브닌·분압·중첩 (2026-10-30)

> 공통 주제: 전압원과 저항이 얽혀 복잡해 보여도, **분압 법칙 · 중첩의 원리 · 테브닌 정리**로 연립방정식 없이 풀립니다.

## 문제 1 (초급) — 단일 루프에서 전위 따라가기

전압원 2개와 저항 2개가 한 루프를 이룹니다. 점 P의 전위는 **V_P = +5 V** 로 주어져 있습니다(기준점은 회로 밖 어딘가에 있음).

```
        P ────── R1 = 2kΩ ────── Q
        │   →I(시계방향)          │
     E1 = 12V                  E2 = 4V
      (+가 위, P쪽)            (+가 위, Q쪽)
        │                         │
        G ────── R2 = 6kΩ ────── S
```

- E1: G(−) → P(+), 12 V
- E2: Q(+) → S(−), 4 V (E1과 반대 방향으로 맞서 있음)
- 전류 I는 시계방향(G→P→Q→S→G)을 양(+)으로 정의

**(a)** 루프 전류 I를 구하세요.
**(b)** 점 Q의 전위 V_Q를 **KVL(전위 따라가기)** 로 구하세요.
**(c)** 같은 V_Q를 **중첩의 원리**(기준을 G로 잡고 전원을 하나씩 살림)로 구하고, (b)와 비교하세요.

🔑 **핵심 개념:** 한 점의 전위가 주어지면 그 점에서 출발해 소자를 지날 때마다 "전원은 +극 방향이면 +E, 저항은 전류 방향이면 −IR"로 전위를 더하고 빼며 다른 점의 전위를 바로 읽을 수 있습니다. 여기서는 V_P=5V에서 R1(−2V)을 지나 V_Q=3V를 얻습니다. 중첩에서는 E1만 살리면(E2 단락) Q→R2→G 경로의 R2 전압강하 9V가, E2만 살리면(E1 단락) R1 전압강하 1V가 V_Q−V_G에 더해져 합이 10V가 됩니다.

## 문제 2 (중급) — 불평형 브리지와 테브닌 정리

12 V 전압원 하나에 분압기 두 갈래가 붙어 있고, 중간 노드 A와 B 사이를 R5가 잇습니다.

```
          +12V (V_s)
      ┌──────┴───────┐
      │              │
    R1=2kΩ         R3=6kΩ
      │              │
      A ──── R5 ──── B        (R5 = 6.5kΩ, 전류 I5는 A→B 방향)
      │      →I5     │
    R2=6kΩ         R4=3kΩ
      │              │
      └──────┬───────┘
            GND
```

**(a)** R5를 떼어낸 상태에서 A-B 단자의 테브닌 등가 (V_th, R_th)를 구하세요.
**(b)** R5 = 6.5 kΩ일 때 R5에 흐르는 전류 I5와 전압 V_AB를 구하세요.
**(c)** R5를 1.5 kΩ으로 바꾸면 전류는? 노드 해석으로 풀 때와 비교해 테브닌 정리의 장점을 설명하세요.
**(d)** (검산) 단락전류 I_sc를 구하고 R_th = V_th / I_sc 와 일치하는지 확인하세요.

🔑 **핵심 개념:** 테브닌 정리는 "부하(R5)를 떼고 A-B에서 본 회로"를 전압원 하나와 저항 하나로 줄입니다. 개방전압은 두 분압기 출력의 차(V_A−V_B = 9−4 = 5V)이고, 전원을 단락하면 R1‖R2와 R3‖R4가 직렬이 되어 R_th = 1.5k+2k = 3.5kΩ입니다. 한 번 구해 두면 R5가 바뀌어도 I = V_th/(R_th+R5) 한 줄로 끝나므로, 값이 바뀔 때마다 연립식을 다시 세울 필요가 없습니다.

## 문제 3 (고급) — 3단 분압기의 부하 효과

분압기 3단(A→B→C)이 직렬로 이어져 있습니다. 출력은 N3 입니다.

```
  Vin=36V           N1                N2                N3 (V_out)
   (+) ──R1=9kΩ──┬────────R3=6kΩ──┬────────R5=6kΩ──┬──── ○ V_out
                 │                │                │      (선택: RL=4kΩ 연결)
              R2=18kΩ          R4=12kΩ           R6=6kΩ
                 │                │                │
   (−) ──────────┴────────────────┴────────────────┴──── GND

   [ A단: R1,R2 ]     [ B단: R3,R4 ]     [ C단: R5,R6 ]
```

**(a)** B단의 입력저항 R_in(B) (N1에서 R3 쪽을 들여다본 저항, 뒤의 C단 부하 포함)
**(b)** B단 출력(N2)에서 앞쪽을 본 출력저항 R_out(B)
**(c)** 테브닌 등가를 단계별(N1 → N2 → N3)로 적용하여 정확한 V_out
**(d)** 부하 효과를 무시하고 각 단 분압비만 곱한 "순진한 값"과 그 오차
**(e)** (보너스) 출력에 R_L = 4 kΩ을 달았을 때의 출력 전압

🔑 **핵심 개념:** 각 단을 "테브닌 전압원 + 직렬저항"으로 바꾸면 다음 단은 그 등가원을 입력으로 받는 한 단짜리 분압기가 됩니다. N1에서 (36V, 9k‖18k=6k), N2에서 6k를 더한 12k를 R4=12k와 분압해 (12V, 6k), N3에서 (4V, 4k)가 나옵니다. 뒤 단이 앞 단 분압기에 병렬 부하로 걸리므로, 분압비만 곱하면 부하 효과(앞 단 전압의 저하)를 놓쳐 크게 틀립니다.

# 📘 정답 및 해설 (교수용)

## 문제 1 해설

**(a)** 두 전원이 서로 맞서므로 I = (12 − 4) / (2k + 6k) = **1 mA** (시계방향, 양수).

**(b) KVL 전위 따라가기** (V_P = 5V에서 출발)
- P→Q: R1에서 전류 방향으로 이동 → V_Q = 5 − (1mA)(2k) = **3 V**
- 검산: Q→S는 E2를 +에서 −로 지나므로 V_S = 3 − 4 = −1 V, S→G는 R2 통과 V_G = −1 − 6 = −7 V. 처음 조건 V_G = V_P − 12 = −7 V와 일치 ✓

**(c) 중첩의 원리** (기준 G, 구하는 것은 V_Q − V_G)
- E1만(E2 단락): I₁ = 12/8k = 1.5 mA. Q→(단락)→S→R2→G 경로이므로 V_Q−V_G = I₁·R2 = 9 V
- E2만(E1 단락): I₂ = 4/8k = 0.5 mA. 전류는 Q의 +단자에서 나와 R1→P→(단락)→G로 흐르므로 V_Q−V_G = I₂·R1 = 1 V
- 합: V_Q − V_G = 10 V → V_G = −7 V 이므로 **V_Q = 3 V** ✓ ((b)와 동일)

## 문제 2 해설

**(a)** 개방 상태 (기준 GND)
- V_A = 12 · 6/(2+6) = 9 V, V_B = 12 · 3/(6+3) = 4 V
- **V_th = V_A − V_B = 5 V**
- 전원 단락: R_th = (2k‖6k) + (6k‖3k) = 1.5k + 2k = **3.5 kΩ**

**(b)** I5 = 5V / (3.5k + 6.5k) = **0.5 mA** (A→B), V_AB = 0.5mA × 6.5k = **3.25 V**
- 검산(노드 해석 수치 확인): V_A = 8.25 V, V_B = 5 V → V_AB = 3.25 V ✓

**(c)** R5 = 1.5k: I5 = 5 / (3.5k+1.5k) = **1 mA**, V_AB = 1.5 V (노드 해석: V_A=7.5, V_B=6 ✓).
테브닌 등가는 한 번만 구하면 되고, R5가 바뀔 때는 I = V_th/(R_th+R5)만 다시 계산합니다. 노드 해석은 R5가 바뀔 때마다 2×2 연립식을 새로 풀어야 합니다. (R5=13k이면 I = 5/16.5k = 10/33 mA ≈ 0.303 mA)

**(d) 검산:** A-B 단락 시 I_sc = 5V/3.5k ≈ 1.4286 mA (노드 해석 단락 계산과 일치), R_th = 5 / 1.4286m = 3.5 kΩ ✓

## 문제 3 해설

**테브닌 단계별 적용**
| 단계 | 구하는 것 | V_th | R_th |
|---|---|---|---|
| N1 (A단) | 36V를 R1=9k, R2=18k로 분압 | 36·18/27 = **24 V** | 9k‖18k = **6 kΩ** |
| N2 (B단) | (24V, 6k)에 R3=6k 직렬, R4=12k 분압 | 24·12/(12+12) = **12 V** | (6k+6k)‖12k = **6 kΩ** |
| N3 (C단) | (12V, 6k)에 R5=6k 직렬, R6=6k 분압 | 12·6/(12+6) = **4 V** | 12k‖6k = **4 kΩ** |

N3 계산: 직렬 합 6k+6k = 12k에 R6=6k를 분압합니다.

**(a)** R_in(B) = R3 + R4‖(R5+R6) = 6k + 12k‖12k = 6k + 6k = **12 kΩ**
**(b)** R_out(B) = (R1‖R2 + R3)‖R4 = (6k+6k)‖12k = **6 kΩ** (위 표 N2의 R_th)
**(c)** **V_out = 4 V** (출력저항 4 kΩ)
**(d)** 순진한 값: 36 × (18/27) × (12/18) × (6/12) = 36 × 2/3 × 2/3 × 1/2 = **8 V**. 오차 = 8 − 4 = 4 V (순진한 값이 정확한 값의 **2배, +100 %**). 이유: 뒤 단이 앞 단 분압기의 아랫저항에 병렬로 걸려 전압을 끌어내리는데 이를 무시했기 때문입니다.
**(e)** R_L = 4k: V = 4 · 4/(4+4) = **2 V**. 출력저항과 부하가 같으면 전압이 절반이 됩니다.

**검산(전체 노드 해석)**: V_N1 = 16 V, V_N2 = 8 V, V_out = 4 V. 이는 단계별 값(24V·12V는 개방 등가 전압)과 다르지만, 실제 회로의 노드 전압이며 V_out이 4V로 일치합니다. 확인: N2→N3 전류 (8−4)/6k = 2/3 mA, R6 전류 4/6k = 2/3 mA ✓; N1→N2 전류 (16−8)/6k = 4/3 mA = R4 전류 8/12k (2/3) + 2/3 ✓. 부하 연결 시 노드 해석 결과 V_out = 2 V ✓.
