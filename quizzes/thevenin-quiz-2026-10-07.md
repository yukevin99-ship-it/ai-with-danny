# ⚡ 테브닌·분압·중첩 회로 퀴즈 (2026-10-07)

> 공통 주제: 전압원과 저항이 직렬·병렬로 얽혀 복잡해 보이지만, **테브닌 정리 · 분압 법칙 · 중첩의 원리**를 쓰면 간단히 풀리는 회로.
> 단위 팁: V ÷ kΩ = mA 입니다.

---

## 🟢 문제 1 (초급) — 두 전원이 마주 보는 단일 루프

전압원 2개와 저항 2개가 하나의 루프를 이룹니다. 접지 기준을 잡았더니 노드 P(= D)의 전위가 **V_P = +2 V** 였습니다.

```
            A ───────── R1 = 2 kΩ ──────────► B  (= Q)
            │        (전류 I 방향 →)           │
         ┌──┴──┐                            ┌──┴──┐
         │ V1  │ 15 V                       │ V2  │ 6 V
         │ +   │ (위쪽이 +)                  │ +   │ (위쪽이 +)
         │ −   │                            │ −   │
         └──┬──┘                            └──┬──┘
            │                                  │
   P (= D) ─┴──────── R2 = 1 kΩ ◄──────────────┘ C
          V_P = 2 V     (전류 I 방향 ←)
```

(루프 전류 I는 시계 방향 D→A→B→C→D 를 양(+)으로 가정)

1. 루프 전류 I를 구하시오.
2. 노드 Q(= B)의 전위 V_Q를 구하시오. **(풀이 ① KVL 전위 추적, 풀이 ② 중첩의 원리, 두 가지로)**

🔑 **핵심 개념:** 전위는 "한 점의 값이 주어지면 소자를 하나씩 건널 때마다 전원은 ±V, 저항은 −IR(전류 방향으로 건널 때)만큼 더하고 빼며 따라가는 것"입니다. 또 중첩의 원리는 전원을 하나씩 켜(나머지 전압원은 단락) 구한 응답을 더하는 것이라, 두 전원이 서로 반대 방향으로 밀어도 각자 효과를 따로 계산해 합치면 됩니다.

## 🟡 문제 2 (중급) — 불평형 브리지와 테브닌 정리

18 V 전압원에 분압기 두 갈래가 붙고, 두 중간 노드 A, B 사이를 R5가 잇습니다.

```
                 +18 V
                   │
          ┌────────┴────────┐
          │                 │
        R1 = 6 kΩ        R3 = 12 kΩ
          │                 │
          ●── A     R5      ● B
          │  ├────/\/\/────┤     (R5 = 10 kΩ, 전류 I : A → B)
        R2 = 3 kΩ        R4 = 4 kΩ
          │                 │
          └────────┬────────┘
                  GND (0 V)
```

1. R5를 떼어 낸 개방 상태에서 A, B 노드의 전압과 **V_th = V_A − V_B** 를 구하시오.
2. 전원을 단락했을 때 A-B 단자에서 본 **R_th** 를 구하시오.
3. 테브닌 등가회로로 R5(= 10 kΩ)에 흐르는 전류 I와 V_AB(R5 양단 전압)를 구하시오.
4. (추가) R5를 **5 kΩ, 25 kΩ, 0 Ω(단락)** 으로 바꿨을 때의 전류를 각각 구하시오. 이때 다시 처음부터 풀 필요가 있는가?
5. (검산) 단락전류 I_sc로 R_th를 다시 구하시오.

🔑 **핵심 개념:** 브리지는 R5 때문에 R1~R4가 "직·병렬이 아닌" 모양이 되지만, **R5를 떼고 A-B 단자만 바라보면** 두 분압기가 각각 독립된 전압원(분압 법칙)과 내부저항(R1‖R2, R3‖R4)이 됩니다. 이를 하나의 (V_th, R_th)로 묶으면 R5가 무엇이든 I = V_th/(R_th+R5) 한 줄로 끝나므로, 노드 해석(R5마다 2원 연립식)보다 R5를 바꿔 가며 계산할 때 훨씬 유리합니다.

## 🔴 문제 3 (고급) — 3단 분압기 (A → B → C) 의 부하 효과

입력 36 V를 3단 분압기에 넣었습니다. 각 단은 (직렬 저항, 병렬 저항) 한 쌍입니다. 출력 V_out은 마지막 R6 양단 전압(개방)입니다.

```
        R1 = 6k        R3 = 2k        R5 = 2k
 Vin ──/\/\/──●1──────/\/\/──●2──────/\/\/──●out
 36 V          │               │               │
             R2 = 12k       R4 = 3k         R6 = 4k
               │               │               │
 GND ──────────┴───────────────┴───────────────┴──
       └──── A단 ────┘└──── B단 ────┘└──── C단 ────┘
```

1. **B단의 입력저항 R_in(B)** (뒤 단 C의 부하 포함, 노드 1에서 B단 쪽을 들여다본 저항)을 구하시오.
2. **B단 출력(노드 2)에서 앞쪽을 본 R_out(B)** 를 구하시오.
3. 각 단에 테브닌 정리를 **단계별로** 적용해 (V_th, R_th)를 구하고, 정확한 **V_out** 을 구하시오.
4. 부하 효과를 무시하고 각 단 분압비만 곱한 **순진한 값**을 구하고, 정확값과의 오차(%)를 구하시오.
5. (보너스) 출력에 R_L = 2 kΩ 을 달았을 때의 출력 전압을 구하시오.
6. (검산) 뒤에서 앞으로(R_in 직렬 환산 → 입력 전류 → 분압) 노드 전압 V1, V2, V_out을 구해 3번과 비교하시오.

🔑 **핵심 개념:** 분압비 R2/(R1+R2)는 **무부하일 때만** 맞습니다. 다음 단이 병렬로 달리면 그 단의 R_in이 R2와 병렬이 되어 분압비가 바뀝니다(부하 효과). 테브닌 정리는 "앞쪽 전체를 (V_th, R_th) 하나로 접어 → 다음 단의 직렬 저항에 R_th를 더하고 → 분압 → 다시 접는" 과정을 반복해, 부하 효과를 연립식 없이 단별 분압 한 번씩으로 정확히 처리합니다.

# 📘 정답 및 해설 (교수용)

## 문제 1 해설

**1) 루프 전류.** 시계 방향 KVL: +15 − 2·I − 6 − 1·I = 0 → 3I = 9 → **I = 3 mA** (시계 방향, 양수이므로 가정과 일치).

**2) V_Q = V_B**

**풀이 ① KVL 전위 추적** (D에서 출발, V_D = 2 V)
- D → A (V1을 − → +로 건넘): 2 + 15 = 17 V
- A → B (R1을 전류 방향으로 건넘): 17 − 3 mA·2 kΩ = 17 − 6 = **11 V**
- 반대 경로로 검산: D → C (R2: 전류가 C→D로 흐르므로 C가 D보다 3 mA·1 kΩ = 3 V 높음) = 5 V, C → B (V2의 − → +) 5 + 6 = **11 V** ✓

**풀이 ② 중첩의 원리** (기준 V_D = 2 V, 구할 값 V_B − V_D)
- V1만 켬(V2 단락, B와 C가 같은 점): I₁ = 15/(2+1) = 5 mA. V_B − V_D = V_C − V_D = 5 mA·1 kΩ = **+5 V**
- V2만 켬(V1 단락, A와 D가 같은 점): I₂ = 6/(2+1) = 2 mA (반시계). V_B − V_D = V_B − V_A = 2 mA·2 kΩ = **+4 V**
- 합: 5 + 4 = 9 V → V_B = 2 + 9 = **11 V** ✓ (두 방향 전류 5 − 2 = 3 mA 도 I와 일치)

> **답: I = 3 mA, V_Q = 11 V**

## 문제 2 해설

**1) 개방 전압**
- V_A = 18 · 3/(6+3) = **6 V**
- V_B = 18 · 4/(12+4) = **4.5 V**
- V_th = 6 − 4.5 = **1.5 V** (A가 높음)

**2) R_th** (18 V 단락 → 위쪽 노드가 GND)
- R_th = (6 ‖ 3) + (12 ‖ 4) = 2 + 3 = **5 kΩ**

**3) R5 = 10 kΩ**
- I = 1.5 V / (5k + 10k) = **0.1 mA** (A → B)
- V_AB = I·R5 = **1 V** (= V_th·R5/(R_th+R5) = 1.5·10/15 ✓)

**4) R5 변경** (V_th, R_th는 그대로 → 나눗셈 한 번)

| R5 | I = 1.5 V /(5k+R5) |
|---|---|
| 5 kΩ | 0.15 mA |
| 10 kΩ | 0.10 mA |
| 25 kΩ | 0.05 mA |
| 0 Ω | 0.30 mA |

→ 다시 풀 필요 없음. 노드 해석은 R5가 바뀔 때마다 2원 연립방정식을 새로 풀어야 합니다.

**5) 검산 (I_sc)**: A-B를 단락하면 하나의 노드 V에 대해 (18−V)/6 + (18−V)/12 = V/3 + V/4 → 54 = 10V → V = 5.4 V. A쪽 가지: (18−5.4)/6 − 5.4/3 = 2.1 − 1.8 = **0.3 mA** = I_sc. R_th = V_th / I_sc = 1.5/0.3 = **5 kΩ** ✓
또한 노드 해석 결과(V_A = 5.8 V, V_B = 4.8 V, R5 = 10k)에서 I = 1 V/10k = 0.1 mA ✓ (Python 정확 분수 계산으로 확인).

> **답: V_th = 1.5 V, R_th = 5 kΩ, I = 0.1 mA, V_AB = 1 V**

## 문제 3 해설

**1) R_in(B)**: C단 입력저항 = R5 + R6 = 6 kΩ. 노드 2의 부하 = R4 ‖ 6k = 3‖6 = 2 kΩ.
R_in(B) = R3 + 2k = 2 + 2 = **4 kΩ**

**2) R_out(B)** (전원 단락, 노드 2에서 앞쪽): 먼저 A단 R_th(A) = R1 ‖ R2 = 6‖12 = 4 kΩ. 여기에 R3를 직렬로 → 6 kΩ, R4와 병렬 → R_out(B) = 6 ‖ 3 = **2 kΩ**

**3) 단계별 테브닌**

| 단 | 앞 단 등가에 직렬 저항을 더함 | V_th | R_th |
|---|---|---|---|
| A | (Vin 36 V, 0 Ω) + R1 = 6k, 병렬 R2 = 12k | 36·12/18 = **24 V** | 6‖12 = **4 kΩ** |
| B | (24 V, 4k) + R3 → 6k, 병렬 R4 = 3k | 24·3/9 = **8 V** | 6‖3 = **2 kΩ** |
| C | (8 V, 2k) + R5 → 4k, 병렬 R6 = 4k | 8·4/8 = **4 V** | 4‖4 = **2 kΩ** |

> **V_out = 4 V** (개방), 출력 테브닌 등가 = 4 V / 2 kΩ

**4) 순진한 값**: 36 × (12/18) × (3/5) × (4/6) = 36 × 4/15 = **9.6 V**
오차 = (9.6 − 4)/4 = **+140 %** (순진한 값이 정확값의 2.4배). 이유: 각 단이 뒤 단의 R_in을 병렬 부하로 받아 분압비가 줄어드는데 이를 무시했기 때문.

**5) 보너스 R_L = 2 kΩ**: V = 4 · 2/(2+2) = **2 V** (R_L = R_out 이므로 정합, 전압은 절반, I_L = 1 mA).
(R_L = 6 kΩ 이면 4·6/8 = 3 V.)

**6) 검산 (뒤→앞)**
- R_in(A) = R1 + R2 ‖ R_in(B) = 6 + 12‖4 = 6 + 3 = 9 kΩ → 입력 전류 = 36/9 = 4 mA
- V1 = 36 − 4 mA·6k = **12 V**
- V2 = V1 · (R4‖6k)/(R3 + R4‖6k) = 12 · 2/4 = **6 V**
- V_out = V2 · R6/(R5+R6) = 6 · 4/6 = **4 V** ✓
- 참고: 노드 2에서 개방 테브닌 8 V를 C단이 6k로 받으면 8·6/(2+6) = 6 V ✓ (V2와 일치)
- Python 정확 분수 노드 해석: (V1, V2, V_out) = (12, 6, 4) V, R_L = 2k 일 때 V_out = 2 V ✓

> **답: R_in(B) = 4 kΩ, R_out(B) = 2 kΩ, V_out = 4 V (등가 4 V/2 kΩ), 순진한 값 9.6 V(+140 %), R_L = 2 kΩ 연결 시 2 V**
