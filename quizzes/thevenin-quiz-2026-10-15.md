# ⚡ 회로 퀴즈: 테브닌 정리 · 분압 법칙 · 중첩의 원리 (2026-10-15)

> 전압원과 저항이 얽혀 복잡해 보여도, **등가회로로 바꾸면** 한두 줄로 풀립니다. 모든 전위는 접지(GND) 기준이며, 저항 단위는 kΩ, 전류 단위는 mA, 전압 단위는 V입니다 (kΩ × mA = V).

---

## 🟢 문제 1 (초급) — 두 전원이 있는 단일 루프

```
        A ──────[ R1 = 3kΩ ]────── B
        │   I →  (A에서 B로 흐른다고 가정)   │
     (+)│                                   │(+)
    ┌───┴───┐                         ┌─────┴────┐
    │ E1=15V│                         │  E2 = 6V │
    └───┬───┘                         └─────┬────┘
     (−)│                                   │(−)
        D ──────[ R2 = 6kΩ ]────── C
        ▲
        P (= D 노드, V_P = +2 V)        Q (= B 노드, 구하려는 점)
```

- E1: 15V, **+ 단자가 위(A)**.  E2: 6V, **+ 단자가 위(B)**.
- 노드 D를 P라 하고 그 전위는 **V_P = +2 V** 입니다. 노드 B를 Q라 합니다.

**문제**
1. 루프 전류 I(mA)의 크기와 방향을 구하시오.
2. Q점(노드 B)의 전위 V_Q를 구하시오.
3. KVL 전위 추적법과 중첩의 원리, 두 방법으로 V_Q를 각각 구하시오.

🔑 **핵심 개념:** 전위는 "기준점 값 + 경로상의 전압 상승/강하의 합"이다. P가 0V가 아니어도 **P~Q 사이의 전위차(V_Q − V_P)는 회로가 정하고**, 절대 전위는 거기에 V_P=2V를 그대로 더하면 된다. 두 전원이 서로 반대 방향이라 순 기전력이 15−6=9V로 줄어드는 점과, 중첩에서 전원을 하나씩 죽여(단락) 전류가 서로 반대로 흐르는 점이 적용 포인트이다.

## 🟡 문제 2 (중급) — 불평형 브리지와 테브닌 정리

```
                    + 12V (Vs)
                       │
              ┌────────┴────────┐
              │                 │
         [ R1 = 3kΩ ]      [ R3 = 6kΩ ]
              │                 │
              A ───[ R5 = 1.5kΩ ]─── B
              │   I5 →(A→B 방향)    │
         [ R2 = 6kΩ ]      [ R4 = 2kΩ ]
              │                 │
              └────────┬────────┘
                      GND (0V)
```

- 전압원 Vs = 12V (+ 위, 아래는 GND). 왼쪽 분압기 R1/R2, 오른쪽 분압기 R3/R4, 가운데 노드 A–B를 R5가 잇는다.

**문제**
1. R5를 떼어낸 A–B 단자에서 본 테브닌 등가 V_th(= V_A − V_B)와 R_th를 구하시오.
2. R5 = 1.5kΩ일 때 R5를 흐르는 전류 I5와 V_AB를 구하시오.
3. (추가) R5를 **6.5kΩ**과 **0.5kΩ**으로 바꾸면 전류는 각각 얼마인가? 그리고 이때 노드·메시 해석을 처음부터 다시 했다면 연립식이 몇 개 필요했을지 비교하시오.

🔑 **핵심 개념:** 테브닌 정리 — R5를 "부하"로 보고 나머지 회로를 (V_th, R_th) 하나로 압축한다. 각 분압기 출력은 분압 법칙으로 V_A = 12·6/(3+6), V_B = 12·2/(6+2)이고, 전원이 단락으로 바뀌면 각 분압기의 R_th는 R1∥R2, R3∥R4가 되어 직렬로 합쳐진다(두 분압기는 GND에서 만나므로 A와 B 사이 경로는 R_A + R_B). 한 번 구한 (V_th, R_th)에 부하만 바꿔 I = V_th/(R_th+R5)로 대입하면 되므로 부하가 바뀌어도 연립식을 다시 풀지 않는다.

## 🔴 문제 3 (고급) — 3단 분압기와 부하 효과

```
 Vin=48V      [A단]                 [B단]                 [C단]
                           
 (+)─┬─[ Ra1 = 4kΩ ]──●N1──[ Rb1 = 3kΩ ]──●N2──[ Rc1 = 3kΩ ]──●N3 ── Vout
     │               │                  │                  │       (+)
 48V │          [ Ra2 = 12kΩ ]      [ Rb2 = 6kΩ ]      [ Rc2 = 3kΩ ]   │
     │               │                  │                  │      [RL=2kΩ]*
 (−)─┴───────────────┴──────────────────┴──────────────────┴─────────GND

   * RL은 3번째 소문제(보너스)에서만 연결
```

- 각 단은 "직렬 저항 1개 + 병렬(션트) 저항 1개"인 분압기이고, 뒤 단이 앞 단의 부하가 된다.
- Vin = 48V, A: 4k/12k, B: 3k/6k, C: 3k/3k.
- "B단의 입력"은 노드 N1(= Rb1 왼쪽), "B단의 출력"은 노드 N2이다.

**문제**
1. 뒤 단(C단) 부하를 포함한 **B단의 입력저항 R_in(B)** 를 구하시오.
2. B단 출력(N2)에서 전원 쪽을 본 **R_out(B)** 를 구하시오 (Vin 단락).
3. 테브닌 등가를 A→B→C 순서로 단계별 적용하여 **정확한 V_out** 을 구하시오.
4. 각 단 분압비만 곱한 **순진한 값**을 구하고 정확한 값과의 **오차(V, %)** 를 구하시오.
5. (보너스) 출력에 R_L = 2kΩ을 달았을 때의 출력 전압을 구하시오.

🔑 **핵심 개념:** 각 단에서 "지금까지의 전원+저항"을 (V_th, R_th) 하나로 바꾼 뒤, 그 R_th를 다음 단의 직렬 저항에 **더해서** 다시 분압한다. 즉 단 하나의 분압비가 아니라 V_th' = V_th·R_shunt/(R_th+R_series+R_shunt), R_th' = (R_th+R_series)∥R_shunt 를 반복 적용한다. 뒤 단이 앞 단의 션트 저항과 병렬로 붙어 전압을 끌어내리는 것(부하 효과) 때문에 분압비의 곱은 틀리고, 이를 R_in으로 정량화한다.

# 📘 정답 및 해설 (교수용)

## 문제 1 해설 — 정답: I = 1 mA (A→B→C→D 시계 방향), **V_Q = 14 V**

**① KVL 전위 추적 (D에서 시작)**
- 루프 방향을 D→A→B→C→D(시계 방향)로 잡는다. E1은 D→A로 지나며 +15V 상승, E2는 B→C로 지나며 −6V 하강.
- 순 기전력 = 15 − 6 = 9V, 총 저항 = 3k + 6k = 9k → **I = 9V/9kΩ = 1 mA** (양수이므로 시계 방향).
- V_D = 2V (주어짐)
- V_A = V_D + 15 = **17 V** (E1 상승)
- V_B = V_A − (3k)(1mA) = 17 − 3 = **14 V** → **V_Q = 14 V**
- 폐루프 확인: V_C = V_B − 6(E2 양단) = 8 V, R2 강하 6k×1mA = 6 V → V_D = 8 − 6 = 2 V ✓ (주어진 V_P와 일치)

**② 중첩의 원리 (P를 기준으로 V_Q − V_P 계산)**
- E1만 (E2 단락): I = 15/9k = 5/3 mA(시계). V_Q − V_P = 15 − 3k·(5/3mA) = 15 − 5 = **10 V**
- E2만 (E1 단락): I = 6/9k = 2/3 mA(반시계, B→A→D→C). R1 강하 2V이므로 V_B − V_D = 2 **V** (검산: 6 − R2 강하 4V = 2V ✓)
- 합: V_Q − V_P = 10 + 2 = 12 V → **V_Q = 2 + 12 = 14 V** ✓ (두 방법 일치)

**③ 해설 포인트**
- V_P가 0이 아니어도 풀이가 같다: "전위차는 회로가, 기준값은 문제가 정한다."
- 흔한 실수: E2의 방향을 무시하고 15+6=21V로 합산 → 방향을 반드시 확인.

## 문제 2 해설 — 정답: V_th = 5 V, R_th = 3.5 kΩ, **I5 = 1 mA, V_AB = 1.5 V**

**① 테브닌 등가 (R5 제거)**
- V_A = 12 × 6/(3+6) = 8 V,  V_B = 12 × 2/(6+2) = 3 V → **V_th = V_A − V_B = 5 V**
- Vs 단락: R_A = 3k∥6k = 2k, R_B = 6k∥2k = 1.5k → **R_th = 2 + 1.5 = 3.5 kΩ**
- 검산(단락전류법): A–B를 단락하면 A=B=V₀. 노드식 (V₀−12)/3 + V₀/6 + (V₀−12)/6 + V₀/2 = 0 → 7V₀ = 36 → V₀ = 36/7 V. 단락선으로 A→B 흐르는 전류 I_sc = (12−V₀)/3 − V₀/6 = 16/7 − 6/7 = 10/7 mA. R_th = V_th/I_sc = 5/(10/7) = **3.5 kΩ** ✓

**② R5 = 1.5 kΩ**
- I5 = V_th/(R_th + R5) = 5/(3.5+1.5) = **1 mA** (A→B), V_AB = 1 × 1.5 = **1.5 V**
- 노드 해석 검산: 7V_A − 4V_B = 24, 2V_B − V_A = 3 → V_A = 6V, V_B = 4.5V → V_AB = 1.5V, I5 = 1.5/1.5 = 1 mA ✓

**③ 부하 변경 (추가 질문)**
| R5 | I5 = 5/(3.5+R5) | V_AB |
|---|---|---|
| 0.5 kΩ | 1.25 mA | 0.625 V |
| 1.5 kΩ | 1 mA | 1.5 V |
| 6.5 kΩ | 0.5 mA | 3.25 V |

- 노드 해석이면 값을 바꿀 때마다 2×2 연립식을 **다시** 풀어야 하지만(풀이 3회 = 연립식 3세트), 테브닌은 (V_th, R_th)를 **한 번** 구해 두고 나눗셈 한 줄로 끝난다. 부하가 여러 번 바뀌는 설계 문제일수록 이점이 커진다.

## 문제 3 해설 — 정답: R_in(B) = 6 kΩ, R_out(B) = 3 kΩ, **V_out = 6 V**, 순진한 값 12 V(오차 +6 V, 100%), R_L=2kΩ → 3 V

**① 단계별 테브닌**
| 단 | 계산 | V_th | R_th |
|---|---|---|---|
| A | 48 × 12/(4+12), 4k∥12k | 36 V | 3 kΩ |
| B | 36 × 6/(3+3+6), (3+3)k∥6k | 18 V | 3 kΩ |
| C | 18 × 3/(3+3+3), (3+3)k∥3k | 6 V | 2 kΩ |

- **V_out = 6 V** (무부하), 출력에서 본 R_th = 2kΩ.

**② R_in(B)**
- C단 입력저항 R_in(C) = 3k + 3k = 6k
- B단 션트 6k ∥ 6k = 3k → **R_in(B) = Rb1 + 3k = 3 + 3 = 6 kΩ**

**③ R_out(B)**
- Vin 단락 → A단 R_th = 4k∥12k = 3k. B단 출력에서: (3k + 3k)∥6k = **3 kΩ** (표의 B행 R_th와 일치)

**④ 순진한 값과 오차**
- 분압비 곱: 12/16 × 6/9 × 3/6 = 3/4 × 2/3 × 1/2 = 1/4 → 48 × 1/4 = **12 V**
- 정확한 값 6V와의 오차 = 6V (순진한 값이 정확한 값의 2배, +100%).
- 이유: 각 단의 분압비는 뒤 단이 "없다"고 가정한 값이다. 실제로는 뒤 단이 션트 저항과 병렬로 붙어 전압이 떨어진다.

**⑤ 보너스: R_L = 2kΩ**
- 출력의 테브닌 등가가 (6V, 2kΩ)이므로 분압 → V = 6 × 2/(2+2) = **3 V**
- 노드 해석 검산: N1=24V, N2=12V, N3=6V (무부하), 부하 시 N3=3V, N2=10.5V, N1=23.25V (유리수 연립 풀이 결과) ✓. 또한 무부하 노드 전압 N1=24V일 때 B단 입력전류 (24−12)/3k = 4mA → R_in = 24/4 = **6 kΩ** ✓

**⑥ 해설 포인트**
- 테브닌 등가 한 단씩 "압축"하면 3단 회로가 3번의 분압 계산으로 끝난다(노드 3개 연립을 회피).
- R_in(B)=6k는 단독 분압기라면 9k(3+6)이었을 값이 부하(C단)로 6k로 낮아졌음을 보여 준다 → 부하 효과의 정량화.
- 흔한 실수: R_th를 더할 때 "직렬 저항에 더한 뒤 션트와 병렬"의 순서를 틀리는 경우.
