# ⚡ 회로 퀴즈: 테브닌 · 분압 · 중첩 (2026-10-22)

> 공통 주제: 전압원과 저항이 직렬·병렬로 얽혀 복잡해 보이지만, **테브닌 정리 / 분압 법칙 / 중첩의 원리**를 쓰면 간단히 풀리는 회로.
> 모든 저항 단위는 kΩ, 전류는 mA 기준 (kΩ × mA = V).

---

## 🟢 문제 1 (초급) — 두 전원이 있는 단일 루프

```
         M ────────[ R1 = 2kΩ ]──────── Q
         │   →I(시계방향 가정)          │
       (+)                            (+)  ↑
   V1 = 12V                        V2 = 6V
       (−)                            (−)
         │                              │
         P ────────[ R2 = 4kΩ ]──────── T
        (V_P = +3V, 기준점 대비)
```

- V1: + 단자가 위(M쪽), 12V
- V2: + 단자가 위(Q쪽), 6V
- P점의 전위는 기준점 대비 **V_P = +3V** 로 주어져 있다.

**(1)** 루프 전류 I 의 크기와 방향을 구하시오.
**(2)** Q점의 전위 V_Q 를 구하시오.
**(3)** KVL 경로 추적과 중첩의 원리, 두 방법으로 풀어 보시오.

🔑 **핵심 개념:** 중첩의 원리 + KVL 전위 추적. 소자를 하나씩 건널 때 전원은 +에서 −로 가면 내려가고(−에서 +로 가면 올라가고), 저항은 전류 방향으로 가면 IR 만큼 내려간다. 중첩에서는 "V2 단락" 상태의 V1 기여분(+8V)과 "V1 단락" 상태의 V2 기여분(+2V)을 따로 구해 더하면 P 대비 Q 의 전위차(10V)가 되며, 여기에 주어진 V_P=3V 를 더해 V_Q 를 얻는다.

## 🟡 문제 2 (중급) — 불평형 브리지와 테브닌 등가

```
              Vs = 12V (+ 위)
        ┌──────────┴──────────┐
        │                     │
     [R1=3kΩ]              [R3=6kΩ]
        │                     │
        A ───→ I ──[R5=6.5kΩ]── B
        │                     │
     [R2=6kΩ]              [R4=2kΩ]
        │                     │
        └──────────┬──────────┘
                  GND (0V)
```

- 전압원 12V(+가 위), 왼쪽 분압기 R1/R2, 오른쪽 분압기 R3/R4, 브리지 저항 R5 가 A–B 사이에 연결.
- I 는 R5 에서 A→B 방향을 양(+)으로 한다. V_AB = V_A − V_B.

**(1)** R5 를 떼어 낸 상태에서 A–B 단자의 테브닌 등가 (V_th, R_th) 를 구하시오.
**(2)** R5 = 6.5kΩ 일 때 R5 의 전류 I 와 V_AB 를 구하시오.
**(3)** R5 를 1.5kΩ 으로 바꾸면 I 는? 단자를 단락했을 때 전류 I_sc 는? (노드·메시 해석과 비교해 테브닌의 장점을 한 줄로 쓰시오.)

🔑 **핵심 개념:** 테브닌 정리 + 분압 법칙. R5 를 "부하"로 보고 떼어 내면 회로는 두 개의 독립 분압기가 되어 V_A, V_B 가 분압 공식 한 줄로 나오고, V_th = V_A − V_B, R_th 는 전원을 단락했을 때 각 분압기의 병렬 저항(R1∥R2 와 R3∥R4)의 직렬합이다. R5 가 바뀌어도 (V_th, R_th) 는 그대로이므로 I = V_th/(R_th+R5) 만 다시 계산하면 된다.

## 🔴 문제 3 (고급) — 3단 분압기의 부하 효과

```
 Vin=48V(+)   R_A1=4kΩ     n1     R_B1=3kΩ     n2     R_C1=3kΩ     n3 = Vout
  o──────────[████]───────┬──────[████]───────┬──────[████]───────┬────o
  (+)                      │                    │                    │
                         [R_A2=12kΩ]          [R_B2=6kΩ]          [R_C2=3kΩ]
  (−)                      │                    │                    │ (선택: R_L)
  o────────────────────────┴────────────────────┴────────────────────┴────o
 GND
        ├──── A단 ────┤    ├──── B단 ────┤     ├──── C단 ────┤
```

- 각 단: 직렬 저항(위) + 병렬(션트) 저항(아래). 노드 n1, n2, n3 = V_out.
- 출력은 처음에 무부하(open).

**(1)** B단의 입력저항 R_in(B) (B단의 직렬 저항 R_B1 부터 뒤 단 C 의 부하까지 포함)을 구하시오.
**(2)** B단 출력(n2)에서 소스 쪽을 본 테브닌 등가 (V_th,B, R_out,B) 를 구하시오.
**(3)** A→B→C 단계별 테브닌 등가를 적용해 정확한 V_out 을 구하시오.
**(4)** 부하 효과를 무시하고 각 단의 무부하 분압비만 곱한 "순진한 값"을 구하고, 정확한 값과의 오차를 구하시오.
**(5)** (보너스) 출력에 R_L = 4kΩ 을 달았을 때 V_out 은?

🔑 **핵심 개념:** 테브닌 등가의 단계적(캐스케이드) 적용 + 부하 효과. 한 단의 (V_th, R_th) 는 다음 단에 "내부저항이 있는 전원"으로 들어가므로, 뒤 단이 앞 단을 끌어내려(R_in 이 유한) 단순 분압비 곱이 틀린다. 앞 단의 R_th 가 다음 단의 직렬 저항에 더해져 분압비가 바뀌는 것이 핵심이다.

# 📘 정답 및 해설 (교수용)

## 문제 1 해설

**정답:** I = 1mA (시계방향: M→Q→T→P), **V_Q = 13V**

**풀이 A — KVL 전위 추적**
- 시계방향 합성 기전력: V1 은 P→M 으로 오르며 +12V, V2 는 Q→T 로 + 에서 − 로 내려가며 −6V → 순 기전력 6V.
- I = 6V / (2k+4k) = **1mA**
- V_M = V_P + 12 = 15V
- V_Q = V_M − I·R1 = 15 − 1·2 = **13V**
- (참고) V_T = V_Q − 6 = 7V, V_P = V_T − I·R2 = 7 − 4 = 3V ✓ (루프 일관성 확인)

**풀이 B — 중첩의 원리 (V_P 를 기준으로 한 V_Q − V_P)**
- V1 만 (V2 단락): I₁ = 12/6k = 2mA (시계방향). 경로 P→M→Q: 12 − 2·2 = **+8V**
- V2 만 (V1 단락): I₂ = 6/6k = 1mA (반시계방향, Q→M→P→T). 이때 R1 에서 Q→M 으로 전류가 흐르므로 V_Q = V_M + I₂R1 = V_P + 2 → **+2V**
- 합: V_Q − V_P = 8 + 2 = 10V → V_Q = 3 + 10 = **13V** ✓

**검산 요약:** 두 방법 모두 13V. (Python 분수 계산으로도 확인)

## 문제 2 해설

**정답:** V_th = 5V, R_th = 3.5kΩ, I = 0.5mA, V_AB = 3.25V / R5=1.5k 일 때 I = 1mA / I_sc ≈ 1.43mA

**(1) 테브닌 등가 (R5 제거)**
- V_A = 12 · 6/(3+6) = **8V**, V_B = 12 · 2/(6+2) = **3V**
- V_th = V_A − V_B = **5V**
- R_th: 전원 단락 → (3k∥6k) + (6k∥2k) = 2k + 1.5k = **3.5kΩ**

**(2) R5 = 6.5kΩ**
- I = 5 / (3.5 + 6.5) = **0.5mA** (A→B)
- V_AB(R5 양단) = 0.5 × 6.5 = **3.25V**

**(3) R5 = 1.5kΩ**
- I = 5 / (3.5 + 1.5) = **1mA**, V_AB = 1.5V
- I_sc = V_th/R_th = 5/3.5 ≈ **1.43mA**

**테브닌의 장점:** 노드 해석은 A, B 두 노드의 연립 2원 1차식을 풀어야 하고 R5 가 바뀔 때마다 다시 풀어야 하지만, 테브닌은 (V_th, R_th) 를 한 번만 구하면 이후 R5 가 바뀔 때마다 한 줄 계산이면 된다.

**검산 (노드 해석, 정확 분수 계산):** R5=6.5k → V_A=7V, V_B=3.75V, V_AB=3.25V, I=0.5mA ✓. R5=1.5k → V_A=6V, V_B=4.5V, I=1mA ✓.
**검산 (V_th/I_sc):** A–B 를 단락한 노드 해석 값 I_sc = 1.4286mA = 5/3.5 ✓.

## 문제 3 해설

**정답:** R_in(B) = 6kΩ, (V_th,B, R_out,B) = (18V, 3kΩ), **V_out = 6V**, 순진한 값 12V (오차 +6V, 정확값의 100%), R_L=4kΩ 일 때 **4V**

**단계별 테브닌**
| 단 | 계산 | V_th | R_th |
|---|---|---|---|
| A | 48·12/(4+12), 4k∥12k | 36V | 3kΩ |
| B | 36·6/(3+3+6), (3+3)∥6 | 18V | 3kΩ |
| C | 18·3/(3+3+3), (3+3)∥3 | **6V** | 2kΩ |

**(1) R_in(B)** = R_B1 + R_B2 ∥ (R_C1 + R_C2) = 3 + 6∥6 = 3 + 3 = **6kΩ** (순수히 B단 션트만 보면 안 되고 뒤 단 부하 6kΩ 이 병렬로 들어간다)

**(2) B단 출력에서 본 등가:** V_th,B = 18V, R_out,B = (R_th,A + R_B1) ∥ R_B2 = 6∥6 = **3kΩ**

**(3) 정확한 V_out:** C단 테브닌: V_out = 18 · 3/(3+3+3) = **6V** (무부하이므로 V_th,C 와 같음)

**(4) 순진한 값:** 각 단 분압비만 곱함: 48 · (12/16) · (6/9) · (3/6) = 48 × 0.75 × 0.667 × 0.5 = **12V**
오차 = 12 − 6 = **6V** (정확값 대비 100% 과대평가). 이유: 앞 단의 출력저항과 뒤 단의 입력저항(부하 효과)을 무시했기 때문.

**(5) R_L = 4kΩ:** V = 6 · 4/(2+4) = **4V**

**검산 (노드 전압을 출력에서 역으로 추적, 다른 경로):**
- V_out = 6V → C단 3k 직렬에 I = 6/3 = 2mA → n2 = 6 + 2·3 = 12V
- n2 션트 6k: 2mA → B단 직렬 3k 전류 = 2 + 2 = 4mA → n1 = 12 + 4·3 = 24V
- n1 션트 12k: 2mA → A단 직렬 4k 전류 = 4 + 2 = 6mA → Vin = 24 + 6·4 = 48V ✓
- 부하 4kΩ: 노드 해석 결과 n1=23.5V, n2=11V, V_out=4V ✓ (Python 분수 연립 해로 확인)

(참고: 노드 전압 n1=24V, n2=12V 는 A단·B단의 "무부하 출력" 36V, 18V 가 아니라 실제 부하가 걸린 값이므로 혼동 주의.)
