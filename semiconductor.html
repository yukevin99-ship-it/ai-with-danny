NOTE01결정 구조비정질·다결정·단결정, 단위셀, 밀러 지수, 다이아몬드 구조, 결함, 초크랄스키 성장

EASY쉽게 말하면

반도체는 전기가 "적당히" 통하는 물질이에요. 금속처럼 너무 잘 통하지도, 유리처럼 아예 막히지도 않아서 우리가 흐름을 조절할 수 있어요. 반도체 원자들은 레고 블록처럼 똑같은 모양이 반복되며 쌓여 있어야 성능이 좋아요.

FIGURE노트 그림 읽기

  • Figure 1.1: 고체의 세 종류
    • (a) 비정질: 원자가 제멋대로 흩어진 모래더미 같아요.
    • (b) 다결정: 작은 레고 덩어리들이 서로 다른 방향으로 붙어 있어요. 덩어리 사이 경계(grain boundary)에서 전자가 걸려 넘어져요.
    • (c) 단결정: 전체가 하나의 완벽한 레고예요. 반도체 칩은 반드시 단결정으로 만들어요.
  • Figure 1.5: 입방 격자 3형제. sc(모서리에만 원자), bcc(가운데에 1개 더), fcc(각 면 가운데에 더)
  • Figure 1.11: 다이아몬드 구조. Si 원자 하나가 이웃 4개와 손을 잡은 정사면체 모양이에요. 단위셀에 원자가 8개 들어 있어요(1×4 + ½×6 + ⅛×8 = 8).
  • Figure 1.14: GaAs. 다이아몬드와 모양은 같지만 원자가 두 종류라서 징크블렌드(zincblende) 구조라고 불러요.
  • 초크랄스키 그림: 녹인 실리콘에 씨앗 결정(seed)을 담갔다가 천천히 끌어올리면 큰 단결정 기둥(잉곳)이 생겨요. 이걸 얇게 자른 것이 웨이퍼예요.

FORMULA핵심 수식

  • 격자 위치 벡터 r = p·a + q·b + s·c: 단위셀을 p, q, s번 옮기면 모든 원자 위치를 찾을 수 있어요.
  • 부피 밀도 = 단위셀 속 원자 수 / 단위셀 부피
    • 노트 Ex 1.1 (fcc, a = 4.25 Å): 원자 수 = ½×6 + ⅛×8 = 4개, 밀도 = 4/(4.25×10⁻⁸)³ ≈ 5.21×10²² cm⁻³
  • 밀러 지수(결정면의 이름표): 면이 축과 만나는 절편 → 역수 → 정수로 바꾸기
    • 예: 절편 (3, 2, 1) → (⅓, ½, 1) → (236)면
  • 결함: 빈자리(vacancy), 틈새 원자(interstitial), 프렌켈 결함, 선결함(dislocation). 불순물은 치환형과 틈새형이 있고, 일부러 넣는 것을 도핑이라고 해요.
현업 포인트
  • 현업은 300 mm (100)면 웨이퍼를 쓰고, 방향은 노치(notch)로 표시해요. 노트 사진의 150 mm 웨이퍼는 flat, 200 mm 웨이퍼는 notch로 표시돼 있어요.
  • (100)면을 쓰는 이유는 산화막과 만나는 계면 결함(Dit)이 가장 적어서 MOSFET에 유리하기 때문이에요.
  • 결정 결함은 곧 수율 손실이에요. COP(결정 유래 미세 결함), 산소 석출, 선결함 관리가 웨이퍼 품질의 핵심이에요.
AI가 풀 수 있는 문제
  • 웨이퍼 검사 이미지(SEM, 광학)에서 결함 자동 분류(CNN 기반 ADC)
  • 잉곳 성장 조건(인상 속도, 회전, 온도 기울기)으로 산소 농도·결함 밀도 예측
  • 원자 단위 계산(DFT)을 머신러닝 퍼텐셜로 크게 가속해서 신소재·결함 거동 탐색
  • 풀기 어려운 점: 결함 데이터가 희귀하고 라벨이 한쪽으로 치우쳐 있어 학습 데이터 확보가 병목이에요.
NOTE02에너지 밴드와 캐리어 모델링가전자대·전도대·밴드갭, 전자와 정공, 유효질량, 진성 반도체, 도핑

EASY쉽게 말하면

원자 하나일 때 전자는 정해진 계단(에너지 준위)에만 설 수 있어요. 원자가 수없이 모여 결정이 되면 계단이 촘촘해져서 띠(band)가 돼요.

  • 가전자대: 아래 띠. 전자로 꽉 찬 주차장이라 움직일 수 없어요.
  • 전도대: 위 띠. 텅 빈 고속도로예요.
  • 밴드갭(Eg): 두 띠 사이의 빈 틈. 전자가 이 틈을 뛰어넘어야 전기가 흘러요.

FIGURE노트 그림 읽기

  • Si 밴드 형성 그림: 원자 사이 거리가 줄면 3s와 3p 준위가 섞이고, 평형 거리에서 아래 4N개 상태(꽉 참)와 위 4N개 상태(텅 빔)로 나뉘어요.
  • Figure 2.8: 부도체·반도체·금속
    • 부도체: Eg가 넓어요. SiO₂는 노트에 ~8 eV로 적혀 있는데 일반적으로는 약 9 eV를 많이 써요. 다이아몬드 ~5 eV.
    • 반도체: Eg가 적당해요(Si 1.12 eV, GaAs 1.42 eV, Ge 0.66 eV). 열만으로도 조금 들떠요.
    • 금속: 띠가 겹치거나 반만 차 있어요.
  • Figure 3.13: 결합 하나가 끊어지면 자유전자(−)와 정공(hole, +)이 쌍으로 생겨요. 정공은 빈자리가 옮겨 다니는 건데, + 전하가 움직이는 것처럼 보여요.
  • Figure 2.10 / 2.13: 도핑. 5족(P, As)은 여분 전자가 있어서 도너(n형), 3족(B)은 전자가 모자라서 억셉터(p형)가 돼요. 결합 에너지가 ~0.045 eV로 아주 작아서 상온에서 거의 다 풀려나요.

FORMULA핵심 수식

  • 진공 속 전자: F = −qE = m₀·dv/dt
  • 결정 속 전자: F = −qE = mₙ*·dv/dt → 결정 안의 복잡한 힘을 유효질량 m* 하나로 묶어요.
  • 유효질량(Table 2.1, 상태밀도 유효질량): Si는 mₙ*/m₀ = 1.18, mₚ*/m₀ = 0.81. GaAs 전자는 0.066으로 가벼워서 빨라요.
    • Note 4의 Table 4.1(1.08/0.56)과 값이 다른 건 교재(Pierret vs Neamen)마다 쓰는 값이 달라서예요.
  • 진성 반도체: n = p = nᵢ, Si는 nᵢ ≈ 10¹⁰ cm⁻³
    • Si 결합 수 약 10²³ cm⁻³ 중 10¹³개 중 1개꼴로만 끊어져 있다는 뜻이에요.
현업 포인트
  • 밴드갭이 소자의 성격을 정해요. 전력 반도체는 넓은 밴드갭의 SiC(~3.3 eV)·GaN(3.4 eV), 고속 RF는 m*가 작은 III-V를 써요.
  • 로직에서는 응력(Strain)으로 유효질량과 산란을 바꿔 이동도를 높여요. 90 nm 세대 이후 표준 기술이에요.
  • 도펀트는 n형 P/As, p형 B가 업계 표준이에요(노트 Table 2.2 화살표 표시).
AI가 풀 수 있는 문제
  • 수만 개 후보 중 원하는 밴드갭·유효질량을 가진 신소재 스크리닝(재료 정보학, GNN)
  • DFT 결과를 학습한 모델로 밴드 구조 즉시 예측 → 채널 재료 탐색 시간 단축
  • 도펀트·모재 조합의 활성화 에너지를 예측해 도핑 공정 후보를 좁히기
NOTE03상태밀도(DOS)와 페르미 함수의자 개수 × 앉을 확률 = 실제 전자 수, 볼츠만 근사, 3kT 규칙

EASY쉽게 말하면

  • 상태밀도 g(E): 에너지 층마다 전자가 앉을 의자가 몇 개 있는지
  • 페르미 함수 f(E): 그 의자에 실제로 전자가 앉아 있을 확률
  • 둘을 곱하면 실제 전자 수가 나와요.

FORMULA핵심 수식

  • g_c(E) = 4π(2mₙ*)^{3/2}/h³ · √(E − E_c): 밴드 끝에서 0으로 시작해 √E 모양으로 증가
  • 페르미-디랙 함수: f(E) = 1 / [1 + exp((E − E_F)/kT)]
    • E = E_F이면 f = ½ (페르미 준위 = "반반 확률"인 에너지)
    • E ≥ E_F + 3kT이면 f ≈ exp[−(E − E_F)/kT] (볼츠만 근사)
  • 노트 예제: 볼츠만 근사 오차가 5%가 되는 지점은 E − E_F = kT·ln(1/0.05) = 2.996kT ≈ 3kT
  • 상온 kT = 0.0259 eV, 3kT = 0.0777 eV. Si 밴드갭(1.12 eV)보다 훨씬 작아요.

현업 포인트
  • TCAD는 캐리어 농도를 DOS × f(E)로 계산해요.
  • 소스/드레인·컨택처럼 도핑이 아주 높은 축퇴 영역에서는 볼츠만 근사가 틀려서 페르미-디랙 통계를 써야 해요.
  • 온도가 오르면 f(E) 꼬리가 길어져 누설 전류가 지수적으로 증가해요. 서버·차량용 반도체의 고온 신뢰성 문제예요.

  • 온도별 누설 데이터를 학습해 고온 동작 한계·수명 예측
  • 노트 숙제(온도별 f(E) 그래프)처럼 물리 모델 코드를 AI 코딩 도구로 빠르게 작성·검증
NOTE04평형 상태의 캐리어 분포 (1)n₀·p₀ 공식, 유효 상태밀도, nᵢ, 질량작용 법칙 n₀p₀ = nᵢ², 축퇴 반도체

EASY쉽게 말하면

평형은 전압·빛·온도차 같은 외부 방해가 없어서 시간이 지나도 아무것도 변하지 않는 "쉬는 상태"예요. 이때 전자와 정공이 몇 개인지 계산하는 공식을 배워요.

FORMULA핵심 수식 (가장 중요한 노트 중 하나)

  • 전자 농도: n₀ = ∫ g_c(E)·f(E) dE = N_c · exp[−(E_c − E_F)/kT]
  • 정공 농도: p₀ = N_v · exp[−(E_F − E_v)/kT]
  • 유효 상태밀도 N_c = 2(2π mₙ* kT/h²)^{3/2}. Si: N_c = 2.8×10¹⁹, N_v = 1.04×10¹⁹ cm⁻³ (Table 4.1)
  • nᵢ² = N_c·N_v·exp(−E_g/kT). Si: nᵢ = 1.5×10¹⁰ cm⁻³ (Table 4.2)
  • nᵢ로 쓴 형태: n₀ = nᵢ·exp[(E_F − E_Fi)/kT], p₀ = nᵢ·exp[(E_Fi − E_F)/kT]
  • ★ 질량작용 법칙: n₀·p₀ = nᵢ² (노트에서 별표 친 식)

FIGURE노트 그림 읽기

  • Figure 2.16: 밴드 → 상태밀도 → 페르미 함수 → 실제 캐리어 분포 순서의 네 칸 그림이에요.
    • n형: E_F가 E_c 가까이 → 전자가 많아요.
    • 진성: E_F가 가운데.
    • p형: E_F가 E_v 가까이 → 정공이 많아요.
    • 핵심: E_F의 위치가 곧 캐리어 농도의 지표예요.
  • Figure 4.11: 축퇴 반도체. 도핑이 너무 많아 E_F가 밴드 안쪽으로 들어간 상태예요. 볼츠만 근사가 틀려요.
현업 포인트
  • n·p = nᵢ²는 현업 엔지니어가 암산할 때 쓰는 공식이에요. 도핑을 10배 늘리면 소수 캐리어는 10배 줄어요.
  • nᵢ는 온도에 따라 지수적으로 커져요(∝ T^{3/2}·exp(−E_g/2kT)). 그래서 고온 누설과 DRAM 리프레시 특성에 직결돼요.
AI가 풀 수 있는 문제
  • 도핑 분포 측정값(SIMS)에서 캐리어 분포와 E_F를 거꾸로 추정하는 역문제를 빠르게 풀기
  • 웨이퍼의 저항·도핑 맵을 학습해 공정 산포 원인(장비, 챔버) 추적
  • 물리식을 제약 조건으로 넣은 신경망(PINN)으로 적은 데이터에서도 물리적으로 맞는 예측
NOTE05평형 상태의 캐리어 분포 (2)완전 이온화, 동결, 보상 반도체, 전하 중성, E_F 위치, 온도 의존성

EASY쉽게 말하면

  • 넣은 도펀트가 모두 전자를 내놓았는지(완전 이온화), 추워서 얼어붙었는지(동결, freeze-out) 따져 봐요.
  • n형 도펀트와 p형 도펀트를 섞으면 서로의 효과를 깎아 먹어요. 이걸 보상이라고 해요.

FORMULA핵심 수식

  • 전하 중성: n₀ + N_a = p₀ + N_d (완전 이온화 가정)
  • n형 전자 농도: n₀ = (N_d − N_a)/2 + √[((N_d − N_a)/2)² + nᵢ²]

NOTE17문턱 전압(V_T)과 C–V 특성V_TN·V_TP 식과 예제, 축적·공핍·반전 커패시턴스, 주파수 효과, 산화막 전하

EASY쉽게 말하면

  • 문턱 전압 V_T: 트랜지스터가 "켜지는" 최소 게이트 전압. 반도체 스위치의 켜짐/꺼짐 기준선이에요.
  • C–V 측정: 게이트 전압을 바꿔 가며 커패시턴스를 재면 소자 속을 엑스레이처럼 들여다볼 수 있어요.

FORMULA핵심 수식

  • ★★ NMOS 문턱 전압 V_TN = (|Q'_SD(max)| − Q'_ss)·(t_ox/ε_ox) + φ_ms + 2φ_fp, Q'_SD(max) = eN_a·x_dT
    • 노트 예제 (N_a = 2×10¹⁶, t_ox = 8 nm, Q'_ss = 2×10¹⁰, φ_ms = 0.28 V): φ_fp = 0.365 V, x_dT = 0.217 μm, Q_SD = 6.96×10⁻⁸ C/cm² → V_TN = 0.154 + 0.28 + 0.731 ≈ 1.16 V
  • n형 기판 문턱 전압 V_TP = (−|Q'_SD(max)| − Q'_ss)·(t_ox/ε_ox) + φ_ms − 2φ_fn
    • 노트 예제 (N_d = 2×10¹⁶, t_ox = 20 nm, Q'_ss = 5×10¹⁰, φ_ms = 1.06 V): V_TP = −0.450 + 1.06 − 0.731 ≈ −0.12 V → 음수라서 enhancement 모드(게이트 0 V에서 꺼짐)
  • C–V 세 구간 (p형 기판)
    • 축적: C = C_ox
    • 공핍: 1/C = 1/C_ox + 1/C_SD → 두 커패시터가 직렬이라 C↓
    • 반전 시작: C'_min = ε_ox / [t_ox + (ε_ox/ε_s)·x_dT] — 노트 예제 (N_a = 3×10¹⁶, t_ox = 8 nm): C'_min/C_ox = 0.118
    • 플랫밴드: C'_FB = ε_ox / [t_ox + (ε_ox/ε_s)·√((kT/e)·(ε_s/eN_a))]
  • V_T와 V_FB의 관계 V_TN = V_FB + 2φ_fp + |Q'_SD(max)|/C_ox

NOTE18MOSFET 기본 동작과 I–V 특성네 종류의 MOSFET, 선형·핀치오프·포화, V_DS(sat) = V_GS − V_T

EASY쉽게 말하면

MOS 커패시터 양옆에 소스(입구)와 드레인(출구)을 붙이면 MOSFET이에요. 게이트 전압이 V_T를 넘으면 반전층이라는 다리가 놓여 전자가 소스에서 드레인으로 건너가요. 게이트는 다리 폭(전자 수)을 조절하는 수도꼭지예요.

FORMULA핵심 수식

  • 네 종류: NMOS/PMOS × enhancement(게이트 0 V에서 꺼짐) / depletion(게이트 0 V에서도 켜짐)
  • 선형 구간 (V_DS 작음, V_GS − V_DS > V_T): 채널 두께가 균일 → 저항처럼 동작
  • ★ 핀치오프 V_DS(sat) = V_GS − V_T: 드레인 쪽 끝에서 채널 전하가 0이 되는 순간
  • 포화 구간 (V_DS > V_DS(sat)): 핀치오프 지점이 소스 쪽으로 조금 이동. ΔL ≪ L이면 I_D가 거의 일정
  • 다음 강의로 이어질 표준 식:
    • 선형 I_D = (W·μₙ·C_ox/2L)·[2(V_GS − V_T)V_DS − V_DS²]
    • 포화 I_D = (W·μₙ·C_ox/2L)·(V_GS − V_T)²
  • depletion 모드 조건: 채널 두께 t_c < x_dT여야 게이트로 채널을 완전히 끌 수 있어요.
