# 정답과 설명 (초등학교 5학년 눈높이)

## 문제 1: 서버실 온도 경보

### 조건문 정답
빈칸: `else if`, `else`. 출력: **주의**
```c
if (temp >= 70) printf("위험");
else if (temp >= 50) printf("주의");
else printf("정상");
```
쉬운 설명: 문 앞에서 경비 아저씨가 위에서부터 차례로 물어보는 거야. "70도 넘어?" 아니면 "50도 넘어?" 하고 물어보고, 처음으로 "응"이 나온 곳에서 멈춰. 65도는 70은 못 넘고 50은 넘으니까 "주의"야. `else`는 "위에서 다 아니었으면 마지막은 이거"라는 뜻이야.

### 반복문 정답
`i = 0`, `i < 5`, `t[i]`. 합 = 250, 평균 = **50**
```c
for (int i = 0; i < 5; i++) {
    sum += t[i];
}
```
쉬운 설명: 사탕 5봉지를 한 봉지씩 열어서 개수를 저금통(sum)에 더하는 거야. 번호는 0번부터 시작하니까 0, 1, 2, 3, 4번 봉지를 열어. 그래서 `i < 5`에서 멈춰. 5번 봉지는 없거든. 다 더하고 5로 나누면 평균이야.

### 흐름제어 정답
```c
for (int i = 0; i < 5; i++) {
    if (t[i] == -1) continue;      // 점검 중이면 이번 칸만 건너뛰기
    if (t[i] >= 90) {
        printf("긴급!");
        break;                      // 바로 반복 끝내기
    }
}
```
60과 50은 **검사되지 않아.** 쉬운 설명: `continue`는 "이 칸은 패스, 다음 칸으로!"이고, `break`는 "불이야! 더 볼 것 없어, 전부 멈춰!"야. 95도에서 break가 실행되니까 뒤에 있는 60, 50은 보지 않아.

## 프로그램 1: 로켓 발사 카운트다운

### 조건문 정답
`&&`. fuel=90, sunny=0이면 **발사 불가**
쉬운 설명: `&&`는 "그리고"야. 연료도 충분하고 날씨도 좋아야 해. 소풍 가려면 도시락도 있고 비도 안 와야 하는 것과 같아. `||`("또는")를 쓰면 날씨가 나빠도 연료만 있으면 발사해 버려서 위험해.

### 반복문 정답
```c
for (int i = 10; i >= 1; i--) {
    printf("%d\n", i);
}
printf("발사!");
```
쉬운 설명: 계단을 위에서 아래로 내려오는 거야. 10에서 시작해서(`i = 10`), 1까지 가고(`i >= 1`), 한 칸씩 내려가(`i--`). 반복문이 다 끝난 뒤에 "발사!"를 외쳐.

### 흐름제어 정답
```c
int abort = 0;                       // 깃발: 0이면 아무 일 없음
for (int i = 10; i >= 1; i--) {
    if (alarm[i] == 1) {
        printf("발사 중단");
        abort = 1;                   // 깃발을 올린다
        break;                       // 카운트다운 멈춤
    }
    printf("%d\n", i);
}
if (abort == 0) printf("발사!");
```
쉬운 설명: 카운트다운하다가 경보가 울리면 `break`로 얼른 멈춰. 그런데 멈춘 다음에 "발사!"가 나오면 큰일이잖아? 그래서 "깃발(abort)"을 들어 둬. 반복문이 끝나고 깃발이 안 올라가 있을 때만(`abort == 0`) "발사!"를 외치는 거야. 반복문과 조건문이 같이 일하는 대표적인 모습이야.
